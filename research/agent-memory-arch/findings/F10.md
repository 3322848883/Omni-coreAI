# F10: 交易 agent 记忆窗口参数

## Findings

### [1] FinMem long-term memory has three layers (shallow/intermediate/deep) with stability day-counts Q_shallow=14, Q_intermediate=90, Q_deep=365 (two weeks / quarter / year).
- quote: "Q_shallow=14, Q_intermediate=90, and Q_deep=365 correspond to day counts of two weeks, a quarter, and a year for shallow, intermediate, and deep processing layers, respectively."
- url: https://arxiv.org/html/2311.13743v2
- source_type: primary
- published: 2023-12-03 (v2; v1 2023-11-23)
- confidence: high

### [2] FinMem retrieves top-K events from EACH of the 3 long-term layers per trading decision; main experiments set K=5 (→ 15 events into working memory = 3×K).
- quote: "we set the number of top memory events retrieved from each layer of long-term memory at 5."
- url: https://arxiv.org/html/2311.13743v2
- source_type: primary
- published: 2023-12-03
- confidence: high

### [3] FinMem working-memory ablation tested K∈{1,3,5,10}; K=5 was optimal on TSLA (lowest volatility and max-drawdown), while K=10 mixed trivial messages with critical ones and hurt stable markets.
- quote: "We tested K values of 1, 3, 5, and 10... a K value of 5 is optimal for trading TSLA stock... setting K to 10... resulted in significant losses in stable market conditions."
- url: https://arxiv.org/html/2311.13743v2
- source_type: primary
- published: 2023-12-03
- confidence: high

### [4] FinMem importance-decay bases are α_shallow=0.9, α_intermediate=0.967, α_deep=0.988 (importance falls to threshold 5 after ~30/90/365 days per layer).
- quote: "we set α_shallow=0.9, α_intermediate=0.967 and α_deep=0.988. This ensures that θ_l decreases to a threshold score of 5 after intervals of 30, 90, and 365 days for shallow, intermediate, and deep layers."
- url: https://arxiv.org/html/2311.13743v2
- source_type: primary
- published: 2023-12-03
- confidence: high

### [5] TradingGPT three-layer memory decay constants: Q_short=3 days, Q_middle=90 days, Q_long=365 days; ranking-score keep thresholds are 40 (short) / 60 (middle) / 80 (long), events scoring below 20 are deleted.
- quote: "where Q_long=365 for long-term, Q_middle=90 for middle-term, and Q_short=3 for short-term events... the ranking score thresholds are 80 for long-term, 60 for middle-term, and 40 for short-term memory. Events scoring below 20 are removed."
- url: https://arxiv.org/html/2309.03736
- source_type: primary
- published: 2023-09-07
- confidence: high

### [6] TradingGPT content routing: macro market indicators → long-term, quarterly investment strategies → middle-term, daily investment messages → short-term; at test time agents also carry ~1 week of prior immediate/extended reflections and debates as auxiliary reference.
- quote: "macro-level market indicators are stored in the long-term memory, quarterly investment strategies are allocated to the mid-term memory, and daily investment messages are channeled into the short-term memory... Time series patterns of prior training reflections and debates, covering a week in our setup, act as auxiliary references."
- url: https://arxiv.org/html/2309.03736
- source_type: primary
- published: 2023-09-07
- confidence: high

### [7] FinCon retrieves top-K=5 pivotal procedural-memory events per agent per inquiry; it has no fixed short/mid/long item counts — memory is procedural events plus conceptual verbal-reinforcement beliefs updated episode-wise.
- quote: "we set the number of top memory events retrieved for each agent at 5."
- url: https://arxiv.org/html/2407.06567v3
- source_type: primary
- published: 2024-11-07 (v3; v1 2024-07-09)
- confidence: high

### [8] TradingAgents does not publish a numeric decision-log injection count in the paper or README; the always-on markdown decision log injects "the most recent same-ticker decisions plus recent cross-ticker lessons" into the Portfolio Manager prompt, with memory_log_max_entries=None (unbounded) by default.
- quote: "injects the most recent same-ticker decisions plus recent cross-ticker lessons into the Portfolio Manager prompt" / "memory_log_max_entries: None"
- url: https://github.com/TauricResearch/TradingAgents (README + tradingagents/default_config.py)
- source_type: primary
- published: 2026-09 (repo v0.5.x; paper arXiv:2412.20138, 2024-12-28)
- confidence: high

### [9] TradingAgents per-decision data windows (config defaults): news_article_limit=20 per ticker, global_news_article_limit=10, global_news_lookback_days=7, holding_period_days=5 (reflection horizon), max_debate_rounds=1.
- quote: "news_article_limit: 20... global_news_article_limit: 10... global_news_lookback_days: 7... holding_period_days: 5... max_debate_rounds: 1"
- url: https://raw.githubusercontent.com/TauricResearch/TradingAgents/main/tradingagents/default_config.py
- source_type: primary
- published: 2026-09
- confidence: high

### [10] FinPos hierarchical memory has short-/mid-/long-term plus reflective layers (deep=annual reports, shallow=company news); its multi-timescale reward uses 1-day, 7-day and 30-day horizons, with the 30-day long window optimal (7–14d too noisy, >30d dilutes signal).
- quote: "important long-term information (e.g., annual reports) is allocated to deep memory, while volatile short-term information (e.g., corporate news) is stored in shallow memory... three horizons (1, 7, and 30 days)... very short windows (7–14 days) yield poor performance... performance peaks at 30 days."
- url: https://arxiv.org/html/2510.27251v2
- source_type: primary
- published: 2026-01-07 (v2; v1 2025-10-31)
- confidence: high

### [11] Cross-system synthesis: at each daily decision point these agents inject ~top-5 per memory layer (FinMem 3×5=15; FinCon 5 per agent), not a sliding N-round transcript; windows are defined by decay half-lives (≈3–14d short, ≈90d mid, ≈365d long) rather than raw token budgets.
- quote: "FinMem retrieves the top-K pivotal memory events from each layer... we set the number of top memory events retrieved from each layer of long-term memory at 5." (FinMem) / "top memory events retrieved for each agent at 5" (FinCon)
- url: https://arxiv.org/html/2311.13743v2
- source_type: primary
- published: 2023-12-03
- confidence: medium

## Dead ends
- "META 记忆窗口": no trading-agent paper named META with a memory window; FinRL-Meta is a market-environment benchmark library (Liu et al., NeurIPS 2022), not a memory architecture.
- FinPos short/mid/long item counts: paper names the four layers (short/mid/long/reflective) in prompts but publishes no per-layer entry counts.
- TradingAgents decision-log injection count: described qualitatively ("most recent same-ticker decisions") in README/paper; exact N not exposed in default_config.py (only memory_log_max_entries).
- arXiv search "FinCon LLM trading concise reflection" returned 0; correct title uses "Conceptual Verbal Reinforcement".

## Suggested follow-ups
- Read TradingAgents `tradingagents/agents/utils/` or reflection node source to pin the exact decision-log injection N (README implies "most recent" without a number).
- Check FinAgent (Zhang et al., 2024, builds on FinMem) for whether it keeps FinMem's K=5×3 window or changes it under multimodal inputs.
- If designing a bot window: FinMem K=5/layer with Q=14/90/365 is the best-documented starting point; FinPos's 30-day long-horizon finding is the best evidence for reward/reflection lookback length.
