# F4: 学术前沿 agent memory

## Findings

### [1] 2026 TMLR 综述把 agent memory 的认知机制划为五类 sensory / working / episodic / semantic / procedural，而非简单三分
- quote: "we provide a unified view of foundation agent memory along three dimensions: memory substrate (internal parametric state and external retrieval-augmented stores), cognitive mechanism (sensory, working, episodic, semantic, and procedural), and memory subject (user-centric personalization and agent-centric experience)"
- url: https://arxiv.org/abs/2602.06052
- source_type: primary
- published: 2026-01-14 (v1), 2026-08-04 (v4)
- confidence: high

### [2] 该综述同时给出 substrate 与 subject 两个正交维度：参数内态 vs 外部检索库；用户个性化 vs agent 自身经验
- quote: "short-term memory gates which experiences are perceived and abstracted during execution, while long-term memory consolidates them into reusable knowledge and skills, forming the loop through which agents improve from their own experience"
- url: https://arxiv.org/abs/2602.06052
- source_type: primary
- published: 2026-01-14
- confidence: high

### [3] 综述指出 2025 年 agent memory 论文已达数百篇，且 memory 管理本身正变成可训练能力（RL 上下文策展、决策时经验固化、可移植 skill）
- quote: "Memory, with hundreds of papers released in 2025, therefore emerges as the critical solution to fill this utility gap. ... learning policies over memory operations, showing how memory management itself is becoming a trainable capability spanning reinforcement-learned context curation, experience consolidation at decision time, and the emerging ecosystem of portable, shareable agent skills"
- url: https://arxiv.org/abs/2602.06052
- source_type: primary
- published: 2026-01-14
- confidence: high

### [4] LongMemEval（ICLR 2025）用 500 题测五种长期记忆能力：信息抽取、跨会话推理、时序推理、知识更新、abstention；商业助手与长上下文 LLM 在持续交互中准确率掉约 30%
- quote: "We introduce LongMemEval, a comprehensive benchmark designed to evaluate five core long-term memory abilities of chat assistants: information extraction, multi-session reasoning, temporal reasoning, knowledge updates, and abstention. With 500 meticulously curated questions ... commercial chat assistants and long-context LLMs showing a 30% accuracy drop on memorizing information across sustained interactions"
- url: https://arxiv.org/abs/2410.10813
- source_type: primary
- published: 2024-10-14 (v1), 2025-03-04 (v2)
- confidence: high

### [5] LongMemEval 把长期记忆设计拆成 indexing / retrieval / reading 三阶段，并提出 session 分解、fact-augmented key expansion、time-aware query expansion 三项优化
- quote: "a unified framework that breaks down the long-term memory design into three stages: indexing, retrieval, and reading. ... session decomposition for value granularity, fact-augmented key expansion for indexing, and time-aware query expansion for refining the search scope"
- url: https://arxiv.org/abs/2410.10813
- source_type: primary
- published: 2024-10-14
- confidence: high

### [6] LoCoMo（2024-02）是超长对话记忆基准：平均 300 turns / 9K tokens、最多 35 sessions；即便长上下文或 RAG 仍显著落后人类
- quote: "we collect LoCoMo, a dataset of very long-term conversations, each encompassing 300 turns and 9K tokens on avg., over up to 35 sessions. ... Employing strategies like long-context LLMs or RAG can offer improvements but these models still substantially lag behind human performance"
- url: https://arxiv.org/abs/2402.17753
- source_type: primary
- published: 2024-02-27
- confidence: high

### [7] 2026 理论工作把 KV 淘汰、prompt 剪枝、状态上界、agent 记忆固化统一为 rate-distortion 问题；指出各类方法共用 attention/recency 信号，且都会在 query 未知时不可逆丢弃后续所需信息
- quote: "At every layer the signal that decides what to keep is attention magnitude or recency, and it fails in the same way everywhere, by discarding, before the query is known and with no way to undo it, information the query later needs. And while compression is measured carefully on single-turn long context, the repeated compaction that agents actually perform is almost never measured"
- url: https://arxiv.org/abs/2607.08032
- source_type: primary
- published: 2026-07-09
- confidence: high

### [8] MemOps（2026-07）把记忆建模为显式生命周期操作序列 remembering / forgetting / updating / reflecting，用结构化 trace（trigger/target/scope/state transition/evidence）做操作级诊断，并发现 session 级检索优于 turn 级、长上下文模型难重建有序记忆状态轨迹
- quote: "memory is not a static collection of facts but a lifecycle of explicit operations, including remembering, forgetting, updating, reflecting, and their compositions. ... session-level retrieval outperforms turn-level retrieval, and long-context models remain notably weak at reconstructing ordered memory-state trajectories"
- url: https://arxiv.org/abs/2607.12893
- source_type: primary
- published: 2026-07-14
- confidence: high

### [9] Memora（ACL 2026 Findings）提出 FAMA（Forgetting-Aware Memory Accuracy）惩罚对已失效/被覆盖记忆的依赖；评测显示 agent 频繁复用无效记忆、难以调和演化中的记忆
- quote: "We further introduce Forgetting-Aware Memory Accuracy (FAMA), a metric that penalizes reliance on obsolete or invalidated memory when evaluating long-term memory. Evaluations of four LLMs and six memory agents reveal frequent reuse of invalid memories and failures to reconcile evolving memories"
- url: https://arxiv.org/abs/2604.20006
- source_type: primary
- published: 2026-04-21
- confidence: high

### [10] 两套主流基准分工渐趋清晰：LoCoMo 侧重超长多会话事实/事件记忆，LongMemEval 侧重新息抽取→跨会话/时序推理→知识更新→abstention 全链路；Memora/MemOps 则补上遗忘与操作级正确性
- quote: "The benchmark evaluates three memory-grounded tasks: remembering, reasoning, recommending. ... Forgetting-Aware Memory Accuracy (FAMA)"
- url: https://arxiv.org/abs/2604.20006
- source_type: primary
- published: 2026-04-21
- confidence: medium

## Suggested follow-ups
- LongMemEval-V2 (arXiv:2605.12493) 把评测对象从用户聊天史转向 web-agent 环境经验（static state / dynamic state / workflow / gotchas / premise），对 7×24 交易 bot 更贴近：接口 affordance、状态动态、反复失败模式。
- DMF (arXiv:2606.03463) 的确定性遗忘：Survival Score Ω + 交互计数衰减 Ω_eff(Δn)，零 LLM 调用做记忆压缩，直接对标 Mem0；适合评估交易 bot 的可审计遗忘策略。
- rate-distortion 论文提出的跨层统一 benchmark 提案（arXiv:2607.08032）尚无落地实现，可跟踪是否出现把 KV/prompt/agent-memory 放同一预算轴上的评测。
