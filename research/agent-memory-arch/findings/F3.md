# F3: Hermes / OpenClaw / 其他记忆项目

## Findings

### [1] MemGPT（arXiv:2310.08560, Packer et al., UC Berkeley, 2023-10-12 / v2 2024-02-12）用 OS 虚拟内存类比做分层记忆：main context（prompt tokens）与 external context（disk）
- quote: "we propose virtual context management, a technique drawing inspiration from hierarchical memory systems in traditional operating systems... MemGPT (MemoryGPT), a system that intelligently manages different storage tiers"
- url: https://arxiv.org/abs/2310.08560
- source_type: primary
- published: 2023-10-12 (v1), 2024-02-12 (v2)
- confidence: high

### [2] MemGPT main context 三段式：system instructions（只读）+ working context（固定大小可写块，存人设/关键事实）+ FIFO queue（消息滚动历史，队首放递归摘要）
- quote: "The prompt tokens in MemGPT are split into three contiguous sections: the system instructions, working context, and FIFO Queue... The first index in the FIFO queue stores a system message containing a recursive summary of messages that have been evicted from the queue."
- url: https://arxiv.org/html/2310.08560v2
- source_type: primary
- published: 2024-02-12
- confidence: high

### [3] MemGPT Queue Manager 用「内存压力」驱逐：约 70% 上下文写入警告、约 100% flush 队列（约 50% 消息）并生成递归摘要；被驱逐消息仍永久保存在 recall storage，可经函数调用找回
- quote: "When the prompt tokens exceed the 'warning token count'... (e.g. 70% of the context window), the queue manager inserts a system message... When the prompt tokens exceed the 'flush token count' (e.g. 100% of the context window), the queue manager flushes the queue... generates a new recursive summary"
- url: https://arxiv.org/html/2310.08560v2
- source_type: primary
- published: 2024-02-12
- confidence: high

### [4] MemGPT 用 function calling + `request_heartbeat=true` 做自导向记忆编辑/检索与多步 function chaining；archival 默认 PostgreSQL + pgvector（HNSW）
- quote: "Memory edits and retrieval are entirely self-directed... MemGPT uses functions to move data between main context and external context (the archival and recall storage databases). The LLM can request immediate follow-up LLM inference to chain function calls together by generating a special keyword argument (request_heartbeat=true)"
- url: https://arxiv.org/html/2310.08560v2
- source_type: primary
- published: 2024-02-12
- confidence: high

### [5] MemGPT DMR（跨会话深度记忆检索）上显著优于固定上下文基线：GPT-4 基线 32.1% accuracy → MemGPT+GPT-4 92.5%；GPT-4 Turbo 基线 35.3% → MemGPT 93.4%
- quote: "GPT-4 32.1% ... ++ MemGPT 92.5% ... GPT-4 Turbo 35.3% ... ++ MemGPT 93.4%"
- url: https://arxiv.org/html/2310.08560v2
- source_type: primary
- published: 2024-02-12
- confidence: high

### [6] Generative Agents（arXiv:2304.03442, Park et al., UIST '23）三件套：memory stream（自然语言全量经验）+ reflection（合成高层推断）+ planning；检索按 relevance、recency、importance 三维加权
- quote: "A memory retrieval model combines relevance, recency, and importance to surface the records needed to inform the agent's moment-to-moment behavior. The second is reflection, which synthesizes memories into higher-level inferences over time"
- url: https://arxiv.org/html/2304.03442v2
- source_type: primary
- published: 2023-04-07 (v1), 2023-08-06 (v2); UIST 2023-10-29
- confidence: high

### [7] Generative Agents 实现 25 个 agent 的 Smallville 沙盒；消融显示 observation/planning/reflection 缺一不可；常见错误是检索不到相关记忆或「记错添油加醋」
- quote: "we manifest a society of twenty-five agents... We demonstrate through ablation that the components of our agent architecture—observation, planning, and reflection—each contribute critically... the most common errors arose when the agent failed to retrieve relevant memories, fabricated embellishments to the agent's memory"
- url: https://arxiv.org/html/2304.03442v2
- source_type: primary
- published: 2023-08-06
- confidence: high

### [8] Letta（f.k.a. MemGPT）产品化为有状态 agent 平台：MemFS 是 git-backed 记忆文件系统；「Dreaming」用后台 subagent 回顾对话并更新记忆，可用 `/sleeptime` 或在 context 压缩后触发，可选「Agent reviews before applying」二审
- quote: "Letta agents use MemFS, a git-backed memory filesystem that they can inspect and edit... Dreaming uses background subagents to review recent conversations, consolidate useful lessons, and update memory without interrupting your active work. Configure dreaming with /sleeptime"
- url: https://docs.letta.com/configuration/memory
- source_type: primary
- published: unknown (docs as of 2026-09)
- confidence: high

### [9] OpenClaw（Peter Steinberger 发起，现 OpenClaw Foundation 501(c)(3)）记忆是显式 Markdown 无隐藏状态：`MEMORY.md`（长期）+ `memory/YYYY-MM-DD.md`（每日工作层）+ 可选 `DREAMS.md`（梦境日记）
- quote: "OpenClaw 通过在智能体的工作区中写入纯 Markdown 文件来记住信息... 模型只会记住保存到磁盘的内容；不存在隐藏状态。... MEMORY.md — 长期记忆... memory/YYYY-MM-DD.md — 每日笔记... DREAMS.md (可选) — 供人工审阅的梦境日记"
- url: https://docs.openclaw.ai/zh-CN/concepts/memory
- source_type: primary
- published: unknown (docs generated_at 2026-07-26)
- confidence: high

### [10] OpenClaw Dreaming（memory-core 插件，opt-in）按 light→REM→deep 三阶段整合；Deep 用六维加权（relevance 0.30 / frequency 0.24 / query-diversity 0.15 / recency 0.15 / integration 0.10 / concept-density 0.06）+ 阈值门控才晋升进 `MEMORY.md`；默认 cron `0 3 * * *`
- quote: "Dreaming 每次扫描按顺序运行三个协作阶段：light -> REM -> deep... Deep | 对持久候选项评分并进行提升 | 是（MEMORY.md）| relevance 0.30 | frequency 0.24 | ... | dreaming.frequency | 0 3 * * *"
- url: https://docs.openclaw.ai/zh-CN/concepts/dreaming
- source_type: primary
- published: unknown (docs generated_at 2026-07-26)
- confidence: high

### [11] OpenClaw 内置记忆引擎是每 agent 独立 SQLite：FTS5/BM25 关键词 + 向量混合检索；分块默认 400 token / 重叠 80；可选 sqlite-vec 加速；默认 OpenAI `text-embedding-3-small`
- quote: "将 MEMORY.md 和 memory/*.md 划分为分块（默认每块 400 个词元，重叠 80 个词元），并将其存储在每个智能体各自的 SQLite 数据库中... FTS5 全文索引（BM25 评分）... 向量搜索... 混合搜索"
- url: https://docs.openclaw.ai/zh-CN/concepts/memory-builtin
- source_type: primary
- published: unknown (docs generated_at 2026-07-26)
- confidence: high

### [12] Hermes Agent（Nous Research，宣称 2026-02 发布，MIT，自托管）主打持久记忆 + 自动技能创建：记忆落本地 `~/.hermes/`，技能为可搜索 SKILL.md（agentskills.io 标准）
- quote: "跨会话记住你的偏好、项目和环境... 所有记忆存储在你机器的 ~/.hermes/ 目录... 当 Hermes 解决了一个难题，它会写下可复用的技能文档... 兼容 agentskills.io 开放标准"
- url: https://hermes-agent.org/zh/
- source_type: secondary
- published: unknown (site claims Feb 2026 release)
- confidence: medium

## Dead ends
- Google/DuckDuckGo SERP via WebFetch 传输失败（仅 Bing HTML 可用）；未能用 Browser Use（本 agent 工具面无 browser/cua）。
- 用户点名的「Letta dreaming」没有独立论文/公告命中；实际是 Letta docs 的 Memory & dreaming（/sleeptime + background subagents）。OpenClaw 另有更完整的 light/REM/deep Dreaming 实现，勿混为一谈。
- `https://github.com/NousResearch/hermes-agent` 直接抓取失败（Transport error）；Hermes 记忆 schema 细节未从源码核实。
- 泛中文 SEO 站（hermesagent.org.cn / runoob / learnagent.wiki 等）未采信。
