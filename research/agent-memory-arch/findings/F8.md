# F8: 多 agent 协作记忆与合规

## Findings

### [1] META 是首个面向金融决策的 RAG 式情景记忆多 agent 框架，记忆模块以市场状态嵌入编码交易情景（含结果与反思）并按相似市况检索、动态重加权信号
- quote: "META integrates a family of specialized indicator agents ... with a Decision Agent that fuses their reports, and a Memory module that retrieves and updates past trading episodes encoded as market state embeddings with outcomes and reflections. By recalling relevant experiences and adaptively reweighting signals under similar market regimes, META achieves improved directional accuracy and robustness under short-horizon evaluation."
- url: https://arxiv.org/abs/2609.28771
- source_type: primary
- published: 2026-09-23
- confidence: high

### [2] TradingGPT 用三层分层记忆（各层独立衰减机制）+ agent 间辩论 + 个性化交易特质来增强记忆多样性与决策鲁棒性
- quote: "one agent organizes memory into three distinct layers, each governed by a custom decay mechanism ... Agents can also engage in inter-agent debate ... equip agents with individualized trading traits, enhancing memory diversity and decision robustness."
- url: https://arxiv.org/abs/2309.03736
- source_type: primary
- published: 2023-09-07
- confidence: high

### [3] FinCon 的跨 agent 知识迁移机制：概念化投资信念作为"语言强化"可选择性传播到需要知识更新的节点，风险控制组件通过自我批判更新系统性投资信念，并在组合管理任务上泛化
- quote: "The conceptualized beliefs serve as verbal reinforcement for the future agent's behavior and can be selectively propagated to the appropriate node that requires knowledge updates. This feature significantly improves performance while reducing unnecessary peer-to-peer communication costs. Moreover, FinCon demonstrates strong generalization capabilities in various financial tasks, including single stock trading and portfolio management."
- url: https://arxiv.org/abs/2407.06567
- source_type: primary
- published: 2024-07-09
- confidence: high

### [4] InKH 架构把 user/market/portfolio/tool 事件统一转为结构化操作知识，用时序图记忆 + wiki 审计面 + 成熟度/衰减/写时失效治理陈旧记忆；相对 agent 驱动 wiki-walk 记忆降低延迟 82.95%、token 成本 82.29%、陈旧知识使用 96.58%，可追溯性 +0.461
- quote: "InKH converts user, market, portfolio, and tool events into structured operational knowledge. It uses passive knowledge injection to assemble a bounded working context buffer before the main model step, temporal graph memory for low-latency retrieval, a wiki audit surface for human-readable governance, and background extraction with maturity, decay, and write-time invalidation."
- url: https://arxiv.org/abs/2606.01886
- source_type: primary
- published: 2026-06-01
- confidence: high

### [5] InKH 明确指出金融 agent 中"被遗忘的上下文与陈旧记忆"会直接导致延迟、重复错误、弱审计性与不安全决策——记忆架构是合规/风控问题而非纯工程优化
- quote: "forgotten context and stale memory can create latency, repeated errors, weak auditability, and unsafe decisions."
- url: https://arxiv.org/abs/2606.01886
- source_type: primary
- published: 2026-06-01
- confidence: high

### [6] 2026 年 agentic 量化交易综述指出：当前系统仍集中在信号发现，与组合构建、执行、风控的完整集成仍不常见；多 agent 系统高度依赖聚合；强预测能力不能可靠转化为实盘表现
- quote: "current systems remain concentrated on signal discovery, while complete integration with portfolio construction, execution, and risk control is still uncommon. Multi-agent systems also rely heavily on aggregation despite increasingly diverse workflow structures. Benchmark evidence further shows that strong model or forecasting capability does not reliably translate into trading performance under live market conditions and reliability controls."
- url: https://arxiv.org/abs/2608.31041
- source_type: primary
- published: 2026-08-31
- confidence: high

### [7] 金融多 agent 评测综述提出四维分类（架构模式、协调机制、记忆架构、工具集成）与 Coordination Primacy Hypothesis：协调协议设计对决策质量的影响常大于模型规模；并记录五类可使收益符号反转的评测失效（look-ahead bias、survivorship bias、backtesting overfitting、transaction cost neglect、regime-shift blindness）
- quote: "we introduce a four-dimensional taxonomy, covering architecture pattern, coordination mechanism, memory architecture, and tool integration ... inter-agent coordination protocol design is a primary driver of trading decision quality, often exerting greater influence than model scaling ... five pervasive evaluation failures (look-ahead bias, survivorship bias, backtesting overfitting, transaction cost neglect, and regime-shift blindness) and show that these can reverse the sign of reported returns."
- url: https://arxiv.org/abs/2603.27539
- source_type: primary
- published: 2026-03-29
- confidence: high

### [8] KTD-Fin 证明 LLM 训练截止记忆会污染回测（记忆化 ticker/日期/价格可替代真实推理），需数据侧掩码隔离；泄漏受控后 LLM agent 收益主要来自被动市场/风格暴露，缺乏持续选股 alpha——"可迁移投资技能"与"记忆泄漏"必须分开评估
- quote: "long backtests often overlap with the knowledge cutoffs of frontier LLMs, allowing memorized tickers, dates, prices, and market narratives to substitute for investment reasoning ... LLM agents' cumulative returns under leakage-controlled evaluation are largely explained by passive market and style exposure, with limited evidence of persistent stock-selection alpha."
- url: https://arxiv.org/abs/2605.28359
- source_type: primary
- published: 2026-05-27
- confidence: high

### [9] 英国监管层（FPC 系统性分析、Critical Third Parties 制度、2026 年 5 月联合声明）正在把"AI 运营韧性"作为独立于 EU AI Act / ISO IEC 42001 / NIST AI RMF 信任栈之外的义务补上；对前沿模型供应商的依赖集中是核心关切
- quote: "That response is necessary but incomplete. It does not, on its own, address operational resilience: the continuity of important business services under severe but plausible disruption, the substitutability of AI components, and the concentration of dependency on the small number of firms that supply frontier models ... United Kingdom financial authorities are already closing this gap through the Financial Policy Committee's systemic analysis, the Critical Third Parties regime, and the May 2026 joint statement."
- url: https://arxiv.org/abs/2607.07359
- source_type: primary
- published: 2026-07-08
- confidence: high

### [10] 受监管 AI 工作负载（含金融）的审计证据标准：每次执行需提交紧凑可验证记录，字段为 code identity、model version、data digests、platform measurements；后量子迁移正成为长期审计日志的新要求
- quote: "each execution is summarized by a compact, verifiable record of code identity, model version, data digests, and platform measurements."
- url: https://arxiv.org/abs/2512.00110
- source_type: primary
- published: 2025-11-27
- confidence: high

### [11] HARP 提出 trace-first 方法审计多 agent 系统：完整记录 specialist 输出、tool calls、memory reads/writes、guard events，识别共享记忆导致的局部扰动向系统级危害放大——共享记忆本身是攻击/污染传播面
- quote: "Multi-agent LLM systems decompose workflows across agents, tools, shared context, memory, and decision gates. This modularity improves interpretability, but creates a propagation risk: a bounded perturbation to one component can be reused by other agents and amplified into system-level harm ... records specialist outputs, tool calls, memory reads/writes, guard events, oracle logs, latency, token cost, and decisions."
- url: https://arxiv.org/abs/2605.27489
- source_type: primary
- published: 2026-05-26
- confidence: high

### [12] FundaPod 用知识图谱记忆支撑多 persona agent pod，强调"独立性保持架构"使投资计划透明、可复用、可验证并累积投资知识——组合级记忆应产出可审计的知识资产而非仅嵌入向量
- quote: "Its broader goal is not merely to predict outcomes, but to produce investment plans that are transparent, reusable, and verifiable, while contributing to the cumulative development of investment knowledge. We present FundaPod, a multi-persona agent pod architecture for AI-assisted fundamental investment research ... an independence-preserving architecture."
- url: https://arxiv.org/abs/2605.27864
- source_type: primary
- published: 2026-05-27
- confidence: high
