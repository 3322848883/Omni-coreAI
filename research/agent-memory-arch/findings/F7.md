# F7: 记忆失败案例与反模式

## Findings

### [1] 幻觉记忆污染是持久性系统级故障：一步写入的幻觉事实会成为后续每一步的错误前提，无法靠 utility/recency 写入策略解决
- quote: "A hallucinated fact written at one step therefore persists as a false premise for every subsequent step, a failure mode we call memory contamination. Existing memory management addresses retrieval and capacity but not write-time correctness; this admission problem cannot be solved by utility- or recency-based criteria, and uncontrolled contamination compounds across long trajectories."
- url: https://arxiv.org/abs/2607.22962
- source_type: primary
- published: 2026-07-24
- confidence: high

### [2] 记忆更新三类错误（遗漏/损坏/幻觉）一旦入库即成为持久系统状态故障；TrustMem 将 transition 级遗漏降低 40.1%、损坏降低 79.1%、幻觉降低 50.0%
- quote: "these updates may omit important information, corrupt existing memory, or introduce unsupported hallucinated content. Once stored, such errors become persistent system-state failures that can affect future reasoning and generation... reduces transition-level omission, corruption, and hallucination by 40.1%, 79.1%, and 50.0%, respectively"
- url: https://arxiv.org/abs/2606.25161
- source_type: primary
- published: 2026-06-23
- confidence: high

### [3] 生产环境 LLM agent 的"fail-plausible"反模式：错误被模型转化为流畅可信的叙事交付给用户，8 周 22 起事故中 70% 靠人工发现而非测试；审计是回归引擎而非预测引擎（0% 事前预防、87% 回归拦截）
- quote: "the system does not merely fail to report an error -- the LLM transforms it into fluent, plausible narrative delivered to the user. We term this fail-plausible... about 70% of silent failures were caught by human user-view observation, not tests or audits; a retrospective audit of 15 incidents found 0% ex-ante prevention but 87% regression blocking"
- url: https://arxiv.org/abs/2606.14589
- source_type: primary
- published: 2026-06-12
- confidence: high

### [4] 错误记忆导致错误决策的量化：仅污染 LongMemEval 语料库的 1.2% 即可将准确率从 0.850 打到 0.300；四阶段内容筛选管道对 360 条毒记忆拒收 0 条
- quote: "Poisoning 1.2% of a LongMemEval corpus reduces accuracy from 0.850 to 0.300. A four-stage write-time screening pipeline that reaches 0.832 recall on indirect prompt injection while flagging 1.5% of trigger-word-laden benign text rejects 0 of 360 poisoned memories."
- url: https://arxiv.org/abs/2608.21230
- source_type: primary
- published: 2026-08-21
- confidence: high

### [5] 防御本身的成本失控：读时 reranker 在无攻击的良性对话中错误隔离 33.6% 合法记忆（单次对话最多 106 条误隔离），核心准确率下降 4.4 点，token 开销 2.7%
- quote: "On conversations containing no attack, the reranker quarantines legitimate memories on 33.6% of adjudicated items, reaching as many as 106 false quarantines in a single conversation, at 2.7% token overhead."
- url: https://arxiv.org/abs/2609.22818
- source_type: primary
- published: 2026-09-19
- confidence: high

### [6] 持久记忆中毒攻击跨会话生效：PMPA 在 OpenClaw 上注入成功率 73.7%、跨会话攻击成功率 55.5%；在 Claude Code 上 66.9%/81.7%——一旦中毒，prompt 级防御保护有限
- quote: "PMPA achieves average Injection Success Rate (ISR) and Cross-session Attack Success Rate (C-ASR) of 73.7%/55.5% on OpenClaw and 66.9%/81.7% on Claude Code... provides limited protection once the persistent memory has been poisoned."
- url: https://arxiv.org/abs/2609.13889
- source_type: primary
- published: 2026-09-12
- confidence: high

### [7] 上下文污染导致错误决策：多 agent 共享记忆中毒在无防御时 100% 到达执行层；即便 Validator 被攻陷，结构化授权层可将不安全动作率压至 0%
- quote: "Across three seeds and 60 labeled tasks, memory poisoning reaches execution in every undefended trial. With authorization enabled, it achieves 100% JBR but 0% Unsafe Action Rate, showing that the Validator can remain compromised while execution is contained."
- url: https://arxiv.org/abs/2609.17648
- source_type: primary
- published: 2026-09-15
- confidence: high

### [8] 记忆膨胀/成本失控反模式：被动全量保留导致大量冗余，迭代过滤噪声又产生高 token 成本；SimpleMem 通过语义压缩将推理时 token 消耗降低最多 30 倍
- quote: "Existing approaches either retain full interaction histories via passive context extension, leading to substantial redundancy, or rely on iterative reasoning to filter noise, incurring high token costs... reducing inference-time token consumption by up to 30-fold"
- url: https://arxiv.org/abs/2601.02553
- source_type: primary
- published: 2026-01-29
- confidence: high

### [9] 统一摘要+检索管道的双输：要么 token 消耗过高，要么不可逆丢失细粒度证据；LeanMem 按可压缩性/时间动态/保真度分流后准确率最高提升 15.1 点
- quote: "existing memory systems typically process heterogeneous dialogue content through a uniform summarization and retrieval pipeline, leading to either excessive token consumption or irreversible loss of fine-grained evidence."
- url: https://arxiv.org/abs/2608.03463
- source_type: primary
- published: 2026-08-04
- confidence: high

### [10] 记忆干扰/过拟合：关系特异性干扰大幅压制更新可塑性却几乎无稳定性收益；中毒对 update-authority 线索比 recency 更敏感——仅靠"最近写入覆盖"是反模式
- quote: "benign accumulation has limited effects, whereas relationship-specific interference sharply suppresses update plasticity with little stability gain, either by blocking target-memory exposure or by disrupting its downstream use... poisoning is more sensitive to update-authority cues than to recency alone."
- url: https://arxiv.org/abs/2608.07622
- source_type: primary
- published: 2026-08-07
- confidence: high

### [11] 记忆错误持久化后修复代价高：删除源记忆不等于清除已传播的错误 claim/action/派生记忆；依赖引导回滚修复在 150 例基准上恢复率 85.3% vs 77.3%（最佳对手），但仍需选择性重放
- quote: "Deleting the source leaves already propagated claims, actions, and derived memories active, whereas resetting the store or replaying the full trace destroys benign state and repeats unnecessary computation... achieves 85.3% recovery versus 77.3% for the best competing recovery method"
- url: https://arxiv.org/abs/2608.10502
- source_type: primary
- published: 2026-08-11
- confidence: high

### [12] 上下文工程质量是独立的可靠性前兆信号：grounding 不足预测幻觉、guardrail 缺失预测被操纵、指令不一致预测指令违背——弱上下文导致 drift/幻觉/工具误用/token 浪费
- quote: "When this context is weak, agents drift, hallucinate, misuse tools, ignore constraints, become vulnerable to injection, and waste tokens... Grounding sufficiency predicts hallucination resistance, guardrail coverage predicts manipulation resistance"
- url: https://arxiv.org/abs/2607.14275
- source_type: primary
- published: 2026-07-15
- confidence: high
