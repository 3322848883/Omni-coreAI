# F3: OpenAI 与其它主流闭源厂商的工具/插件/扩展体系

## Findings

### [1] OpenAI 正式计划退役 custom GPTs，迁移到 Plugins；Enterprise 标准退役日为 2026-12-11，获批延期工作区为 2027-02-11。
- quote: "We're planning to retire custom GPTs and help creators migrate them to plugins. Plugins can bring reusable instructions, reference files, and connected apps together"
- url: https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq
- source_type: primary
- published: 2026-09 (updated ~5 days before 2026-09-30)
- confidence: high

### [2] 迁移映射关系：GPT instructions → 新 plugin 内的一个 skill；knowledge files → plugin reference files；connected apps → plugin apps；但 custom actions 不会自动迁移，需用 MCP server/官方 app 重建。
- quote: "the GPT's instructions become a skill within the new plugin. Connected apps are added to the plugin as apps. The GPT's knowledge files are copied into the plugin's reference files. ... GPT custom actions do not transfer through the migration workflow."
- url: https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq
- source_type: primary
- published: 2026-09
- confidence: high

### [3] OpenAI Skill 是可复用、可分享的工作流单元，包含 instructions + examples + code；安装后 ChatGPT 会在任务匹配时自动选用；账户默认自带 skill-creator 用于生成/维护 skill。
- quote: "Skills are reusable, shareable workflows that help ChatGPT complete specific tasks more consistently. A skill can include instructions, examples, and code. After a skill is created and installed, ChatGPT can automatically use one or more skills when they are helpful."
- url: https://help.openai.com/en/articles/20001066-skills-in-chatgpt
- source_type: primary
- published: 2026-08/09 (Updated: last month)
- confidence: high

### [4] 上传 skill 必须经过扫描才能使用；可能被标为 Needs Review 或 Blocked，官方明确扫描不能替代人工信任审查——这是能力包供应链安全的现实约束。
- quote: "When you upload a skill, ChatGPT scans it before it becomes available. ... Some skills may be marked Needs Review ... Skills that appear to contain content or behavior that could pose a risk may be marked Blocked and cannot be used. The scan should not replace your own review, policies, or judgment"
- url: https://help.openai.com/en/articles/20001066-skills-in-chatgpt
- source_type: primary
- published: 2026-08/09
- confidence: high

### [5] Plugin 是扩展包的聚合单元：可打包 skills（指令工作流）+ connected apps（外部服务）+ app templates + extensions；安装 plugin 不绕过底层 app 的 OAuth/权限/工作区策略。
- quote: "A plugin can include: Skills that provide instructions and workflow guidance. Connected apps that link external accounts, information, and actions. App templates ... Extensions ... Installing a plugin may start an app-connection or setup flow. You must still complete any required account authorization, and installation cannot bypass provider or workspace permissions."
- url: https://help.openai.com/en/articles/20001256-plugins-in-chatgpt
- source_type: primary
- published: 2026-09-29 (Updated: 19 hours ago)
- confidence: high

### [6] GPT Actions 的可靠性基础是 OpenAPI schema + 三种鉴权（None / API key / OAuth），并有工作区域名校验；公开 GPT 的 action 必须提供 Privacy Policy URL；用户可能在执行前被要求 approve。
- quote: "The schema must be provided as an OpenAPI specification in JSON or YAML. ... Available options: None ... API key ... OAuth ... Users may be asked to approve actions before they run. ... Public GPTs (link or GPT Store) with actions must include a valid privacy policy URL."
- url: https://help.openai.com/en/articles/9442513-configuring-actions-in-gpts
- source_type: primary
- published: 2026-09-28 (Updated: 2 days ago)
- confidence: high

### [7] 工具调用权限是分层风险模型：Always ask / Allow read actions / Allow low-risk actions / Allow all actions；高风险动作（发消息、删文件、改权限、购买、共享敏感数据）会额外确认或直接拒绝，而不是静默执行。
- quote: "Always ask: ChatGPT asks before reading app information or making changes. Allow read actions ... Allow low-risk actions: ChatGPT automatically approves low-risk actions. Higher-risk actions may require confirmation or be denied. Allow all actions ... This option carries elevated risk."
- url: https://help.openai.com/en/articles/20001495-managing-app-permissions-in-chatgpt
- source_type: primary
- published: 2026-09-18 (Updated: 12 days ago)
- confidence: high

### [8] OpenAI 对网络/外部连接类能力引入统一 "Elevated Risk" 标签（盾牌感叹号图标），主因是 prompt injection 与数据外泄尚未被业界充分缓解；该类功能按 early access 提供，不纳入标准 GA 保证。
- quote: "some network-related capabilities introduce new risks, especially prompt injections, that aren't yet fully addressed by the industry's safety and security mitigations. ... we aim to communicate this risk using a consistent 'Elevated Risk' label ... Features labeled 'Elevated risk' are offered on an optional and early access basis, outside of the standard representations and warranties"
- url: https://help.openai.com/en/articles/20001062-elevated-risk-labels
- source_type: primary
- published: 2026-08-31 (Updated: 30 days ago)
- confidence: high

### [9] Lockdown Mode 是面向敏感数据的硬隔离开关：禁用 Agent mode、Deep research、实时网页、文件下载、Canvas 网络，并限制 app/MCP/connector 出站请求；其目标是阻断 prompt injection 的最终外泄阶段，但不阻止注入本身。
- quote: "Lockdown Mode is designed to help prevent the final stage of data exfiltration from a prompt injection attack by limiting outbound network requests ... Lockdown Mode disables or limits ... Deep research is disabled. Agent mode is disabled. ... File downloads ... Live web browsing ... Does Lockdown Mode prevent all prompt injection attacks? ... it does not guarantee data exfiltration cannot happen."
- url: https://help.openai.com/en/articles/20001061-lockdown-mode
- source_type: primary
- published: 2026-09-28 (Updated: 2 days ago)
- confidence: high

### [10] Microsoft 365 Copilot 的 skill 等价物明确采用 `SKILL.md` 目录格式（required SKILL.md + supporting resources/scripts），并把 skill 定义为 plugin 的一种 capability，与 declarative agent / connector / MCP server 并列。
- quote: "A skill provides reusable instructions or a workflow that teaches an agent or supported Microsoft experience how to perform a specific job. A skill is represented by a directory with a required SKILL.md file and can include supporting resources or scripts. ... A plugin can bring together a skill with other supported capabilities, such as agents, Copilot connectors, or MCP-based tools. The plugin is the unit of extensibility; the skill remains a distinct reusable capability."
- url: https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugin-type-skills
- source_type: primary
- published: 2026-09-30 (ms.date)
- confidence: high

### [11] Microsoft 的 Plugin 生命周期强调「发布 ≠ 可用」：package/registry 只完成注册分发，之后仍需 review、acquisition、assignment、enablement、connection 等治理步骤；这与仅做 skill 安装即用的模型不同。
- quote: "Publishing doesn't by itself make a plugin usable. The actions after publishing depend on the distribution route and components. ... Registration and distribution don't replace product-specific administration."
- url: https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugins-overview
- source_type: primary
- published: 2026-09-30
- confidence: high

### [12] Microsoft 把 MCP server 作为 plugin 的远程工具层：plugin 包只携带连接配置，运行时服务独立；要求在设计阶段就记录 transport、auth、permission model、failure behavior、versioning 与 confirmation requirements——这是交易类工具「确认/回滚/超时」可借鉴的契约清单。
- quote: "The running MCP server remains separate from the plugin package. The package references or carries the configuration required for a supported Microsoft experience to discover the tools, connect to the server, and apply the appropriate authentication and permission model. ... Review its tool definitions, inputs, outputs, errors, and confirmation requirements."
- url: https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugin-type-mcp-servers
- source_type: primary
- published: 2026-09-30
- confidence: high

### [13] OpenAI 官方对 Actions 可靠性的工程约束：GPT 同时只能用 apps 或 actions 之一；工作区若 zero action domains 则 custom actions 完全不可执行；Pro mode 不支持 actions——说明闭源体系用白名单/能力开关做故障域隔离，而非纯模型侧保证。
- quote: "A GPT can use either apps or actions, but not both at the same time. ... If your workspace allows zero action domains, GPT custom actions cannot execute because no action domain can pass allowlist checks. ... Actions are not available for Pro mode."
- url: https://help.openai.com/en/articles/9442513-configuring-actions-in-gpts
- source_type: primary
- published: 2026-09-28
- confidence: high
