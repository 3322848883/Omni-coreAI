# F4: 开源 agent 框架的 skill/plugin/tool 扩展体系设计

## Findings

### [1] Agent Skills 已收敛为跨产品的开放格式：目录 + `SKILL.md`（YAML frontmatter 的 name/description + 指令正文），可捆绑 scripts/references/assets，采用 Discovery → Activation → Execution 三阶段渐进披露
- quote: "At its core, a skill is a folder containing a `SKILL.md` file. This file includes metadata (`name` and `description`, at minimum) and instructions... Agents load skills through **progressive disclosure**, in three stages: Discovery... Activation... Execution"
- url: https://agentskills.io/
- source_type: primary
- published: unknown (standard site; format originally Anthropic, open standard)
- confidence: high

### [2] Agent Skills 标准由 Anthropic 发起后开放共建，已被 Claude Code / Cursor / Gemini CLI / OpenCode / Goose / VS Code / GitHub Copilot / Hermes Agent / OpenClaw / Letta / OpenHands 等数十个 agent 客户端采用
- quote: "The Agent Skills format was originally developed by [Anthropic](https://www.anthropic.com/), released as an open standard, and has been adopted by a growing number of agent products."
- url: https://agentskills.io/
- source_type: primary
- published: unknown
- confidence: high

### [3] OpenClaw 把 skill 定义为「教 agent 何时/如何用工具」的 markdown 指令文件，严格遵循 AgentSkills 规范；frontmatter 至少含 name + description，正文用 `{baseDir}` 引用技能目录
- quote: "Skills are markdown instruction files that teach the agent how and when to use tools. Each skill lives in a directory containing a `SKILL.md` file with YAML frontmatter and a markdown body... OpenClaw follows the [AgentSkills](https://agentskills.io) spec."
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown (docs as of 2026-09)
- confidence: high

### [4] OpenClaw 的 skill 发现是 7 级优先级文件系统扫描：workspace skills > project `.agents/skills` > personal `~/.agents/skills` > managed/state skills > workshop skills > bundled/custodian > extraDirs+plugin skills；同名取高优先级，发现深度上限 6 层，`SKILL.md` 出现即停向下遍历
- quote: "File-backed skills load from these sources, **highest precedence first**... 1 — highest | Workspace skills | `<workspace>/skills`... 7 — lowest | Extra directories | `skills.load.extraDirs` + plugin skills... OpenClaw discovers a skill whenever `SKILL.md` appears anywhere under a configured root (up to 6 levels deep)"
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown
- confidence: high

### [5] OpenClaw 用 frontmatter `metadata.openclaw` 做加载时资格过滤（gating）：`requires.bins/anyBins/env/config`、硬 `os` 过滤（darwin/linux/win32）、`always` 旁路、`primaryEnv` 绑定 apiKey；还支持 brew/uv/npm/go/download 安装器规格（download 可带 sha256，响应体上限 256 MiB）
- quote: "OpenClaw filters skills at load time using `metadata.openclaw`... `requires.bins`: Each binary must exist on `PATH`... `requires.env`: Each env var must exist... `requires.config`: Each `openclaw.json` path must be truthy... `url` (required), `sha256` (optional 64-character hexadecimal digest, verified after download)"
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown
- confidence: high

### [6] OpenClaw 将「技能所在位置（precedence）」与「哪个 agent 可见（visibility/allowlist）」拆成两套控制；`agents.entries.*.skills` 非空即最终集合不与 defaults 合并，`[]` 表示该 agent 无技能
- quote: "Skill **location** (precedence) and skill **visibility** (which agent can use it) are separate controls... A non-empty `agents.entries.*.skills` list is the **final** set — it does not merge with defaults."
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown
- confidence: high

### [7] OpenClaw 把第三方 skill 明确视为不可信代码，用路径遏制（realpath 必须落在配置根内）、`security.installPolicy` 本地策略命令（失败即拒绝）、ClawHub `clawhub.skill.verify.v1` 信任封 + VirusTotal/ClawScan/静态分析、以及 host-only 密钥注入（不进 sandbox）做故障/安全隔离
- quote: "Treat third-party skills as **untrusted code**. Read them before enabling... Skill discovery only accepts skill roots whose resolved realpath stays inside the configured root... Configure `security.installPolicy` to run a trusted local policy command before skill installs continue... fails closed when the command cannot return a valid decision... `skills.entries.*.env` and `skills.entries.*.apiKey` inject secrets into the **host** process for that agent turn only — not into the sandbox."
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown
- confidence: high

### [8] OpenClaw 对 prompt 成本做硬预算：每个 skill 约 97 字符（≈24 tokens）+ name/description/location 长度，超出 `skills.limits.maxSkillsPromptChars` 时先砍描述、再截断列表；会话启动时快照技能列表，由 watcher（250ms debounce）/Gateway 重启/节点接入等触发刷新
- quote: "**Per skill:** ~97 characters + your `name`, `description`, and `location` field lengths... At ~4 chars/token, 97 chars ≈ 24 tokens per skill before field lengths... OpenClaw snapshots eligible skills **when a session starts** and reuses that list until a refresh trigger below applies."
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown
- confidence: high

### [9] OpenClaw 设 Skill Workshop 提案队列：agent 发现可复用工作时不直接写 `SKILL.md`，而是产出 proposal，由操作员 `openclaw skills workshop list/inspect/evaluate/apply` 审批落地——形成「agent 草稿、人裁决」的技能自生成隔离环
- quote: "Skill Workshop is a proposal queue between the agent and its `<state-dir>/agents/<agentId>/agent/workshop-skills` directory. When the agent spots reusable work, it drafts a proposal instead of writing directly to `SKILL.md`."
- url: https://docs.openclaw.ai/tools/skills
- source_type: primary
- published: unknown
- confidence: high

### [10] LangChain/LangGraph 的 tool 扩展以「带类型注解的函数 + docstring 为 schema」为核心（`@tool` 装饰器 / Pydantic / JSON Schema），经 `ToolNode` 执行；错误隔离用 `@wrap_tool_call` middleware 把异常转成可回给模型的 `ToolMessage`，动态注册则需 `wrap_model_call` + `wrap_tool_call` 双钩子
- quote: "Type hints are **required** as they define the tool's input schema. The docstring should be informative and concise... Handle tool errors using LangChain agent middleware to retry failed tool calls or return custom error messages... `wrap_tool_call` hook is required for runtime-registered tools because the agent needs to know how to execute tools that weren't in the original tool list."
- url: https://docs.langchain.com/oss/python/langchain/tools
- source_type: primary
- published: unknown (docs current 2026-09)
- confidence: high

### [11] LangChain 通过 `ToolRuntime` 注入 state/context/store/execution_info/tool_call_id，用 `MCPAdapter.list_tools()` 从 MCP server 发现并适配工具（`langchain[mcp]>=1.4.0` beta）；还定义了 schema-only 的 HeadlessTool——服务端注册、客户端执行、interrupt/resume 握手
- quote: "`MCPAdapter` discovers a server's tools and converts them into LangChain tools. Open the adapter, call `list_tools()`, and hand the result to `create_agent`... The `langchain.mcp` namespace requires `langchain[mcp]>=1.4.0` and is in beta... A headless tool is schema-only, with no in-process implementation."
- url: https://docs.langchain.com/oss/python/langchain/tools
- source_type: primary
- published: unknown
- confidence: high

### [12] CrewAI 新项目改为 JSON-first：`agents/*.jsonc` + `crew.jsonc`，自定义工具放 `tools/` 并以 `"custom:<name>"` 引用，另有可选 `skills/` 与 `knowledge/` 目录；工具/技能/记忆/MCP/A2A 是同一 agent 能力面
- quote: "`crewai create crew` creates a JSON-first crew project. Agents live in `agents/*.jsonc`, tasks and crew-level settings live in `crew.jsonc`... Add custom tools in `tools/` and reference them as `\"custom:<name>\"`. Add optional knowledge files in `knowledge/` and skill files in `skills/`."
- url: https://github.com/crewAIInc/crewAI
- source_type: primary
- published: unknown (README as of 2026-09; repo 59.2k stars)
- confidence: high

### [13] CrewAI 官方为编码 agent 发布独立 skill 包（`crewAIInc/skills`，4 个技能：getting-started / design-agent / design-task / ask-docs），经 `/plugin marketplace add` 或 `npx skills add` 安装——厂商把「框架使用知识」本身做成可安装技能
- quote: "Four skills that activate automatically when you ask relevant CrewAI questions: getting-started... design-agent... design-task... ask-docs... npx skills add crewaiinc/skills"
- url: https://github.com/crewAIInc/crewAI
- source_type: primary
- published: unknown
- confidence: high

### [14] smolagents 提供 CodeAgent（工具调用写成 Python 代码片段）与 ToolCallingAgent（JSON/text tool 调用）双轨；工具可从 Hub/LangChain/MCP/Hub Space 互操作（`Tool.from_hub` / `from_langchain` / `from_space` / `ToolCollection.from_mcp`），核心 agents.py <1000 行
- quote: "Tool-agnostic: you can use tools from any MCP server, from LangChain, you can even use a Hub Space as a tool... the LLM engine writes its actions as Python code snippets... uses 30% fewer steps (thus 30% fewer LLM calls)"
- url: https://github.com/huggingface/smolagents
- source_type: primary
- published: 2025 (paper citations 2402.01030 / 2411.01747; repo 29.6k stars)
- confidence: high

### [15] smolagents 明确将本地执行与安全边界分离：`LocalPythonExecutor` 不是安全沙箱，生产隔离靠 E2B / Blaxel / Modal / Docker——「工具能跑」与「工具敢跑」是两个独立能力层
- quote: "The built-in `LocalPythonExecutor` is **not a security sandbox**. It applies some restrictions but can be bypassed and must not be used as a security boundary."
- url: https://github.com/huggingface/smolagents
- source_type: primary
- published: unknown
- confidence: high

### [16] Nous Hermes Agent（MIT，Nous Research）把技能与插件拆成两套目录：Skills Hub 声称聚合 88k+ skills（Built-in/Optional/Community，链到 agentskills.io），Plugin Catalog 则装 memory/voice/messaging/browsing 等社区插件；记忆可「auto-generate skills」，子 agent 隔离带独立会话/终端/Python RPC
- quote: "It learns your projects, auto-generates skills, and never forgets how it solved a problem... Isolated subagents with their own conversations, terminals, and Python RPC scripts for zero-context-cost pipelines... Discover, search, and install from **…** skills across 0 registries... Fetching 88k+ skills across every registry."

- AutoGen (microsoft/autogen) tool registration 专页未抓到（时间/配额）；仅在对照中未引用
- LangGraph ToolNode / durable execution 专页未单独 fetch；LangChain tools 页中的 middleware/ToolNode/MCP 段落已覆盖可靠性相关主张
- Hermes Skills Hub / Plugin Catalog 页面为客户端渲染目录，数字「88k+ skills」来自页面脚本文案，registry 计数显示 0（动态未加载）——故 confidence: medium
