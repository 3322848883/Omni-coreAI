# F1: Anthropic Agent Skills / Claude Code skill 体系

## Findings

### [1] Agent Skill 是「含 SKILL.md 的目录」，SKILL.md 以 YAML frontmatter 开头，必填 `name` + `description`，body 为 Markdown 指令
- quote: "A skill is a directory containing a SKILL.md file. This file must start with YAML frontmatter that contains some required metadata: `name` and `description`."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [2] 渐进式披露（progressive disclosure）是核心设计原则，分三层：metadata（~100 tokens，启动时全量预载）→ SKILL.md 指令正文（建议 <5000 tokens，触发时读入）→ 打包资源（scripts/references/assets，按需读取）
- quote: "1. **Metadata** (~100 tokens): The `name` and `description` fields are loaded at startup for all skills 2. **Instructions** (< 5000 tokens recommended): The full `SKILL.md` body is loaded when the skill is activated 3. **Resources** (as needed): Files ... are loaded only when required"
- url: https://agentskills.io/specification
- source_type: primary
- published: 2025-12-18
- confidence: high

### [3] 触发/发现流程：启动时仅把每个已安装 skill 的 name+description 注入 system prompt；任务匹配时 agent 用 Bash 读 `SKILL.md` 全文；再按需读 forms.md 等附加文件；最后可执行打包脚本而不把脚本/PDF 载入 context
- quote: "At startup, the agent pre-loads the `name` and `description` of every installed skill into its system prompt. ... Claude triggers the PDF skill by invoking a Bash tool to read the contents of `pdf/SKILL.md`"
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [4] Agent Skills 已于 2025-12-18 发布为跨平台开放标准（agentskills.io），被 Claude Code / Claude.ai / Claude Agent SDK / API 以及 Cursor、Gemini CLI、GitHub Copilot、OpenCode、Goose 等数十个客户端采纳
- quote: "We've published Agent Skills as an open standard for cross-platform portability. (December 18, 2025) ... The Agent Skills format was originally developed by Anthropic, released as an open standard, and has been adopted by a growing number of agent products."
- url: https://agentskills.io/
- source_type: primary
- published: 2025-12-18
- confidence: high

### [5] 官方 spec 的 frontmatter 仅 6 个字段：`name`（1–64 字符，小写字母数字+连字符，不得以连字符开头/结尾或连续连字符，必须与父目录名一致）、`description`（1–1024 字符）、`license`、`compatibility`（≤500 字符）、`metadata`（string→string map）、`allowed-tools`（空格分隔预授权工具，Experimental）
- quote: "`name` | Yes | Max 64 characters. Lowercase letters, numbers, and hyphens only. ... Must match the parent directory name. `description` | Yes | Max 1024 characters."
- url: https://agentskills.io/specification
- source_type: primary
- published: 2025-12-18
- confidence: high

### [6] Claude Code 在开放标准之上扩展了私有 frontmatter：`disable-model-invocation` / `user-invocable` / `allowed-tools` / `disallowed-tools` / `model` / `effort` / `context: fork` / `agent` / `background` / `hooks` / `paths` / `shell` / `argument-hint` / `arguments` / `when_to_use`；跨产品打包（claude.ai 上传、Skills API、`package_skill.py`）只接受 spec 六字段，多字段会 hard error
- quote: "Claude Code extends the standard with additional features like invocation control, subagent execution, and dynamic context injection. ... Unexpected key(s) in SKILL.md frontmatter: argument-hint. Allowed properties are: allowed-tools, compatibility, description, license, metadata, name"
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown (docs live as of 2026-09)
- confidence: high

### [7] 目录结构约定：`SKILL.md` 必填；可选 `scripts/`（可执行代码，需自含依赖与错误信息）、`references/`（按需文档，如 REFERENCE.md / FORMS.md）、`assets/`（模板/图片/查找表）；引用其他文件用相对路径且「一层深」，避免嵌套引用链
- quote: "skill-name/ ├── SKILL.md # Required: metadata + instructions ├── scripts/ # Optional: executable code ├── references/ ... Keep file references one level deep from `SKILL.md`. Avoid deeply nested reference chains."
- url: https://agentskills.io/specification
- source_type: primary
- published: 2025-12-18
- confidence: high

### [8] Claude Code 的 skill 加载位（install/discovery 层级）覆盖企业托管目录、`~/.claude/skills/`（个人）、`.claude/skills/`（项目）、嵌套 monorepo 子目录、`--add-dir` 附加目录、plugin `skills/`、claude.ai 账号同步；同名冲突优先级为 enterprise > personal > project，plugin skill 以 `/plugin-name:skill-name` 命名空间并存
- quote: "Where you save a skill decides which sessions load it. ... Enterprise | `.claude/skills/<skill-name>/SKILL.md` in the managed settings directory ... Personal | `~/.claude/skills/<skill-name>/SKILL.md` ... Project | `.claude/skills/<skill-name>/SKILL.md`"
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown
- confidence: high

### [9] skill 与 subagent 双向组合：(a) skill frontmatter `context: fork` + `agent` 让 skill 在独立 subagent 里以 SKILL.md 为 prompt、无对话历史地执行（默认 background，`background: false` 同步等待）；(b) subagent 的 `skills` 字段可在启动时整份预载 skill 正文——与常规 session「仅预载 description」不同
- quote: "Add `context: fork` to your frontmatter when you want a skill to run in isolation. Claude Code starts a new subagent of the type set in the `agent` field and gives it the skill content as its prompt. The subagent doesn't see your conversation history"
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown
- confidence: high

### [10] skill 与 MCP 的官方边界：Skills 是「程序性知识/工作流打包」（instructions + scripts + resources），MCP 是外部工具/服务接口；官方定位是「Skills 通过教会 agent 更复杂的工作流来 complement MCP servers」，而非互斥替代——skill 目录加 `.claude-plugin/plugin.json` 可同时捆绑 agents、hooks、MCP servers
- quote: "We'll also explore how Skills can complement Model Context Protocol (MCP) servers by teaching agents more complex workflows that involve external tools and software."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [11] 官方安全建议：skill 会带来指令与代码执行能力，恶意 skill 可引入漏洞或指示 exfiltrate；只从可信来源安装，低可信来源须先审计全部打包文件（尤其脚本依赖、图片/资源、指向外部网络的指令）；产品公告明确「skills 给了 Claude 执行代码的能力，须 stick to trusted sources」
- quote: "We recommend installing skills only from trusted sources. When installing a skill from a less-trusted source, thoroughly audit it before use. ... paying particular attention to code dependencies and bundled resources"
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [12] 上下文经济（context budget）：`description`+`when_to_use` 合计在 listing 中截断到 1,536 字符；skill listing 预算 = 模型 context window 的 1%（可 `skillListingBudgetFraction` 调），溢出时优先丢弃最少使用 skill 的 description；SKILL.md 载入后跨轮常驻，auto-compaction 时按最近调用顺序回贴每个 skill 前 5,000 tokens，合计预算 25,000 tokens
- quote: "When the conversation is summarized to free context, Claude Code re-attaches the most recent invocation of each skill after the summary, keeping the first 5,000 tokens of each. Re-attached skills share a combined budget of 25,000 tokens."
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown
- confidence: high

### [13] Claude Code 动态上下文注入（非标准扩展）：body 中 `` !`command` `` / ` ```! ` 块在 skill 渲染前执行并内联输出；`@` 引用附文件；`${CLAUDE_SKILL_DIR}` / `${CLAUDE_PROJECT_DIR}` / `$ARGUMENTS` / `$name` 等占位符替换；同步自 claude.ai 的 skill 在本机 session 中被禁用 `!` 执行与 `@` 附件（防远程内容代码执行），Cowork 中 `disableSkillShellExecution` 可全局关掉
- quote: "Claude Code runs the command and replaces the line with its output before Claude sees the skill content, so the instructions arrive with the current diff already inlined."
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown
- confidence: high

### [14] API 路径：Agent Skills 通过 Messages API + `/v1/skills` 端点做自定义 skill 版本管理，且 API 侧 skill 依赖 Code Execution Tool beta（提供安全执行环境）；`anthropics/skills` 公开仓库（179k stars / 21.2k forks，含 Apache-2.0 示例与 source-available 的 docx/pdf/pptx/xlsx 生产 skill）提供 `template/`、`spec/`、`skills/` 与 `package_skill.py` 打包
- quote: "Agent Skills ... can now be added to Messages API requests and the new `/v1/skills` endpoint gives developers programmatic control over custom skill versioning and management. Skills require the Code Execution Tool beta"
- url: https://claude.com/blog/skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [15] 官方作者方法论：先跑评测找能力缺口再增量写 skill；SKILL.md 过大就拆引用文件；互斥场景拆独立路径以省 token；代码既可作可执行工具也可作文档（须标明跑还是读）；重点打磨 `name`/`description` 以控制触发；用 `/skill-doctor` 找未用 skill、`claude plugin eval` + `tool_used: Skill` grader 量触发率、`claude plugin validate` 查 frontmatter 解析
- quote: "Start with evaluation: Identify specific gaps in your agents' capabilities by running them on representative tasks and observing where they struggle"
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high
