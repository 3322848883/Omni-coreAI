# F5: 量化/交易 LLM 智能体如何把策略、指标、风控、分析流程打包成可复用模块

## Findings

### [1] FinRobot Desktop V2 把分析师方法论打包成 56 个 `SKILL.md` playbook 文件，按 desk 分类（financial-analysis 11、equity-research 9、private-equity 10、investment-banking 9、partner-lseg 8、wealth-management 6、partner-spglobal 3），并提供 `finrobot skill list` / `finrobot skill search` CLI 检索入口
- quote: "skills/ holds 56 analyst playbooks as SKILL.md files, grouped by desk"
- url: https://github.com/AI4Finance-Foundation/FinRobot/blob/master/finrobot_desktop/README.md
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [2] FinRobot 明确分离「确定性计算」与「LLM 叙述」：32 个纯 Python 算子（26 估值/分析 + 6 audit）负责所有财务数字，LLM 只做推理与写作，每个数字可溯源到 `finrobot/engine/compute/` 的函数调用
- quote: "Numbers are code-calculated. Narratives are LLM-assisted. Every output is provenance-tracked."
- url: https://github.com/AI4Finance-Foundation/FinRobot
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [3] FinRobot 用 6 个 audit 算子（currency_caliber、ev_bridge、narrative_divergence、narrative_numeric_grounding、sector_sign、ttm_period）在报告发布前核对 LLM 叙述与代码计算数字的一致性，标记 drift
- quote: "6 audit operators check the narrative back against the numbers and flag drift before a report ships"
- url: https://github.com/AI4Finance-Foundation/FinRobot/blob/master/finrobot_desktop/README.md
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [4] FinRobot 的 9 个 agent 各自由 `finrobot/engine/agents/instructions/` 下的 markdown 指令文件定义（data/analysis/modeling/synthesis/report 流水线 + bull/bear/judge 辩论 + lead 编排），改 agent 行为不必改 Python；7 条 pipeline 是带 per-step validator 与 retry 的 typed step 序列，而非开放式 agent 对话
- quote: "Because instructions are plain markdown, changing an agent's behavior does not require touching Python."
- url: https://github.com/AI4Finance-Foundation/FinRobot/blob/master/finrobot_desktop/README.md
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [5] AI Hedge Fund v2 把系统拆成三层可插拔接口：FUND = allocator over STRATEGIES，STRATEGY = blend policy over MODELS，MODEL = `AlphaModel.predict(ticker, date, data_client) -> Signal`（conviction ∈ [-1,+1] + thesis）；LLM investor persona 与 quant model 实现同一接口，策略用 YAML 落地且无需写代码
- quote: "A new strategy (no code): drop a YAML in strategies/ bundling existing models with a blend policy — the fund builder picks it up automatically."
- url: https://github.com/virattt/ai-hedge-fund/tree/main/hedge_fund
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [6] AI Hedge Fund 把风控隔离写成不可协商原则：「LLM never touches the trade」——agent 只产出 view/narrate，确定性代码负责 sizing 与下单，risk limits 是 agent 无法超越的 hard gates（per-position 与 gross-exposure clamps）
- quote: "The LLM never touches the trade. Agents form views and narrate; deterministic code sizes and places orders; risk limits are hard gates."
- url: https://github.com/virattt/ai-hedge-fund/tree/main/hedge_fund
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [7] AI Hedge Fund 用单一 `run_cycle` 管线（data → analysts → portfolio → risk → execution → ledger）覆盖 backtest / paper / live 三模式，仅 clock 与 broker 不同，从而保证「回测即实盘同一代码路径」；回测时对 investor agent 隐去 ticker/行业/日历以防 LLM 训练数据记忆伪装成 skill
- quote: "a backtest withholds the ticker, industry and calendar dates from the investor agents' prompts; the personas see the fundamentals with periods labelled t-0, t-1, ..."
- url: https://github.com/virattt/ai-hedge-fund
- source_type: primary
- published: unknown (as of 2026-09)
- confidence: high

### [8] TradingAgents 用 LangGraph 把交易公司角色拆成可组合 agent：Fundamentals/Sentiment/News/Technical 四分析师并行各自持有工具集，Bull/Bear researcher 辩论，Trader 合成决策，Risk Management team 评估敞口，Portfolio Manager 最终批准/否决交易提案——风控与执行是独立节点而非 prompt 里的一段话
- quote: "The Portfolio Manager approves/rejects the transaction proposal. If approved, the order will be sent to the simulated exchange and executed."
- url: https://github.com/TauricResearch/TradingAgents
- source_type: primary
- published: 2026-09 (v0.5.x news; paper arXiv:2412.20138 v7 2025-06-03)
- confidence: high

### [9] TradingAgents v0.5.x 引入跨全部 dated path 的 point-in-time 完整性与「verified data-access contract」：SEC EDGAR 按 filing date 供给基本面、Alpha Vantage look-ahead 过滤、市场分析师把价格/指标 claim 锚定到 verified data snapshot，回测只读分析日已公开数据
- quote: "backtests that see only data published by each analysis date" / "a verified data-access contract"
- url: https://github.com/TauricResearch/TradingAgents
- source_type: primary
- published: 2026-09
- confidence: high

### [10] TradingAgents 的可靠性实践包括：结构化输出 agent（Research Manager/Trader/Portfolio Manager）、LangGraph checkpoint resume（per-ticker SQLite 于 `~/.tradingagents/cache/checkpoints/<TICKER>.db`）、持久 decision log + reflection 注入 Portfolio Manager prompt、可配置 LLM retry budget
- quote: "structured-output agents (Research Manager, Trader, Portfolio Manager), LangGraph checkpoint resume, persistent decision log"
- url: https://github.com/TauricResearch/TradingAgents
- source_type: primary
- published: 2026-04 (v0.2.4) / 2026-07 (v0.3.1)

### [11] FinAgent（arXiv:2402.18485）把交易能力打包为 tool-augmented 多模态 agent：market intelligence 模块处理数值/文本/K线图，dual-level reflection + diversified memory retrieval 学习历史决策，并显式「integrates established trading strategies and expert insights」把经典策略与专家规则作为可复用组件注入
- quote: "FinAgent integrates established trading strategies and expert insights, ensuring that its trading approaches are both data-driven and rooted in sound financial principles."
