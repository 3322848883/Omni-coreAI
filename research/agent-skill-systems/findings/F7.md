# F7: agent 能力扩展格式的对比与选型（SKILL.md vs MCP vs plugin vs prompt-template vs subagent）

## Findings

### [1] Agent Skills 的核心设计是三级 progressive disclosure：启动只注入 name/description，触发才读完整 SKILL.md，深层 bundled 文件按需再读，使「可打包的上下文实际上无上限」。
- quote: "This metadata is the first level of progressive disclosure: it provides just enough information for Claude to know when each skill should be used without loading all of it into context. The actual body of this file is the second level of detail. ... These additional linked files are the third level (and beyond) of detail"
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [2] SKILL.md 与 CLAUDE.md / 常驻 prompt 的边界官方划在「procedure vs fact」：重复粘贴的 checklist/多步流程应做成 skill，因为 skill body 未触发时几乎零成本；body 一旦加载则跨轮驻留，每行都是重复 token 开销。
- quote: "Unlike CLAUDE.md content, a skill's body loads only when it's used, so long reference material costs almost nothing until you need it. ... Once a skill loads, its content stays in context across turns, so every line is a recurring token cost."
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown (live docs, content as of 2026-09)
- confidence: high

### [3] 业界并未把 Skills 与 MCP 对立起来，而是分工：MCP 提供外部工具/数据连接，Skills 负责编排「涉及外部工具的复杂工作流」；MCP 规范侧同样建议 skill 文件声明所需 MCP server，仅在 skill 被调用时连接。
- quote: "We'll also explore how Skills can complement Model Context Protocol (MCP) servers by teaching agents more complex workflows that involve external tools and software."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [4] MCP 官方 client best practices 明确给出「何时用 progressive discovery」阈值：tool 定义占上下文约 1%–5% 时应切换；naive 全量注入与按需加载的图示对比约为 ~150,000 tokens vs ~2,000 tokens。
- quote: "Implement a threshold as a percentage of the context window. For example, 1%-5%. Load tool definitions. Once the threshold is reached, switch to progressive discovery. ... the upfront approach consumes ~150,000 tokens on definitions alone, while progressive discovery uses ~2,000 tokens"
- url: https://modelcontextprotocol.io/docs/2026-07-28/develop/clients/client-best-practices
- source_type: primary
- published: 2026-07-28 (protocol version referenced in docs path)
- confidence: high

### [5] MCP 的可靠性/成本争论焦点在 tool-result 穿透模型：官方推荐 programmatic tool calling（code mode），对比图示为直接链式调用 ~100K+ tokens 中间结果 vs ~200-token 脚本 + ~15-token 摘要；这是「工具型扩展」在高频数据面上相对纯指令包的结构性短板。
- quote: "Direct calling passes every intermediate result through the model (~100K+ tokens). Programmatic calling sends a ~200-token script to a sandbox, which executes the tool calls and returns a ~15-token summary."
- url: https://modelcontextprotocol.io/docs/2026-07-28/develop/clients/client-best-practices
- source_type: primary
- published: 2026-07-28
- confidence: high

### [6] MCP 协议层把「prompt-template」定义为一等原语（tools / resources / prompts）：tools 是可执行动作，resources 是上下文数据，prompts 是可复用交互模板（system prompts、few-shot）；与 SKILL.md 的差别在于 prompt-template 是协议内参数化模板，skill 是带脚本与资源的文件夹式能力包。
- quote: "Tools: Executable functions that AI applications can invoke to perform actions ... Resources: Data sources that provide contextual information ... Prompts: Reusable templates that help structure interactions with language models (e.g., system prompts, few-shot examples)"
- url: https://modelcontextprotocol.io/docs/2026-07-28/learn/architecture
- source_type: primary
- published: 2026-07-28
- confidence: high

### [7] Claude Code plugin 官方定位是「分发/打包单元」而非新能力原语：skills、subagents、hooks、MCP servers 均可独立存在，plugin 仅在需要把它们作为一个单元安装、更新、分发时使用。
- quote: "Skills, subagents, hooks, and MCP servers all work on their own, without a plugin. ... Use a plugin when you want several skills, subagents, hooks, or MCP servers packaged as one unit."
- url: https://code.claude.com/docs/en/plugins/overview
- source_type: primary
- published: unknown (live docs, content as of 2026-09)
- confidence: high

### [8] 启用 plugin 的上下文成本是「常驻但按需展开」：每个 Claude 可自动调用的 skill/agent/command 的 name+description 每轮都在 context 里，全文只在使用时加载；plugin 定义的 MCP server 进程常驻、hooks 生命周期常触发；Anthropic 官方 marketplace 在安装前直接展示「Context cost」估算。
- quote: "for each skill, agent, and command that Claude can invoke on its own, the name and description are in Claude's context on every turn ... Plugins in Anthropic's official marketplace show a Context cost estimate there."
- url: https://code.claude.com/docs/en/plugins/overview
- source_type: primary
- published: unknown (live docs, content as of 2026-09)
- confidence: high

### [9] Subagent 的适用边界是上下文隔离与工具/权限收敛：side-task 的搜索结果、日志、文件内容留在独立 context window，只回传摘要；description 常驻主上下文且官方给出 15,000-token 合计上限告警，细则应放进 subagent system prompt（仅在委派时加载）。
- quote: "Use one when a side task would flood your main conversation with search results, logs, or file contents you won't reference again: the subagent does that work in its own context and returns only the summary. ... when the combined descriptions of your subagents ... exceed 15,000 tokens, Claude Code shows a warning"
- url: https://code.claude.com/docs/en/sub-agents
- source_type: primary
- published: unknown (live docs, content as of 2026-09)
- confidence: high

### [10] Skills 与 subagents 可双向组合，且语义不同：`context: fork` 让 skill 以独立 subagent 执行（看不到会话历史，指令必须自洽）；subagent 的 `skills` 字段则把 skill 全文预加载为参考材料——前者隔离任务，后者隔离知识。
- quote: "Add context: fork to your frontmatter when you want a skill to run in isolation. ... The subagent doesn't see your conversation history, so the skill's instructions have to stand on their own."
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown (live docs, content as of 2026-09)
- confidence: high

### [11] 纯指令的可靠性短板由「skill 内捆绑确定性代码」弥补：Anthropic 明确以排序为例说明 token 生成不如直接跑算法，PDF skill 用预写 Python 脚本抽取表单字段且不把脚本/PDF 载入 context——这是 SKILL.md 相对纯 prompt-template 的关键增强。
- quote: "sorting a list via token generation is far more expensive than simply running a sorting algorithm. ... Claude can run this script without loading either the script or the PDF into context. And because code is deterministic, this workflow is consistent and repeatable."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [12] Agent Skills 已于 2025-12-18 发布为开放标准（agentskills.io），被 Gemini CLI、Cursor、GitHub Copilot、VS Code、OpenCode、OpenHands、Goose、ChatGPT & Codex 等数十家客户端采纳；标准 frontmatter 仅 6 字段（name, description, license, compatibility, metadata, allowed-tools），Claude Code 扩展字段在跨平台打包时会硬报错——可移植性是选型硬约束。
- quote: "The Agent Skills format was originally developed by Anthropic, released as an open standard ... Unexpected key(s) in SKILL.md frontmatter: argument-hint. Allowed properties are: allowed-tools, compatibility, description, license, metadata, name"
- url: https://agentskills.io
- source_type: primary
- published: 2025-12-18 (standard announcement date from Anthropic update note; site live 2026-09)
- confidence: high
