**两套状态词表（防混淆，不互译）**：
- **七态枚举**（战术层，`features.seven_state().state` 中文 + patrol_report / fast-plan `classification` JSON 英文）：突破`breakout` / 窄通道`tight_channel` / 宽通道`broad_channel` / 小反转`minor_reversal` / 大反转`major_reversal` / 宽区间`broad_range` / 窄区间·铁丝网`barb_wire` / 中性`neutral`（中性=K线不足，本周期该品种不产生 S2 动作）
- **五态基线枚举**（深析层既有，`features.market_state().state` 中文 + signal_eval `_MARKET_STATE_ALIASES` 英文）：突破/强趋势`breakout`·`strong_trend` / 窄通道/趋势`narrow_channel`·`narrow` / 宽通道/弱趋势`wide_channel`·`wide` / 宽区间/震荡`range`·`trading_range` / 窄区间/铁丝网`barb_wire`·`barbwire`·`tight_range` / 中性`neutral`
- 七态在五态主干上叠加反转分流（小反转/大反转）与连续谱；`market_state` 条件类型（trigger_conditions.params.expect）仍走五态词表，零改动。

**订单类型语义交叉校验（与门禁第 29 项 / `infer_entry_type` 同口径）**：多头带中值 &lt; 现价 → `limit`（回调接货），&gt; 现价 → `stop`（突破追认）；空头镜像。**矩阵为第一权威**，语义仅交叉校验（如状态=突破 却用 limit 追入 → FAIL）。

**止损单数学（scalp 级强制）**：止损单入场因滑点/价差，市场须运动 6tick 才净赚 4tick——scalp 级 fast-plan 用止损单时目标距离 ≥ 1.5×止损距离，否则 fast gate 第 7 项拒。

**限价单纪律**：限价单仅限矩阵允许状态（宽区间边界 / 通道回撤 / 通道线逆势刮头皮）；弱势突破后限价反手、L1/L2 弱信号低点限价买等「仅限经验丰富者」高难操作**战术层禁用**（节点2 深析层可酌情）。
