# 质量自检清单（交付前强制逐项核验）

AI 交付前逐项检查；任何一项未通过 → 返回对应步骤修正，全部通过才交付。

> **本清单是"有证据的勾选"**：每项必须给出核对方式与结果（只读 DB 查询 / 全文检索 / 算术重算），写不进证据的项视为未通过。可执行核对步骤见 `verification-checklist.md`（Level A 硬性门禁 + Level B 软性门禁 + 反向审读 + 复核记录），其中 A1 数值溯源、A2 K 线关系断言、A3 H/L 计数复核、A4 段落自洽为**必做新增项**。

## 一、真实性
- [ ] 当前价格/EMA/ATR/关键位均来自节点1 数据库或用户图表，报告注明数据来源路径与数据时间
- [ ] **现价=锚点 as-of 价**（BLOCKER1 教训）：`current_price` 取冻结库 data_time 时点最近闭合 bar 收盘（1m/5m），禁用交付时实时价充当分析基准；若需另示"交付对表价"，须显式区分两个时点并各自标注来源
- [ ] **同名口径单义**（W2 教训）：同一名称（"日高/日开/今日 OHLC"）全报告单一口径；若 1d bar 口径与日内 15m 聚合口径并存（如加密 7×24 品种），必须在首次出现处显式声明两套口径的取值与各自用途，禁止同词两值不声明
- [ ] **关键位来源精确到 bar**（W3 教训）：价格阶梯/止损依据引用的结构位标注「周期 + bar 时间戳」（如"09-07 04:00 4h 高"而非"09-06 4h 高点"）；DB 无对应 bar 的价位（如凭空的 78,198）禁止作为止损/触发依据
- [ ] **量能倍数口径统一=前 20 均口径**（W4 教训）：全报告量能倍数逐处标注口径；如需引用"相对前一根"口径必须显式区分，禁止同句/同段混用两种口径（1.5× 与 3.1× 并存即口径分裂信号）
- [ ] 没有凭空补价格、补 K 线、补成交细节；无"庄家操纵/消息面必然"式不可验证依据
- [ ] 引用知识模块/指南的判断有据可查；无法引用处标注为推断

## 五、交易生命周期（每笔交易计划的处理）
- [ ] 每个方案（含观察方案）含 `lifecycle`，五阶段齐全：触发前 / 触发确认 / 入场后 / 失效 / 止损后
- [ ] 未触发有明确路径：waiting→approaching→expired（离开入场区 >2×ATR 或窗口超时 → 撤单+active=false）；窄区间/信号组合否决会跳过
- [ ] 触发确认链 = 信号K收盘 → 入场K收盘 → 跟进K；触发即失效互斥检查；部分成交与立即挂止损有处理
- [ ] 入场后情形表 ≥8 种，覆盖 盈利/亏损/持平/时间/事件/断连 六类；每情形有"条件→动作→规则引用"
- [ ] 每个触发条件有对应失效条件（一一对应）；失效动作分级（fatal→全平/撤单，warning→减仓50%）
- [ ] 方案含 quality_tag（Type A/B/C），供复盘比较触发质量；**两套标签体系并用时须声明映射**（N13 教训）：quality_tag（决策树标签 Type A/B/C）与 framework 附录F 信号×背景矩阵评级（A/B/C级）非同一体系，报告首次并用处须给映射说明（如"TypeA ≈ 矩阵 A 级=路径干净×强背景"），未声明映射不得同时出现两套评级
- [ ] 前提状态机：连续 3 根质疑K → 前提否定 → 立即离场（不等止损被扫）
- [ ] 止损被扫后：禁止追回（BAN-11）；二次机会仅限新结构；连亏/日亏冷却（RM-01/03）；复盘记录（节点4）
- [ ] 报告含"54 板块覆盖对照"（template-coverage.md）：逐模块标注 ✓/△/✗/➖；必填类缺失 → 返回补齐；**不适用项必须显式申报 ➖ 并写品种特性原因**（N14 教训：如 BTC 7×24 无缺口 → §11 标 ➖"加密无缺口机制"，禁止留空/未申报的不适用）；增强类按需标注（不隐藏缺项）
