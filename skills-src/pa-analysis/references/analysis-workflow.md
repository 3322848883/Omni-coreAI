# 分析工作流（每步三元约束）

> 每个步骤按「输入 → 处理 → 通过标准 → 失败处理」四段执行。不满足通过标准时按明确的失败路径降级，**不临时发明新分支**。
> **无脚本版**：原先的预检管线、特征表、断点状态、报告渲染全部取消 —— 取数用只读行情工具，判读由你自己做。**「算出再写」改为「引用工具返回值」**：任何数字都必须来自 `klines` / `indicators` / `account` 等工具的返回，**禁止心算、目测、估算**。

## 前置：方案交接（重分析必做；首份跳过并标注「无前版」）

- **输入**：订单上下文里的旧方案（**读订单上下文，不靠会话记忆** —— 换会话仍可执行）。
- **处理**：对旧方案**逐条**四选一定案 —— ①已触发（转入复盘）/ ②已失效（注明失效价与时间）/ ③继续等待（原样延续，注明「延续自 YYYY-MM-DD」）/ ④结构已变（supersede：新方案替代 + 一句话归因 —— 行情演化（数据驱动）还是判断修正（分析驱动））。可选：用 `ticker` 取现价，对旧方案的结构位做一次机械对表（已进入场区 / 已破失效位 / 仍在等待）。
- **通过标准**：覆盖旧方案**每一条**（含观察方案），无遗漏、无静默丢弃；每条结局有一句话依据（价格证据或结构理由）；超龄方案（scalp >30 分钟 / swing >4 小时）归「已失效-过期」并注明；首份标注「无前版」。
- **失败处理**：旧方案结构读不出来 → 以降级说明代替，并注明依据不足；结局无法判定（价格未到任何结构位）→ 归「继续等待」并复核过期边界。

## 步骤 0：确认输入与事实源

- **输入**：`account`（权益/持仓/挂单/保护单）+ `klines`（主周期 ≥200 根）+ `contract`（精度/最小名义/杠杆上限）。
- **处理**：确认品种、周期、数据时间范围与新鲜度；只以工具返回为事实源。记下**最后一根已收盘K 的时间戳** —— 之后所有「当前判断」都站在它上面。
- **通过标准**：能给出当前价、最新 K 线时间、账户状态（权益/持仓/挂单/保护单）；数据够 ≥200 根。
- **失败处理**：数据缺失或过旧 → 换周期/换工具重取，或明确说明数据缺口；信息不足会编造时，先问最少的关键问题。

## 步骤 1：走势分段草稿

- **输入**：主周期最近 80-160 根 K 线（决策侧重最近 20-30 根）。
- **处理**：从左到右切 5-7 段，每段一句话：这段是什么 → 谁在控制 → 为什么 → 交易动作怎么变。给每段分配角色：背景段 / 状态切换段 / 控制权切换段 / 当前决策段。
- **通过标准**：每段能说清控制权在哪切换；标注可追溯到具体 bar。
- **失败处理**：说不清控制权或证据的段落 → 只入正文或删除；分段覆盖不到最后一根已收盘K → 重读。

## 步骤 2：状态决策树化

- **输入**：分段草稿 + 七状态（突破/窄通道/宽通道/小反转/大反转/宽区间/窄区间）判定要素。
- **处理**：把模糊判断拆成可复查节点（突破后有没有跟进？距离是否足够远？不利影线是否超过实体一半？回撤是否进入磁体射程？）。每节点只产生明确分支：做 / 等 / 缩仓 / 改目标 / 删除。参数必须可复查（20 缺口棒必须数 K；急赴磁体必须量距离；区间突破回调必须确认跟进）。
- **周期切换信号（每次切换必列）**：每次状态切换必须指出当时已能看到的 K 线信号，例如连续 2-3 根同向强 K、突破后跟进、K 线重叠突然增加、强反向 K 收在极端位置、逆势方开始轻松赚钱；**无信号证据的切换不成立**。
- **阶段不明按保守侧处理**：无法在七状态中定位时按更保守一侧处理（如「可能区间可能通道」→ 按区间边界交易或观察），并标注「阶段不明，按保守侧」。
- **通过标准**：状态判定有可复查参数支撑；分支无「看感觉」。
- **失败处理**：只差一点满足规则（如 19 根不等于 20 根）→ 默认不交易，可标注「接近条件」但不当作已触发；暴露规则盲区 → 当下不发明新分支。

## 步骤 3：逐根读取

- **输入**：最近一段 K 线（重点最近 20-30 根）。
- **处理**：每根至少判断：实体长短、收盘位置、影线、与前几根关系（推进/重叠/回测/停顿/反向突破）、后续跟随。单根先分两类：趋势 K（实体明显；顺势=动能延续，破位=看跟进）与区间 K（影线重叠明显；区间内=停顿，边界=看失败突破/反转）。外观暧昧时服从脉络。
- **通过标准**：只标注会改变计划的 K（突破 K、信号 K、失败突破 K、回测失败 K、加速 K、停顿 K）；其余判断留在证据链。
- **失败处理**：关键 bar 复盘放正文；原图无编号时不新增编号。

## 步骤 4：运动分段与数推

- **输入**：走势分段草稿。
- **处理**：用四个标准分段：阴阳交替（一串同向 K=一方持续控制，颜色切换=断点）；回调 K（低点下移/高点抬高=对方造成回调）；显著高低点连线（连接每推最远端确认轮廓）；规模匹配（时间间距与振幅同级）。二推失败≈双顶底、三推失败≈楔形；多数波段在顺势二推/三推后出现止盈/回调/小型反转。
- **通过标准**：推数分段能对应波段和趋势层级，并标出第一推/第二推/第三推。
- **失败处理**：规模不匹配的过细/过粗分段 → 合并或拆分；推数无法确认 → 只标趋势不标推数。

## 步骤 5：交易日准备（磁体与波幅）

- **输入**：日线数据（`klines` 取 1d）+ 当前周期图 + `indicators` 的 ATR14。
- **处理**：用 ATR（无则用近日平均波幅/前日高低）估计今日可能波幅；在波幅内向左找磁体：前一日高低收、当日开盘、明显前高前低、突破后跟进的回调高低点、开盘区间上下沿、历史新高新低；**只保留会改变行为的 3-6 个磁体**；开盘前几根强双边争夺 → 标开盘区间，若区间高度远小于平均波幅，预期突破/扩张。
- **通过标准**：每个磁体有用途（目标/触发/失效/观察反应/不交易理由）。
- **失败处理**：超出波幅太远、未被接近、只会让图变乱的线 → 删除。

## 步骤 6：建仓方案设计（价格行为理据 + 交易数学）

- **输入**：状态判定 + 逐根证据 + 磁体。
- **处理**：每个建仓方案必须同时满足：① 价格行为理据（为什么此处有人愿意买卖、谁被困、谁止盈止损、哪些磁体作用）；② 交易数学（入场/止损/目标/胜率假设/盈亏比/风格匹配）。方案类型按 `pattern-catalog_part1.md` 全表 + M51 27 条规则选择：收线追进、首次逆势失败后顺势恢复、双顶底旗形、楔形旗形、区间边界短打、突破回测（BOP）、H2/L2 二次进场、急赴磁体、通道尾端反转、均线缺口、缺口K线、ii/iii/ioi、最终旗形、高潮反转、失败之失败、头肩顶、扩张三角、DBL/DBS、决斗线等；**方案命名必须能落到 catalog 或 M51 规则**。处理顺序：先定脉络 → 再定方案 → 再定离场（硬止损价 / 止盈分批 / 移动止损按方案风格定参 / 时间止损 —— swing 24h 重估 + 72h 全平、scalp 45min 减半 + 90min 全平 或按 K 线计数 / 峰值回撤 50% / 前提否定打平）→ 再定删除条件。
- **输出即完整（硬约束）**：方案设计完成时字段必须**一次齐全** —— 分析位（入场带 / 入场触发 / 入场理由类型 / 止损 / 止盈 / 仓位）+ 执行位（离场规则六件套）+ 生命周期五阶段；缺任何一项 = 方案未完成，不得进入下一步。**禁止先出骨架、事后补字段** —— 补出来的字段没经过分析流程，等于让程序做判断。
- **通过标准**：只有统计现象没有价格行为解释，或只有故事没有止损/目标/期望约束 → 都不能直接用；方案能命名、能给出完整交易链、字段齐全。
- **失败处理**：无法命名交易假设或逻辑说不清 → 降级为观察；方案撞不利磁体/路径被挡/跟进失败/数学失衡 → 删除或降级；离场规则定不出参数（如无明确前提否定条件）→ 该方案降级观察。

## 步骤 7：交易数学与风格校准

- **处理**：交易是否值得 = 成功概率×潜在回报 > 失败概率×风险。胜率与盈亏比通常反向。1:1 RR 需明显高于五成胜率；2:1 可接受更低胜率但止损清楚、空间足够；3:1 以上不默认高胜率。**一个计划同时声称高胜率+高RR+近止损+无需确认 → 假定估算错误**。等距校准：均衡≈50%；强趋势顺势 1R 按 60% 上限，逆势按 40% 或更低。风格：波段（2R+，10-30 根 K，急速/窄通道/强趋势）；剥头皮（1R 或以下，1-5 根 K，宽通道/区间边界/磁体/均线回归）。强趋势中的逆势剥头皮默认删除。
- **通过标准**：每方案有胜率/RR/风格一致；数学不矛盾；RR 用**入场带中值**实算（`(T1−带中值)/(带中值−止损)`，空头镜像）。
- **失败处理**：止损无法定义 → 不构成可执行交易；入场远离失效点 → 等回调/二次进场/放弃；数学失衡 → 删除或缩仓。

## 步骤 8：知识引用

- **处理**：每步分析引用对应知识模块（Mxx）或 references 章节（见 SKILL.md 知识路由表），把依据写进 `rule_ids`。
- **通过标准**：关键判断（状态/信号/形态/概率/入场规则）有知识依据可查。
- **失败处理**：无法引用知识依据的判断 → 标记为推断，不写成事实；存疑处降级处理。

> **范围边界**：本文件只展开分析阶段。输出形态、字段契约、交付前自检以 SKILL.md 为准；**形态名与 sequence 名必须取自 `sequence-vocabulary.md` / `contract-enums.md` 的登记词表**，写错会被执行侧拒。
