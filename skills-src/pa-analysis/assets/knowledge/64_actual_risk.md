# 实际风险分析（Actual Risk Analysis）

> 来源：Al Brooks 价格行为学 - 风险与回报
> 核心概念：实际风险往往不等于理论风险。理论风险是止损距离，实际风险需要考虑滑点、缺口、流动性、心理因素等。

---

## 一、理论风险 vs 实际风险

### 1.1 定义

| 类型 | 定义 | 计算方式 |
|------|------|---------|
| 理论风险 | 计划中的止损距离 | 入场价 - 止损价 |
| 实际风险 | 交易中实际承担的风险 | 理论风险 + 滑点 + 缺口 + 心理成本 |

### 1.2 实际风险放大因素

| 因素 | 放大倍数 | 说明 |
|------|---------|------|
| 滑点 | 1.1-1.3x | 市价单/止损单在快速市场中可能滑点 |
| 缺口风险 | 1.5-3x | 隔夜持仓的缺口风险 |
| 流动性不足 | 1.2-2x | 薄市场中止损可能被击穿 |
| 心理成本 | 1.1-1.5x | 焦虑、过度交易、报复性交易 |
| 紧凑区间止损 | 1.5-2x | 紧凑区间中最差的止损入场环境 |

---

## 二、实际风险计算

### 2.1 冒1点风险博2点利润的真相

| 场景 | 理论 | 实际 |
|------|------|------|
| 理论风险 | 1点 | 1点 |
| 滑点（入场+离场） | 0 | 0.3-0.5点 |
| 心理成本（过早离场） | 0 | 0.2-0.3点 |
| **实际风险** | 1点 | **1.5-1.8点** |
| 理论回报 | 2点 | 2点 |
| 实际风险回报比 | 1:2 | **1:1.1-1:1.3** |

**结论**：冒1点风险博2点利润，实际风险回报比可能只有1:1.1，交易者方程为负！

### 2.2 最小可行风险回报比

| 胜率 | 理论最小RR | 实际需要RR（含滑点） |
|------|-----------|-------------------|
| 60% | 1:1 | 1:1.5 |
| 50% | 1:2 | 1:2.5 |
| 40% | 1:2.5 | 1:3 |
| 30% | 1:3.3 | 1:4 |

**规则**：实际风险回报比至少需要比理论高0.5，才能覆盖滑点和心理成本。

---

## 三、实际风险的隐藏因素

### 3.1 机会成本

| 因素 | 说明 | 量化 |
|------|------|------|
| 持仓时间 | 持仓时间越长，错过的机会越多 | 每持仓1小时 = 0.1R机会成本 |
| 资金占用 | 保证金占用期间的利息损失 | 可忽略（日内交易） |
| 注意力占用 | 监控持仓的注意力成本 | 无法量化，但真实存在 |

### 3.2 心理成本

| 心理状态 | 影响 | 成本 |
|---------|------|------|
| 持仓焦虑 | 过早离场 | 平均损失0.3R |
| 盈利兴奋 | 过晚离场 | 平均损失0.2R |
| 亏损恐惧 | 拒绝止损 | 平均损失1.5R |
| 报复交易 | 情绪化交易 | 平均损失2R+ |

### 3.3 紧凑区间中的实际风险

Al Brooks 警告：**"紧凑交易区间是最差的止损入场环境，机构正在做相反的事情。"**

| 风险因素 | 放大倍数 |
|---------|---------|
| 假突破频繁 | 1.5x |
| 止损被猎杀 | 1.3x |
| 双向不确定性 | 1.2x |
| **总实际风险放大** | **2-3x** |

## 四、实际风险控制策略

### 4.1 风险预算

| 账户规模 | 单笔理论风险 | 单笔实际风险（含缓冲） |
|---------|------------|-------------------|
| $10,000 | $200（2%） | $150（1.5%） |
| $50,000 | $1,000（2%） | $750（1.5%） |
| $100,000 | $2,000（2%） | $1,500（1.5%） |

**规则**：用实际风险（含缓冲）来计算仓位，而不是理论风险。

### 4.2 实际风险分层

| 风险层级 | 风险比例 | 适用场景 |
|---------|---------|---------|
| 极低风险 | 0.5% | 不确定环境、窄区间、午间 |
| 低风险 | 1% | 逆势交易、反转交易 |
| 标准风险 | 1.5% | 正常顺势交易 |
| 高风险 | 2% | 高概率架构、强趋势 |

### 4.3 实际风险检查清单

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 实际RR是否>1.5？ | 理论RR - 0.5 >= 1.5 |
| 2 | 是否在紧凑区间中？ | 否 → 可以交易；是 → 不交易 |
| 3 | 是否有隔夜缺口风险？ | 日内交易 → 无；隔夜 → 减仓50% |
| 4 | 流动性是否充足？ | 主流币种/合约 → 是；山寨币 → 减仓 |
| 5 | 心理状态是否稳定？ | 是 → 正常仓位；否 → 减仓50% |
| 6 | 今日是否已亏损？ | 否 → 正常；是 → 减仓50%，不逆势 |
| 7 | 是否已有持仓？ | 否 → 正常；是 → 总风险不超过3% |

---

## 五、核心原则

1. **实际风险 > 理论风险**：滑点、心理成本、机会成本都会放大实际风险
2. **RR需要缓冲**：理论RR需要比最低要求高0.5，才能覆盖实际风险
3. **紧凑区间不交易**：紧凑区间中的实际风险是理论风险的2-3倍
4. **用实际风险算仓位**：不要用止损距离算仓位，要用实际风险算
5. **亏损后减仓**：当天已亏损后，实际风险因心理因素而放大，需要减仓
