# 多时间框架分析（Multi-Timeframe Analysis）

## 三层时间框架

| 层级 | 时间框架 | 用途 | 频率 |
|------|----------|------|------|
| HTF（高时间框架） | 日线/4小时 | 确定大方向、关键价位 | 每日盘前 |
| MTF（中时间框架） | 1小时/30分钟 | 确认趋势结构、通道 | 盘中每30分钟 |
| LTF（低时间框架） | 5分钟/1分钟 | 精确入场、信号K线 | 实时 |

---

## HTF决策逻辑

### 日线趋势判断

```
多头趋势：日线 HH+HL 序列 + 收盘在EMA上方
空头趋势：日线 LH+LL 序列 + 收盘在EMA下方
日线区间：无持续序列 + 价格穿越EMA
```

### HTF关键价位

```
从日线/4小时提取：
- 最近摆动高点/低点
- 整数关口
- EMA位置
- 前日高/低/收盘
- 周线关键价位
```

### HTF对交易的影响

| HTF状态 | 日内交易策略 |
|---------|-------------|
| 日线多头趋势 | 日内优先做多，做空仅在明确反转信号时 |
| 日线空头趋势 | 日内优先做空，做多仅在明确反转信号时 |
| 日线区间 | 日内双向交易，但边界附近优先 |
| 日线突破 | 日内顺势追入，注意BOP机会 |

---

## 时间框架对齐

### 三级对齐（最强信号）

```
HTF方向 + MTF方向 + LTF入场信号 = 最高概率交易

示例：
- 日线多头趋势
- 1小时图出现回调到EMA
- 5分钟图出现H2信号K线 → 入场做多
```

### 两级对齐（标准信号）

```
HTF方向 + LTF入场信号 = 标准概率交易

示例：
- 日线多头趋势
- 5分钟图出现H1信号K线 → 入场做多
```

### 单级信号（低概率）

```
仅LTF信号，无HTF支持 → 剥头皮或放弃

示例：
- 日线区间
- 5分钟图出现H1 → 仅剥头皮，目标1倍风险
```

---

## 周期演进序列

```
市场周期的演进顺序：
1. HTF趋势 → MTF通道 → LTF回撤入场
2. HTF趋势 → MTF区间 → 等待突破
3. HTF区间 → MTF突破 → LTF BOP入场
4. HTF反转 → MTF确认 → LTF第二个信号入场
```

---

## 市场惯性框架

```
惯性原则：
- HTF趋势的惯性 > MTF趋势的惯性 > LTF趋势的惯性
- 逆HTF方向的交易需要更严格的信号确认
- HTF趋势改变前，MTF的所有反转都是小反转
- 只有当MTF反转确认 + HTF趋势线被突破 → 才考虑HTF反转
```

## 自动化多时间框架分析

```
输入：日线、4小时、1小时、5分钟K线数据
输出：多时间框架对齐判断

算法：
1. 分析HTF（日线）：判断趋势/区间/突破
2. 分析MTF（1小时）：判断趋势/区间/通道
3. 分析LTF（5分钟）：检测信号K线

对齐判断：
- HTF趋势 + MTF趋势 + LTF信号 = 3级对齐（最高概率，标准仓位）
- HTF趋势 + LTF信号 = 2级对齐（标准概率，0.75仓位）
- 仅LTF信号 = 1级对齐（低概率，0.5仓位）


```
