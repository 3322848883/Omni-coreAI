# 20根法则（20-Bar Rule）

> 20根法则是判断趋势持续性和背景有效性的重要工具。来自思维导图"20根法则"模块。
> 交叉参考：62_bar_counting_pullback.md AC.§9 20根法则与K线计数、AC.§13 Always In方向切换的K线数阈值

---

## 一、法则核心

```
20根法则：
- 当一段趋势运行少于20根K线时，顺势一方继续顺势的概率较大
- 当一段趋势运行超过20根K线时，不再依赖"背景"判断，多空概率回到50对50
- 超过20根K线后，市场更可能进入震荡、回调或反转阶段
```

### 核心含义

| K线数量 | 市场含义 | 交易策略 |
|---------|----------|----------|
| < 20根 | 趋势背景仍然有效 | 优先顺势交易 |
| ≈ 20根 | 临界点，警惕状态转换 | 减少仓位，观察信号 |
| > 20根 | 背景优势消失 | 不追势，等待明确新信号 |

## 二、20根法则在不同场景中的应用

### 2.1 顺势交易场景

```
当趋势刚开始（<20根）：
- 顺势入场胜率高
- 回调是入场机会
- 可以使用H1/H2等顺势信号
- 仓位可以标准或略加重

当趋势运行已久（>20根）：
- 顺势追入风险增大
- 需要更高质量的信号
- 警惕反转和 deep pullback
- 考虑减仓或观望
```

### 2.2 反转交易场景

```
当趋势<20根时：
- 第一次反转80%概率失败
- 不要急于逆势
- 等待第二次信号或趋势线突破

当趋势>20根时：
- 反转概率上升
- 但仍需完整反转结构
- 大反转需要：趋势线突破 + 测试旧极端 + 第二个信号
```

### 2.3 区间交易场景

```
区间持续时间<20根：
- 区间可能还在形成
- 边界可能不稳定
- 谨慎交易

区间持续时间>20根：
- 区间边界更可靠
- 高抛低吸胜率更高
- 突破后的测量移动也更有参考价值
```

## 三、20根法则与七状态结合

| 市场状态 | <20根K线 | >20根K线 |
|----------|----------|----------|
| 突破 | 顺势追入，高概率延续 | 警惕衰竭，不追入 |
| 窄通道 | H1/H2顺势入场 | 注意通道变宽或反转 |
| 宽通道 | H2顺势，高抛低吸 | 收缩阶梯，准备反转 |
| 小反转 | 80%失败，顺势入场 | 反转概率增加 |
| 大反转 |  rarely valid | 更可能发生 |
| 宽区间 | 边界可能不稳定 | 边界可靠，高抛低吸 |
| 窄区间 | 能量积累中 | 突破概率增加 |

## 四、20根法则与20GB的区别

| 概念 | 定义 | 用途 |
|------|------|------|
| 20根法则 | 一段趋势/区间持续约20根K线后背景优势消失 | 判断趋势延续概率 |
| 20GB | 连续20根K线未触及20EMA | 判断趋势极强但接近极端 |
| 均线缺口K线(MAGB) | 单根K线不触及EMA | 判断当前K线趋势强度 |

```
关系：
- 20GB是趋势极强的信号
- 20根法则告诉我们，即使趋势很强（20GB），超过20根后也要警惕
- 20GB后如果出现反向信号K线 → 高概率反转
```

## 五、实际应用检查清单

| # | 问题 | 处理方式 |
|---|------|----------|
| 1 | 当前趋势/区间已经运行了多少根K线？ | 数K线 |
| 2 | 是否少于20根？ | 优先顺势/按当前背景交易 |
| 3 | 是否超过20根？ | 不依赖背景，等待新信号 |
| 4 | 是否出现20GB？ | 极强趋势，但警惕反转 |
| 5 | 超过20根后是否有反转结构？ | 可考虑逆势（需完整结构） |
| 6 | 超过20根后是否仍在创新高/低？ | 趋势可能延续，但仓位降低 |

---

## 六、常见错误

1. **在趋势运行超过20根后仍重仓追势**——背景优势已消失
2. **趋势刚运行5-10根就急于做反转**——80%会失败
3. **忽视20根法则与20GB的结合**——极强趋势后反转更猛烈
4. **机械地数到20就反向**——需要结合形态和信号
