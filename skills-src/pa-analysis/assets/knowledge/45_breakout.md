## 一、突破定义

Al Brooks原文：

> "突破什么？任何支撑或阻力。每一个趋势烛台都是某种突破，即使只是前一根烛台的高点或低点。随着经验的积累，交易者将看到真正被突破的是什么。"（#3 突破）

> "在10种最佳价格行为交易模式中，突破是我最喜欢的，因为我喜欢高概率交易。"（Al Brooks #3 突破）

**核心定义**：突破是价格超越任何支撑或阻力位的行为。突破不仅限于大型形态，每根趋势K线本质上都是某种突破。突破是市场从一种状态（区间/通道）进入另一种状态（趋势）的过渡机制。

**突破的本质**（来自31_market_cycle.md §1.1）：
- 连续3根以上大趋势K线
- 实体之间几乎没有重叠
- 每根K线的低点（多头）在前一根K线收盘价处或仅低一跳
- K线没有影线或只有小影线，表明紧迫感

## 二、最常见的突破类型

> 来源：Al Brooks #3 突破

| # | 突破类型 | 描述 | 含义 |
|---|----------|------|------|
| 1 | **交易区间突破** | 价格突破区间上边界或下边界 | 区间结束，新趋势开始（80%失败） |
| 2 | **回调突破** | 价格突破回调的高点（牛）或低点（熊） | 回调结束，趋势恢复 |
| 3 | **前高/前低突破** | 价格突破之前的摆动高点或低点 | 趋势延续或反转 |
| 4 | **趋势线突破** | 价格突破主要趋势线 | 趋势可能终结（80%回到趋势线内） |
| 5 | **通道突破** | 价格突破通道线 | 趋势加速或反转（75%失败） |
| 6 | **移动平均线突破** | 价格突破EMA或其他关键均线 | 趋势方向变化 |

> "有时交易者需要切换到更高的时间框架来看突破。"（Al Brooks #3 突破）

## 三、真突破 vs 假突破对比表

> 来源：19_playbook.md 突破质量评估

| 特征 | 真突破（Strong Breakout） | 假突破（False Breakout） |
|------|--------------------------|--------------------------|
| **实体** | 大，明显大于近期平均 | 可能大但无跟进 |
| **影线** | 小或不存在 | 可能有长影线 |
| **收盘价** | 收在极端位置 | 回到区间内 |
| **距离** | 远离区间/突破点 | 未能远离 |
| **跟进** | 有后续K线确认 | 无跟进 |
| **急迫感** | 强，突破过程迅速 | 弱 |
| **成交量/动能** | 配合 | 缺乏 |
| **突破后回撤** | <50%或不回撤 | >50%或完全回撤 |
| **常见位置** | 趋势早期、引爆点 | 区间边界、趋势末端 |
| **交易策略** | 顺势追入或等小幅回调 | 不追突破，准备反向交易 |

### 3.1 弱突破（Weak Breakout）

| 特征 | 说明 |
|------|------|
| 突破K线实体较小 | 动能不足 |
| 有较长影线 | 多空分歧 |
| 突破后回踩较深 | 未能远离突破点 |
| 后续K线迅速回到区间内 | 突破失败 |
| **交易策略** | 不追入，等待回踩测试突破点 |

### 3.2 假突破的常见位置

> 来源：19_playbook.md

| 位置 | 机制 |
|------|------|
| 震荡区间的第二段陷阱 | 弱势一方让步，看似突破实则陷阱 |
| 区间边界附近的诱多/诱空 | 大部分人以为要突破 |
| 趋势末端的高潮K线 | 高潮后反转 |

## 四、突破后回撤的三种情况

> 来源：19_playbook.md 突破回踩的三种情况

| 情况 | 回撤幅度 | 趋势强度 | 交易策略 |
|------|----------|----------|----------|
| **情况1：无回撤** | 无 | 非常强势 | 不要等待回踩，直接追入或放弃 |
| **情况2：小幅回撤** | <50% | 正常强势 | 回踩是入场机会，止损在回踩低点下方 |
| **情况3：大幅回撤** | >50%或完全回踩 | 较弱或失败 | 多空概率回到50/50，重新评估，不急于入场 |

> "缺口越大，上涨/下跌趋势越强势。不要等待回踩，直接追入或放弃。"（19_playbook.md）

## 五、突破确认条件

> 来源：19_playbook.md、31_market_cycle.md

### 5.1 真突破的确认条件

| # | 条件 | 重要性 |
|---|------|--------|
| 1 | 突破K线收盘在极端位置 | 必须 |
| 2 | 突破K线实体明显大于近期平均 | 必须 |
| 3 | 后续K线有跟进（不回到区间内） | 必须 |
| 4 | 突破K线远离突破点 | 重要 |
| 5 | 成交量/动能配合 | 加分 |
| 6 | 突破过程有急迫感 | 加分 |

### 5.2 引爆点（Breakout Point of No Return）

> 来源：02_decision_tree.md

| 条件 | 阈值 |
|------|------|
| 突破K线实体 | > 3x 平均实体 |
| 成交量 | > 2x 平均成交量 |
| 策略 | 顺势追入（止损单），仓位 x 0.5-0.75 |

## 六、交易策略

> 来源：19_playbook.md Playbook 1、02_decision_tree.md

### 6.1 突破中的交易方式

| 策略 | 条件 | 做法 |
|------|------|------|
| **顺势追入** | 引爆点/真突破 | 突破K线高点+1 tick止损单入场 |
| **等BOP入场**（突破回撤） | 非引爆点/一般突破 | 回撤到突破点+信号K线确认后入场 |
| **不追弱突破** | 弱突破信号 | 等待更明确确认 |

> "好信号K线进场，强突破等 2nd leg 回调入场。"（19_playbook.md）

### 6.2 Playbook 1：突破完整操作手册

| 维度 | 规则 |
|------|------|
| **识别确认** | 连续3+根大趋势K线 · 实体间几乎无重叠 · 无影线或极小 · 急迫感 · 20+根K线不触及EMA |
| **优先信号** | H1/L1顺势入场 · 微趋势线突破失败入场 · 任何小回调处的市价追入 |
| **信号K线** | 趋势方向的强趋势K线（大实体、小尾巴）· 突破阶段不需要完美信号 |
| **入场** | 信号K线极值外1 tick止损单 · 或在回调K线收盘时市价入场 |
| **止损** | 信号K线反向极值外1 tick · 或最近的微摆动点外 |
| **目标** | 最小目标：前摆动高/低点 · 延伸目标：测量移动=突破前区间高度 |
| **仓位** | 初始仓位50-75% · 趋势确认后加至100% · 绝不逆势 |
| **管理** | 突破阶段不刮头皮——摆动持有至少到通道阶段出现 · 追踪止损用微趋势线 |
| **退出条件** | 出现3+根重叠K线（突破->窄通道转换）· 或大逆势K线突破微趋势线 |
| **禁用信号** | 任何逆势信号 · ii形态逆势突破 · 楔形反转 · 双顶/底做反转 |

## 七、概率

> 来源：31_market_cycle.md §4.3

### 7.1 突破失败概率

| 概率 | 条件 | 出处 |
|------|------|------|
| **80%** | 震荡区间突破失败 | 区间篇第1章 |
| **80%** | 趋势线突破后回到趋势线内 | 趋势篇 |
| **80%** | 趋势通道线穿越后回到通道内 | 趋势篇 |
| **80%** | 摆动高点/低点突破失败 | 趋势篇 |

### 7.2 突破成功概率

| 条件 | 概率 | 说明 |
|------|------|------|
| 趋势中的顺势突破 | 较高 | 趋势中突破成功率高 |
| 区间中的突破尝试 | 20% | 80%区间突破失败 |
| 引爆点突破 | 60-70% | 大实体+高成交量 |
| 区间收窄后突破 | 较高 | 能量积累+突破方向 |

### 7.3 关键概率洞察

| 场景 | 反转成功率 | 策略含义 |
|------|-----------|----------|
| 震荡区间突破 | 20% | 在区间边界逆势交易突破 |
| 趋势中反转尝试 | 80%失败 | 顺势交易，第一次反转=入场机会 |
| 通道突破 | 25%成功 | 通道线附近反转更常见 |

## 八、突破决策树速查

> 来源：02_decision_tree.md

```
趋势 -> 判断突破还是通道？
    [量化：连续趋势K线数 >= 5 且 平均重叠率 < 10% -> 突破]
    [量化：不满足以上 -> 通道]

    ├── 突破 -> 判断是否引爆点？
    │      [量化：突破K线实体 > 3x平均实体 且 成交量 > 2x平均成交量]
    │      ├── 是 -> 顺势追入（止损单）
    │      │      └── 入场：突破K线高点+1tick
    │      │      └── 止损：突破K线低点-1tick
    │      │      └── 仓位：标准仓位 x 0.5-0.75
    │      └── 否 -> 等待BOP（突破回撤）
    │             └── 入场：回撤到突破点+信号K线
    │             └── 止损：回撤极值外
```

## 九、突破与状态转换

> 来源：19_playbook.md 状态转换规则

| 从 | 到 | 关键信号 |
|----|-----|----------|
| 突破 -> 窄通道 | 回撤出现、K线开始重叠 | 持续持有/等H1入场 |
| 宽区间 -> 突破 | 引爆点、连续突破K线 | 追入突破方向 |
| 窄区间 -> 突破 | 能量积累释放、缺口 | 突破方向入场 |

## 十、核心原则总结

| # | 原则 | 出处 |
|---|------|------|
| 1 | 突破任何支撑或阻力，每根趋势K线都是某种突破 | Al Brooks #3 |
| 2 | 最常见的突破是交易区间、回调、前高前低、趋势线、通道、均线 | Al Brooks #3 |
| 3 | 80%区间突破失败，趋势中突破成功率高 | 31_market_cycle.md |
| 4 | 引爆点突破：实体>3x平均且成交量>2x平均 -> 顺势追入 | 02_decision_tree.md |
| 5 | 突破后无回撤 = 最强，不要等待直接追入 | 19_playbook.md |
| 6 | 突破后回撤<50% = 正常强势，回撤是入场机会 | 19_playbook.md |
| 7 | 突破后回撤>50% = 弱突破，重新评估 | 19_playbook.md |
| 8 | 假突破常见于区间第二段陷阱和趋势末端高潮 | 19_playbook.md |
| 9 | 突破阶段不刮头皮，摆动持有至少到通道阶段 | 19_playbook.md |
| 10 | 有时需要切换到更高时间框架看突破 | Al Brooks #3 |

---

> **核心洞见**：突破是趋势的起点。80%的区间突破会失败，但一旦突破成功，利润空间巨大。关键区分：在区间中逆势交易突破（高概率），在趋势中顺势交易突破（高概率）。引爆点突破是最佳追入时机。
