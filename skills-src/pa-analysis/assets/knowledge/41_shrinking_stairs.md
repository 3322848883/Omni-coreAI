## 一、收缩阶梯定义

收缩阶梯（Shrinking Stairs）是一系列三个或更多趋势高点（牛）或低点（熊），每个突破到新极端的跳数比前一个少，表明动量减弱。

> 来源：31_market_cycle.md §3.1："一系列三个或更多趋势高点（牛）或低点（熊），每个突破到新极端的跳数比前一个少，表明动量减弱。"

| 要素 | 说明 |
|------|------|
| 中文 | 收缩阶梯 |
| 英文 | Shrinking Stairs |
| 本质 | 动能减弱的量化信号 |
| 核心特征 | 每次突破新极端的跳数递减 |
| 出现位置 | 宽通道中，趋势末端 |
| 含义 | 趋势动量减弱，可能反转 |

## 二、量化识别

> 来源：31_market_cycle.md §3.1

| 突破次序 | 跳数 | 与前次对比 | 含义 |
|----------|------|-----------|------|
| 第一次突破 | 14跳 | — | 初始动能 |
| 第二次突破 | 10跳 | 减少4跳（-29%） | 动能减弱 |
| 第三次突破 | 6跳 | 减少4跳（-40%） | 动能显著减弱 |

**量化规则**：最近3次回撤/突破深度递减。

| 判断标准 | 操作 |
|----------|------|
| 3次突破深度递减 | 确认收缩阶梯 |
| 第三次更小突破 | 准备反转信号 |
| 递减幅度越大 | 反转概率越高 |

## 三、作为宽通道→震荡区间的核心转换信号

> 来源：31_market_cycle.md §2.2 转换三

收缩阶梯是宽通道向震荡区间转换的最重要信号。

| 转换阶段 | 信号 | 交易动作 |
|----------|------|----------|
| 宽通道中 | 识别到收缩阶梯 | 停止顺势追入 |
| 第三次更小突破后 | 观察反转信号K线 | 准备反转 |
| 趋势线被突破 | 确认转换 | 从"趋势思维"转为"区间思维" |
| 高低点不再创新 | 区间形态形成 | 转为BLiSHS策略 |

> 来源：31_market_cycle.md §6.1 关键转换链路：
> "宽通道(状态3) → 收缩阶梯 → 小反转(状态4) → 大反转(状态5) → 宽区间(状态6)"

## 四、与楔形反转的关系

| 维度 | 收缩阶梯 | 楔形反转 |
|------|----------|----------|
| 本质 | 动能减弱的量化度量 | 收敛的价格结构 |
| 识别方式 | 量化：突破跳数递减 | 视觉：趋势线收敛 |
| 关系 | 收缩阶梯常伴随楔形 | 楔形常包含收缩阶梯 |
| 信号强度 | 收缩阶梯+楔形=最强反转信号 |

> 来源：31_market_cycle.md §3.5："许多三推反转符合阶梯或收缩阶梯趋势失败并反转的条件"

## 五、交易策略

### 5.1 入场策略

> 来源：31_market_cycle.md §3.1

| 步骤 | 操作 |
|------|------|
| 1 | 识别收缩阶梯（量化确认：3次突破深度递减） |
| 2 | 停止顺势追入 |
| 3 | 第三次更小突破后 → 观察反转信号K线 |
| 4 | 信号K线要求：强反转K线（大实体、小影线）+ 第二个信号确认 |
| 5 | 多头通道中收缩阶梯后 → 做空入场 |
| 6 | 空头通道中收缩阶梯后 → 做多入场 |

### 5.2 仓位管理

| 维度 | 规则 |
|------|------|
| 仓位 | 标准仓位 × 0.5（反转交易风险更高） |
| 逻辑 | 反转交易胜率低（约40%），需要更保守的仓位 |

### 5.3 信号K线标准

> 来源：31_market_cycle.md §3.1（来自theme5_reversals.md第2章）

| 标准 | 要求 |
|------|------|
| 实体 | 大实体 |
| 影线 | 小影线 |
| 跟进 | 接下来2-3根K线也应具有同向实体 |
| 收盘价 | 收盘价高于/低于许多先前K线的高点/低点 → 信号更强 |
| 超冲 | 反转始于从旧趋势通道线超冲（Overshoot）的反转 → 更强信号 |

## 七、决策树衔接

> 来源：31_market_cycle.md §6.1

```
宽通道 → 判断是否收缩阶梯？
    [量化：最近3次回撤深度递减 → 收缩阶梯]
    ├── 是 → 准备反转（等第二个信号）
    │      └── 信号：楔形反转 + 第二个信号确认
    │      └── 仓位：标准仓位 × 0.5
    └── 否 → 等H2入场（ABC回调）
```

## 八、收缩阶梯与高潮反转

> 来源：31_market_cycle.md §3.4

| 对比维度 | 收缩阶梯 | 高潮反转 |
|----------|----------|----------|
| 动能变化 | 逐渐减弱（递减） | 突然爆发后反转 |
| K线特征 | 突破越来越小 | 连续大K线后突然反转 |
| 识别难度 | 需要量化测量 | 视觉上明显 |
| 反转概率 | 中等（随收缩程度递增） | 较高 |

> Al Brooks原文："当有三个或更多推动且每个突破越来越小时 → 收缩阶梯。例：多头市场三推向上，第二推比第一推高10跳，第三推仅比第二推高7跳。这是动能减弱的信号，增加了两段反转的概率。"

## 九、实战检查清单

| # | 检查项 |
|---|--------|
| 1 | 当前市场是否在宽通道中？ |
| 2 | 最近3次突破是否可以用跳数量化？ |
| 3 | 突破深度是否递减？（如14→10→6跳） |
| 4 | 第三次更小突破后是否出现了反转信号K线？ |
| 5 | 反转信号K线是否满足大实体+小影线标准？ |
| 6 | 是否有第二个信号确认？ |
| 7 | 仓位是否已调整为标准仓位×0.5？ |
| 8 | 止损是否在趋势极端外？ |

---

> **核心原则**：收缩阶梯是量化趋势动能减弱的最重要工具。当每次突破都比前一次更小时，动量正在耗尽。结合楔形反转信号，收缩阶梯提供了从宽通道转为反转交易的最佳时机。仓位减半，等第二个信号确认。
