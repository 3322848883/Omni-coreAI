## 一、BOP定义

BOP（Breakout Pullback）即突破回撤建仓形态，是指在价格突破关键水平后，出现的价格回调或回撤的情况。常被用作进一步确认价格趋势的信号。

> 来源：theme12_abbreviations.md BOP词条："指的是在价格突破关键水平后，出现的价格回调或回撤的情况。常被用作进一步确认价格趋势的信号。"

| 要素 | 说明 |
|------|------|
| 全称 | Breakout Pullback |
| 中文 | 突破回撤建仓形态 |
| 发生时机 | 突破后几个K线内 |
| 回撤幅度 | 1到约5根K线的小幅回撤 |
| 核心条件 | 不破突破点 |
| 信号含义 | 趋势延续的强确认信号 |

> 来源：SKILL.md §1.2："突破后几个K线内发生的1到约5根K线的小幅回撤"

## 二、BOP与突破测试的区别

| 维度 | BOP（突破回撤） | 突破测试（Breakout Test） |
|------|----------------|--------------------------|
| 回撤幅度 | 小幅（<50%突破幅度） | 可能更大（接近50%或更多） |
| 是否触及突破点 | 不触及突破点 | 可能触及或接近突破点 |
| 趋势强度 | 强趋势信号 | 趋势确认信号 |
| 入场时机 | 回撤过程中入场 | 测试后反弹入场 |
| 可靠性 | 高（趋势延续确认） | 中等 |

### 完美突破测试（Perfect Breakout Test）

当价格回撤精确测试突破点、然后反转回升时，称为"完美突破测试"。这是最强的突破确认信号之一。

> 来源：19_playbook.md："他们特别喜欢测试突破点的回调，然后反转回升。"

## 三、BOP的识别

| 识别要素 | 判断标准 |
|----------|----------|
| 前提 | 市场已发生有效突破（突破关键支撑/阻力） |
| 回撤K线数 | 1-5根K线 |
| 回撤幅度 | 小幅，不超过突破K线实体的50% |
| 关键条件 | 回撤不破突破点 |
| 确认信号 | 回撤后出现顺应原突破方向的K线 |
| 突破K线要求 | 实体大、收盘极端、有急迫感 |

| 特征 | 真突破后的BOP | 假突破后的"BOP" |
|------|-------------|----------------|
| 突破K线实体 | 大 | 可能大但无跟进 |
| 突破K线收盘 | 极端 | 回到区间内 |
| 回撤幅度 | 小（<50%） | 可能完全回撤 |
| 跟进 | 有 | 无 |
| 可靠性 | 高 | 低（陷阱） |

## 四、BOP与最终旗形的关系

BOP与最终旗形（Final Flag）存在直接的转换关系：

> 来源：31_market_cycle.md §3.3："失败的最终旗形：如果最终旗形突破未能反转市场，变成突破回撤建仓形态（BOP）——这是趋势延续的强信号。"

| 场景 | 形态 | 结果 |
|------|------|------|
| 最终旗形成功 | 趋势末端旗形 → 突破反转 | 趋势反转 |
| 最终旗形失败 | 趋势末端旗形 → 未能反转 | 变成BOP，趋势延续 |
| BOP = 失败的最终旗形 | 原趋势方向恢复 | 趋势延续强信号 |

**核心逻辑**：最终旗形预期趋势反转，但如果反转失败、原趋势恢复，那么这个"失败的最终旗形"就变成了BOP——原趋势方向上的突破回撤建仓形态。这是趋势延续的最强信号之一。

> 来源：SKILL.md §11（失败处理）："最终旗形失败 → 原趋势方向入场"

## 五、交易策略

### 5.1 入场策略

| 策略 | 操作 |
|------|------|
| 入场位置 | 突破回撤处入场（回撤到突破点附近但不破） |
| 入场方式 | 限价单在回撤区域入场 |
| 止损位置 | 突破点下方（多头）或突破点上方（空头） |
| 止损距离 | 紧止损（因为回撤不破突破点） |

### 5.2 仓位管理

| 维度 | 规则 |
|------|------|
| 初始仓位 | 50-75% |
| 趋势确认后 | 加至100% |
| 止损 | 突破点反向侧1-2 tick |

> 来源：19_playbook.md Playbook 1（突破模式）

### 5.3 目标设置

| 目标类型 | 计算方法 |
|----------|----------|
| 最小目标 | 前摆动高/低点 |
| 延伸目标 | 测量移动 = 突破前区间高度 |
| 趋势强可摆动持有 | 追踪止损用微趋势线 |

## 七、BOP在不同市场状态中的表现

| 市场状态 | BOP含义 | 交易策略 |
|----------|---------|----------|
| 突破（Breakout） | 突破后回撤确认 | 顺势追入，等BOP |
| 窄通道（Tight Channel） | 趋势线回调确认 | 回调至趋势线入场 |
| 宽通道（Broad Channel） | 趋势线附近H2入场 | 顺势摆动 |
| 震荡区间（Trading Range） | 突破后的回撤确认 | 等突破确认后入场 |

## 八、实战检查清单

| # | 检查项 |
|---|--------|
| 1 | 突破是否有效？（大实体+收盘极端+有跟进） |
| 2 | 回撤是否小幅？（1-5根K线，不破突破点） |
| 3 | 回撤幅度是否小于突破K线实体的50%？ |
| 4 | 回撤后是否出现顺应原方向的信号K线？ |
| 5 | 止损位置是否合理？（突破点外1-2 tick） |
| 6 | 是否排除了假突破的可能？（突破K线有跟进） |

---

> **核心原则**：BOP是趋势延续的强确认信号。失败的最终旗形 = BOP = 趋势延续的最强信号之一。回撤不破突破点是BOP的核心识别条件。
