# 失败处理与再入场（Failure Handling and Re-entry）

## 失败类型与处理

### 突破失败（Failed Breakout）

```
定义：突破后未能持续，价格回到突破水平之内
识别：突破K线后的3-5根K线内回撤超过突破水平
处理：
  1. 立即平仓（如果已入场）
  2. 记录失败突破
  3. 观察反向交易机会（失败突破 = 反向信号）

失败突破的再入场：
  - 如果价格回到突破水平后出现反向信号K线 → 逆突破方向入场
  - 失败突破 + 双顶/底 → 高概率反向交易
```

### 失败H1/H2（Failed Entry Signal）

```
失败Low1/Low2：
  - Low1/Low2信号触发后，价格未达到1倍风险就反转
  - 原因：趋势弱、信号K线质量差、不在关键价位

失败H1/H2：
  - H1/H2信号触发后，价格未达到1倍风险就反转
  - 原因：同上

处理：
  1. 止损触发后不立即再入场
  2. 等待下一个明确的信号
  3. 如果连续失败2次 → 重新评估市场状态
```

### 扭转失败（Failed Reversal）

```
定义：反转信号触发后，反转失败，原趋势恢复
识别：大反转信号+第二个信号确认 → 但第二个信号失败
处理：
  1. 如果已入场反转 → 止损
  2. 如果出现扭转失败 → 原趋势方向入场
  3. 扭转失败是极强的顺势信号
```

### 最终旗形失败（Failed Final Flag）

```
定义：最终旗形突破后，未能使市场反转，突破方向恢复原趋势
识别：楔形/三推后突破失败 → 原趋势方向强力恢复
处理：
  1. 如果已入场反转 → 立即止损
  2. 原趋势方向入场 → 这是最强的顺势信号之一
```

## 连续亏损处理

### 亏损纪律

```
连亏1笔：正常，继续交易
连亏2笔：冷静15分钟，停止交易
连亏3笔：当日停止交易，进行复盘
连亏4笔+：当日停止交易，减仓至50%，检查系统是否有问题
```

### 亏损后心理恢复

```
步骤1：承认亏损（30秒）
  - 亏损是交易的一部分
  - 不要自责，不要愤怒

步骤2：分析原因（2分钟）
  - 是系统问题还是执行问题？
  - 如果是系统问题 → 需要改进规则
  - 如果是执行问题 → 需要加强纪律

步骤3：冷静期（15分钟）
  - 离开屏幕
  - 做深呼吸
  - 不做任何交易相关的事

步骤4：重新评估
  - 情绪回到1-2级？
  - 如果是 → 可以继续交易（减仓50%）
  - 如果否 → 当日停止交易
```

## 再入场规则

### 止损后再入场

```
条件（必须全部满足）：
1. 止损触发原因已明确（不是系统问题）
2. 情绪已恢复平静
3. 市场状态未变（或变化方向明确）
4. 新信号比原信号更可靠（优先级更高）
5. 如果原信号方向错误 → 考虑反向交易

不允许再入场的情况：
- 窄区间 → 等了很久的突破失败 → 不等了，寻找其他机会
- 连续亏损后 → 不追单
- 同价位同方向 → 不重复入场
```

### 止盈后再入场

```
条件（必须全部满足）：
1. 趋势仍在持续
2. 出现新的回撤和信号K线
3. 不是趋势过度延伸的位置
4. 新信号与旧信号方向一致
5. 仓位不超过标准仓位的1.5倍

止盈后再入场的最佳时机：
- 趋势中回撤到EMA后出现H1/H2
- 通道中回撤到通道线后出现信号K线
- 突破后回撤（BOP）完成
```

## 自动化失败处理

```
伪代码：
function handle_failure(trade_result, account_state):
    // 更新连续亏损计数
    if trade_result == LOSS:
        account_state.consecutive_losses += 1
    else:
        account_state.consecutive_losses = 0
    
    // 检查止损规则
    if account_state.consecutive_losses >= 2:
        return COOLDOWN_15_MINUTES
    
    if account_state.consecutive_losses >= 3:
        return STOP_FOR_DAY
    
    // 检查日内亏损
    if account_state.daily_loss >= account_state.max_daily_loss:
        return STOP_FOR_DAY
    
    // 检查失败类型
    if trade_result.failure_type == FAILED_BREAKOUT:
        // 观察反向交易机会
        return WAIT_FOR_REVERSE_SIGNAL
    
    if trade_result.failure_type == FAILED_REVERSAL:
        // 扭转失败 → 原趋势方向
        return LOOK_FOR_TREND_RESUMPTION
    
    // 正常 → 等待下一个信号
    return WAIT_FOR_NEXT_SIGNAL
```
