# AJ. 期权交易规则（Option Trading Rules）

> 来源：Al Brooks《反转篇》第23章+第12章
> 场记指南参考：pa-trading-field-guide.html AJ章节

## 概述

Al Brooks的10条期权交易核心规则，涵盖ITM期权选择、时间衰减管理、Delta选择、隐含波动率考量和垂直价差策略。这些规则是Brooks将价格行为分析与期权交易融合的实战总结。

## 7条核心规则

| # | 规则 | 要点 |
|---|------|------|
| 1 | ITM期权选择 | 选择价内(ITM)期权，Delta 0.60-0.80 |
| 2 | 时间衰减管理 | 避免买入到期日<30天的期权 |
| 3 | Delta选择 | 0.60-0.80范围，过高权利金成本高，过低杠杆不足 |
| 4 | 隐含波动率(IV)考量 | 高IV时卖出期权，低IV时买入期权 |
| 5 | 垂直价差策略 | 用垂直价差降低权利金成本和风险 |
| 6 | 止损逻辑 | 标的资产价格止损，非期权价格止损 |
| 7 | 仓位规模匹配 | 期权仓位等于等效股票仓位的Delta |

## 规则详解

### 规则1：ITM期权选择
Brooks的核心观点：永远选择价内(ITM)期权。原因：
- ITM期权Delta高（0.60-0.80），与标的价格联动紧密
- 价外(OTM)期权的Theta衰减过快，即使方向判断正确也可能亏损
- ITM期权的时间价值占比小，减少时间衰减的不利影响
- 避免选择深度ITM期权（Delta>0.90），权利金成本过高且杠杆不足

### 规则2：时间衰减管理
- 买入期权时，到期日应>30天
- 30天以内Theta加速衰减，方向正确也可能不赚钱
- 理想到期日：45-90天，平衡时间价值和权利金成本
- 如果持有到到期前2周仍未盈利，考虑平仓减少损失

### 规则3：Delta选择
| Delta | 特点 | 适用场景 |
|-------|------|----------|
| 0.40-0.60 | 轻微ITM，权利金较低 | 中等确信、波段交易 |
| 0.60-0.80 | 标准ITM，Brooks推荐 | 高确信趋势交易 |
| 0.80-0.95 | 深度ITM，权利金高 | 替代股票持仓 |

### 规则4：隐含波动率考量
- 低IV环境（IV Rank < 30%）：买入期权，权利金便宜
- 高IV环境（IV Rank > 70%）：卖出期权或使用垂直价差
- 财报、重大事件前IV通常上升 → 适合卖出策略
- 事件后IV崩溃 → 买入期权持有者受损

### 规则5：垂直价差策略
- 牛市垂直价差：买入ITM Call + 卖出OTM Call
- 熊市垂直价差：买入ITM Put + 卖出OTM Put
- 优势：降低净权利金支出、限制最大亏损、减少IV影响
- 代价：限制最大盈利

### 规则6：止损逻辑
- 止损基于标的资产价格，而非期权价格
- 例如：买入BTC Call，止损设在BTC的PA止损位，不管期权价格如何
- 期权价格受IV、时间衰减等多因素影响，不适合作为止损参考
- 提前计算好：如果标的价格到达止损位，期权大约值多少钱

### 规则7：仓位规模匹配
- 期权仓位 = 等效股票仓位 / Delta
- 例如：想控制100股等效仓位，Delta=0.70 → 买入约143股期权（100/0.70）
- 不按此规则可能导致实际杠杆远超预期

## 策略矩阵

| 市场观点 | 策略 | 适用条件 |
|----------|------|---------|
| 看涨（高确信） | 买入Call | 低IV、趋势确认 |
| 看涨（中等确信） | 牛市垂直价差 | 中等IV、降低权利金成本 |
| 看跌（高确信） | 买入Put | 低IV、反转确认 |
| 看跌（中等确信） | 熊市垂直价差 | 中等IV、降低权利金成本 |
| 区间震荡 | 铁鹰/Iron Condor | 高IV、区间确认 |
| 不确定性 | 不交易 | 任何时间 |

## 风险逆转策略（Risk Reversal）

风险逆转 = 卖出OTM期权融资买入反向OTM期权：
- 牛市风险逆转：卖出OTM Put + 买入OTM Call（零成本或低成本）
- 熊市风险逆转：卖出OTM Call + 买入OTM Put
- 适用场景：隐含波动率偏高时
- 风险：如果方向判断错误，裸卖期权可能带来无限亏损

## 代尔塔中性（Delta Neutral）

Delta中性 = 同时持有Call和Put，使总Delta接近0：
- 适用场景：预期大波动但方向不确定
- 典型做法：买入跨式(Straddle)或宽跨式(Strangle)
- 要求：IV不能太高，否则权利金成本过大
- 风险管理：如果波动未如期出现，时间衰减将导致损失

## 期权交易与PA分析的结合

1. 先用PA分析确定方向和级别
2. 根据确信度选择策略（高确信→裸买，中等确信→价差）
3. 根据IV环境调整策略（低IV买，高IV卖）
4. 止损基于PA关键位，非期权价格
5. 仓位计算考虑Delta等效
