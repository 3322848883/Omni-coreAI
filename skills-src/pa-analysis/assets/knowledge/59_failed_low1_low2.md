# AP. 失败Low1/Low2（Failed Low1/Low2）

> 来源：Al Brooks三部曲
> 场记指南（原文语料，未随技能打包）AP章节

## Low1/Low2/High1/High2 基础回顾

| 术语 | 定义 | 位置 |
|------|------|------|
| High1/Low1 | 牛旗/熊旗中第一次出现的高/低点 | 回调早期 |
| High2/Low2 | 第二次出现的H1/L1 | ABC回调C点 |
| High3/Low3 | 第三次出现 | 楔形旗形 |

## 什么是失败Low1/Low2

在空头趋势中，Low1或Low2入场信号出现后，价格未能继续下跌，反而反转上涨。这是空头趋势走弱的信号，也是Brooks认为最重要的趋势反转预警信号之一。

### 核心逻辑
当空头按规则在Low1/Low2入场做空后，价格不跌反涨：
- 空头被套 → 被迫止损平仓 → 产生买入压力
- 买入压力推动价格进一步上涨
- 更多空头被套 → 正反馈循环
- 最终可能导致趋势反转

## 识别条件

### Low1失败的条件
1. Low1信号K线出现（熊旗中第一个低点）
2. 后续K线未能跌破信号K线低点
3. 价格反转向上突破信号K线高点
4. 通常伴随被困空头止损

### Low2失败的条件
1. Low2信号K线出现（ABC回调的C点）
2. 后续K线未能跌破信号K线低点
3. 价格反转向上突破信号K线高点
4. Low2失败比Low1失败更可靠（因为Low2是更好的入场点）

### 失败High1/High2
同理，在多头趋势中：
- High1失败 → 多头趋势减弱
- High2失败 → 多头趋势可能反转
- High2失败比High1失败更可靠

## 失败程度的判断

| 失败程度 | 特征 | 含义 |
|----------|------|------|
| 轻微失败 | 价格短暂反转后恢复，1-3根K线 | 趋势仍在，只是回调 |
| 中度失败 | 价格反转持续5-10根K线 | 趋势走弱，警惕 |
| 严重失败 | 价格反转形成新的趋势方向 | 趋势可能反转 |

## 交易含义

| 场景 | 含义 | 交易策略 | 止损 |
|------|------|----------|------|
| Low1失败 | 空头趋势减弱 | 准备做多，等确认 | - |
| Low2失败 | 空头趋势可能反转 | 做多 | Low2极值外 |
| High1失败 | 多头趋势减弱 | 准备做空，等确认 | - |
| High2失败 | 多头趋势可能反转 | 做空 | High2极值外 |

## 被困交易者效应详解

失败Low1/Low2的核心驱动力是"被困交易者"：

1. **空头入场**：空头在Low1/Low2按规则入场做空
2. **价格反转**：价格不跌反涨，空头被套
3. **止损触发**：空头被迫止损平仓 → 买入订单
4. **正反馈**：买入压力推动价格进一步上涨
5. **更多空头被套**：价格上涨触发更多空头止损
6. **加速反转**：止损单集中触发，价格加速上涨

这就是为什么失败Low2往往是强反转信号——因为它触发了大量空头止损。

## 失败之失败（Failed Failure）

失败Low1/Low2也有失败的可能，这被称为"失败之失败"：

### 识别
- 价格短暂反转后恢复原趋势
- Low2失败后，价格再次下跌并跌破Low2
- 这是突破回撤（BOP）的变体

### 交易策略
- 失败之失败 = 顺势入场的高概率机会
- 价格恢复原趋势方向
- 这表明原趋势仍然强劲
- 止损设在反转极值外

## 决策树

```
Low1/Low2失败
├── 价格反转突破信号K线高点
│   ├── 反转持续>5根K线 → 趋势可能反转，准备反向交易
│   └── 反转<5根K线 → 可能只是回调，等待确认
├── 价格短暂反转后恢复原趋势
│   └── 失败之失败 → 顺势入场
└── 价格在信号K线范围内震荡
    └── 等待突破方向
```

## 概率数据

| 场景 | 反转概率 | 恢复概率 |
|------|:------:|:------:|
| Low1失败 | ~40% | ~60% |
| Low2失败 | ~60% | ~40% |
| High1失败 | ~40% | ~60% |
| High2失败 | ~60% | ~40% |

> Low2/High2失败比Low1/High1失败更可靠，约60%的概率导致趋势反转

## 实战应用

### 场景1：经典Low2失败做多
1. 空头趋势中，价格出现Low2入场信号
2. Low2信号K线后，价格不跌反涨
3. 一根大阳线突破Low2信号K线高点
4. 入场做多，止损在Low2下方
5. 目标：前一个摆动高点（至少1:2盈亏比）

### 场景2：失败之失败顺势做空
1. 空头趋势中，Low2失败出现
2. 价格短暂反弹后再次下跌
3. 价格跌破Low2
4. 入场做空，止损在反弹高点上方
5. 目标：测量移动目标

## 常见错误

1. **Low1失败就入场做多**：Low1失败可靠性低，应等Low2失败
2. **忽略失败之失败**：短暂反转后恢复原趋势是顺势入场机会
3. **止损设置过紧**：反转初期波动大，需要给价格足够空间
4. **不等待确认**：必须在信号K线高点被突破后才入场
