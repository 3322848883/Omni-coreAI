# AO. 限价单 vs 止损单决策矩阵（Limit vs Stop Order Matrix）

> 来源：Al Brooks三部曲
> 场记指南参考：pa-trading-field-guide.html AO章节

## 核心概念

限价单和止损单是两种完全不同的入场方式，选择哪种取决于市场状态、交易方向和你的交易逻辑。Brooks强调：**80%的交易者用错了入场方式**，这是导致亏损的主要原因之一。

## 决策矩阵

| 市场状态 | 顺势方向 | 逆势方向 |
|----------|---------|---------|
| **突破** | 止损单 | ❌ 不交易 |
| **窄通道** | 限价单(EMA回撤) | ❌ 不交易 |
| **宽通道** | 限价单(H2优先) | 限价单(通道线) |
| **交易区间** | 限价单(边界) | 限价单(边界) |
| **反转初期** | 止损单(等第二个信号) | 止损单(确认后) |
| **窄区间** | ❌ 不交易 | ❌ 不交易 |

## 选择原则

### 使用止损单的场景
- **突破确认**：需要方向确认，突破后追入
- **反转确认**：等第二个信号，确认反转有效
- **强趋势中不想错过**：趋势不会等你回调到限价单位置
- **缺口K线跟进**：缺口后价格快速移动，限价单无法成交
- **新闻事件后**：价格快速移动，需要止损单追入

### 使用限价单的场景
- **回调到EMA/趋势线**：提前挂单在EMA20附近
- **区间边界附近**：价格大概率到达边界后反转
- **通道线附近**：通道线是天然的反转点
- **有明确支撑/阻力位**：在这些位置提前挂限价单
- **窄通道中**：价格沿EMA有序运行，回调到EMA是入场点

### 使用市价单的场景
- **信号K线收盘确认**：收盘后立即市价入场
- **错过限价入场后的追入**：价格已经离开限价区域
- **紧急平仓**：需要立即退出
- **流动性充足时**：滑点成本可接受

## 优势对比

| 维度 | 止损单 | 限价单 |
|------|--------|--------|
| 成交确定性 | 价格到达必成交 | 可能不成交 |
| 价格优势 | 可能滑点 | 更好的价格 |
| 适用市场 | 趋势/突破 | 区间/回调 |
| 假突破风险 | 可能被假突破触发 | 不会被假突破触发 |
| 错过行情风险 | 较低 | 可能错过 |
| 心理压力 | 追高/追低压力大 | 等待回调压力小 |

## 按市场状态的详细决策

### 突破状态
- **顺势**：止损单。突破后价格快速移动，限价单等待回调可能错过行情
- **逆势**：不交易。突破中逆势是自杀行为
- **入场时机**：突破确认后，等待第一次回撤（PBT），用止损单入场

### 窄通道状态
- **顺势**：限价单。价格沿EMA20有序运行，回调到EMA是入场点
- **逆势**：不交易。窄通道中逆势风险极高
- **入场时机**：价格回调到EMA20附近，出现信号K线后，在信号K线外1tick挂止损单入场

### 宽通道状态
- **顺势**：限价单。H2入场优先，回调深度较大
- **逆势**：限价单。在通道线附近挂限价单，止损设在通道线外
- **入场时机**：顺势等H2回调，逆势在通道线附近

### 交易区间状态
- **顺势**：限价单。在区间边界附近挂限价单
- **逆势**：限价单。同上
- **入场时机**：价格接近区间边界时，提前挂限价单

### 反转初期
- **顺势**：止损单。等第二个信号确认反转
- **逆势**：止损单。确认后再入场
- **入场时机**：第一个反转信号出现后，等待第二个信号确认

## 成本分析

### 止损单成本
- 滑点：通常1-3tick（流动性差时可能更多）
- 心理成本：追高/追低的不适感
- 假突破成本：被假突破触发后止损

### 限价单成本
- 机会成本：可能无法成交，错过行情
- 等待成本：可能需要等待较长时间
- 方向错误成本：如果方向判断错误，限价单成交后可能立即亏损

## 常见错误

1. **趋势中用限价单**：趋势不会回调到你的限价位置
2. **区间中用止损单**：区间中的假突破频繁触发止损
3. **忽略市场状态切换**：从区间切换到突破时，未及时切换到止损单
4. **止损单入场后止损过紧**：需要给价格足够的波动空间
5. **限价单未成交后追高**：追高时往往在最高点

## 实战决策流程

```
1. 判断市场状态（七状态分类）
2. 确定交易方向（顺势/逆势）
3. 选择入场方式：
   ├── 趋势/突破 → 止损单
   ├── 区间/通道 → 限价单
   └── 不确定 → 不交易
4. 设定具体入场价位
5. 设定止损和目标
6. 执行并记录
```
