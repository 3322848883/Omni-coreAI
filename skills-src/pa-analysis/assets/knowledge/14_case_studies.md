# 实战案例演练（Case Studies）

> 来源：HTML指南附录O — 五个完整交易场景，覆盖七种市场状态
> 每个案例按完整交易闭环执行：市场背景 → 状态判断 → 信号确认 → 入场执行 → 持仓管理 → 复盘

---

## 案例1：突破追入（Breakout Entry）

**状态：突破 · 方向：多头 · 信号：H1 + 趋势K线**

| 步骤 | 操作 | 关键知识 |
|------|------|----------|
| 盘前分析 | 日线连续3日阳线，处于多头趋势早期。5分钟图标记前日高点为关键阻力 | HTF结构、关键价位 |
| 开盘判断 | 开盘后区间整理15分钟，随后大阳线突破区间上沿 → **突破状态** → Playbook 1 | 七状态分类、Playbook |
| 等待信号 | 突破后2根小回调K线（H1），回调幅度不到突破K线的1/3 | H1识别 |
| 评估信号K线 | 回调K线为小实体十字星。**突破状态下，丑陋的信号K线往往是好的** — 趋势太强，不给完美信号 | 信号K线评估 |
| 信号组合 | 单一H1 + 突破状态 = 标准确认。同时有均线缺口支持（价格远离EMA） | 信号组合矩阵 |
| 入场 | 仓位：50%（突破状态建议）。止损单：H1高点+1tick。止损：信号K线低点-1tick。目标：前日高点（MM=突破前区间高度） | 仓位规则、止损单 |
| 持仓管理 | 突破状态→不刮头皮，摆动持有。价格快速到达目标，获利了结 | 剥头皮vs波段 |
| 复盘 | 结果：盈利。系统正确+盈利。该状态胜率统计+1 | 每日复盘 |

**核心教训：**
- 突破状态中，趋势太强不给完美信号，接受"丑陋信号K线"
- 突破状态仓位降低至50%，因假突破风险高
- 突破状态不刮头皮，摆动持有让利润奔跑

## 案例2：窄通道H1入场（Tight Channel H1 Entry）

**状态：窄通道 · 方向：多头 · 信号：H1 + 微趋势线**

| 步骤 | 操作 | 关键知识 |
|------|------|----------|
| 开盘判断 | 价格沿微趋势线稳步上升，K线紧贴趋势线，回调不超过2根K线 → **窄通道多头趋势** → Playbook 2 | 窄通道识别 |
| 等待+评估 | 价格触及微趋势线后出现有下影线的小阳线 — H1回调信号。位置完美（正好在微趋势线上），影线表明空头尝试失败 | 信号K线位置评估 |
| 信号组合 | H1 + 微趋势线支撑 = **双重确认** → 可适当增加仓位 | 双重确认 |
| 入场 | 仓位：75%（窄通道标准）。止损单：H1高点+1tick。止损：H1低点-1tick。目标：通道线上沿 | 仓位规则 |
| 持仓管理 | 窄通道→部分刮头皮+部分摆动。价格到通道线获利50%，剩余50%追踪止损。价格突破通道线后继续持有（通道升级为突破） | 分批止盈、追踪止损 |
| 复盘 | 结果：大盈利（摆动部分继续获利）。系统正确+盈利 | 复盘记录 |

**核心教训：**
- 窄通道中信号位置完美（微趋势线）时，可增加仓位
- 窄通道建议部分刮头皮+部分摆动，兼顾安全与利润
- 通道线突破 → 状态升级为突破，继续持有摆动部分

## 案例3：宽通道H2入场（Broad Channel H2 Entry）

**状态：宽通道 · 方向：多头 · 信号：H2 + 趋势线 + DBS**

| 步骤 | 操作 | 关键知识 |
|------|------|----------|
| 开盘判断 | 价格在上升，但回调幅度大（5-10根K线），有明显高低点抬高 → **宽通道多头趋势**。注意：通道宽度在缩小→"收缩阶梯"警告，可能酝酿大反转 | 宽通道识别、收缩阶梯 |
| 等待信号 | 第一次回调（H1）深度不够，放弃。第二次回调触及主要趋势线，形成H2结构 | H2 vs H1选择 |
| 评估信号K线 | H2信号K线：长下影线多头反转K线，收盘高于开盘，下影线约1/3K线高度，上影线极小。位置：正好在趋势线支撑 | 高质量信号K线 |
| 信号组合 | H2 + 趋势线支撑 + DBS（空头在趋势线处失败）= **三重确认** → 可满仓 | 三重确认 |
| 入场 | 仓位：100%（三重确认）。入场：H2高点+1tick。止损：H2低点-1tick。注意"收缩阶梯"警告→目标保守设为通道线 | 仓位规则、收缩阶梯 |
| 持仓管理 | 宽通道顺势→摆动持有。到通道线全部获利。不追延伸目标，因为"收缩阶梯"警告尚在 | 宽通道摆动 |
| 复盘 | 结果：盈利。虽然错过后续突破，但按系统规则在通道线退出是正确的 — "收缩阶梯"警告意味着宁可少赚不要冒险 | 纪律执行 |

**核心教训：**
- 宽通道中H2比H1更可靠，等第二次回调
- 收缩阶梯警告 → 降低目标，不贪心
- 三重确认可满仓（但需注意收缩阶梯）

## 案例4：宽区间边界反转（Broad Range Boundary Reversal）

**状态：宽区间 · 方向：区间内反转 · 信号：双底 + ii突破 + 区间下边界**

| 步骤 | 操作 | 关键知识 |
|------|------|----------|
| 开盘判断 | 价格在明确横向区间内运行，宽度约30 tick。HH和HL不明确 → **宽区间** → Playbook 6 | 宽区间识别 |
| 等待信号 | 价格下跌至区间下边界。形成两根低点相近的K线→微型双底。随后出现ii形态（两根内包K线） | 双底、ii形态 |
| 评估+组合 | 双底 + ii形态 + 区间下边界 = **三重确认**。ii突破方向：向上突破时入场 | 三重确认、ii突破 |
| 入场 | 仓位：100%（三重确认）。入场：ii突破高点+1tick。止损：双底低点-1tick。目标：区间上边界 | 区间边界入场 |
| 持仓管理 | 区间内→到达区间中线移止损到盈亏平衡→到达区间上边界获利了结。**80%的区间突破会失败**，不贪心追突破 | 80%规则 |
| 复盘 | 结果：盈利。区间边界交易的高胜率再次验证。三重确认在区间边界特别有效 | 区间边界经验 |

**核心教训：**
- 区间边界处的多重确认信号最可靠
- 80%的区间突破会失败 → 在边界获利了结，不追突破
- 区间中线移至盈亏平衡是标准做法

## 案例5：大反转楔形（Major Reversal Wedge）

**状态：大反转 · 方向：多头→空头反转 · 信号：上升楔形H3 + 趋势线突破**

| 步骤 | 操作 | 关键知识 |
|------|------|----------|
| 开盘判断 | 价格在上升，但每次推升幅度越来越小，形成上升楔形（三个递升高点，但上升速度减慢）→ **楔形警告大反转** → Playbook 5 | 楔形识别、大反转 |
| 等待信号 | 楔形第三个高点（H3）形成后，价格开始下跌。跌破楔形趋势线→第一信号。等待回测 | 趋势线突破 |
| 评估+组合 | 趋势线突破后回测（原支撑变阻力），回测处形成空头反转K线（上影线长、实体向下）。楔形H3 + 趋势线突破 + 回测空头信号 + 双顶（H2和H3高点相近）= **四重确认** | 四重确认、回测 |
| 入场 | 仓位：仅25%（大反转胜率低约40%）。入场：回测空头信号K线低点-1tick。止损：信号K线高点+1tick。目标：楔形起点（MM） | 大反转仓位、MM目标 |
| 持仓管理 | 大反转→摆动持有，不刮头皮。因胜率低，必须让盈利交易充分奔跑以弥补亏损交易。到达目标全部获利 | 盈亏比管理 |
| 复盘 | 结果：大盈利。四重确认的大反转虽胜率低，但盈亏比极高（约1:4）。验证了"大反转用轻仓+大目标"策略 | 盈亏比验证 |

**核心教训：**
- 大反转胜率低（~40%），必须用轻仓+大目标
- 楔形+趋势线突破+回测+双顶 = 四重确认，可靠性极高
- 大反转不刮头皮，必须让利润充分奔跑
