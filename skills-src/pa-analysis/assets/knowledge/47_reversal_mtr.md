# 反转/MTR（Major Trend Reversal）深度解析

> 来源：Al Brooks QQ新闻文章「10种最佳价格行为模式 #1 主要趋势逆转」、31_market_cycle.md 转换部分、19_playbook.md Playbook 4/5、15_pattern_recognition.md 形态部分、SKILL.md
> 适用：pa-trading-system 完整交易系统 -- 反转识别与交易策略

## 一、MTR定义

Al Brooks原文：

> "上涨趋势是一系列更高的低点和高点，下跌趋势是一系列更低的高点和低点。交易主要趋势反转形态是尝试在新趋势开始时入市，希望随后出现一系列趋势高点和低点。"（#1 主要趋势逆转）

**核心定义**：

| 趋势类型 | 定义 | 反转条件 |
|----------|------|----------|
| 上涨趋势 | HH（更高高点）+ HL（更高低点） | 不再出现HH+HL，出现LH+LL |
| 下跌趋势 | LH（更低高点）+ LL（更低低点） | 不再出现LH+LL，出现HH+HL |
| MTR | 在新趋势开始时入市 | 趋势线突破 + 测试极端 + 二次确认 |

## 二、MTR的组成部分

Al Brooks原文：

> "主要趋势逆转的组成部分包括：◎ 趋势 ◎ 突破通道的回调 ◎ 恢复趋势 ◎ 第二次回调，趋势反转"（#1 主要趋势逆转）

| 阶段 | 描述 | 市场行为 | 交易者心理 |
|------|------|----------|------------|
| 1. **趋势** | 原趋势运行中 | HH+HL或LH+LL持续 | 顺势方占主导 |
| 2. **突破通道的回调** | 第一次回调突破通道 | 趋势线/通道线被突破 | 部分交易者开始怀疑 |
| 3. **恢复趋势** | 趋势再次测试极端 | 可能创出新高/新低 | 大多数人认为趋势恢复 |
| 4. **第二次回调，趋势反转** | 反转确认 | 趋势线突破 + 测试极端后反转 | 新趋势开始 |

> "通常，首次突破狭窄的下跌通道影响较小。第二次反转有40%的可能性转变为重大反转。"（Al Brooks #1）

**MTR的演进路径**（来自31_market_cycle.md）：

```
突破 -> 窄通道 -> 宽通道 -> 收缩阶梯 -> 小反转 -> 大反转/MTR -> 宽区间 -> 新趋势
```

## 三、小反转 vs 大反转对比表

> 来源：02_decision_tree.md 反转子决策、19_playbook.md Playbook 4/5

| 维度 | 小反转（Minor Reversal） | 大反转/MTR（Major Trend Reversal） |
|------|--------------------------|-------------------------------------|
| **趋势线** | 未破主要趋势线 | 已破主要趋势线 |
| **测试极端** | 未测试旧极端 | 测试旧极端（前高/前低） |
| **方向** | 顺势（回调结束） | 逆势（新趋势开始） |
| **胜率** | 约70% | 约40% |
| **仓位** | 75% | <=50% |
| **信号** | 失败信号的反向入场 | 楔形反转 + 双顶底 + 二次确认 |
| **策略** | 被套交易者止损处顺势入场 | 等第二个信号，分两批入场 |
| **风险回报** | 中等 | 数倍于风险 |
| **升级条件** | 趋势线突破 -> 升级为大反转 | -- |
| **失败含义** | 趋势恢复 | 扭转失败 -> 原趋势方向入场（最强信号） |

### 3.1 小反转策略 -- 失败信号的反向入场

> 来源：19_playbook.md Playbook 5

Al Brooks核心思维：

> "被套交易者止损处入场（核心策略）——在逆势交易者被套的位置顺势入场。"

| 策略 | 细节 |
|------|------|
| **入场** | 在逆势信号K线反向极值外1 tick设顺势止损单 |
| **本质** | 在被套交易者的止损位入场 |
| **胜率** | 约70%（这是顺势交易） |
| **仓位** | 正常仓位75% |
| **目标** | 前趋势极端（测试）-> 创新极端 |

## 四、MTR概率

> 来源：31_market_cycle.md §4.2、Al Brooks #1

| 概率 | 条件 | 出处 |
|------|------|------|
| **~40%** | 平均MTR建仓形态产生盈利摆动（Swing Profit） | Brooks概率总结 |
| **40%** | 第二次反转转变为重大反转 | Al Brooks #1 |
| **60%** | 交易结果是小幅盈利和亏损，互相平衡 | Al Brooks #1 |
| **60%+** | 三波连续卖出高潮后，市场将试图形成至少两条腿上涨 | V3 P106 |
| **80%** | 紧密通道中反转尝试失败 | 趋势篇 |

Al Brooks原文：

> "由于交易者在新趋势明确之前入场，即使是最好看的设置的概率通常也只有40%。这些交易者正在寻找低风险（较紧止损），但几乎总是伴随低概率出现。"（#1）

> "想要更高概率的交易者通常会等待反转在新方向上有强劲的突破。此时，波段交易的概率通常是60%或更高，但止损点会较远。风险的增加是一种权衡。"（#1）

## 五、大反转的5个条件

> 来源：19_playbook.md Playbook 4、Al Brooks #1

| # | 条件 | 说明 | 必要性 |
|---|------|------|--------|
| 1 | **趋势线突破** | 强趋势K线突破主要趋势线 | 必须 |
| 2 | **测试趋势极端** | 更高高点/双顶（牛转熊）或更低低点/双底（熊转牛） | 必须 |
| 3 | **强反转K线** | 大实体、小尾巴、收盘价反转多条先前K线 | 必须 |
| 4 | **二次确认信号** | 等第二个信号，不急于第一信号入场 | 必须 |
| 5 | **至少3个理由** | 支持反转的多个技术理由叠加 | 必须 |

### 5.1 大反转优先信号（按优先级）

| 优先级 | 信号 | 特征 |
|--------|------|------|
| 1 | **楔形反转** | 趋势线突破后的三推 = 最强MTR形态 |
| 2 | **双顶/双底在趋势线突破后** | 测试极端 |
| 3 | **ii形态逆势突破** | 最终旗形反转 |
| 4 | **趋势线突破后的H2/L2二次入场** | 二次确认 |

### 5.2 信号K线标准

> 来源：19_playbook.md Playbook 4

| 维度 | 标准 |
|------|------|
| 实体 | 大实体 |
| 影线 | 小尾巴（入场方向） |
| 收盘价 | 反转多条先前K线的收盘价和高点/低点 |
| 最佳 | 反转K线收盘价反转了多条K线的收盘价和高点/低点 |

## 六、交易策略

> 来源：19_playbook.md Playbook 4、02_decision_tree.md

### 6.1 Playbook 4：大反转完整操作手册

| 维度 | 规则 |
|------|------|
| **识别确认** | 趋势线被强势突破（必须）· 测试趋势极端 · 测试时出现强反转K线 · 二次确认信号 · 至少3个理由支持反转 |
| **入场** | 等待第二个信号——不急于第一信号入场 · 在第二个信号K线极值外1 tick止损单入场 |
| **止损** | 测试极端的反向侧（更高高点上方/更低低点下方）1 tick |
| **目标** | 最小目标：测量移动=楔形/形态高度 · 延伸目标：前主要摆动点 · 最终目标：原趋势起点方向 |
| **仓位** | <=50%仓位（胜率仅40%）· 分两批入场：第一信号25% + 第二信号25% |
| **管理** | 入场后立即设止损 · 第一目标到达后移止损至盈亏平衡 · 摆动持有剩余仓位 |
| **退出条件** | 二次入场失败（趋势恢复）->立即退出 · 或到达测量移动目标 |
| **禁用信号** | 无趋势线突破的"反转"信号 · 仅靠单一理由入场 · 在1分钟图上寻找反转 |

### 6.2 仓位管理

| 策略 | 做法 |
|------|------|
| **分两批入场** | 第一信号25% + 第二信号25% = 总仓位50% |
| **止损** | 测试极端反向侧1 tick |
| **盈亏平衡** | 第一目标到达后移止损至盈亏平衡 |
| **加仓** | 反转确认后（趋势线突破+跟进）可加至正常仓位 |

## 七、反转失败 -> 趋势延续

> 来源：02_decision_tree.md 反转子决策、19_playbook.md

### 7.1 扭转失败（Failed Reversal）

| 场景 | 结果 | 交易动作 |
|------|------|----------|
| 第二个信号失败 | 扭转失败、恢复原趋势 | 原趋势方向入场（最强信号之一） |
| 最终旗形失败 | 趋势延续 | 原趋势方向入场 |
| 趋势线突破后回到趋势线内 | 80%概率 | 顺势回撤入场 |

> "如果第二个信号失败 -> 扭转失败、恢复原趋势 -> 入场：原趋势方向入场（最强信号之一）-> 仓位：标准仓位 x 1.0"（02_decision_tree.md）

### 7.2 反转失败概率

| 场景 | 概率 | 后续 |
|------|------|------|
| 紧密通道中反转尝试 | 80%失败 | 趋势延续 |
| 趋势中第一次反转 | 80%失败 | 顺势入场机会 |
| MTR产生盈利摆动 | 40% | 60%小幅盈亏 |
| 楔形突破后继续新方向 | 50% | 50%反转失败 |

## 八、反转决策树速查

> 来源：02_decision_tree.md

```
趋势中出现了反向信号 -> 判断是小反转还是大反转？
    [量化：反向走势是否突破主要趋势线？]
    [量化：反向走势是否测试旧极端（前高/前低）？]

    ├── 小反转 -> 未破主要趋势线
    │      └── 顺势回撤入场（继续原趋势方向）
    │      └── 入场：回撤到支撑/阻力位
    │      └── 止损：回撤极值外
    │      └── 仓位：标准仓位 x 0.75

    └── 大反转/MTR -> 破趋势线+测试旧极端
           └── 等第二个信号确认 -> 逆势入场
           │      └── 信号：第二个信号K线触发
           │      └── 止损：第二信号极值外
           │      └── 仓位：标准仓位 x 0.5
           │
           └── 如果第二个信号失败 -> 扭转失败、恢复原趋势
                  └── 入场：原趋势方向入场（最强信号之一）
                  └── 仓位：标准仓位 x 1.0
```

## 九、大反转与形态的关系

> 来源：15_pattern_recognition.md

### 9.1 MTR常见形态

| 形态 | 可靠性 | 特征 |
|------|--------|------|
| **楔形反转** | ★★★★★ | 趋势末端收缩三推，等第二个信号 |
| **双顶/双底** | ★★★★ | 两次触及同一价位失败 |
| **头肩顶/底** | ★★★★ | 三次尝试+颈线突破 |
| **最终旗形** | ★★★ | 趋势末端窄幅旗形 |
| **高潮反转** | ★★★ | 连续大K线+影线+反转 |

### 9.2 楔形反转的可靠性

| 质量 | 特征 | 策略 |
|------|------|------|
| 优质楔形 | 有重叠、收敛明显、信号K线强 | 可波段反向交易 |
| 普通楔形 | 收敛一般、信号一般 | 剥头皮为主 |
| 劣质楔形 | 不收敛、无重叠、信号弱 | 不交易 |

> **核心洞见**：MTR是低概率（40%）但高回报的交易。成功的MTR交易需要5个条件全部满足，尤其是趋势线突破和二次确认。最安全的做法是等第二个信号。如果第二个信号失败，原趋势方向入场是最强信号之一。小反转和大反转的关键区别在于是否突破主要趋势线。

## 十一、反转命名纪律：MRV vs MTR

> 来源对照：同源价格行为体系对反转按严重度分级命名，避免"动不动就把小反转标成大反转（MTR）"的认知偏差。

| 命名 | 英文 | 含义 | 纪律 |
|------|------|------|------|
| **MRV** | Minor Reversal | 小反转，多半回撤/区间——**不单独作为交易信号** | 用"反转尝试（reversal attempt）"表达；**勿轻易标 mtr** |
| **MTR** | Major Trend Reversal | 主要趋势反转，需趋势线突破 + 前极点测试失败等完整条件 | 只有满足本模块 §五 的 5 个条件才可标 MTR |

**核心纪律**：
1. **多数"反转"其实只是回撤或区间**——趋势中第一次反转 80% 失败，是顺势入场机会（见 §十 原则 8）。
2. 只有**破主要趋势线 + 二次确认**的反转才升级为 MTR，进入大反转交易逻辑（§六）。
3. 标注时宁可保守：转未破趋势线前一律按 MRV/反转尝试处理，避免把高概率趋势回撤误当低概率反转入场。
