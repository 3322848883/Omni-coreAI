## 一、铁丝网定义

铁丝网（Barb Wire, BW）是紧凑的交易区间，K线重叠严重且方向不明确。铁丝网中不应交易，因为突破假突破概率极高，风险/回报比不利。

> 来源：theme12_abbreviations.md BW词条："紧凑的交易区间，K线重叠严重且方向不明确。铁丝网中不应交易，因为突破假突破概率极高，风险/回报比不利。"

| 要素 | 说明 |
|------|------|
| 全称 | Barb Wire (BW) |
| 中文 | 铁丝网 |
| 等价概念 | 窄区间（Tight Trading Range, TTR） |
| 核心特征 | 大量重叠K线、十字星多、振幅极小 |
| 交易规则 | **不交易！** |

## 二、识别特征

> 来源：19_playbook.md Playbook 7

| 识别特征 | 具体表现 |
|----------|----------|
| K线重叠 | 大量重叠K线，K线之间高低点反复交叉 |
| 十字星多 | 十字星/Doji频繁出现，实体极小 |
| 振幅极小 | 价格波动范围狭窄，利润空间不足 |
| 动量缺乏 | 双向都缺乏动量，突破方向无法判断 |
| 影线突出 | 上下影线多，表明多空双方都无力推动 |
| 方向不明 | 多空双方都无法确定方向 |

> 来源：SKILL.md §2.1："窄区间/铁丝网：K线大量重叠、影线突出、不宜交易"

## 三、铁丝网中的交易策略：不交易！

> 来源：19_playbook.md Playbook 7

| 维度 | 规则 |
|------|------|
| 优先信号 | **没有任何信号是可靠的。** H1/H2/L1/L2/ii/ioi/双顶底——全部不可靠。 |
| 信号K线 | 不评估——所有信号K线在此状态都是噪音 |
| 入场 | **不入场。** 等待窄区间被有效突破后再进入突破模式 |
| 止损 | 不适用 |
| 仓位 | **0%** ——空仓等待 |

> Al Brooks原文（19_playbook.md）："在窄区间中交易会在一小时内亏掉一周利润"

## 五、铁丝网后的突破

> 来源：19_playbook.md Playbook 7

### 5.1 能量积累释放

铁丝网持续时间越长，积累的能量越大，突破后的运动幅度越大。

| 维度 | 规则 |
|------|------|
| 测量移动 | 区间宽度 × 2-3 |
| 突破方向 | 无法预判，等突破后跟随 |
| 突破确认 | 大实体K线 + 收盘极端 + 急迫感 |
| 转换状态 | 铁丝网 → 突破 → Playbook 1 |

> 来源：19_playbook.md Playbook 7："如果窄区间持续时间长（能量积累），突破后的测量移动=区间宽度×2-3"

### 5.2 突破后的操作

| 步骤 | 操作 |
|------|------|
| 1 | 看到大实体K线+收盘极端+急迫 |
| 2 | 切换到Playbook 1（突破模式） |
| 3 | 顺势追入或等待小幅回调 |
| 4 | 目标：测量移动 = 铁丝网区间宽度 × 2-3 |

## 六、铁丝网出现的常见位置

| 位置 | 原因 | 后续 |
|------|------|------|
| 趋势末端 | 多空双方对方向产生分歧，动能耗尽 | 可能反转或进入更大区间 |
| 开盘后 | 市场在寻找方向，等待更多信息 | 可能突破或继续区间 |
| 重大数据前 | 交易者观望，等待数据公布 | 数据公布后突破 |
| 午盘时段 | 交易活跃度降低 | 可能持续至收盘 |
| 趋势中段 | 短暂休息/能量积累 | 趋势恢复 |

## 八、铁丝网中的陷阱

| 陷阱 | 说明 | 避免方法 |
|------|------|----------|
| 假突破 | 看似突破铁丝网但迅速反转 | 等待突破确认（大实体+跟进） |
| 信号幻觉 | 看到H1/H2/ii等信号，觉得可以交易 | 记住：铁丝网中所有信号都不可靠 |
| 无聊交易 | 因等待太久而随意入场 | 耐心等待，空仓也是交易 |
| 刮头皮诱惑 | 想在小波动中刮头皮 | 利润空间不足，手续费会吃掉利润 |

## 九、管理策略

> 来源：19_playbook.md Playbook 7

| 管理维度 | 规则 |
|----------|------|
| 核心策略 | 关注"窄区间持续多久了" |
| 新形成的窄区间 | 继续等待 |
| 持续时间久的窄区间 | 能量积累，准备突破入场 |
| 突破信号 | 大实体K线+收盘极端+急迫 → 切换到Playbook 1 |
| 退出条件 | 窄区间被有效突破 → 进入Playbook 1 |

## 十、实战检查清单

| # | 检查项 |
|---|--------|
| 1 | K线是否大量重叠、十字星多？ |
| 2 | 振幅是否极小、利润空间不足？ |
| 3 | 突破方向是否无法判断？ |
| 4 | 是否确认处于铁丝网状态？ |
| 5 | 如果是铁丝网 → 是否已空仓？ |
| 6 | 铁丝网已持续多久？（<20根K线→继续等；>20根→准备突破） |
| 7 | 是否出现了突破信号（大实体+收盘极端+急迫）？ |

---

> **核心原则**：铁丝网 = 窄区间 = 不可交易。所有信号在此状态都是噪音。最好的交易就是不交易。等待能量积累释放后的突破，测量移动 = 区间宽度 × 2-3。在铁丝网中交易会在一小时内亏掉一周利润。
