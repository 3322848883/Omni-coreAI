# AG. 完整概率数据手册（Probability Data Manual）

> 来源：Brooks概率总结 + 三部曲各章节概率数据
> 核心理念：概率是Al Brooks体系的核心。理解不同概率层级有助于交易者做出正确的交易决策。

## 概率层级体系

### 99.5%概率规则（3条）

| # | 规则 | 适用条件 |
|---|------|---------|
| 1 | 强劲多头趋势日至少3根K线低点低于EMA | 超过50根K线高于MA |
| 2 | 趋势日内触及EMA | 所有趋势日（无论多强） |
| 3 | 趋势日内至少1根K线收于EMA下方 | 所有趋势日 |

### 90%概率规则（6条）

|---|------|---------|

| 4 | HOD/LOD在日内前三分之一形成 | 所有交易日 |
| 5 | 每天至少3根K线收于EMA下方 | 所有交易日 |
| 6 | 前2小时内盈利摆动交易 | 日内前2小时（Bar 7之前） |

## 交易者方程式速查

> **注意：** 此表为数学推导（交易者方程式），非Brooks原文。Brooks没有给出精确的胜率与R:R对应表。此表用于理解胜率与回报的数学关系。

| 胜率 | 最低R:R（回报:风险） | 说明 |
|------|---------------------|------|
| 80% | 1:4（即0.25:1） | 胜率极高，可接受较小回报 |
| 70% | 1:1 | 回报至少等于风险 |
| 60% | 1:1 | 回报至少等于风险（盈亏平衡线） |
| 50% | 2:1 | 回报必须是风险的两倍 |
| 40% | 3:2 | 回报必须是风险的1.5倍 |
| 30% | 7:3 | 回报必须是风险的2.33倍 |

### 核心公式

**交易者方程 = (胜率 × 潜在回报) - (败率 × 风险)**

示例：60%胜率 × 2点回报 - 40%败率 × 2点风险 = 1.2 - 0.8 = +0.4（正期望值）

## 概率速查表（按场景）

| 场景 | 概率 | 策略 |
|------|------|------|
| 趋势日触及EMA | 99.5% | 等EMA回撤，不要追高/追低 |
| 每日至少一次摆动机会 | 90% | 耐心等待高概率架构 |
| 区间突破失败 | 80% | 在区间边界反向交易突破 |
| 首次反转失败 | 80% | 等第二个信号再入场 |
| 多头通道上方突破失败 | 75% | 做空突破（5棒内） |
| 高潮日次日形成区间 | 75% | 转为区间交易策略 |
| 趋势中H2/L2入场 | 60%+ | 标准仓位 |
| 区间边界双顶/底 | 60%+ | 标准仓位 |
| 楔形反转(等第二个信号) | 60%+ | 标准仓位 |
| 逆势单一信号 | <40% | 不交易，等更多确认 |

## 核心原则

1. **99.5%规则是"几乎确定"**：趋势日必触及EMA，但触及后未必是可交易的入场点
2. **80/20是核心框架**：趋势中80%反转失败，区间中80%突破失败——这是策略选择的基础
3. **60%是实际交易的优势上限**：即使最佳架构，胜率也很少超过60%
4. **概率与回报互补**：低胜率需要高回报，高胜率可接受低回报
5. **概率不是确定性**：60%只是90%情况中的60%，有时可能是90%，有时可能是10%

> **核心洞见**：理解概率不是用来预测单笔交易的结果，而是用来确保长期交易者方程为正。即使60%胜率的架构，也可能连续亏损——这是概率的本质，不是策略失效。
