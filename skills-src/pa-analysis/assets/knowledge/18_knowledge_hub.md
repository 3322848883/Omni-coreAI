## 三、信号棒判断标准（Brooks 原文）

> 以下全部来自 Al Brooks 原文（V1 P111-P118），不做主观量化。Brooks 不使用打分系统。
> 详细原文见：price-action-trading/theme15_signal_bar_standards.md

### 判断维度与原文出处

| 维度 | Brooks 原文标准 | 出处 |
|------|----------------|------|
| 收盘位置 | 收盘反转了多于一条棒线的收盘价和高/低点 → 更强 | V1 P118 |
| 影线质量 | 入场方向影线短或不存在；反方向影线约1/3到1/2棒线高度 | V1 P117 |
| 实体大小 | 中等实体最佳；十字星是单棒交易区间；耗尽棒太大 | V1 P117-118 |
| 位置优势 | 在磁铁/支撑/阻力/EMA关键位；背景 > K线形态 | 区间篇 Part II |
| 趋势位置 | 顺势对强信号棒要求低，逆势要求高；趋势早期优于过度延伸 | V1 P113 |

### 信号棒判断结论（二元/三元）

Brooks 不使用数字评分，而是做定性判断：

- **强信号棒**：满足全部5条最佳特征，在关键价位，顺势 → 可入场
- **中等信号棒**：满足部分特征，需第二个信号确认或在关键价位 → 降仓位或等确认
- **弱信号棒**：不满足关键特征，或在无意义区域 → 不入场

**核心原则**：趋势越强，顺势交易对强信号棒的要求就越低，逆势交易对强信号棒的要求就越高。最强的趋势通常有着外观丑陋的信号棒，但交易仍然是极好的。

### 信号组合判断

| 可靠性 | 组合 | Brooks 原文依据 |
|--------|------|----------------|
| 最高 | 趋势方向 + H2 + 强信号棒 + 磁铁附近 | "顺势交易总是最明智的选择" |
| 高 | 趋势方向 + H1 + 支撑/阻力 | "趋势越强，对信号棒要求越低" |
| 中高 | 双顶/底 + 区间边界 | 区间边界是最可靠的磁铁之一 |
| 中 | 楔形反转 + 第二个信号 | "大多数反转尝试会失败，应仅在一切完美时考虑反转" |
| 低 | 单一信号 | "架构棒本身不是入场理由" |
| 最低 | 逆趋势单一信号 | "初学者应避开所有逆势交易" |
