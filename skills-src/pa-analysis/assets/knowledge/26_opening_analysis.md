# 开盘分析（Opening Analysis）

> 开盘是全天最重要的信息窗口。开盘前15-30分钟的价格行为，往往决定了当日的主要市场状态和最佳交易策略。
> 来源：思维导图开盘模块 + HTML指南开盘/早盘章节

---

## 一、开盘前准备清单

### 1.1 盘前5分钟必查项

| # | 检查项 | 目的 | 工具/来源 |
|---|--------|------|-----------|
| 1 | 隔夜消息面 | 判断是否有重大事件驱动 | 财经日历、新闻快讯 |
| 2 | 关联市场走势 | 期货、外汇、指数是否联动 | HTF图表 |
| 3 | 前日关键价位 | 支撑/阻力、高点/低点、收盘价 | 日线图 |
| 4 | 当前市场情绪 | 恐慌/贪婪、隔夜持仓 | 市场情绪指标 |
| 5 | 自身心理状态 | 是否冷静、是否有上一日情绪残留 | 心理检查清单 |

### 1.2 开盘前需要回答的三个问题

1. **今日大致方向？** 基于前日收盘、隔夜走势、消息面判断偏多/偏空/不确定
2. **关键价位在哪里？** 前高前低、重要支撑阻力、开盘价本身
3. **今日最佳策略是什么？** 顺势突破 / 高抛低吸 / 观望等待

## 二、开盘区间（Opening Range）

### 2.1 定义与划分

```
开盘区间 = 开盘后前 N 根K线形成的高低点区间

常用周期：
- 5分钟开盘区间：超短线/剥头皮
- 15分钟开盘区间：日内波段
- 30分钟开盘区间：趋势确认
```

### 2.2 开盘区间的交易意义

| 开盘区间状态 | 含义 | 当日策略 |
|-------------|------|----------|
| 区间窄幅、K线重叠多 | 能量积累，等待突破 | 观望，等突破方向 |
| 区间向上突破 | 多头控制，日内偏多 | 回踩做多/顺势追多 |
| 区间向下突破 | 空头控制，日内偏空 | 反弹做空/顺势追空 |
| 区间宽幅震荡 | 多空拉锯，可能是宽区间日 | 高抛低吸 |

### 2.3 开盘区间突破规则

```
向上突破做多：
  - 价格突破开盘区间高点
  - 突破K线收盘在高位（大实体、小影线）
  - 突破后有跟进K线确认
  - 止损：开盘区间低点下方 或 突破K线低点下方

向下突破做空：
  - 价格跌破开盘区间低点
  - 突破K线收盘在低位（大实体、小影线）
  - 跌破后有跟进K线确认
  - 止损：开盘区间高点上方 或 突破K线高点上方
```

## 三、开盘二元决策框架

开盘后要迅速做出一系列二元判断，确定当日主策略：

### 3.1 第一步：趋势还是震荡？

| 趋势特征 | 震荡特征 |
|----------|----------|
| 连续更高高/更低低 | 高低点水平运行 |
| K线实体大、重叠少 | K线重叠多、影线多 |
| 价格远离开盘价运行 | 价格在开盘价附近来回 |
| EMA斜率明显 | EMA走平、价格穿越频繁 |

### 3.2 第二步：突破还是通道？

如果是趋势：

| 突破特征 | 通道特征 |
|----------|----------|
| 连续大实体K线 | 有趋势方向但K线重叠 |
| 几乎无回撤 | 存在1-3根K线回撤 |
| 急迫感强 | 节奏相对缓慢 |
| 远离EMA | 沿EMA运行 |

### 3.3 第三步：窄通道还是宽通道？

| 窄通道 | 宽通道 |
|--------|--------|
| 回撤1-3根K线 | 回撤3-5根以上 |
| 回调幅度小 | 回调幅度大 |
| 沿微趋势线运行 | 触及通道线 |
| 80%第一次反转失败 | 75%概率被反转/测试起点 |

### 3.4 第四步：宽区间还是窄区间？

| 宽区间 | 窄区间 |
|--------|--------|
| 高低点明确、振幅大 | 高低点模糊、振幅小 |
| 可双向交易 | 不宜交易 |
| 边界处信号可靠 | 所有信号都是噪音 |

### 3.5 第五步：小反转还是大反转？

| 小反转 | 大反转 |
|--------|--------|
| 未破趋势线 | 破趋势线+测试旧极端 |
| 80%概率失败 | 需要第二个信号确认 |
| 顺势交易者止损处入场 | 逆势摆动 |
| 可作为顺势入场机会 | 仓位需减半 |

### 3.6 大反转后的目标空间（趋势幅度定理）

> 来源：Al Brooks 视频课程笔记（L2，2026-09-11 补录）。

开盘出现趋势并演化出大反转后，用**原趋势的幅度**评估新趋势的目标空间：

| 开盘趋势幅度 | 大反转后的新趋势空间 |
|--------------|----------------------|
| 幅度小 | 新趋势可能远超开盘价 |
| 幅度大 | 即使完全反转，也很难超过开盘价太多 |

使用：反转方案的 MM/T1/T2 测算须计入原开盘趋势幅度——原趋势越大，反转目标越难越过开盘价，直接约束 RR 估算与目标序设置。

## 四、开盘强趋势规则

### 4.1 强趋势开盘的识别

开盘后出现以下特征，判断为强趋势开盘：

1. **连续大实体K线**，几乎无重叠
2. **远离开盘价**快速运行
3. **无影线或影线极小**
4. **EMA斜率陡峭**，价格不触及EMA
5. **有急迫感**，市场朝一个方向快速推进

### 4.2 开盘反转定理与 30 日实证

> 来源：Al Brooks 视频课程笔记（L2，2026-09-11 补录）。

```
核心定理：
- 刚开盘时，市场往往需要时间寻找方向；大部分时间里，市场选择的第一个方向是错误的
- 如果开盘前几根K线就直接形成趋势——不论这个趋势有多强：
  - 80% 的概率，至少会有小反转
  - 50% 的概率，会有大反转
```

30 个交易日实证（Sep 25 ~ Nov 3，日线样本）：

| 样本 | 结果 | 比率 |
|------|------|------|
| 开盘有或大或小的震荡区间 | 21 天，绝大部分在突破后达到 MM | 21/30 = 70% |
| 开盘不久即形成看似很强的趋势 | 6 个大反转 + 4 个小反转 + 3 天几乎无反转（或迟至中午/下午才反转） | 13/30 |
| 强趋势开盘的合计反转概率 | 10/13 = 77%（≈80%）；其中大反转 6/13 = 46%（≈50%） | — |

使用：开盘即出的强趋势不追突破——先按定理预期第一次反向摆动（见 4.3 第一次反转 80% 失败），等待回调结构再顺势入场；开盘若形成震荡区间，按区间突破→MM 目标处理（见 09_gap_analysis.md 缺口开盘四形态）。

### 4.3 强趋势第一次反转80%会失败

```
核心规则：
- 强上升趋势的第一次回调，80%概率只是反弹/小回调，不是反转
- 强下降趋势的第一次反弹，80%概率只是回调/小反弹，不是反转

交易策略：
- 多头：等待第一次回调结束后的H1/H2做多机会
- 空头：等待第一次反弹结束后的L1/L2做空机会
- 不要急于在第一次反转时逆势入场
```

### 4.4 强趋势中的入场方式

| 方式 | 适用场景 | 具体做法 |
|------|----------|----------|
| H1/L1入场 | 极强趋势、窄通道 | 第一根顺势信号K线极值外止损单 |
| H2/L2入场 | 强趋势中的明显回调 | 回调后的第二根顺势信号K线 |
| 突破入场 | 突破开盘区间/前高前低 | 突破K线高点/低点外止损单 |
| 回调入场 | 强趋势中的小幅回撤 | 回撤到EMA/微趋势线附近限价单 |

## 五、开盘震荡规则

### 5.1 开盘震荡的识别

1. K线之间大量重叠
2. 高低点大致水平
3. 价格在开盘价附近来回波动
4. EMA走平
5. 多空双方都能赚钱（说明趋势不强）

### 5.2 震荡开盘的交易策略

| 策略 | 适用条件 | 风险 |
|------|----------|------|
| 观望等待 | 窄区间/铁丝网 | 无风险，但可能错过突破 |
| 区间边界高抛低吸 | 宽区间、边界清晰 | 在区间中间位置入场风险大 |
| 等待突破 | 震荡区间持续较久 | 假突破风险，需确认 |

### 5.3 震荡中的80-20法则

```
震荡行情中80%的突破会失败：
- 区间内的突破尝试大多数会失败
- 区间边界处的逆势交易（高抛低吸）胜率更高
- 只有在区间被有效突破后，才转为趋势策略

有效突破的标准：
1. 突破K线实体大、收盘极端
2. 突破后有跟进K线
3. 成交量/动能配合
4. 价格远离区间边界
```

## 六、开盘缺口处理

### 6.1 缺口强度判断

| 缺口类型 | 强度 | 特征 | 策略 |
|----------|------|------|------|
| 最高/最低价影线之间的缺口 | 最强 | 完全无价格重叠 | 顺势追入/等待回调 |
| 收盘价与实体之间的缺口 | 较强 | 实体之间有缺口 | 顺势，但需警惕回补 |
| 影线重叠的缺口 | 较弱 | 仅影线之间有缺口 | 可能快速回补 |

### 6.2 缺口开盘后策略

```
向上跳空开盘：
1. 观察开盘区间是否形成
2. 若突破开盘区间高点 + 强势K线 → 追多
3. 若回补缺口 + 弱势 → 回到区间策略

向下跳空开盘：
1. 观察开盘区间是否形成
2. 若跌破开盘区间低点 + 强势K线 → 追空
3. 若回补缺口 + 弱势 → 回到区间策略
```

## 七、不同开盘状态的Playbook选择

| 开盘状态 | 主策略 | 优先信号 | 仓位 |
|----------|--------|----------|------|
| 强突破开盘 | 顺势追入 | 突破K线/H1 | 50-75% |
| 窄通道开盘 | 回调顺势 | H1/H2在趋势线 | 75% |
| 宽通道开盘 | 高抛低吸+顺势 | H2在趋势线，DBL/DBS在通道线 | 100%顺势/25%逆势 |
| 宽区间开盘 | 区间边界交易 | H2/L2在边界 | 100% |
| 窄区间开盘 | 不交易 | 无 | 0% |
| 大反转开盘 | 等待确认 | 第二个信号 | ≤50% |

## 八、开盘交易铁律

1. **开盘前15分钟内不要急于重仓**——等待市场状态明确
2. **强趋势中只做顺势，不做逆势**——第一次反转80%失败
3. **窄区间中不交易**——观望比亏损好
4. **开盘区间突破需确认**——单根K线突破不足够
5. **大反转需等第二个信号**——不要急于逆势
6. **开盘方向≠全天方向**——随时准备根据状态转换调整
