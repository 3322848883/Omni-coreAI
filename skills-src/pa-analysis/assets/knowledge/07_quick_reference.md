## 信号K线快速判断（Brooks原文）

- 收盘是否反转了多条棒线的收盘价和高/低点？
- 入场方向影线是否短或不存在？
- 实体是否适中（不是十字星也不是耗尽）？
- 是否在关键价位（磁铁/支撑/阻力/EMA）？
- 趋势位置：顺势还是逆势？趋势早期还是过度延伸？

> 强信号棒：满足大部分特征，在关键价位，顺势 → 可入场
> 中等信号棒：满足部分特征 → 降仓位或等第二个信号
> 弱信号棒：不满足关键特征 → 不入场

## 交易者方程式

```
(胜率 × 平均盈利) - (败率 × 平均亏损) > 0

例如：60%胜率 × 2R盈利 - 40%败率 × 1R亏损 = 1.2R - 0.4R = 0.8R > 0 ✓
```
