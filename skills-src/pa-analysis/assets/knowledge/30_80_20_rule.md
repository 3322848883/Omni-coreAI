# 80-20 法则（80-20 Rule）

> 价格行为交易中的核心概率法则。它不是精确的数学 80%，而是表达一种强烈的概率偏向：趋势有惯性，震荡也有惯性。
> 来源：思维导图"80-20法则"模块 + 七状态交易逻辑

---

## 一、法则核心

```
80-20 法则两条主轴：

1. 趋势行情有惯性：约 80% 的反转尝试会失败
   → 在趋势中，顺势交易比逆势交易更容易获利

2. 震荡行情有惯性：约 80% 的突破尝试会失败
   → 在震荡中，高抛低吸比追突破更容易获利
```

### 核心含义

| 市场状态 | 惯性方向 | 失败概率高的一方 | 高胜率策略 |
|----------|----------|------------------|------------|
| 趋势（强/弱） | 原趋势延续 | 逆势反转交易 | 顺势回撤入场 |
| 震荡（宽/窄） | 区间维持 | 追突破交易 | 区间边界高抛低吸 |

---

## 二、趋势行情中的 80-20 法则

### 2.1 强趋势中的第一次反转

```
强趋势中第一次反转尝试：
- 约有 80% 的概率失败
- 不会立即形成大反转
- 更可能是小回调/反弹，之后趋势继续
```

#### 具体表现

| 趋势类型 | 第一次反转 | 结果 | 应对策略 |
|----------|-----------|------|----------|
| 强上升趋势 | 第一次回调 | 大概率是浅回调，继续创新高 | 等待 H1/H2 做多 |
| 强下降趋势 | 第一次反弹 | 大概率是浅反弹，继续创新低 | 等待 L1/L2 做空 |
| 窄通道 | 突破通道线 | 80% 失败，回到通道内 | 通道线附近顺势入场 |
| 突破阶段 | 首次反向 K 线 | 多为获利回吐，不是反转 | 顺势持有/加仓 |

### 2.2 等待第二次信号

```
不要因为第一次反转就急于逆势入场：

- 第一次反转 → 观望或减仓
- 第二次反转 + 趋势线突破 → 才考虑大反转交易
- 第二次顺势信号（H2/L2）→ 更可靠的顺势入场点
```

### 2.3 趋势中的高胜率入场位置

| 入场位置 | 胜率 | 说明 |
|----------|------|------|
| 第一次回撤 H1/L1 | 50-60% | 极强趋势中可用，一般趋势需谨慎 |
| 第二次回撤 H2/L2 | 50-60% | 更可靠的顺势入场（Brooks：最佳架构也很少超过60%） |
| 趋势线/EMA 支撑处 | 50-60% | 趋势结构完整时有效 |
| 被套交易者止损处 | 约60% | 小反转失败后顺势入场（Brooks："失败之失败"约60%） |

## 三、震荡行情中的 80-20 法则

### 3.1 震荡区间的突破

```
震荡行情中约 80% 的突破尝试会失败：
- 区间内的大部分"突破"只是测试边界
- 价格很快回到区间内
- 追突破往往被套
```

#### 具体表现

| 震荡类型 | 突破结果 | 应对策略 |
|----------|----------|----------|
| 宽震荡区间 | 大部分突破失败 | 边界处高抛低吸 |
| 窄震荡区间 | 几乎不交易 | 观望等待真正突破 |
| 震荡第二段 | 常见假突破陷阱 | 准备反向交易 |
| 区间边界 | 诱多/诱空频繁 | 等确认再追 |

### 3.2 有效突破的确认条件

虽然 80% 突破会失败，但剩下的 20% 有效突破非常重要：

```
有效突破四要素：
1. 突破 K 线实体大
2. 收盘在极端位置
3. 突破后有跟进 K 线
4. 价格远离区间边界
```

| 确认项 | 有效突破 | 假突破 |
|--------|----------|--------|
| 突破 K 实体 | 大 | 小或长影线 |
| 收盘价 | 接近极端 | 回到区间内 |
| 跟进 | 有连续跟进 | 无跟进或迅速反向 |
| 距离 | 远离边界 | 未能远离 |
| 成交量 | 放大配合 | 不配合 |

### 3.3 震荡中的高胜率策略

| 策略 | 适用位置 | 胜率 |
|------|----------|------|
| 区间底部做多 | 宽区间下边界 + 多头信号 | 50-60% |
| 区间顶部做空 | 宽区间上边界 + 空头信号 | 50-60% |
| 区间中间观望 | 区间中部 | N/A（不交易） |
| 突破后回踩入场 | 有效突破后的回踩确认 | 约50% |

## 四、80-20 法则在七状态中的应用

### 4.1 各状态的概率偏向

| 市场状态 | 主要惯性 | 80% 会失败的方向 | 优先策略 |
|----------|----------|------------------|----------|
| 突破 | 趋势延续 | 逆势做空/做多 | 顺势追入 |
| 窄通道 | 趋势延续 | 逆势交易 | 只做顺势 |
| 宽通道 | 通道内双向 | 追破通道线 | 趋势线顺势 + 通道线逆势刮头皮 |
| 大反转 | 原趋势反转 | 继续顺势 | 等二次确认后逆势 |
| 小反转 | 原趋势延续 | 将小反转当大反转做 | 顺势入场 |
| 宽区间 | 区间维持 | 追突破 | 高抛低吸 |
| 窄区间 | 能量积累 | 任何方向交易 | 不交易 |

### 4.2 二元决策中的应用

```
下单前问自己：

1. 当前是趋势还是震荡？
   - 趋势 → 80% 反转会失败 → 做顺势
   - 震荡 → 80% 突破会失败 → 做高抛低吸

2. 如果是趋势，是强趋势还是弱趋势？
   - 强趋势 → 第一次反转失败概率高 → 等第二次信号
   - 弱趋势 → 回调深 → 可以在关键位置双向刮头皮

3. 如果是震荡，是宽区间还是窄区间？
   - 宽区间 → 边界处交易
   - 窄区间 → 不交易，等突破
```

## 五、80-20 法则与风险收益

### 5.1 为什么顺势交易更容易盈利

```
顺势交易优势：
- 趋势有惯性，延续概率高
- 即使信号不完美，方向正确也能盈利
- 止损可以设在小回撤极值外，风险可控
- 盈利目标可以是测量移动位，盈亏比合理
```

### 5.2 为什么震荡中追突破容易亏损

```
追突破劣势：
- 80% 突破失败，追突破等于赌小概率
- 震荡中止损容易被触发
- 假突破后反向运行速度快，亏损大
- 情绪化追涨杀跌是亏损主因
```

### 5.3 80-20 法则的仓位启示

| 交易方向 | 与惯性同向 | 与惯性反向 |
|----------|-----------|-----------|
| 仓位规则 | ×1.0-1.25 | ×0.25-0.5 |
| 止损 | 正常 | 更紧 |
| 目标 | 摆动持有 | 刮头皮 |
| 信号要求 | 标准 | 必须第二信号确认 |

## 六、常见错误与纠正

### 错误 1：在强趋势中做反转

```
表现：看到一根大阴线就做空强上升趋势
原因：认为"涨多了要跌"
纠正：强趋势中第一次反转 80% 失败，等第二次信号或趋势线突破
```

### 错误 2：在震荡中追突破

```
表现：区间刚向上突破就追多
原因：害怕错过趋势
纠正：等突破确认 + 回踩，或回到区间边界逆势交易
```

### 错误 3：忽视背景，只看 K 线形态

```
表现：任何位置看到信号 K 线就入场
原因：孤立看待形态
纠正：先看市场是趋势还是震荡，再决定顺势还是逆势
```

### 错误 4：把"80%"当成绝对概率

```
表现：认为数到 80% 就必然发生
原因：机械化理解 80-20
纠正：80-20 是经验概率，需结合具体形态、位置、信号综合判断
```

## 七、80-20 法则实战检查清单

每次入场前检查：

| # | 问题 | 如果是 | 如果否 |
|---|------|--------|--------|
| 1 | 当前是趋势还是震荡？ | 确定策略方向 | 继续观察 |
| 2 | 我的交易方向是否与当前惯性一致？ | 标准仓位 | 降低仓位或放弃 |
| 3 | 如果是逆势交易，是否有第二信号确认？ | 小仓位尝试 | 放弃 |
| 4 | 如果是顺势交易，是否处于趋势早期（<20 根）？ | 积极入场 | 谨慎追势 |
| 5 | 如果是在震荡中，是否在区间边界附近？ | 可交易 | 不交易 |
| 6 | 我是否在追突破？突破是否已确认？ | 确认后入场 | 等待或放弃 |
