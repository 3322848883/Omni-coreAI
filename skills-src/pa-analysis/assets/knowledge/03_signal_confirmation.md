# 信号确认（Signal Confirmation）

> 以下所有信号棒判断标准均来自 Al Brooks 原文，不做主观量化。
> 来源：V1第4章棒线基础（P111-P118）、V1第5章信号棒：反转棒（P117-P118）

## 信号棒判断：Brooks 原文定性标准

Brooks 不使用打分系统。他的判断方式是：**信号棒本身不构成入场理由，必须结合它前面的棒线一起观察。背景决定一切。**

### 最佳多头反转棒特征（V1 P117）

1. 开盘价接近或低于前一棒线的收盘价，收盘价高于开盘价，并且高于前一棒线的收盘价
2. 下尾线长度约为棒线高度的三分之一到二分之一，上尾线较短或不存在
3. 与前一条或前面多条棒线没有重叠
4. 信号棒之后的棒线不是一条十字星内包棒线，而是一条强势入场棒线
5. 收盘价反转了（收盘高于）多于一条棒线的收盘价和最高价

### 最佳空头反转棒特征（V1 P117）

1. 开盘价接近或高于前一棒线的收盘价，收盘价远低于前一棒线的收盘价
2. 上尾线长度约为棒线高度的三分之一到二分之一，下尾线较短或不存在
3. 与前一条或前面多条棒线没有重叠
4. 信号棒之后的棒线不是一条十字星内包棒线，而是一条强势入场棒线
5. 收盘价反转了（收盘低于）多于一条棒线的收盘价和低点

### 反转棒强度判断规则（V1 P118，10条原文）

1. 收盘价反转了多于一条棒线的收盘价和最高价/低点的反转棒，通常比仅反转前一棒的反转棒更强
2. 因为顺势交易总是最明智的选择，所以当信号棒是交易方向上的强势趋势棒时，交易最有可能成功
3. **趋势越强，顺势交易对强信号棒的要求就越低，逆势交易对强信号棒的要求就越高**
4. 当信号棒较大，而且与前两棒或三棒有较大重叠时，它是交易区间的一部分
5. 当多头反转棒的中点高于前一棒低点时，重叠可能过多，表明交易区间正在形成
6. 大约60%的时间里，恰在均线上方的多头旗形中如果有三条或多条基本重叠的大棒线，那么通常都是陷阱
7. 在正确的一方至少已经控制了信号棒后入场总是要好得多
8. 架构棒本身并不是进入交易的一个理由，必须与它前面的棒线联系在一起观察
9. 最强的趋势通常有着外观丑陋的信号棒，但交易仍然是极好的
10. 除了绝对强劲的逆势交易之外，初学者应该避开所有逆势交易

> **核心原则：** 当考虑在强趋势中做逆势交易时，你必须等待趋势线被突破，然后在测试极点时形成了强势反转棒，否则交易获利的几率就太小了。不要在1分钟反转棒上入场，因为绝大多数1分钟反转棒都会失败，成为顺势架构。

## 核心信号详细说明

### H1/H2/H3 入场信号

| 信号 | 条件 | 入场规则 | 止损 |
|------|------|----------|------|
| H1 | 牛旗中第一根高点高于前根K线的K线 | 在H1高点+1tick买入止损单 | H1低点-1tick |
| H2 | 第二次出现H1（ABC回调完成） | 在H2高点+1tick买入止损单 | H2低点-1tick |
| H3 | 第三次出现（楔形旗形） | 在H3高点+1tick买入止损单 | H3低点-1tick |
| L1 | 熊旗中第一根低点低于前根K线的K线 | 在L1低点-1tick卖出止损单 | L1高点+1tick |
| L2 | 第二次出现L1（ABC回调完成） | 在L2低点-1tick卖出止损单 | L2高点+1tick |
| L3 | 第三次出现（楔形旗形） | 在L3低点-1tick卖出止损单 | L3高点+1tick |

### 楔形反转

| 类型 | 识别 | 入场 |
|------|------|------|
| 楔形多头反转 | 三推下跌+趋势线/通道线收敛 | 等第二个信号（H2或双底）确认 |
| 楔形空头反转 | 三推上涨+趋势线/通道线收敛 | 等第二个信号（L2或双顶）确认 |
| 楔形旗形（顺势） | 趋势中三推回撤 | 在第一个信号入场 |
| 嵌套楔形 | 大楔形内嵌套小楔形 | 更可靠，小楔形突破入场 |

### 双顶/双底

| 形态 | 条件 | 入场 | 止损 |
|------|------|------|------|
| 双顶 | 两个大致相同的高点 | 第二个高点形成后，跌破两高之间的低点 | 第二个高点+1tick |
| 双底 | 两个大致相同的低点 | 第二个低点形成后，突破两低之间的高点 | 第二个低点-1tick |
| 微型双顶(DBL) | 两K线形成的小双顶 | 失望多头平仓+空头入场 | 微型高点+1tick |
| 微型双底(DBS) | 两K线形成的小双底 | 失望空头平仓+多头入场 | 微型低点-1tick |

### IOI/ii/iii 突破模式

| 模式 | 结构 | 入场 | 可靠性 |
|------|------|------|--------|
| ii | 连续2根内包K线 | 突破第2根内包K线的高/低 | ★★★ |
| iii | 连续3根内包K线 | 突破第3根内包K线的高/低 | ★★★★ |
| ioi | 内包→外包→内包 | 突破第3根内包K线的高/低 | ★★★★ |

## 缺口信号

| 缺口类型 | 识别 | 交易策略 |
|----------|------|----------|
| 突破缺口 | 突破关键价位形成 | 顺势追入 |
| 测量缺口 | 趋势中段形成 | 测量目标=缺口前走势长度 |
| 衰竭缺口 | 趋势末端形成 | 准备反转 |
| 缺口开盘 | 开盘价与前日收盘有缺口 | 等开盘区间形成后交易 |
| MAGB | 不触及20EMA的K线 | 趋势强劲、继续持有 |
| 20GB | 连续20根不触及EMA | 趋势极强、但警惕反转 |

## 信号组合判断（Brooks 原文逻辑）

以下为 Brooks 原文中关于信号强度的表述，按可靠性从高到低排列：

| 可靠性 | 组合 | Brooks 原文依据 |
|--------|------|----------------|
| 最高 | 趋势方向 + H2 + 强信号棒 + 磁铁附近 | "顺势交易总是最明智的选择"（V1 P118） |
| 高 | 趋势方向 + H1 + 支撑/阻力 | "趋势越强，对强信号棒的要求就越低" |
| 中高 | 双顶/底 + 区间边界 + 信号棒确认 | 区间边界是最可靠的磁铁之一 |
| 中 | 楔形反转 + 第二个信号 | "大多数趋势反转尝试会失败，应仅在一切完美时考虑反转" |
| 中 | ii/iii/ioi突破 + 趋势方向 | ii形态顺势突破通常只是刮头皮机会 |
| 低 | 单一信号 | "架构棒本身不是入场理由，必须与前面的棒线联系观察" |
| 最低 | 逆趋势单一信号 | "初学者应该避开所有逆势交易"（V1 P113） |
