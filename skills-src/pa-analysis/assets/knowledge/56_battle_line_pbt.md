# AL. 决斗线与完美突破测试（Battle Line & PBT）

> 来源：Al Brooks三部曲
> 场记指南参考：pa-trading-field-guide.html AL章节

## 决斗线（Battle Line）

### 定义
多空双方激烈争夺的关键价格水平，通常与前高或前低重合，突破后往往有强后续跟进。决斗线是市场中最重要的价格参考点之一，因为它代表了多空力量平衡的临界点。

### 识别条件（5项）
1. **至少被测试3次以上**：越多次测试越可靠
2. **每次测试都有显著的价格反应**：至少5-10tick的反转或停顿
3. **通常与前摆动高点/低点重合**：增加其重要性
4. **整数关口上的决斗线更可靠**：心理因素加强
5. **多时间框架共振**：如果在多个时间框架上都是关键位，更强

### 决斗线的类型

| 类型 | 特征 | 交易含义 |
|------|------|----------|
| 水平决斗线 | 明确的价格水平 | 最简单的识别和交易 |
| 趋势线决斗线 | 沿趋势线分布的多个测试点 | 趋势中更常见 |
| 动态决斗线 | EMA20/EMA50等 | 需要结合价格行为确认 |
| 缺口决斗线 | 缺口区域 | 缺口回补时的高概率位置 |

### 交易含义
- **决斗线突破** → 顺势追入，止损设在决斗线另一侧
- **决斗线未突破** → 考虑反向交易，止损设在决斗线外
- **决斗线突破后回测** → 高概率BOP入场（完美突破测试）
- **决斗线假突破** → 反向交易的高概率信号

### 决斗线交易决策树

```
决斗线测试
├── 突破确认（收盘在决斗线外）
│   ├── 有回撤 → 等待PBT入场
│   └── 无回撤 → 追入或等待
├── 未突破（在决斗线处反转）
│   ├── 信号K线强 → 反向入场
│   └── 信号K线弱 → 等待更好信号
└── 假突破（突破后迅速反转）
    └── 反向入场（被困交易者效应）
```

## 完美突破测试（PBT: Perfect Breakout Test）

### 定义
价格精确回测突破点后迅速反弹的形态，是突破回撤中最可靠的二次入场信号之一。Brooks认为PBT是判断突破是否为真突破的最重要验证。

### 识别条件（4项）
1. **价格突破关键价位**（决斗线/前高前低/区间边界）
2. **价格回撤到恰好突破点附近**（±1-2tick）
3. **回撤后迅速反弹**（1-3根K线内）
4. **反弹方向与突破方向一致**

### PBT的等级

| 等级 | 特征 | 可靠性 |
|------|------|:------:|
| 完美PBT | 精确触及突破点±1tick，立即反弹 | ★★★★★ |
| 近似PBT | 触及突破点±3tick，2-5根K线内反弹 | ★★★★ |
| 宽松PBT | 回撤到突破点附近区域，但未精确触及 | ★★★ |

### 交易策略

| 条件 | 入场 | 止损 | 目标 |
|------|------|------|------|
| PBT确认 | 反弹K线后1tick止损单 | 回撤极值外 | 测量移动目标 |
| 突破后无PBT | 等待，不急入场 | - | - |
| PBT失败 | 反向交易机会 | 突破点另一侧 | 区间边界 |

### PBT失败的含义

PBT失败（价格回撤到突破点后继续下跌/上涨）意味着：
1. 突破可能是假突破
2. 原方向的交易者正在被套
3. 这是反向交易的高概率信号
4. 目标至少是区间的另一边

### PBT vs BOP

| 维度 | PBT | BOP |
|------|-----|-----|
| 位置 | 突破后回测 | 突破前回调 |
| 方向 | 顺势 | 顺势 |
| 确认 | 突破已发生 | 突破尚未确认 |
| 风险 | 较低（突破已确认） | 较高（可能不突破） |
| 胜率 | 高 | 中高 |

## 常见错误

1. **把每个回撤都当PBT**：PBT要求精确回测突破点
2. **PBT未确认就入场**：必须等反弹K线确认
3. **忽略决斗线强度**：弱决斗线（仅测试1-2次）的PBT不可靠
4. **止损设置过紧**：PBT的止损应设在回撤极值外，给价格足够空间

## 实战应用

### 场景1：区间突破PBT
1. 价格突破区间顶部
2. 回撤到区间顶部附近（±2tick）
3. 出现买入信号K线 → PBT确认
4. 入场做多，止损在回撤低点下方，目标测量移动

### 场景2：决斗线PBT
1. 决斗线被突破（前高）
2. 价格回撤到决斗线
3. 在决斗线处获得支撑
4. 入场做多，止损在决斗线下方
