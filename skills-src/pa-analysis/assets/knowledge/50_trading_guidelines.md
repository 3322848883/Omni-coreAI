# AE. 78条交易指南（78 Trading Guidelines）

> 来源：Al Brooks《价格行为交易三部曲》第三卷《反转》第25章（第410-421页）
> 场记指南参考：pa-trading-field-guide.html AE章节

## 概述

Al Brooks的78条交易指南是所有交易决策的底层框架。Brooks强调这些是"指引"（Guidelines）而非硬性规则，因为交易是主观的，优势总是很小。如果存在明确而客观的规则，每个人都会发现它们，它们也就失效了。

## 核心原则

1. **指引非规则**：这些是"指引"（Guidelines）而非硬性规则，市场总有例外
2. **灰色迷雾原则**：市场永远在灰色地带运行，不存在100%确定性
3. **零和博弈**：每一笔盈利都来自另一方的亏损
4. **优势上限**：即使最佳设置，胜率也很少超过60%
5. **双向信号棒**：大多数信号棒可以被解读为双向
6. **谦逊原则**：市场永远正确，交易者必须适应

## 一、趋势交易（Trend Trading）— 指引1-20

| # | 指引 | 核心要点 |
|---|------|---------|
| 1 | **学习基础** | 阅读57万字就像阅读详尽的交易指南，将这些信息转变为赚钱能力需要大量艰苦工作 |
| 2 | **灰色迷雾原则** | 你所看到的一切都处于灰色迷雾之中，没有什么是完全清楚的，近似就好 |
| 3 | **主观性与零和游戏** | 没有简单又可靠的规则，一切都是主观的。这是一场零和游戏，对手都非常聪明 |
| 4 | **优势上限** | 优势绝不会变得非常大，因为机构会在优势增长时利用它们 |
| 5 | **读图与交易是两项技能** | 学好读图只是成功所需能力的一半，还需要学会交易 |
| 6 | **数学优势与时间设定** | 交易者需要数学优势来赚钱。当优势相对明显时，转瞬即逝且非常小 |
| 7 | **交易者方程为正** | 做交易者方程为正的交易的能力是交易成功的关键 |
| 8 | **买卖双方判断** | 交易者需要做的唯一最重要的决定：前一棒上方和下方，到底有更多买家还是卖家 |
| 9 | **对手方意识** | 每当你使用止损单买进时，就有聪明人使用限价单在那里做空 |
| 10 | **双向信号棒** | 每一棒都是两个方向的信号棒，考虑与预期相反的可能性 |
| 11 | **反向突破检查** | 确保市场不是向信号棒的反方向突破 |
| 12 | **理解趋势棒** | 理解趋势棒是交易者能获得的最重要技能之一 |
| 13 | **市场强弱评估** | 寻找并评估市场强弱的征兆，决定它们是否会带给你优势 |
| 14 | **谦逊原则** | 每当你认为架构很强势，不要选择那个交易——你正在错过某些东西 |
| 15 | **概率灵活性** | 60%只是90%情况中的60%，有时可能是90%，有时可能是10% |
| 16 | **退出不好的交易** | 一天中最重要的事情就是告诉自己退出不好的交易 |
| 17 | **市场惯性** | 趋势中80%反转尝试失败；区间中80%突破尝试失败 |
| 18 | **回撤vs反转** | 如果你纠结回撤幅度太大，很可能趋势已经反转 |
| 19 | **市场非理性** | 市场可长期保持非理性，勿与市场争辩，无须证明自己是对的 |
| 20 | **价格即真相** | 不要去与市场争辩。对于日内交易者，基本面几乎毫无用处 |

## 二、区间交易（Trading Range）— 指引21-35

| # | 指引 | 核心要点 |
|---|------|---------|
| 21 | **一切合理** | 如果你知道如何阅读价格行为，就没有什么会令你感到奇怪 |
| 22 | **公平无关** | 计算机程序控制着所有市场行为，它们没有公平这一概念 |
| 23 | **价格行为的基因基础** | 价格行为以人类行为为基础，有基因基础，适用于所有国家所有市场所有时间框架 |
| 24 | **保护性止损** | 总要设好保护性止损，避免你作为交易者的最大危险——你自己 |
| 25 | **拒绝救世主** | 失败者寻找使他们免于亏损的救世主，救世主只是在为自己赚钱 |
| 26 | **言者不知** | 言者不知，知者不言。不要看电视也不要看新闻 |
| 27 | **头寸规模调整** | 如果你认为能交易3张合约，只交易1张；切换到SPY 100-300股 |
| 28 | **"我不在乎"咒语** | 我不在乎这笔交易是否亏损，因为交易规模非常小 |
| 29 | **减小规模** | 因止损太远不敢交易时，减小规模到正常四分之一 |
| 30 | **市场过度** | 市场永远不确定何时已经走得足够远，但走得太远时总是确定的 |
| 31 | **反转头寸** | 反转头寸很难，对大部分交易者来说最好是离场 |
| 32 | **逆势交易警告** | 没有可靠的逆势形态，除非出现重要趋势线的强势突破 |
| 33 | **反转架构与获利了结** | 任意反转架构都是很好的获利了结理由，但逆势需要很强 |
| 34 | **太早vs太迟** | 太早总是比太迟更糟。较早入场很可能失败，较迟入场可能仍不错 |
| 35 | **失败的失败** | 所有形态都会失败，失败常常失败，失败的失败形成突破回撤 |

## 三、反转交易（Reversal）— 指引36-45

| # | 指引 | 核心要点 |
|---|------|---------|
| 36 | **被套交易者** | 一方突然被套时，反向刮头皮交易的可靠性上升 |
| 37 | **止损猎杀** | 市场突然猎杀止损后恢复趋势，是可靠的刮头皮架构 |
| 38 | **等待规则** | 如果你与市场失去联系，等待。不要被突然的大型趋势棒套入 |
| 39 | **不必交易** | 目标是赚钱，不是做交易。仅当架构会帮助你实现目标时才交易 |
| 40 | **简单原则** | 越简单越好。不需要指标，只观察一张图表 |
| 41 | **交易是爱好还是工作** | 如果是爱好，请另找一种。这是一个太昂贵的爱好 |
| 42 | **5分钟图交易规则** | 回撤入场用止损单；多头：均线处多头棒上方买进；空头：均线处空头棒下方做空 |
| 43 | **SPY vs 电子迷你** | 初始：SPY 200-500股；过渡：SPY 1000-1500股；进阶：电子迷你 |
| 44 | **低买高卖例外** | 明确且常见的趋势中除外。在别人贪婪时恐惧，在别人恐惧时贪婪 |
| 45 | **恐惧、贪婪与专业交易者** | 新手：恐惧和贪婪。稳定获利者：不确定性（混乱）和紧迫性 |

## 四、入场与止损（Entry & Stop）— 指引46-60

| # | 指引 | 核心要点 |
|---|------|---------|
| 46 | **不确定性策略** | 不确定时市场处于交易区间，只采用低买高卖策略 |
| 47 | **区间交易策略** | 区间底部获利了结空头或建立多头；区间顶部获利了结多头或建立空头 |
| 48 | **执行质量** | 好的执行，不好的交易。如果市场让你在好于预期的价位入场，要怀疑 |
| 49 | **开盘时段** | 开盘1-2小时最容易赚钱（波段大、十字星少），也最容易赔钱 |
| 50 | **亏损后心理** | 当天已亏损+下半天=流沙中游泳。最明智：确保收盘前遵守规则 |
| 51 | **日区间中部回避** | 初学者应避免在日区间中部交易，尤其是紧凑交易区间和突出尾线 |
| 52 | **紧凑区间止损风险** | 紧凑交易区间是最差的止损入场环境，机构正在做相反的事情 |
| 53 | **紧凑区间强制离场** | 紧凑交易区间会战胜一切，一旦察觉就强制自己不做任何交易 |
| 54 | **趋势或区间二选一** | 每一棒要么是趋势要么是交易区间。选择一个，决定总在场内方向 |
| 55 | **信号棒选择** | 最好的信号棒是交易方向上的趋势棒。十字星棒通常是糟糕的信号棒 |
| 56 | **逆势vs顺势** | 大部分逆势架构失败，大部分顺势架构成功。做好数学计算 |
| 57 | **逆势刮头皮陷阱** | 停止逆势刮头皮之前很难稳定获利。4次亏损后需6次盈利回本 |
| 58 | **交易者方程公式** | 胜率 x 潜在回报 > 败率 x 风险。不能冒2点风险博1点利润 |
| 59 | **交易者方程三变量** | 结果为正的任意架构都是好的交易，可以是高胜率低回报或低胜率高回报 |
| 60 | **逐步入场出场** | 经验丰富者利用逐步入场/出场提升交易者方程 |

## 五、交易管理（Trade Management）— 指引61-70

| # | 指引 | 核心要点 |
|---|------|---------|
| 61 | **顺势回撤** | 在你开始交易顺势回撤之前，你不会赚钱 |
| 62 | **反转交易前提** | 等待重要趋势线突破并出现测试趋势极点的强反转棒 |
| 63 | **每日图表复习** | 每天打印5分钟图表，把看到的每个架构写上去，年复一年日复一日 |
| 64 | **个性与交易风格** | 足够了解个性找到适合自己的交易风格之前，长期不会赚钱 |
| 65 | **收盘前纪律** | 如果失去纪律，最后1-2小时做开盘不会做的交易，不会赚钱 |
| 66 | **与计算机竞争** | 计算机有速度优势、不受情绪影响、永不疲劳——调整你的交易 |
| 67 | **两条腿原则** | 总要寻找两条腿。市场尝试做两件事两次都失败时，通常相反方向成功 |
| 68 | **不要过分挑拣** | 绝不要过分挑拣，难免选到足够多不好的交易而成为失败者 |
| 69 | **避开亏损交易** | 寻找盈利交易很容易，但避开亏损交易很难。成功的关键是避开亏损交易 |
| 70 | **交易离场判断** | 观察市场，假定自己持平。如果现在会做那笔交易就持有，否则离场 |

## 六、心理与纪律（Psychology & Discipline）— 指引71-78

| # | 指引 | 核心要点 |
|---|------|---------|
| 71 | **波段vs刮头皮互斥** | 应做波段时不要刮头皮，应做刮头皮时不要做波段 |
| 72 | **风格转换陷阱** | 做波段却转为刮头皮会赔钱；做刮头皮但提前退出也会赔钱 |
| 73 | **月度亏损后规则** | 上月亏损就不做任何反转交易；10棒中7棒在均线上方只做多 |
| 74 | **初学者最佳实践** | 只选择最好的交易。连续两三小时盯着屏幕不交易很难但最好 |
| 75 | **纪律（最重要特征）** | 纪律是盈利交易者最重要的特征。培养只选择最佳交易的纪律 |
| 76 | **无为能力** | 伟大交易者第二重要品质：一次连续几小时什么都不做的能力 |
| 77 | **头寸规模优先** | 致力于增加头寸规模，而不是交易数量或架构种类。每天赚2点即可 |
| 78 | **最终指引** | 如果你的交易技能已臻完美，所赚到的钱比你所能想象的要多得多 |
