# 交易者方程式与赚钱逻辑

> 交易者方程式 = 概率 x 回报 > (1-概率) x 风险。这是所有交易决策的数学基础。

---

## 一、交易者方程式

### 核心公式

```
期望值 = (胜率 x 平均盈利) - (败率 x 平均亏损)
```

**交易者方程式必须为正**才能入场：
**概率 x 回报 > (1-概率) x 风险**

### 七状态交易者方程式速查

| 市场状态 | 关键概率 | 核心规则 | 交易者方程式 |
|----------|----------|----------|-------------|
| 突破 | 60-70%顺势 | 顺势追入 | 正（趋势强） |
| 窄通道 | 55-65%顺势 | 趋势线回调入场 | 正 |
| 宽通道 | 50-60%顺势 | 顺势方向优先 | 正（顺势） |
| 大反转 | 约40% | 等第二个信号 | 正（高回报） |
| 小反转 | 约70%顺势 | 被套交易者止损入场 | 正 |
| 宽区间 | 50-60%边界 | 边界交易 | 正（边界） |
| 窄区间 | N/A | 不交易 | 不适用 |

### 应用检查清单

入场前必问：**交易者方程式为正吗？**
- （成功概率 x 目标利润）>（失败概率 x 止损距离）？
- 如果算不过来→不交易。

## 二、多头/空头赚钱逻辑

### 核心思维

在任何市场位置，你必须同时从两个角度思考：
1. **多头在这个位置能赚钱吗？怎么赚？**
2. **空头在这个位置能赚钱吗？怎么赚？**

如果你只能回答其中一个问题，说明你对市场的理解不完整。

### 多头赚钱的4种方式

| 方式 | 市场状态 | 赚钱逻辑 | 风险 |
|------|----------|----------|------|
| **1. 顺趋势做多** | 上升趋势 | 在回调到支撑位时买入，利用趋势惯性获利 | 趋势可能结束 |
| **2. 反转做多** | 下降趋势末端 | 楔形反转、双底、高潮卖出后抓反转第一波 | 反转失败 |
| **3. 区间做多** | 交易区间 | 区间下沿买入，目标区间上沿 | 区间向下突破 |
| **4. 突破做多** | 突破时刻 | 突破关键阻力后追入 | 假突破 |

### 空头赚钱的4种方式

| 方式 | 市场状态 | 赚钱逻辑 | 风险 |
|------|----------|----------|------|
| **1. 顺趋势做空** | 下降趋势 | 在反弹到阻力位时卖出 | 趋势可能结束 |
| **2. 反转做空** | 上升趋势末端 | 楔形反转、双顶、高潮买入后抓反转第一波 | 反转失败 |
| **3. 区间做空** | 交易区间 | 区间上沿卖出，目标区间下沿 | 区间向上突破 |
| **4. 突破做空** | 突破时刻 | 跌破关键支撑后追入 | 假突破 |

### 高抛低吸的本质

高抛低吸不是简单的"高了卖低了买"：
- **在趋势中：**"低吸"是在回调到支撑位时买入，"高抛"是在趋势延续到目标位时卖出
- **在区间中：**"低吸"是在区间下沿买入，"高抛"是在区间上沿卖出
- **不是逆势：**在趋势中逆势"低吸"（抄底）或"高抛"（摸顶），是新手最常见的错误

**核心公式：**高抛低吸 = 在合理的位置 + 顺市场方向 + 有明确的前提 = 交易

### Always In 在赚钱逻辑中的应用

- **Always In多头：**多头正在赚钱，空头正在亏钱。你应该做多或观望，绝对不要做空。
- **Always In空头：**空头正在赚钱，多头正在亏钱。你应该做空或观望，绝对不要做多。
- **Always In不确定：**市场处于区间/均衡状态。可以在区间边缘交易，但要降低仓位。

### 双向思维训练表

| 市场位置 | 多头如何赚钱 | 空头如何赚钱 | 谁更有利？ |
|----------|-------------|-------------|-----------|
| 上升趋势中 | 回调买入，顺势持有 | 等待趋势结束 | 多头 |
| 下降趋势中 | 等待趋势结束 | 反弹卖出，顺势持有 | 空头 |
| 区间上沿 | 突破后追多（风险大） | 区间上沿做空（风险小） | 空头 |
| 区间下沿 | 区间下沿做多（风险小） | 跌破后追空（风险大） | 多头 |
| 关键阻力位 | 突破后追多 | 阻力位做空 | 空头 |
| 关键支撑位 | 支撑位做多 | 跌破后追空 | 多头 |

## 三方核心观点

**方方土：**"交易前提就是你赚钱的逻辑。如果你说不清楚你凭什么赚钱，那你就是在赌博。每一笔交易之前，你必须能用一句话说清楚：'我做多是因为……'或者'我做空是因为……'。"

**ROSE：**"知道机构在哪里挂单，就知道从哪里赚钱。如果你能识别机构可能挂单的位置（关键支撑/阻力、整数关口、前高/前低），你就能在这些位置找到高概率的交易机会。"
