# 持仓管理（Position Management）

## 追踪止损三步法

### 步骤1：初始止损
- 入场后立即设置
- 基于价格行为：信号K线极值外1-2tick
- 基于金额：不超过账户的2%

### 步骤2：移到盈亏平衡
- 当价格运行1倍风险距离后
- 将止损移动到入场价（平手）
- 此时交易变成"免费交易"

### 步骤3：追踪止损
- 当价格运行2倍风险距离后
- 将止损移动到每根K线的极值外
- 多头：每根K线的低点-1tick
- 空头：每根K线的高点+1tick

## 止盈策略：坚定持有 vs 见好就收

### 两种策略的对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 坚定持有 | 能抓住大波段 | 需要忍受利润回撤 | 强趋势、突破、窄通道 |
| 见好就收 | 落袋为安、心态稳定 | 可能错过更大波段 | 震荡、宽通道、不确定状态 |

### 如何选择

```
选择坚定持有的条件：
1. 市场处于强趋势或窄通道
2. 价格远离成本，有足够安全垫
3. 止损已移动到盈亏平衡
4. 有明确的测量移动（MM）目标
5. 没有明显反转信号

选择见好就收的条件：
1. 市场处于震荡或宽通道
2. 到达第一目标位
3. 出现不确定信号K线
4. 临近重要事件或收盘
5. 需要保护既得利润
```

### 分批获利模板

### 标准模板（波段交易）

| 批次 | 比例 | 目标 | 触发条件 |
|------|------|------|----------|
| 第1批 | 40% | 1倍风险 | 价格到达1倍风险 |
| 第2批 | 30% | 2倍风险 | 价格到达2倍风险 |
| 第3批 | 30% | MM/磁铁 | 追踪止损触发 |

### 激进模板（剥头皮）

| 批次 | 比例 | 目标 |
|------|------|------|
| 全部 | 100% | 1-2倍风险 |

### 保守模板（长波段）

| 批次 | 比例 | 目标 |
|------|------|------|
| 第1批 | 30% | 2倍风险 |
| 第2批 | 30% | MM目标 |
| 第3批 | 40% | 趋势线/通道线 |

## 目标位优先级

### MM位的多重作用

```
MM位（测量移动位）不仅可以作为目标位，还可以作为支撑/阻力位：

多头趋势中：
- MM位是目标位
- 价格到达MM位后可能回落
- MM位上方形成压力

空头趋势中：
- MM位是目标位
- 价格到达MM位后可能反弹
- MM位下方形成支撑

实际应用：
- 大约60%的概率会到达MM位
- 到达MM位后考虑减仓或全部平仓
- 如果价格强势突破MM位，可继续持有
```

### 目标位到达概率

| 目标类型 | 概率 | 应用 |
|----------|------|------|
| 区间MM位 | 约60% | 区间交易中到达对侧边界 |
| leg1=leg2的N字结构MM位 | 约60% | 趋势中的测量移动 |
| 实际风险测量的目标位 | 约60% | 基于风险的等距目标 |
| 特别大K线翻倍的距离 | 约60% | 惊喜K线后的目标 |

## 加仓/减仓规则

### 加仓条件（必须全部满足）

1. 趋势方向明确且强劲
2. 信号棒质量高（强信号棒）
3. 第一笔仓位已有盈利
4. 加仓后的总风险不超过账户2%
5. 不是窄区间/铁丝网行情

### 减仓条件（任一满足即减仓）

1. 价格到达第一目标 → 减仓50%
2. 通道变宽、回撤加深 → 减仓至50%
3. 出现反向信号K线 → 全部平仓
4. 到达MM目标 → 全部平仓
5. 状态转换（如趋势→区间） → 全部平仓
6. 入场前提不再成立 → 立即离场

## 离场规则：前提失效即离场

```
核心原则：一旦入场的前提不再成立，就应该离场。

具体表现：
1. 重要低点被跌破（多头趋势）
   - 上升趋势的前提可能不再成立
   - 市场可能进入震荡区间甚至下降趋势
   - 应立即离场或减仓

2. 重要高点被突破（空头趋势）
   - 下降趋势的前提可能不再成立
   - 市场可能进入震荡区间甚至上升趋势
   - 应立即离场或减仓

3. 趋势线被有效突破
   - 趋势结构破坏
   - 重新评估市场状态
   - 顺势仓位应考虑离场

4. 出现反向强信号K线
   - 市场方向可能改变
   - 至少减仓，必要时全部平仓
```

## 绝不做的事

1. 绝不移动止损远离入场价（只能向盈利方向移动）
2. 绝不在窄区间中加仓
3. 绝不让盈利交易变成亏损交易
4. 绝不在情绪激动时交易（连亏2笔后冷静15分钟）
5. 绝不超单日最大亏损限额（账户的3-5%）
6. 绝不在入场前提失效后仍死扛
7. 绝不因为"怕错过更大波段"而拒绝止盈
8. 绝不因为"已经赚了不少"而提前离场（除非计划如此）

## 仓位计算公式

```
标准仓位 = 账户余额 × 单笔风险% / |入场价 - 止损价|

凯利仓位 = 标准仓位 × (胜率 - (1-胜率)/(盈亏比))

实际仓位 = 标准仓位 × 状态系数
```

### 状态系数

| 状态 | 系数 | 原因 |
|------|------|------|
| 突破 | 0.5-0.75 | 假突破风险 |
| 窄通道 | 1.0 | 高概率顺势 |
| 宽通道(H2) | 1.0-1.25 | 最高概率信号 |
| 小反转 | 0.75 | 顺势但需谨慎 |
| 大反转 | 0.5 | 逆势交易 |
| 宽区间 | 1.0 | 边界附近 |
| 窄区间 | 0 | 不交易 |

## 止损的哲学

```
止损 = 救命

为什么要止损？
1. 学会亏钱，才能赢钱
2. 钱是赚不完的，但可以很快亏完
3. 不愿止损会错过新的交易机会
4. 承认错误很痛苦，但不承认更痛苦

为什么不愿意止损？
1. 大脑会正当化错误行为
2. 期待小概率事件发生："万一涨回去呢？"
3. 亏损时充满希望，盈利时急于离场

正确做法：
- 入场前确定止损位
- 入场后立即设置止损
- 止损只能向有利方向移动
- 触发止损后立即离场，不犹豫
```

## 窄止损 vs 宽止损决策

> 止损宽窄没有绝对的好坏，关键是匹配当前市场状态和交易风格。
> 来源：思维导图"止损"模块 — 窄止损 or 宽止损

### 窄止损 vs 宽止损对比

| 维度 | 窄止损 | 宽止损 |
|------|--------|--------|
| 止损距离 | 信号K线极值外1-2 tick | 信号K线反向极值外3-5 tick |
| 单笔风险 | 小（账户0.5-1%） | 大（账户1-2%） |
| 仓位 | 可以更大 | 必须更小 |
| 被扫损概率 | 高（假突破/噪音容易触发） | 低（给市场更多空间） |
| 心态要求 | 需要接受频繁小亏 | 需要忍受更大浮亏 |
| 盈亏比 | 易实现高盈亏比 | 盈亏比相对较低 |
| 适用风格 | 剥头皮 | 波段交易 |

### 选择窄止损的条件

```
窄止损适用于：
1. 信号K线质量极高（A级）
   - 收盘在极端、影线极小、实体适中
   - 在关键价位（磁铁/支撑/阻力）精确反转
   - 信号出现位置非常精确

2. 市场状态适合紧止损
   - 窄通道/微通道：回调极小，止损紧贴趋势线
   - 窄区间突破：突破点明确，止损在区间边界外
   - 高潮后的反转：反转K线极端明确

3. 交易风格
   - 剥头皮交易：天然需要窄止损
   - 短期波段：第一段行情通常方向明确

4. 高动能时段
   - 开盘第一小时：方向明确、噪音小
   - 突破阶段：动量强、回撤小
```

### 选择宽止损的条件

```
宽止损适用于：
1. 信号K线质量中等（B级-C级）
   - 有一定影线、实体不够极端
   - 信号位置在"区域"而非"精确价位"
   - 需要更多空间让市场确认方向

2. 市场状态需要宽止损
   - 宽通道：回调深、波动大，窄止损容易被扫出
   - 宽区间：边界处假突破频繁，需要更宽空间
   - 大反转/MTR：逆势交易，市场需要更多空间来确认反转

3. 交易风格
   - 波段交易：天然需要宽止损来穿越回撤
   - 长波段：持有时间越长，止损需要越宽

4. 高波动环境
   - 重要事件前后：波动率飙升
   - 加密货币：天然波动大
   - 开盘/收盘前后：流动性变化
```

### 止损宽度决策矩阵

| 信号K线质量 | 市场状态 | 止损选择 | 推荐仓位 |
|-------------|----------|----------|----------|
| A级(4.5-5.0) | 窄通道/突破 | 窄止损（1-2 tick） | 标准×1.0 |
| A级(4.5-5.0) | 宽通道 | 正常止损（2-3 tick） | 标准×1.0 |
| B级(3.5-4.4) | 窄通道 | 正常止损（2-3 tick） | 标准×0.75 |
| B级(3.5-4.4) | 宽通道/区间 | 宽止损（3-5 tick） | 标准×0.5 |
| C级(2.5-3.4) | 任何状态 | 宽止损或放弃 | 标准×0.25 |
| C级以下 | 任何状态 | 不交易 | 0 |

### 按市场状态的止损宽度

| 市场状态 | 剥头皮止损 | 波段止损 | 推荐 |
|----------|-----------|----------|------|
| 突破 | 紧（1-2 tick） | 正常（2-3 tick） | 剥头皮优先 |
| 窄通道 | 紧（1-2 tick） | 正常（2-3 tick） | 均可 |
| 宽通道 | 正常（2-3 tick） | 宽（3-5 tick） | 波段优先 |
| 小反转 | 正常（2-3 tick） | 正常（2-3 tick） | 均可 |
| 大反转 | — | 宽（3-5 tick） | 仅波段 |
| 宽区间 | 紧（1-2 tick） | 宽（3-5 tick） | 剥头皮优先 |
| 窄区间 | — | — | 不交易 |

### 止损宽度的实用原则

```
1. 止损必须在"有意义"的位置
   - 信号K线极值外（最重要）
   - 最近的摆动高/低点外
   - 趋势线/通道线外
   - 而不是"固定多少tick"或"固定金额"

2. 止损宽度 = f(仓位大小)
   - 窄止损 → 可以开更大仓位（因为风险金额固定）
   - 宽止损 → 必须减小仓位（保持单笔风险≤2%）
   - 仓位 = 风险金额 / 止损宽度 → 止损越宽，仓位越小

3. 新手建议：从正常止损开始
   - 不要追求极窄止损（容易被噪音扫出）
   - 不要用超宽止损（容易扛单到无法承受）
   - 先从信号K线极值外2-3 tick的"正常止损"开始
   - 积累经验后，根据市场状态和信号质量灵活调整

4. 依靠初始止损 / 提前离场
   - 如果发现入场理由错误，不要等止损触发
   - 争取打平或小亏离场，保留本金
   - 初始止损是"最后的防线"，不是"唯一的离场条件"

5. 核心原则：止损宽窄 = 给市场"合理"的呼吸空间
   - 太窄 → 被噪音震出，错失好交易
   - 太宽 → 单笔亏损过大，难以回本
   - 合理 → 市场正常波动不会触发，但真正反转时能保护本金
```
