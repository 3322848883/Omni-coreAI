## 一、区间定义

> "大部分突破尝试会失败，市场会再三从区间底部形成的支撑区向上反转，从区间顶部形成的阻力区向下反转。"（Al Brooks，区间篇）

> "在任何时间点，市场要么在趋势中，要么在区间中。"（Al Brooks 第6条交易指南）

**核心定义**：交易区间是价格在支撑位和阻力位之间来回波动的市场状态。多空双方力量均衡，没有持续的更高高点或更低低点。

**区间与趋势的本质区别**：

| 维度 | 趋势 | 区间 |
|------|------|------|
| 摆动高/低点 | HH+HL 或 LH+LL | 没有持续的HH+HL或LH+LL |
| 边界 | 趋势线倾斜 | 水平支撑和阻力 |
| K线重叠 | 少（趋势中） | 多（大量重叠） |
| EMA关系 | 价格始终在EMA一侧 | 价格穿越EMA |
| Always In | 单向 | 频繁切换 |
| 80%规则 | 80%反转尝试失败 | 80%突破尝试失败 |

## 二、宽区间 vs 窄区间对比表

> 来源：31_market_cycle.md §1.4、19_playbook.md Playbook 6/7、02_decision_tree.md

| 维度 | 宽区间（Broad Range） | 窄区间/铁丝网（Tight Range/Barbwire） |
|------|----------------------|--------------------------------------|
| **区间高度** | > 2 x ATR(14) | <= 2 x ATR(14) |
| **重叠率** | 正常 | > 80% |
| **边界清晰度** | 明确（可交易） | 模糊 |
| **利润空间** | 足够（可刮头皮） | 不足 |
| **K线特征** | 在边界处有明确信号K线 | 大量重叠K线、十字星多、影线突出 |
| **交易策略** | BLiSHS（高抛低吸） | 不交易！等待突破 |
| **仓位** | 100% | 0% |
| **信号可靠性** | 边界处信号可靠 | 所有信号都不可靠 |
| **突破方向** | 可双向判断 | 无法判断 |
| **持续时间** | 任意 | 新形成(<10根) vs 长期(>=10根) |

### 2.1 窄区间中的铁丝网（Barb Wire）

Al Brooks原文（来自区间篇）：

> "铁丝网（Barb Wire）形态常见。窄区间中任何交易都是赌博。"

| 铁丝网特征 | 说明 |
|------------|------|
| 大量重叠K线 | 几乎每根K线都在前一根范围内 |
| 十字星多 | 多空双方都缺乏方向 |
| 振幅极小 | 利润空间不足 |
| 双向都缺乏动量 | 突破方向无法判断 |

## 三、区间中的交易策略

> 来源：19_playbook.md Playbook 6、31_market_cycle.md §1.4

### 3.1 BLiSHS（高抛低吸）核心策略

| 策略 | 方向 | 位置 | 信号 | 做法 |
|------|------|------|------|------|
| **Buy Low** | 做多 | 区间底部 | H2 + 双底 + DBS | 限价单入场 |
| **Sell High** | 做空 | 区间顶部 | L2 + 双顶 + DBL | 限价单入场 |
| **区间中部** | 不交易 | 中间位置 | 任何信号 | 磁性拉力导致双向风险 |

> "区间中间位置的任何信号=不可靠。区间中间不交易——磁性拉力导致双向风险。"（19_playbook.md）

### 3.2 Playbook 6：宽区间完整操作手册

| 维度 | 规则 |
|------|------|
| **识别确认** | 边界清晰 · 振幅足够大（有利润空间）· 价格在支撑和阻力间来回 · 区间中部K线重叠多 · 突破尝试频繁但大多失败 |
| **优先信号** | 区间底部：H2买入 + 双底 + DBS · 区间顶部：L2做空 + 双顶 + DBL · 区间边界处的ii/ioi逆势突破 · 区间内的楔形（第一个信号即可入场） |
| **信号K线** | 区间底部：强多头反转K线（下影线、大实体）· 区间顶部：强空头反转K线（上影线、大实体） |
| **入场** | 使用限价单在区间边界入场（而非止损单）· 在信号K线极值处设限价单 |
| **止损** | 区间边界外1-2 tick · 止损距离较小（因为区间边界清晰） |
| **目标** | 最小目标：区间对侧边界（刮头皮）· 延伸目标：如果区间突破成功，摆动持有 |
| **仓位** | 正常仓位100% · 可适当增大（止损距离小）· 双向交易但每次只做一个方向 |
| **管理** | 刮头皮为主——到达对侧边界时获利了结 · 区间中间不交易 · 80%突破失败->可以在边界处逆势交易突破 |
| **退出条件** | 区间被有效突破（强趋势K线+后续跟进）->停止区间交易->转为突破模式 |
| **禁用信号** | 区间中间位置的所有信号 · 区间边界处的顺势突破追入 · 窄区间中的所有信号 |

### 3.3 Playbook 7：窄区间操作手册

| 维度 | 规则 |
|------|------|
| **识别确认** | 大量重叠K线 · 十字星多 · 振幅极小 · 利润空间不足 · 突破方向无法判断 |
| **优先信号** | 没有任何信号是可靠的。H1/H2/L1/L2/ii/ioi/双顶底——全部不可靠 |
| **入场** | 不入场。等待窄区间被有效突破后再进入Playbook 1（突破模式） |
| **仓位** | 0%——空仓等待 |
| **管理** | 关注窄区间持续多久——新形成的窄区间：继续等待 · 持续时间久（能量积累）：准备突破入场 |
| **退出条件** | 窄区间被有效突破->进入Playbook 1 |

## 四、区间突破预警

> 来源：31_market_cycle.md 转换四、19_playbook.md

### 4.1 区间 -> 突破的3个预警信号

| # | 信号 | 说明 | 交易动作 |
|---|------|------|----------|
| 1 | **区间收窄** | 震荡区间变窄，K线变小，出现铁丝网 | 警戒，准备突破 |
| 2 | **第二次入场信号** | 对区间边缘的第二次测试失败 | 突破概率增加 |
| 3 | **强趋势K线突破** | 一根强趋势K线突破区间边缘，有后续跟进 | 顺势追入，突破方向入场 |

### 4.2 窄区间突破后的测量移动

> "窄区间持续时间长（能量积累），突破后的测量移动 = 区间宽度 x 2-3。"（19_playbook.md）

## 五、80%区间突破失败原则

> 来源：31_market_cycle.md §4.3、19_playbook.md

| 原则 | 内容 |
|------|------|
| **核心概率** | 80%震荡区间突破失败 |
| **策略含义** | 在区间边界处逆势交易突破是做高概率交易 |
| **例外** | 区间收窄 + 第二次入场失败 + 强趋势K线突破 -> 突破概率显著增加 |
| **区间持续时间** | >20根K线 -> 突破概率增加；<10根K线 -> 区间可能持续 |

Al Brooks原文（区间篇）：

> "大部分突破尝试会失败，市场会再三从区间底部形成的支撑区向上反转，从区间顶部形成的阻力区向下反转。"

## 七、真空效应在区间中的表现

> 来源：Al Brooks #8 交易区间反转

Al Brooks原文：

> "市场经常在顶部出现真空，多头获利了结而不是买入更多，空头便突然出现。多头和空头都期望测试阻力位将导致突破失败。在底部则相反。当价格接近支撑时，剥头皮的空头交易者会卖出更多，期望市场再下跌一点。多头停止买入，因为他们相信市场会达到支撑位并可能突破它。"

**真空效应的机制**：

| 位置 | 多头行为 | 空头行为 | 结果 |
|------|----------|----------|------|
| **区间顶部（阻力）** | 获利了结，不买入更多 | 突然出现做空 | 价格反转下跌 |
| **区间底部（支撑）** | 不买入，等待更低价格 | 卖出更多，期望再跌 | 但买家出现，反转上涨 |

**真空效应的交易含义**：

> "结果是，市场在底部形成强烈看跌烛台，随后价格被推动到支撑位。然后买家来了，而非跟进卖出。空头获利了结并进行回补，多头买入启动牛市行情。"（Al Brooks #8）

| 现象 | 含义 |
|------|------|
| 底部出现强看跌K线 | 不是趋势延续信号，而是空头最后一击 |
| 价格到达支撑位后买家出现 | 真空被填补 |
| 空头回补 | 加速反弹 |

## 八、区间中双向交易信号与初学者陷阱

Al Brooks原文：

> "当交易者开始时，通常直到一天结束才会意识到市场正在形成交易区间。初学者会对反复的反转感到困惑和失望，没有意识到这些感觉其实就是区间交易的标志。"

| 初学者的错误 | 区间交易者的正确做法 |
|-------------|---------------------|
| 在顶部追多（以为要突破） | 在顶部做空（押注突破失败） |
| 在底部追空（以为要跌破） | 在底部做多（押注突破失败） |
| 对反复反转感到困惑失望 | 将反复反转视为区间交易机会 |
| 在区间中部交易 | 只在区间边界交易 |

## 九、区间决策树速查

> 来源：02_decision_tree.md

```
区间 -> 判断宽区间还是窄区间？
    [量化：区间高度 > 2xATR(14) -> 宽区间]
    [量化：区间高度 <= 2xATR(14) 且 重叠率 > 80% -> 窄区间]

    ├── 宽区间 -> 判断价格在哪个位置？
    │      [量化：价格距上边界 < 区间高度x20% -> 上边界附近]
    │      [量化：价格距下边界 < 区间高度x20% -> 下边界附近]
    │      [量化：价格在中间 -> 不交易]
    │      ├── 上边界附近 -> 做空/等突破
    │      ├── 下边界附近 -> 做多/等突破
    │      └── 中间位置 -> 不交易（磁性拉力）

    └── 窄区间 -> 判断持续多久？
           [量化：已持续K线数 < 10 -> 新形成的窄区间]
           [量化：已持续K线数 >= 10 -> 长期窄区间]
           ├── 新形成的窄区间 -> 等待、不交易
           └── 长期窄区间 -> 能量积累、准备突破入场
```

## 十一、三角形与收敛形态（区间内特殊收敛）

> 来源对照：同源价格行为体系将三角形视为**交易区间中的特殊收敛**，置于交易区间框架（Brooks 原文="Triangles are trading ranges and therefore channels"）。

### 四类三角形

| 类型 | 结构 | 突破偏向 | 规则 |
|------|------|---------|------|
| 上升三角形 | 上边界水平（阻力）+ 下边界抬高（更高低点） | 传统惯例偏向上；**Brooks 强调水平三角形可双向突破**，务实以突破后是否跟随确认 | 无效：仅 1-2 次触顶、下轨不清晰 |
| 下降三角形 | 下边界水平（支撑）+ 上边界降低（更低高点） | 传统惯例偏向向下；**Brooks 强调可双向**，同样以跟随确认为准 | 无效：下轨多次刺穿未收稳 |
| 对称三角形 | 上边界下降 + 下边界上升，收敛 | **突破方向不确定，禁止赌方向**；等收盘突破 + 跟随确认 | 目标 = 最大宽度投影 MM |
| 扩张三角形 | 边界向外扩散，波动加大 | 方向不定、**风险更高** | 需更强信号与更高质量形态；Brooks 亦讨论过扩张三角交易，**非绝对不交易**——无强信号时暂避 |

> 注：上升/下降"偏向"多为传统技术分析惯例，Brooks 官方强调**水平三角形可双向突破**（Wiley Brooks 章节）；故边界入场一律以"价位于边界 + 反转信号棒 + 与 Always In 一致"为据，不单靠形态偏向押注。

### 识别 checklist

- [ ] 至少 2 次触顶 + 2 次触底（或对应边界测试）
- [ ] 边界线可描述（水平 + 倾斜，或双向收敛）
- [ ] 位于区间/趋势中，非尖峰中部
- [ ] 收敛末端：波动收缩、内包棒增多

### 交易规则

1. **默认区间思维**：80% 突破尝试失败——普通突破不追。
2. **边界入场**：第二次触边 + 反转信号棒（且与方向一致），优于第一次。
3. **突破交易**：须尖峰级/强趋势棒 + 跟随，或"失败的失败"后二次入场；**禁止追第一根突破棒**。
4. **对称三角形**：等收盘确认方向，不得同时挂双向；仅当突破方向与 Always In 方向一致时评估入场。

### 与楔形区别

| | 三角形 | 楔形 |
|---|--------|------|
| 上边 | 常水平或单向下倾 | 两边同向倾斜 |
| 三推 | 非必须 | 必须三推 |
| 归属 | 区间内特殊收敛（本模块） | 三推反转形态（`15_pattern_recognition.md`、`40_final_flag`） |
