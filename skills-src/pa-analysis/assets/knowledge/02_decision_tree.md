# 决策树（Decision Tree）— 带量化阈值

> **重要提示：** 本文中的量化阈值（重叠率、ATR倍数、实体倍数等）为作者基于Brooks定性框架的实用扩展，**非Al Brooks原文**。Brooks的价格行为分析是定性分析，不使用精确的百分比或倍数指标。量化阈值作为辅助参考，不应替代对市场背景的定性判断。

## 完整决策流程（含量化阈值）

```
开始 → 判断趋势还是区间？
    │    [量化：计算最近20根K线重叠率]
    │    [重叠率 < 30% → 趋势；重叠率 ≥ 60% → 区间；30-60% → 结合EMA判断]
    │
    ├── 趋势 → 判断突破还是通道？
    │      │    [量化：连续趋势K线数 ≥ 5 且 平均重叠率 < 10% → 突破]
    │      │    [量化：不满足以上 → 通道]
    │      │
    │      ├── 突破 → 判断是否引爆点？
    │      │      │    [量化：突破K线实体 > 3×平均实体 且 成交量 > 2×平均成交量]
    │      │      │
    │      │      ├── 是 → 顺势追入（止损单）
    │      │      │      └── 入场：突破K线高点+1tick
    │      │      │      └── 止损：突破K线低点-1tick
    │      │      │      └── 仓位：标准仓位 × 0.5-0.75
    │      │      │
    │      │      └── 否 → 等待BOP（突破回撤）
    │      │             └── 入场：回撤到突破点+信号K线
    │      │             └── 止损：回撤极值外
    │      │
    │      └── 通道 → 判断窄通道还是宽通道？
    │             │    [量化：平均回撤K线数 ≤ 3 且 最大回撤 < 通道宽度40% → 窄通道]
    │             │    [量化：平均回撤K线数 > 3 或 最大回撤 ≥ 通道宽度40% → 宽通道]
    │             │
    │             ├── 窄通道 → 等H1入场（限价单）
    │             │      └── 回撤到EMA/小趋势线
    │             │      └── 止损：信号K线极值外
    │             │      └── 仓位：标准仓位 × 1.0
    │             │
    │             └── 宽通道 → 判断是否收缩阶梯？
    │                    │    [量化：最近3次回撤深度递减 → 收缩阶梯]
    │                    │
    │                    ├── 是 → 准备反转（等第二个信号）
    │                    │      └── 信号：楔形反转 + 第二个信号确认
    │                    │      └── 仓位：标准仓位 × 0.5
    │                    │
    │                    └── 否 → 等H2入场（ABC回调）
    │                           └── 通道线附近优先
    │                           └── 止损：回调腿极值外
    │                           └── 仓位：标准仓位 × 1.0-1.25
    │
    └── 区间 → 判断宽区间还是窄区间？
           │    [量化：区间高度 > 2×ATR(14) → 宽区间]
           │    [量化：区间高度 ≤ 2×ATR(14) 且 重叠率 > 80% → 窄区间]
           │
           ├── 宽区间 → 判断价格在哪个位置？
           │      │    [量化：价格距上边界 < 区间高度×20% → 上边界附近]
           │      │    [量化：价格距下边界 < 区间高度×20% → 下边界附近]
           │      │    [量化：价格在中间 → 不交易]
           │      │
           │      ├── 上边界附近 → 做空/等突破
           │      │      └── 入场：限价单在上边界附近
           │      │      └── 止损：上边界外1-2tick
           │      │      └── 仓位：标准仓位 × 1.0
           │      │
           │      ├── 下边界附近 → 做多/等突破
           │      │      └── 入场：限价单在下边界附近
           │      │      └── 止损：下边界外1-2tick
           │      │      └── 仓位：标准仓位 × 1.0
           │      │
           │      └── 中间位置 → 不交易（磁性拉力）
           │
           └── 窄区间 → 判断持续多久？
                  │    [量化：已持续K线数 < 10 → 新形成的窄区间]
                  │    [量化：已持续K线数 ≥ 10 → 长期窄区间]
                  │
                  ├── 新形成的窄区间 → 等待、不交易
                  │
                  └── 长期窄区间 → 能量积累、准备突破入场
                         └── 入场：突破窄区间边界+确认K线
                         └── 方向：突破方向
                         └── 仓位：标准仓位 × 0.75
```

## 反转子决策（含量化阈值）

```
趋势中出现了反向信号 → 判断是小反转还是大反转？
    │    [量化：反向走势是否突破主要趋势线？]
    │    [量化：反向走势是否测试旧极端（前高/前低）？]
    │
    ├── 小反转 → 未破主要趋势线
    │      └── 顺势回撤入场（继续原趋势方向）
    │      └── 入场：回撤到支撑/阻力位
    │      └── 止损：回撤极值外
    │      └── 仓位：标准仓位 × 0.75
    │
    └── 大反转/MTR → 破趋势线+测试旧极端
           └── 等第二个信号确认 → 逆势入场
           │      └── 信号：第二个信号K线触发
           │      └── 止损：第二信号极值外
           │      └── 仓位：标准仓位 × 0.5
           │
           └── 如果第二个信号失败 → 扭转失败、恢复原趋势
                  └── 入场：原趋势方向入场（最强信号之一）
                  └── 仓位：标准仓位 × 1.0
```

## 量化阈值汇总表

| 决策节点 | 量化指标 | 阈值 | 分支 |
|----------|----------|------|------|
| 趋势 vs 区间 | 20根K线重叠率 | < 30% → 趋势 | ≥ 60% → 区间 |
| 突破 vs 通道 | 连续趋势K线数 | ≥ 5 → 突破 | < 5 → 通道 |
| 突破 vs 通道 | 平均重叠率 | < 10% → 突破 | ≥ 10% → 通道 |
| 引爆点 | 突破K线实体 | > 3×平均实体 | → 引爆点 |
| 引爆点 | 成交量 | > 2×平均成交量 | → 引爆点 |
| 窄通道 vs 宽通道 | 平均回撤K线数 | ≤ 3 → 窄 | > 3 → 宽 |
| 窄通道 vs 宽通道 | 最大回撤深度 | < 40%通道宽度 → 窄 | ≥ 40% → 宽 |
| 收缩阶梯 | 最近3次回撤深度 | 递减趋势 | → 收缩阶梯 |
| 宽区间 vs 窄区间 | 区间高度 | > 2×ATR(14) → 宽 | ≤ 2×ATR(14) → 窄 |
| 窄区间判定 | 重叠率 | > 80% → 窄区间 | — |
| 区间位置 | 距边界距离 | < 20%区间高度 | → 边界附近 |
| 窄区间持续时间 | K线数 | < 10 → 新 | ≥ 10 → 长期 |
| 小反转 vs 大反转 | 是否破趋势线 | 否 → 小反转 | 是 → 大反转 |
| 大反转确认 | 测试旧极端 | 是 → 确认 | 否 → 继续观察 |

## 关键决策原则

| 原则 | 说明 |
|------|------|
| 趋势优先 | 始终优先顺势交易 |
| 第二信号优先 | H2 > H1，楔形反转第二个信号 > 第一个信号 |
| 窄区间不交易 | 铁丝网中任何交易都是赌博 |
| 区间中间不交易 | 磁性拉力导致双向风险 |
| 收缩阶梯=反转预警 | 宽通道中动量减弱是反转前兆 |
| 80/20规则 | 大反转中80%的回撤会失败，等极端确认 |
| 连亏2笔冷静 | 连续亏损2笔后必须冷静15分钟 |
| 信号K线收盘再入场 | 不等收盘就入场 = 赌博 |

## 可执行规则族（IF-THEN-EXCEPT）

> 同源对照 strategy_workflow（133 条规则引擎）精简提炼，用于入场/风控决策的机器可读判断。统一格式 `IF 条件 THEN 动作 EXCEPT 排除`。优先级 P0=禁止/强制 > P1 > P2 > P3。

### 入场优先级（顺势 > 逆势 > 观望）

| 优先级 | 触发条件 | 动作 | 例外 |
|--------|---------|------|------|
| P1 | 顺势信号且 HTF 方向一致（≥3/5） | 正常入场，标准仓位 | 信号棒质量差 → 降级观望 |
| P2 | 顺势信号但 HTF 方向中性 | 可交易，仓位减半 | 星级≥⭐⭐⭐⭐ 可用 75% 仓位 |
| P3 | HTF 方向矛盾（≤1/5）或 HTF 强趋势下逆势信号 | **禁止交易** | HTF 处区间且⭐⭐⭐⭐⭐ 建仓形态，可用 25% 仓位 |
| P2 | 多个同向顺势信号并存 | 合并理由，选最佳入场点 | — |
| P3 | 强趋势中的弱逆势信号 vs 弱趋势强逆势信号 | **都不交易** | 有⭐⭐⭐⭐⭐ 建仓形态才考虑 |
| P0 | 铁线网/区间中间 30% 区域 | **不交易** | 有强突破信号 |

### 仓位/风控规则族

| 规则 | 触发条件 | 动作 |
|------|---------|------|
| RM-杠杆 | 摆动=max 3x、日内=max 5x、刮头皮=max 3x 有效杠杆 | 超限 → 不执行 |
| RM-RR | 交易者方程式 P(win)×Reward > P(loss)×Risk 不为正 | 期望值为负 → 不做 |
| RM-新闻 | 重大宏观数据前 30 分钟 | 停止开新仓，数据后等建仓形态 |
| PM-单笔 | 单笔风险 > 2% 或总风险 > 6% | 拒绝 |
| PM-重仓 | 重仓赌单笔 | 拒绝（BAN-10） |
| 管理 | 有浮盈时保护至少一部分利润 | 不要让盈利变亏损 |

## 核心决策哲学（Trade What You See）

1. **不求为什么**：不要用新闻/基本面/逻辑解释价格行为，图表告诉你需要知道的一切。
2. **只交易看到的**：图是趋势做趋势，图是区间做区间；不要交易"你认为应该发生"的事。
3. **接受不确定性**：价格行为始终在灰色迷雾中，接近就足够接近。
4. **不要预测**：预测是输家的游戏；对正在发生的事做反应，而非预测将要发生的事。
5. **价格行为矛盾时永远相信价格行为**（当预期与图表冲突，后者为真）。
