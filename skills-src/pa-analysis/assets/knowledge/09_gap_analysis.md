# 缺口分析（Gap Analysis）

## 缺口类型与识别

### 缺口四分类

| 类型 | 英文 | 出现位置 | 特征 | 交易含义 |
|------|------|----------|------|----------|
| 突破缺口 | Breakaway Gap | 突破关键价位 | 大缺口、大成交量 | 顺势追入，趋势刚刚开始 |
| 测量缺口 | Measuring Gap | 趋势中段 | 缺口大小适中 | 测量目标=缺口前走势长度 |
| 衰竭缺口 | Exhaustion Gap | 趋势末端 | 缺口后迅速反转 | 趋势结束，准备反转 |
| 普通缺口 | Common Gap | 区间内 | 小缺口、迅速回补 | 忽视，无交易意义 |

### 缺口K线（Gap Bar / GB）

```
条件：当前K线低点 > 前一根K线高点（向上缺口）
      当前K线高点 < 前一根K线低点（向下缺口）
含义：动能强劲，市场价格跳过了一段区域
```

### 均线缺口K线（MAGB）

```
条件：当前K线完全在20EMA上方（多头）或下方（空头），不触及EMA
含义：趋势强劲，价格远离均线运行
注意：与普通缺口K线（GB）不同，MAGB仅指与EMA的关系
```

### 20缺口棒（20GB）

```
条件：连续20根或更多K线未触及EMA
含义：趋势极强，但接近极端，警惕反转
信号：20GB后出现反向信号K线 → 高概率反转
```

## 缺口强度分级

### 按价格重叠程度分级

| 强度 | 类型 | 特征 | 交易含义 |
|------|------|------|----------|
| 最强 | 影线之间缺口 | 当前K线低点 > 前根K线高点（完全无重叠） | 动能极强，趋势延续概率高 |
| 较强 | 实体之间缺口 | 当前K线实体完全在前根实体之外 | 动能强劲，但需警惕影线回补 |
| 较弱 | 仅影线缺口 | 仅影线部分不重叠，实体有重叠 | 动能一般，可能快速回补 |

### 缺口强度与交易策略

```
最强缺口（影线之间）：
- 代表上涨或反转非常强势
- 顺势追入或等待小幅回调入场
- 止损设在缺口另一侧

较强缺口（实体之间）：
- 趋势动能强
- 可以顺势，但仓位略减
- 警惕完全回补缺口

较弱缺口（影线重叠）：
- 动能不足
- 不追入，等待确认
- 可能演变为区间内普通波动
```

## 缺口测量与目标位

### 缺口对半分测量法

```
测量缺口目标位 = 缺口中点 ± 缺口前走势长度

多头缺口：
  缺口中点 = (缺口下沿 + 缺口上沿) / 2
  目标位 = 缺口中点 + 缺口前上涨腿长度

空头缺口：
  缺口中点 = (缺口上沿 + 缺口下沿) / 2
  目标位 = 缺口中点 - 缺口前下跌腿长度
```

### 缺口作为支撑/阻力

```
向上缺口形成后：
- 缺口下沿成为支撑
- 价格回踩缺口下沿 + 多头信号 → 做多
- 价格完全回补缺口 → 缺口失效

向下缺口形成后：
- 缺口上沿成为阻力
- 价格反弹到缺口上沿 + 空头信号 → 做空
- 价格完全回补缺口 → 缺口失效
```

## 缺口开盘策略

### 开盘缺口类型

| 开盘情况 | 判定 | 策略 |
|----------|------|----------|
| 向上跳空开盘 | 开盘价 > 前日最高价 | 等开盘区间形成 → 如果突破开盘区间高点 → 追多 |
| 向下跳空开盘 | 开盘价 < 前日最低价 | 等开盘区间形成 → 如果跌破开盘区间低点 → 追空 |
| 向上跳空但未破前高 | 开盘价在前日范围内偏上 | 正常交易，不特殊处理 |
| 向下跳空但未破前低 | 开盘价在前日范围内偏下 | 正常交易，不特殊处理 |

### 开盘区间（Opening Range）

```
定义：开盘后前5-15分钟形成的价格区间
作用：开盘区间的高低点是当日重要的支撑/阻力
交易规则：
  - 价格突破开盘区间高点 → 日内偏多
  - 价格跌破开盘区间低点 → 日内偏空
  - 价格在开盘区间内 → 等待突破
```

### 缺口开盘四形态（高开/低开 × 延续/反转）

> 来源：Al Brooks Encyclopedia 视频课程 Part 7（大幅高开）/ Part 5（大幅低开）Slide 4 笔记（L2，2026-09-11 补录）。大幅高开/低开后，以下四种形态占据 80% 的情况。

**大幅高开的 4 种常见结果**

| # | 形态 | 结构位置 | 交易含义 |
|---|------|----------|----------|
| 1 | 回踩 EMA，双底 | 高开后回踩 EMA 附近形成双底，守住转强 | 延续多：双底确认后继续向上 |
| 2 | 回踩 EMA，楔形底 | 高开后回踩 EMA 附近形成收敛楔形底 | 延续多：楔形底突破后继续向上 |
| 3 | 双顶 | 高开后在上方形成双顶（两次上冲失败） | 反转空：跌破颈线后向下 |
| 4 | 楔形顶 | 高开后形成上升楔形（楔顶常见 2 次冲击） | 反转空：第三推失败后向下 |

**大幅低开的 4 种常见结果**

| # | 形态 | 结构位置 | 交易含义 |
|---|------|----------|----------|
| 1 | 反弹 EMA，双顶 | 低开后反弹至 EMA 附近形成双顶 | 延续空：双顶确认后继续向下 |
| 2 | 反弹 EMA，楔形顶 | 低开后反弹至 EMA 附近形成收敛楔形顶 | 延续空：楔形顶跌破后继续向下 |
| 3 | 双底 | 低开后在下方形成双底 | 反转多：突破颈线后向上 |
| 4 | 楔形底 | 低开后形成下降楔形 | 反转多：楔形底突破后向上 |

```
判定枢纽：价格与 EMA 的关系
- 高开/低开后回到 EMA 附近并守住 → 延续原缺口方向（形态 1/2）
- 远离 EMA 后在极端位形成双顶/双底或楔形 → 反转（形态 3/4）
- 楔形顶注意「2 次冲击楔顶」：第二次冲击失败后的反转概率更高

背景概率：80% 的交易日开盘为某种形式的交易区间（并非直接单边趋势），
与「四种形态占据 80% 的情况」互为印证——开盘先按区间假设处理，
突破确认后再切换趋势策略。

入场衔接（与 51_entry_rules / 58_limit_vs_stop 同口径）：
- 延续形态（回踩 EMA 后双底/楔形底确认）→ 突破形态颈线用止损单
- 反转形态（双顶/楔形顶）→ 逆势性质：至少 3 个理由且含趋势线突破，仓位 ≤50%
```

## 缺口测量目标

### 测量缺口的目标计算

```
测量移动目标 = 缺口位置 + 缺口前走势长度

多头趋势：
  MM目标 = 缺口上沿 + (缺口前上涨腿的长度)
  
空头趋势：
  MM目标 = 缺口下沿 - (缺口前下跌腿的长度)
```

### 缺口回补交易

```
条件：缺口形成后，价格回补缺口
多头缺口回补（向上缺口后回落到缺口区域）：
  - 如果回到缺口上沿 + 多头信号K线 → 做多（缺口支撑有效）
  - 如果完全回补缺口 → 缺口失效，重回区间

空头缺口回补（向下缺口后回升到缺口区域）：
  - 如果回到缺口下沿 + 空头信号K线 → 做空（缺口阻力有效）
  - 如果完全回补缺口 → 缺口失效，重回区间
```

## 缺口自动化检测

```
输入：K线序列
输出：缺口类型

算法：
1. 检测所有缺口位置
2. 对每个缺口：
   a. 判断缺口前走势：趋势还是区间？
   b. 判断缺口位置：趋势起点/中段/末端？
   c. 判断缺口大小：大/中/小？
   d. 判断缺口后走势：是否迅速回补？

判定规则：
- 缺口前是区间 + 缺口突破关键价位 + 大缺口 → 突破缺口
- 缺口前是趋势 + 缺口后趋势继续 + 缺口大小适中 → 测量缺口
- 缺口前趋势已延伸 + 缺口后迅速反转 → 衰竭缺口
- 缺口在区间内 + 小缺口 → 普通缺口
```
