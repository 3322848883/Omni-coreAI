# AS. 情绪追踪量表（Sentiment Tracking Scale）

> 来源：Al Brooks 78条指南心理条目
> 场记指南参考：pa-trading-field-guide.html AS章节

## 5维度情绪记录

每笔交易记录以下5个维度：

### 1. 入场时情绪（1-5分）
| 分数 | 状态 | 交易建议 |
|:----:|------|---------|
| 1 | 极度恐惧 | 不交易，检查原因 |
| 2 | 轻度焦虑 | 减少仓位至50% |
| 3 | 平静 | 正常交易 |
| 4 | 轻度兴奋 | 注意纪律，不追单 |
| 5 | FOMO/贪婪 | 不交易，冷静15分钟 |

### 2. 持仓中情绪变化
记录持仓期间情绪是否波动：
- 稳定：情绪始终如一
- 焦虑：担心亏损，想提前平仓
- 贪婪：想扩大目标，不想止盈
- 报复：连亏后想翻本

### 3. 检查清单完成度
- 100%：全部完成
- 75%：大部分完成
- 50%：仅完成一半
- <50%：严重不足

### 4. 规则违反情况
- 无违反：严格遵守计划
- 轻微违反：小幅偏差（如止损移1-2tick）
- 中度违反：明显偏差（如提前平仓）
- 严重违反：完全无视规则（如不止损）

### 5. 决策质量评级
| 评级 | 标准 |
|:----:|------|
| A | 完美执行，所有检查清单完成，情绪稳定 |
| B | 有小瑕疵，但总体按计划执行 |
| C | 有重大错误，规则违反，情绪影响决策 |

## 情绪触发模式识别

常见情绪触发模式：
1. **连亏后报复** → 强制冷静15分钟
2. **连赢后过度自信** → 减少仓位
3. **窄区间中焦虑** → 不交易窄区间
4. **错过行情后FOMO** → 接受错过，等下一个
5. **大盈亏后情绪波动** → 当日停止交易
