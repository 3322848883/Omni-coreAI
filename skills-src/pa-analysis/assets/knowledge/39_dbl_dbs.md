## 一、DBL定义

DBL（Disappointed Bulls）即失望的多头，是指在最近强劲的多头K线买入的交易者，因出现的空头K线而感到失望，并可能卖出持有的多头头寸。

> 来源：theme12_abbreviations.md DBL词条："在最近强劲的多头K线买入的交易者，因出现的空头K线而感到失望，并可能卖出持有的多头头寸。可能形成微型双顶并开始向下反转。"

| 要素 | 说明 |
|------|------|
| 全称 | Disappointed Bulls |
| 中文 | 失望的多头 |
| 触发条件 | 多头K线买入后出现空头反转K线 |
| 交易者行为 | 卖出多头头寸（平仓） |
| 价格行为结果 | 形成微型双顶（Micro Double Top） |
| 方向含义 | 空头信号 |

---

## 二、DBS定义

DBS（Disappointed Bears）即失望的空头，是指在最近强劲的空头K线卖出空头头寸的交易者，因价格反转而感到失望，并可能回购空头头寸。

> 来源：theme12_abbreviations.md DBS词条："在最近强劲的空头K线卖出空头头寸的交易者，因价格反转而感到失望，并可能回购空头头寸。可能形成微型双底图形，表明可能从下降趋势转为上升趋势。"

| 要素 | 说明 |
|------|------|
| 全称 | Disappointed Bears |
| 中文 | 失望的空头 |
| 触发条件 | 空头K线卖出后出现多头反转K线 |
| 交易者行为 | 回购空头头寸（回补） |
| 价格行为结果 | 形成微型双底（Micro Double Bottom） |
| 方向含义 | 多头信号 |

---

## 三、DBL/DBS的形成机制

| 阶段 | DBL（失望多头） | DBS（失望空头） |
|------|----------------|-----------------|
| 第1步 | 出现强多头K线，交易者买入 | 出现强空头K线，交易者卖出 |
| 第2步 | 市场未能继续上涨，出现空头反转K线 | 市场未能继续下跌，出现多头反转K线 |
| 第3步 | 多头失望，卖出平仓 | 空头失望，回补平仓 |
| 第4步 | 卖压增加，形成微型双顶 | 买压增加，形成微型双底 |
| 第5步 | 价格可能向下反转 | 价格可能向上反转 |

> Al Brooks原文："在最近强劲的多头K线买入的交易者，因出现的空头K线而感到失望，并可能卖出持有的多头头寸。可能形成微型双顶并开始向下反转。"

## 四、DBL/DBS与微型双顶/双底的关系

| 形态 | DBL/DBS角色 | 价格结构 | 可靠性 |
|------|------------|----------|--------|
| 微型双顶（Micro DT） | DBL是多头失望后卖出 → 形成第二个顶 | 2-3根K线形成的小双顶 | ★★★★ |
| 微型双底（Micro DB） | DBS是空头失望后回补 → 形成第二个底 | 2-3根K线形成的小双底 | ★★★★ |
| 经典双顶（DT） | DBL可能演变为更大的双顶 | 两次触及同一阻力位 | ★★★★ |
| 经典双底（DB） | DBS可能演变为更大的双底 | 两次触及同一支撑位 | ★★★★ |

> 来源：15_pattern_recognition.md §2 双顶/双底完整分类表

## 五、DBL/DBS的可靠性评级

| 可靠性 | 评级 | 适用场景 |
|--------|------|----------|
| ★★★★ | 高 | 区间边界处、趋势末端、关键磁铁附近 |
| ★★★ | 中等 | 趋势中（作为小反转信号） |
| ★★ | 低 | 强趋势中段（逆势信号不可靠） |

## 六、交易策略

### 6.1 DBL做空策略

| 维度 | 规则 |
|------|------|
| 识别 | 强多头K线后出现空头反转K线，形成微型双顶 |
| 入场 | 第二个顶形成后，阴线反转信号K线低点下方做空 |
| 止损 | 微型双顶极端上方1-2 tick |
| 目标 | 第一目标：颈线位置；第二目标：测量移动 |
| 仓位 | 标准仓位（区间边界处）；减仓（趋势中） |

### 6.2 DBS做多策略

| 维度 | 规则 |
|------|------|
| 识别 | 强空头K线后出现多头反转K线，形成微型双底 |
| 入场 | 第二个底形成后，阳线反转信号K线高点上做多 |
| 止损 | 微型双底极端下方1-2 tick |
| 目标 | 第一目标：颈线位置；第二目标：测量移动 |
| 仓位 | 标准仓位（区间边界处）；减仓（趋势中） |

### 6.3 止损规则

| 规则 | 说明 |
|------|------|
| DBL止损 | 微型双顶顶部上方1-2 tick |
| DBS止损 | 微型双底底部下方1-2 tick |
| 止损距离 | 紧止损（微型结构边界清晰） |

> 来源：15_pattern_recognition.md §8.3："双顶止损：前高上方1-2 tick；双底止损：前低下方1-2 tick"

## 七、DBL/DBS在区间和趋势中的不同含义

| 市场状态 | DBL/DBS含义 | 交易策略 | 可靠性 |
|----------|------------|----------|--------|
| 宽区间底部 | DBS = 强做多信号 | 区间边界做多 | ★★★★ |
| 宽区间顶部 | DBL = 强做空信号 | 区间边界做空 | ★★★★ |
| 上升趋势中 | DBL = 小反转/回调 | 顺势等H2做多 | ★★★ |
| 下降趋势中 | DBS = 小反转/反弹 | 顺势等L2做空 | ★★★ |
| 趋势末端 | DBL/DBS = 大反转预警 | 等第二个信号确认 | ★★★★ |
| 窄区间/铁丝网 | DBL/DBS = 不可靠 | 不交易 | ★ |

> 来源：19_playbook.md Playbook 6（宽区间）："区间顶部：L2做空 + 双顶 + DBL（做空）；区间底部：H2买入 + 双底 + DBS（做多）"

## 八、DBL/DBS与信号组合

| 优先级 | 信号组合 | 概率加成 |
|--------|----------|----------|
| 最高 | DBL/DBS + 区间边界 + 强信号K线 | 80%+ |
| 高 | DBL/DBS + 趋势末端 + 磁铁附近 | 70%+ |
| 中高 | DBL/DBS + 双顶/双底确认 | 65%+ |
| 中低 | DBL/DBS + 趋势中段（作为小反转） | 50-55% |

## 九、实战检查清单

| # | 检查项 |
|---|--------|
| 1 | 是否出现了强多头/空头K线后紧跟着反转K线？ |
| 2 | 是否形成了微型双顶/双底结构？ |
| 3 | 当前市场状态是什么？（区间>趋势末端>趋势中段） |
| 4 | DBL/DBS是否发生在关键价位（磁铁/支撑/阻力）？ |
| 5 | 反转K线质量如何？（收盘极端、实体大、影线小） |
| 6 | 止损位置是否合理（极端外1-2 tick）？ |
| 7 | 是否有第二个信号确认？ |

---

> **核心原则**：DBL/DBS是交易者心理的直接体现——失望导致平仓，平仓导致价格反转。在区间边界处最强，在强趋势中段最弱。始终确认信号K线质量和市场背景。
