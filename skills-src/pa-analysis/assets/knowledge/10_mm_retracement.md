# 测量移动与回调（Measured Moves and Retracements）

> 交叉参考：62_bar_counting_pullback.md AC. 回调K线数定义与深度分类、AC.§11 测量移动与K线数关系

## 测量移动（MM）类型

### 1. AB=CD 测量

```
条件：AB腿和CD腿方向相反、长度相等（或斐波那契比例）
C点位置：AB的0.618、0.786或1.27回撤
D点目标：C点 + (B点 - A点)

多头AB=CD：A低→B高→C低→D高
空头AB=CD：A高→B低→C高→D低
```

### 2. 基于突破的MM

```
突破区间后的MM目标 = 突破点 + 区间高度

多头突破：
  MM目标 = 区间上沿 + (区间上沿 - 区间下沿)

空头突破：
  MM目标 = 区间下沿 - (区间上沿 - 区间下沿)
```

### 3. 基于通道的MM

```
通道中的MM目标：
  - 第一目标：通道线（对侧）
  - 第二目标：突破通道线后 = 通道线 + 通道宽度
```

### 4. 基于缺口的MM

```
测量缺口MM目标 = 缺口位置 + 缺口前走势长度
```

### 5. MM目标优先级

| 优先级 | 目标类型 | 可靠性 |
|--------|----------|--------|
| 1 | 基于突破的MM | 最高 |
| 2 | AB=CD | 高 |
| 3 | 基于通道的MM | 中高 |
| 4 | 基于缺口的MM | 中 |
| 5 | 斐波那契扩展 | 中低 |

## 回调水平

### 回调深度分类

| 深度 | 范围 | K线数 | 含义 |
|------|------|-------|------|
| 浅回调 | < 38.2% | 1-3根 | 强趋势，激进入场 |
| 正常回调 | 38.2%-50% | 3-5根 | 标准结构，顺势入场 |
| 深回调 | 50%-61.8% | 5+根 | 趋势减弱，谨慎入场 |
| 过度回调 | > 61.8% | 可能反转 | 等待反转确认或观望 |

### 50%回调规则

```
50%回调是最常见的回调深度
- 强趋势中：50%回调是理想的入场点
- 如果回调超过50%：趋势可能减弱
- 如果回调超过61.8%：可能反转而非回调
- 在50%位置结合信号K线入场 → 高概率
```

### 75%回撤规则

```
在双顶/双底形态中：
- 突破后回撤不超过75% → 突破有效
- 回撤超过75% → 突破可能失败
```

## 磁铁系统

### 磁铁类型

| 磁铁 | 位置 | 强度 |
|------|------|------|
| 前摆动高点 | 最近的高点 | 强 |
| 前摆动低点 | 最近的低点 | 强 |
| 整数关口 | 如10000, 15000 | 强 |
| 前日高/低 | 昨日的高低点 | 中强 |
| 均线(20EMA) | 当前EMA位置 | 中 |
| 趋势线/通道线 | 趋势线交点 | 中 |
| 缺口区域 | 缺口上下沿 | 中 |
| MM目标 | 测量移动目标 | 中 |

### 磁性拉力规则

```
- 价格倾向于被吸引到最近的磁铁
- 在区间中间时，价格同时受到上方和下方磁铁吸引 → 双向风险 → 不交易
- 在区间边界时，价格被对面边界吸引 → 可交易
- 整数关口是最强的磁铁之一
```

## MM自动化计算

```
输入：K线序列 + 识别到的形态
输出：MM目标列表

算法：
1. 如果检测到区间突破：
   MM = 突破点 ± 区间高度
   
2. 如果检测到AB=CD形态：
   A, B, C = 识别三点
   D = C + (B - A)
   
3. 如果检测到缺口：
   MM = 缺口位置 ± 缺口前腿长度
   
4. 如果检测到通道：
   MM = 通道线 ± 通道宽度

5. 合并所有MM目标，按优先级排序
6. 取最近的2-3个作为止盈目标
```
