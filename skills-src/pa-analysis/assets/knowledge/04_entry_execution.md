# 入场执行（Entry Execution）

## 入场方式选择决策树

```
信号K线收盘后 → 选择入场方式
    │
    ├── 突破/强趋势行情 → 止损单入场
    │      └── 在突破K线高点+1tick（多头）或低点-1tick（空头）
    │
    ├── 回调/区间行情 → 限价单入场
    │      └── 在回调目标价位挂限价单
    │
    └── 信号K线收盘确认 → 市价单入场
           └── 在信号K线收盘后立即以市价入场
```

## 止损设置规则

### 价格行为止损

| 状态 | 止损位置 |
|------|----------|
| 突破 | 突破K线低点-1tick（多头）/高点+1tick（空头） |
| 窄通道(H1) | 信号K线低点-1tick |
| 宽通道(H2) | 回调腿的低点-1tick |
| 小反转 | 回撤极值外1-2tick |
| 大反转 | 第二个信号K线极值外 |
| 宽区间 | 区间边界外1-2tick |

### 金额止损

```
金额止损 = 账户余额 × 单笔风险百分比
例如：账户10万，单笔风险1% = 1000元
止损点数 = 金额止损 / 每点价值 / 合约数量
```

## 止盈目标设置

### 剥头皮 vs 波段 选择矩阵

| 条件 | 选择剥头皮 | 选择波段 |
|------|-----------|----------|
| 窄区间/铁丝网 | ✓ | ✗ |
| 突破初期 | ✓ | ✗ |
| 窄通道 | ✓（部分） | ✓（部分） |
| 宽通道 | ✗ | ✓ |
| 宽区间 | ✓ | ✗ |
| 大反转 | ✗ | ✓ |

### 目标位计算

| 目标类型 | 计算方法 |
|----------|----------|
| 1倍风险 | 入场价 ± 止损距离 |
| 2倍风险 | 入场价 ± 2×止损距离 |
| AB=CD | D点 = C点 + (B点 - A点) |
| 测量移动(MM) | 基于突破前区间高度或腿的长度 |
| 磁铁 | 前高/前低、整数关口、均线 |
| 50%回调 | 趋势中回撤到50%位置 |

## OCO订单设置

```
OCO（One Cancels Other）订单：
- 止盈单：在目标价位
- 止损单：在止损价位
- 任一触发，另一个自动取消
```

## 入场五级决策系统

| 级别 | 条件 | 仓位 |
|------|------|------|
| 5级（最强） | 趋势方向+H2+高质量信号+磁铁+信号组合 | 100%标准仓位 |
| 4级（强） | 趋势方向+H2+高质量信号 | 100%标准仓位 |
| 3级（标准） | 趋势方向+H1+中等信号 | 75-100%标准仓位 |
| 2级（谨慎） | 趋势方向+单一信号 | 50%标准仓位 |
| 1级（试探） | 逆趋势+第二个信号+高质量 | 25-50%标准仓位 |
| 0级（不入场） | 任何条件不满足 | 0% |
