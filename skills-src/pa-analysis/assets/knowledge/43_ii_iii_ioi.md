## 一、ii模式

### 1.1 定义

ii模式（ii Pattern）即连续两根内包K线，第二根K线的高低点完全在第一根K线之内。

> 来源：theme12_abbreviations.md："双内包：两根连续内包K线，第二根在第一根之内，是突破模式形态"

| 要素 | 说明 |
|------|------|
| 全称 | ii Pattern（Inside-Inside） |
| 中文 | 双内包模式 |
| 结构 | 内包K线1 + 内包K线2（第二根在第一根之内） |
| 本质 | 力量收缩、蓄势突破 |
| K线数量 | 2根 |

### 1.2 识别特征

| 特征 | 描述 |
|------|------|
| 第一根K线 | 内包于前一根K线（IB） |
| 第二根K线 | 内包于第一根内包K线 |
| 波动范围 | 越来越窄，收缩蓄势 |
| 突破方向 | 未确定，等待突破 |

---

## 二、iii模式

### 2.1 定义

iii模式（iii Pattern）即连续三根内包K线，每一根都在前一根之内。

> 来源：theme12_abbreviations.md："三内包：三根连续内包K线，比ii更可靠，突破后走势通常更强"

| 要素 | 说明 |
|------|------|
| 全称 | iii Pattern（Inside-Inside-Inside） |
| 中文 | 三内包模式 |
| 结构 | 内包K线1 + 内包K线2 + 内包K线3（层层嵌套） |
| 本质 | 更强的力量收缩，更长的蓄势 |
| K线数量 | 3根 |

### 2.2 识别特征

| 特征 | 描述 |
|------|------|
| 波动范围 | 三层嵌套，波动越来越窄 |
| 能量积累 | 比ii积累更多能量 |
| 突破后走势 | 通常比ii更强 |
| 可靠性 | 高于ii |

---

## 三、ioi模式

### 3.1 定义

ioi模式（IOI Pattern）即内-外-内三根K线组合：内包K线后跟外包K线，再跟内包K线。

> 来源：theme12_abbreviations.md IOI词条："内包-外包-内包：三K线模式：内包K线后跟外包K线，再跟内包K线，突破模式形态"

| 要素 | 说明 |
|------|------|
| 全称 | Inside-Outside-Inside (IOI) |
| 中文 | 内-外-内模式 |
| 结构 | 内包K线 → 外包K线 → 内包K线 |
| 本质 | 突破模式形态 |
| K线数量 | 3根 |

### 3.2 识别特征

| 阶段 | K线 | 含义 |
|------|-----|------|
| 第1根 | 内包K线（IB） | 力量收缩 |
| 第2根 | 外包K线（OB） | 波动扩大，测试方向 |
| 第3根 | 内包K线（IB） | 再次收缩，确认方向 |
| 突破 | 突破第3根K线极值 | 方向确认 |

## 四、三种模式的可靠性对比

| 模式 | K线结构 | 可靠性 | 突破后走势 | 适用场景 |
|------|----------|--------|-----------|----------|
| ii | 内-内（2根） | ★★★ | 中等 | 窄区间、通道中 |
| iii | 内-内-内（3根） | ★★★★ | 较强 | 窄区间、通道中 |
| ioi | 内-外-内（3根） | ★★★ | 中等 | 任何状态 |

> 来源：15_pattern_recognition.md §9 形态识别速查表；SKILL.md §1.2

| 对比维度 | ii | iii | ioi |
|----------|-----|-----|-----|
| 蓄势时间 | 较短 | 较长 | 中等 |
| 能量积累 | 中等 | 最大 | 中等 |
| 突破可靠性 | 中等 | 最高 | 中等 |
| 假突破风险 | 中等 | 较低 | 中等 |

## 五、在趋势中 vs 区间中的不同含义

> 来源：SKILL.md §1.2 内包/外包K线详解

| 市场状态 | ii/iii含义 | ioi含义 | 策略 |
|----------|-----------|---------|------|
| 趋势中 | 趋势暂停，可能继续 | 突破前蓄势 | 等待顺势突破 |
| 区间边界 | 突破前蓄势 | 突破方向确认 | 等待突破方向 |
| 区间中部 | 普通整理 | 普通整理 | 不交易 |
| 趋势末端 | 可能是最终旗形 | 可能是最终旗形 | 等反转确认 |

> 来源：SKILL.md §1.2 内包K线(IB)位置含义表

### 5.1 趋势中的ii/iii

- 趋势暂停，顺势方在整固
- 大概率顺势突破
- 逆势突破概率较低

### 5.2 区间中的ii/iii

- 区间边界处：突破前蓄势，等待突破方向
- 区间中部：无意义整理，不交易
- 窄区间（铁丝网）：不可靠，不交易

## 六、交易策略

### 6.1 突破方向入场

| 维度 | 规则 |
|------|------|
| 入场 | 等待突破方向，在突破K线极值外1 tick入场 |
| 止损 | 模式极值外（ii/iii/ioi的整个结构范围外） |
| 目标 | 测量移动 = 模式前趋势腿高度 |

### 6.2 ii模式交易

| 维度 | 规则 |
|------|------|
| 入场 | 突破ii模式高点（做多）或低点（做空） |
| 止损 | ii模式范围外1 tick |
| 可靠性 | ★★★ |
| 仓位 | 标准仓位 |

### 6.3 iii模式交易

| 维度 | 规则 |
|------|------|
| 入场 | 突破iii模式高点（做多）或低点（做空） |
| 止损 | iii模式范围外1 tick |
| 可靠性 | ★★★★（比ii更可靠） |
| 仓位 | 标准仓位（可略加重） |

### 6.4 ioi模式交易

| 维度 | 规则 |
|------|------|
| 入场 | 突破第3根内包K线高点（做多）或低点（做空） |
| 止损 | ioi模式极值外1 tick |
| 可靠性 | ★★★ |
| 仓位 | 标准仓位 |

> 来源：31_market_cycle.md §3.3

| 关系 | 说明 |

| ii可能是最终旗形 | 趋势末端的ii模式可能是水平最终旗形 |
| iii可能是最终旗形 | 趋势末端的iii模式可能是最终旗形 |
| ioi可能是最终旗形 | 趋势末端的ioi模式可能是最终旗形 |

## 十、实战检查清单

| # | 检查项 |
|---|--------|
| 1 | 是否识别出ii/iii/ioi模式？ |
| 2 | 当前市场状态是什么？（趋势/区间/铁丝网） |
| 3 | 模式出现在什么位置？（趋势中/区间边界/区间中部/趋势末端） |
| 4 | 如果是趋势末端 → 是否可能是最终旗形？ |
| 5 | 如果是铁丝网中 → 是否已放弃交易？ |
| 6 | 突破方向是否明确？ |
| 7 | 止损是否在模式极值外？ |
| 8 | 目标是否设置了测量移动？ |

---

> **核心原则**：ii/iii/ioi是经典的突破模式形态。iii比ii更可靠。在趋势中顺势突破概率高，在趋势末端可能是最终旗形（反转）。在铁丝网中所有信号不可靠。始终等待突破方向确认后再入场。
