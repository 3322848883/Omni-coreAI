# 概念识别（Concept Recognition）

## 1.1 逐K分析

每根K线包含四个价格：开盘价(O)、最高价(H)、最低价(L)、收盘价(C)。

### 单根K线力量判断

| K线类型 | 多头力量 | 空头力量 | 特征 |
|----------|----------|----------|------|
| 大阳线（光头光脚） | 极强 | 极弱 | 实体大、无上下影线、收盘=最高 |
| 大阳线（有上影线） | 强 | 弱 | 实体大、上影线长=上方有阻力 |
| 大阳线（有下影线） | 强 | 弱 | 实体大、下影线长=下方有支撑 |
| 大阴线（光头光脚） | 极弱 | 极强 | 实体大、无上下影线、收盘=最低 |
| 大阴线（有下影线） | 弱 | 强 | 实体大、下影线长=下方有支撑 |
| 十字星（收盘=开盘） | 中 | 中 | 多空均衡、市场犹豫 |
| 十字星（长上影线） | 弱 | 中 | 多头尝试但失败 |
| 十字星（长下影线） | 中 | 弱 | 空头尝试但失败 |

### 反转K线判断标准

**最佳多头反转K线：**
- 开盘接近或低于前一根K线收盘价
- 收盘高于开盘价且高于前一根K线收盘价
- 下影线约为K线高度的1/3到1/2
- 上影线小或不存在

**最佳空头反转K线：**
- 开盘接近或高于前一根K线收盘价
- 收盘低于开盘价且低于前一根K线收盘价
- 上影线约为K线高度的1/3到1/2
- 下影线小或不存在

## 1.2 K线关系

### 与前一根K线的关系

| 关系 | 定义 | 含义 |
|------|------|------|
| 更高高(HH) | 当前高点 > 前根高点 | 多头控制 |
| 更高低(HL) | 当前低点 > 前根低点 | 多头控制 |
| 更低高(LH) | 当前高点 < 前根高点 | 空头控制 |
| 更低低(LL) | 当前低点 < 前根低点 | 空头控制 |
| 内包K线(IB) | 高点≤前高 且 低点≥前低 | 力量收缩 |
| 外包K线(OB) | 高点>前高 且 低点<前低 | 波动扩大 |
| 缺口K线(GB) | 低点>前高 或 高点<前低 | 动能强劲 |
| 重叠 | 与前根K线部分重合 | 正常走势 |

### 重叠程度判断

| 重叠程度 | 特征 | 含义 |
|----------|------|------|
| 无重叠（缺口） | 当前K线完全在前根范围外 | 强动能、突破 |
| 少量重叠（<30%） | 仅影线部分重叠 | 趋势强 |
| 正常重叠（30-70%） | 实体部分重叠 | 正常趋势 |
| 大量重叠（>70%） | 几乎完全重叠 | 区间/铁丝网 |

## 1.3 市场背景判断

### 趋势判断三要素

| 要素 | 多头趋势 | 空头趋势 |
|------|----------|----------|
| 摆动高/低点 | HH + HL | LH + LL |
| 趋势线 | 向上倾斜 | 向下倾斜 |
| 与EMA关系 | 价格在EMA上方 | 价格在EMA下方 |

### 区间判断

| 特征 | 说明 |
|------|------|
| 摆动高/低点 | 没有持续的HH+HL或LH+LL |
| 水平边界 | 可以画出明确的上边界和下边界 |
| 重叠 | K线之间有大量重叠 |
| 价格位置 | 价格在EMA上下穿越 |

### 20EMA的使用

- 趋势中：价格始终在EMA一侧，回撤到EMA是入场机会
- 区间中：价格穿越EMA，EMA失去指示作用
- MAGB(均线缺口K线)：不触及EMA的K线，表明趋势强劲
- 20GB(20缺口棒)：连续20根或更多未触及EMA的K线，趋势极强

## 1.4 K线形态识别（来自思维导图）

### 核心原则：收盘价最重要

```
价格行为第一原则：等待 K 线收盘再做决定。

原因：
1. 收盘前 K 线形态可能发生变化
2. 影线是噪音，收盘才是多空博弈结果
3. 很多"看起来很好"的信号，收盘后会变弱
4. 交易决策应基于已完成的 K 线，而不是未完成的形态
```

| 错误做法 | 正确做法 |
|----------|----------|
| K 线还没收盘就匆忙入场 | 等待收盘确认 |
| 被长影线吸引提前行动 | 看收盘位置是否仍在极端 |
| 盘中追突破 | 等突破 K 线收盘在极端再决策 |

---

### 趋势K线（Trend Bar）

```
趋势K线特征：
- 实体大
- 影线小
- 大阳 K 收在高位
- 大阴 K 收在低位
```

#### 趋势K线的多空含义

| K线 | 多头信号 | 空头信号 |
|-----|----------|----------|
| 大阳 K | 强烈看多 | — |
| 大阴 K | — | 强烈看空 |
| 小阳 K | 弱势看多 | — |
| 小阴 K | — | 弱势看空 |

#### 位置和环境 > K线形态本身

```
重要原则：
- 背景 > K线形态
- 同样的趋势K线，在不同位置意义完全不同
- 反转需要：好背景 + 好信号K

示例：
- 区间中部的大阳 K → 可能只是普通波动
- 区间底部的大阳 K → 可能是反转信号
- 趋势末端的大阳 K → 可能是抢购高潮
```

---

### 震荡K线（Trading Range Bar / Doji）

```
震荡K线特征：
- 实体小
- 影线大
- 无明确方向性
- 多空力量均衡
```

| 类型 | 特征 | 含义 |
|------|------|------|
| 十字星 | 实体极小 | 多空平衡，市场犹豫 |
| 长上影线 | 上影线长 | 上方有抛压 |
| 长下影线 | 下影线长 | 下方有支撑 |
| 纺锤线 | 实体小但影线也小 | 动能减弱，可能变盘 |

```
震荡K线交易策略：
- 单根震荡K线：观望
- 连续震荡K线：可能形成区间
- 震荡K线后出现趋势K线：关注突破方向
```

---

### 抢购/抛售高潮K线（Climax Bar）

```
高潮K线特征：
- 出现在强势趋势中
- 长实体、大波动
- 可能是情绪化交易的极致
- 需要警惕是否为趋势末端
```

| 类型 | 位置 | 风险 | 策略 |
|------|------|------|------|
| 抢购高潮 | 强上升趋势末端 | 追多容易被套 | 谨慎入场，观察跟随 |
| 抛售高潮 | 强下降趋势末端 | 追空容易被套 | 谨慎入场，观察跟随 |

```
关键判断：
- 当做上涨K线处理时，必须观察是否有良好跟随
- 如果没有跟随，可能是反转前的高潮
- 如果有跟随，趋势可能继续加速
```

---

### 内含K线 / 外包K线（Inside Bar / Outside Bar）

#### 内含K线（Inside Bar）

```
定义：当前 K 线高点 ≤ 前一根 K 线高点，且低点 ≥ 前一根 K 线低点
含义：整理信号，市场在蓄势，等待突破
```

| 位置 | 含义 | 策略 |
|------|------|------|
| 趋势中 | 趋势暂停，可能继续 | 等待顺势突破 |
| 区间边界 | 突破前蓄势 | 等待突破方向 |
| 区间中部 | 普通整理 | 不交易 |

#### 外包K线（Outside Bar）

```
定义：当前 K 线高点 > 前一根 K 线高点，且低点 < 前一根 K 线低点
含义：波动扩大，可能预示趋势反转或加速
```

| 类型 | 特征 | 含义 |
|------|------|------|
| 向上外包 | 阳线外包前一根 | 多头力量增强 |
| 向下外包 | 阴线外包前一根 | 空头力量增强 |

```
注意：外包K线本身方向需要看收盘。
- 向上外包 + 收盘在高位 → 偏多
- 向下外包 + 收盘在低位 → 偏空
- 外包后回到前一根范围内 → 可能是假突破
```

---

### 回调与反弹（Pullback / Rally）

```
回调：上升趋势中的暂时下跌
反弹：下降趋势中的暂时上涨

大周期星线隐藏小周期回调/反弹：
- 大周期的一根十字星/小K线，可能在小周期上是一段完整的回调或反弹
- 需要结合多时间框架观察
```

#### 高胜率入场原则

```
顺大趋势、逆小回调 = 高胜率入场

解释：
- 大趋势方向明确时，小回调结束后的顺势入场胜率最高
- 不要逆大趋势去猜小回调的终点
- 等待回调出现结束信号后再入场
```

| 大趋势 | 小回调结束信号 | 入场 |
|--------|---------------|------|
| 上升 | H1/H2、下影线、阳线反转 | 做多 |
| 下降 | L1/L2、上影线、阴线反转 | 做空 |

---

### 数K线：高1 / 高2 / 低1 / 低2

#### 高1（H1）

```
定义：在上升趋势或牛旗中，第一根高点高于前一根 K 线高点的 K 线
含义：回调可能结束，趋势可能继续
```

#### 高2（H2）

```
定义：第二次出现 H1，即经典的 ABC 回调完成
含义：更可靠的顺势入场信号
```

#### 低1（L1）

```
定义：在下降趋势或熊旗中，第一根低点低于前一根 K 线低点的 K 线
含义：反弹可能结束，趋势可能继续
```

#### 低2（L2）

```
定义：第二次出现 L1，即经典的 ABC 反弹完成
含义：更可靠的顺势入场信号
```

| 信号 | 趋势类型 | 可靠性 | 用途 |
|------|----------|--------|------|
| H1 | 上升/牛旗 | 中等 | 强趋势中可用 |
| H2 | 上升/牛旗 | 高 | 最佳顺势入场 |
| L1 | 下降/熊旗 | 中等 | 强趋势中可用 |
| L2 | 下降/熊旗 | 高 | 最佳顺势入场 |

```
使用原则：
- 强趋势中 H1/L1 即可入场
- 一般趋势中优先等待 H2/L2
- H3/L3 通常是楔形旗形，需要谨慎
- H4/L4 后的反转概率增加
```
