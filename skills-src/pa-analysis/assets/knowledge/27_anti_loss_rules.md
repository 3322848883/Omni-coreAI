# 防止大亏的入场规则（Anti-Loss Entry Rules）

> 交易的第一目标不是赚钱，而是不亏大钱。这些规则来自思维导图中的"防止大亏的入场规则"模块，用于在入场前过滤掉高风险交易。

---

## 一、六条核心入场规则

### 规则一：强势信号K线 + 突破单入场 + 保护性止损

```
必要条件：
1. 信号K线必须是强势K线
   - 大实体、小影线
   - 收盘接近K线极端
   - 入场方向影线短或无

2. 使用突破单（Stop Order）入场
   - 只在确认方向后入场
   - 不猜测、不预埋假设

3. 必须同时设置保护性止损
   - 止损位在信号K线反向极值外
   - 入场前就知道最大亏损
```

| 质量 | 信号K线特征 | 处理 |
|------|------------|------|
| 强势 | 大实体、收盘极端、影线小 | 可以突破单入场 |
| 中等 | 实体一般、有少量影线 | 降低仓位或等待更好信号 |
| 弱势 | 小实体、长影线、收盘中间 | 不入场 |

---

### 规则二：第二入场点入场 / 第二次反转时离场

```
核心思想：第一次信号可能失败，第二次信号更可靠。

应用场景：
1. 强趋势中的第一次回调（H1/L1）——可轻仓尝试
2. 第二次回调（H2/L2）——优先入场点
3. 大反转中——必须等待第二个信号确认
4. 当前仓位方向出现第一次反向信号——警惕
5. 第二次反向信号出现——考虑离场
```

| 情况 | 第一次信号 | 第二次信号 | 行动 |
|------|-----------|-----------|------|
| 顺势回调 | H1/L1，可轻仓 | H2/L2，标准仓位 | 优先H2 |
| 趋势反转 | 警惕，不入场 | 确认后入场 | 必须等第二信号 |
| 持仓反向 | 警惕 | 考虑离场 | 第二次反转通常有效 |

---

### 规则三：不！加！仓！

```
严格执行：亏损仓位绝不加仓！

原因：
- 亏损说明你的判断可能是错的
- 加仓摊平成本是情绪化行为
- 大亏往往来自亏损加仓

正确做法：
- 如果仓位亏损，按计划止损
- 如果认为还有机会，等新的独立信号
- 新的独立信号 = 新的入场理由，不是原仓位的摊平
```

**唯一允许加仓的情况：**
1. 第一笔仓位已经盈利
2. 趋势依然强劲
3. 出现新的高质量顺势信号
4. 加仓后总风险仍≤账户2%

---

### 规则四：风险与仓位控制

```
单笔风险：账户余额 × 1-2%
单日风险：账户余额 × 3-5%
单周风险：账户余额 × 10%

仓位公式：
仓位 = 账户风险金额 / |入场价 - 止损价|
```

| 风险层级 | 比例 | 触发后果 |
|----------|------|----------|
| 单笔最大风险 | 2% | 正常交易上限 |
| 单日最大亏损 | 3-5% | 达到后停止当日交易 |
| 单周最大回撤 | 10% | 达到后减仓至50% |
| 单月最大回撤 | 20% | 停止交易，系统复盘 |

---

### 规则五：亏损之后等待几根K线再做决定

```
亏损后大脑会进入"复仇模式"，此时做的决定80%是错的。

纪律：
1. 单笔亏损后 → 至少等待3-5根K线
2. 连续2笔亏损后 → 强制休息15-30分钟
3. 连续3笔亏损后 → 当日停止交易
4. 重新入场前 → 必须重新完成完整分析

目的：
- 让情绪冷却
- 避免报复性交易
- 重新客观评估市场
```

---

### 规则六：避开重要事件

```
重大事件前后市场波动剧烈，价格行为失真：
- 非农数据（NFP）
- 利率决议
- CPI/PPI数据
- 重要财报
- 地缘政治事件

处理方式：
1. 事件前15-30分钟降低仓位或平仓
2. 事件后等待15-30分钟，让市场消化
3. 事件期间不入场
4. 如果持仓跨越事件，确保风险可控
```

## 二、入场前的自我审查清单

| # | 问题 | 必须满足 |
|---|------|----------|
| 1 | 这个信号K线足够强势吗？ | 是 |
| 2 | 我的入场理由是突破单触发，还是预测性入场？ | 突破单 |
| 3 | 止损位是否明确且合理？ | 是 |
| 4 | 这是第一信号还是第二信号？ | 优先第二信号 |
| 5 | 我是否在摊平亏损仓位？ | 否 |
| 6 | 单笔风险是否≤账户2%？ | 是 |
| 7 | 今日已累计亏损是否接近上限？ | 未接近 |
| 8 | 最近是否刚经历亏损？ | 已冷却 |
| 9 | 是否有重要事件即将发生？ | 否 |
| 10 | 如果这笔交易亏损，我是否仍然认为它是好交易？ | 是 |

## 三、高风险入场红灯

以下情况**绝对不要入场**：

1. **窄区间/铁丝网中的任何信号**
2. **没有明确止损位置的交易**
3. **为了翻本而做的交易**
4. **重要事件前后15分钟内的交易**
5. **逆势且没有第二个信号确认的交易**
6. **信号K线质量差（小实体、长影线）的交易**
7. **仓位超过单笔风险上限的交易**
8. **情绪不稳定时的交易**

---

## 四、防止大亏的心态铁律

1. **接受亏损是交易的一部分**——学会亏钱才能赢钱
2. **钱是赚不完的，但可以很快亏完**——保护本金第一
3. **承认自己错了很痛苦，但不承认会更痛苦**——止损是自救
4. **大脑会正当化你的错误行为**——用规则对抗情绪
5. **不要期待小概率事件发生**——"万一涨回去呢"是陷阱
6. **亏损时光充满希望，盈利时急于离场**——这是失败者的模式

## 五、规则执行流程图

```
发现潜在交易机会
      ↓
检查信号K线质量 → 差 → 放弃
      ↓ 好
检查是否有第二信号 → 无 → 降低仓位或放弃
      ↓ 有
检查止损位置 → 不明确 → 放弃
      ↓ 明确
检查仓位/风险 → 超限 → 调整或放弃
      ↓ 合规
检查是否有重要事件 → 有 → 等待
      ↓ 无
检查自身情绪状态 → 不稳定 → 休息
      ↓ 稳定
用突破单入场 + 同时设止损
```
