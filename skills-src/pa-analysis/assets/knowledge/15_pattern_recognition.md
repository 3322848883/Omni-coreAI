# 形态识别完整体系（Pattern Recognition）

> 来源：HTML指南附录T — 楔形、双顶/底、头肩、扩张三角形、最终旗形、高潮反转等完整形态识别体系

---

## 一、楔形完整分类

| 楔形类型 | 方向 | 入场策略 | 成功率 | 关键特征 |
|----------|------|----------|--------|----------|
| **楔形旗形** (Wedge Flag) | 顺势 | 第一个信号入场 | 高 (70%+) | 趋势中的回调，三推后顺势突破 |
| **楔形反转** (Wedge Reversal) | 逆势 | 等第二个信号 | 中 (55-65%) | 趋势末端的收缩结构，三推后反转 |
| **嵌套楔形** (Nested Wedge) | 顺势/逆势 | 大楔形结束入场 | 中高 | 大楔形内含小楔形，多层级结构 |
| **三推楔形** (Three-Push Wedge) | 逆势 | 第三推结束入场 | 中 (60%) | 三次清晰的推进，每次推进幅度递减 |
| **扩张楔形** (Broadening Wedge) | 逆势 | 等明确信号 | 低 (50%) | 趋势线发散而非收敛，波动加大 |

### 楔形识别5条规则

1. **三条腿每次推进延伸**：楔形通常由三次推进组成，每次推进的高点/低点越来越接近
2. **趋势线和通道线收敛**：连接高点的趋势线和连接低点的通道线逐渐靠拢，形成收敛三角形
3. **通常在第3推或第4推结束**：大多数楔形在第3推结束，少数延伸到第4推，第5推非常罕见
4. **ROSE的三推正确画法**：从趋势起点开始，连接每次推进的极端点，不连接中间波动
5. **ROSE的三推情绪线**：三推的终点往往是机构止盈的位置

## 三、头肩顶/底形态

### 头肩顶 (Head & Shoulders Top)

- **结构**：左肩 → 头部（更高）→ 右肩（更低，不超过头部）→ 跌破颈线
- **心理含义**：多头三次尝试推高，但每次动能都在减弱，最终空头接管
- **入场**：跌破颈线后做空，或在右肩形成后做空
- **目标**：头部到颈线的距离，从跌破点向下投影

### 头肩底 (Inverse H&S)

- **结构**：左肩 → 头部（更低）→ 右肩（更高，不低于头部）→ 突破颈线
- **心理含义**：空头三次尝试打压，但每次动能都在减弱，最终多头接管
- **入场**：突破颈线后做多，或在右肩形成后做多
- **目标**：头部到颈线的距离，从突破点向上投影

## 四、扩张三角形

扩张三角形（Broadening Triangle / Megaphone）是高点和低点都在向外扩张的喇叭口形态。

- **特征**：每次波动都比前一次更大，高低点不断向外延伸
- **交易策略**：风险极高，建议等待形态明确结束
- **Al Brooks警告**：扩张三角形是最难交易的形态之一，除非非常有经验，否则避免在其中交易

---

## 五、最终旗形

最终旗形（Final Flag, FF）是趋势末端的最后一个回调/暂停形态，之后趋势将反转。

- **位置**：出现在趋势末端，通常是第三次或第四次回调
- **特征**：旗形本身非常小（窄幅K线），之前趋势动能已明显减弱
- **识别**：趋势末端窄幅旗形 + 趋势K线越来越小 = 最终旗形
- **交易**：等反转确认后再入场

## 六、高潮反转

| 类型 | 特征 | 识别方法 | 交易策略 |
|------|------|----------|----------|
| **买入高潮** (Buy Climax) | 连续大阳线+加速上涨+放量 | 3+根连续大阳线，越来越长，最终出现长上影 | 等高潮后反转信号K，做空 |
| **卖出高潮** (Sell Climax) | 连续大阴线+加速下跌+放量 | 3+根连续大阴线，越来越长，最终出现长下影 | 等高潮后反转信号K，做多 |
| **高潮反转** (Climax Reversal) | 高潮后立即出现反向大K线 | 高潮K线+反向外包K线 | 反向外包K线是入场信号，止损在高潮极端 |

## 七、来自思维导图的三维楔形详解

### 7.1 三维楔形的核心原理

```
三维楔形（Wedge）的本质：
- 三次倾斜向上的推动
- 每次推动的幅度递减
- 高点和低点形成收敛三角形
- 最终在第三推末端反向反转
```

| 要素 | 说明 |
|------|------|
| 三次推动 | 必须有清晰可辨的三次推进 |
| 倾斜方向 | 三推沿同一方向倾斜运行 |
| 收敛 | 趋势线和通道线逐渐靠拢 |
| 反转 | 第三推结束后反向突破 |

### 7.2 倾斜三推 > 形态本身

```
关键原则：
- 倾斜的三推结构比单纯的楔形形态更可靠
- 收敛三角形比非收敛的三推更可靠
- 普通三推（不收敛）双向突破概率约 50%，不具备明显优势
```

| 类型 | 可靠性 | 说明 |
|------|--------|------|
| 收敛三角形三推 | 高 | 每次推进幅度递减，力量衰竭 |
| 非收敛三推 | 中/低 | 双向突破概率接近 50% |
| 扩张三推 | 低 | 波动加大，方向不确定 |

### 7.3 优质 Wedge 的识别

```
优质 Wedge 特征：
1. 三推之间有重叠
2. 重叠 = 逆势力量增强
3. 收敛明显
4. 第三推末端出现反向信号K线
```

| 质量 | 特征 | 交易策略 |
|------|------|----------|
| 优质 Wedge | 有重叠、收敛明显、信号K线强 | 可波段反向交易 |
| 普通 Wedge | 收敛一般、信号一般 | 剥头皮为主 |
| 劣质 Wedge | 不收敛、无重叠、信号弱 | 不交易 |

### 7.4 不是所有楔形都会大反转

```
重要认知：
- 大量楔形只产生小反转或震荡
- 只有处于趋势末端、结构完整的楔形才容易产生大反转
- 趋势中段的楔形更可能是楔形旗形（顺势）
```

| 位置 | 结果 | 策略 |
|------|------|------|
| 趋势末端 + 收敛楔形 | 大反转 | 等第二信号后反向波段 |
| 趋势中段 | 楔形旗形（顺势） | 第一信号顺势入场 |
| 区间内 | 小反转/震荡 | 剥头皮 |
| 不收敛 | 双向可能 | 减少仓位或观望 |

### 7.5 三维楔形的交易策略

```
策略：剥头皮 + 波段结合

剥头皮：
- 第三推末端出现反向信号K线
- 小止损，目标前低/前高或第一支撑位

波段：
- 等待第二信号确认
- 仓位略大，目标测量移动位
```

| 信号质量 | 止损 | 目标 | 仓位 |
|----------|------|------|------|
| 第三推末端第一信号 | 信号K线极值外 | 前低/前高 | 50% |
| 第二信号确认 | 第二信号极值外 | 测量移动位 | 75-100% |
| 收敛楔形 + 强信号K | 楔形极端外 | 趋势起点方向 | 100% |

## 八、来自思维导图的双顶/双底细节

### 8.1 双顶（Double Top）

```
经典双顶：
- 第二个高点低于或等于前高
- 配合阴线反转信号
- 是空头信号
```

| 特征 | 含义 | 策略 |
|------|------|------|
| 第二个高点低于前高 | 多头力量减弱 | 准备做空 |
| 第二个高点处出现阴线 | 反转确认 | 第二信号后做空 |
| 跌破颈线 | 双顶完成 | 加仓做空 |

### 8.2 双底（Double Bottom）

```
经典双底：
- 第二个低点高于或等于前低
- 配合阳线反转信号
- 是多头信号
```

| 特征 | 含义 | 策略 |
|------|------|------|
| 第二个低点高于前低 | 空头力量减弱 | 准备做多 |
| 第二个低点处出现阳线 | 反转确认 | 第二信号后做多 |
| 突破颈线 | 双底完成 | 加仓做多 |

### 8.3 双顶/双底的入场与止损

```
入场：
- 双顶：第二个高点形成 + 阴线反转信号后做空
- 双底：第二个低点形成 + 阳线反转信号后做多

止损：
- 双顶止损：前高上方 1-2 tick
- 双底止损：前低下方 1-2 tick

目标：
- 第一目标：颈线位置
- 第二目标：测量移动 = 顶/底到颈线的距离
```

## 十、ROSE经典形态识别规则

1. **位置优先于形态**：形态在关键价位附近才有意义
2. **三推情绪线**：三推的终点是机构止盈位置
3. **Mother Bar策略**：利用大实体K线的50%回撤做刮头皮
4. **FOFS形态**：假突破后的强力反转是最强信号
5. **早期入场**：在趋势反转的第一个信号K就入场，小止损大利润
