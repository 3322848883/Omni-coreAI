## 每日复盘流程（15分钟）

### 1. 回顾交易（3分钟）
- 逐笔查看今日所有交易
- 对照日志检查每笔交易

### 2. 决策质量评估（3分钟）
- A级：完美执行，按计划入场/出场
- B级：有小瑕疵，但整体合理
- C级：有重大错误（情绪交易、无信号入场、不止损等）

### 3. 错误模式识别（3分钟）
- 今天犯的错误是否与之前重复？
- 记录到错误模式库

### 4. 知识复习（3分钟）
- 针对今日错误，复习对应知识模块
- 例如：入场太早 → 复习信号确认标准

### 5. 明日准备（3分钟）
- 标记关键价位（前高/前低/整数关口）
- 查看HTF结构
- 设定明日交易目标

## 系统校准（每周）

### 校准指标

| 指标 | 计算方法 | 标准 |
|------|----------|------|
| 胜率 | 盈利笔数/总笔数 | 剥头皮≥60%，波段≥50% |
| 盈亏比 | 总盈利/总亏损 | ≥1.5:1 |
| 执行一致性 | 按计划执行笔数/总笔数 | ≥80% |
| 情绪管理 | 情绪稳定天数/总天数 | ≥80% |
| 最大回撤 | (峰值-谷值)/峰值 | 周≤10% |
| 夏普比率 | (平均收益-无风险利率)/标准差 | ≥1.0 |

### 校准行动

| 问题 | 行动 |
|------|------|
| 胜率低于标准 | 收紧入场标准，只做5级和4级信号 |
| 盈亏比低于标准 | 检查止盈设置，不要过早止盈 |
| 执行一致性低 | 加强纪律训练，使用检查清单 |
| 情绪管理差 | 减仓至50%，增加休息时间 |
| 回撤过大 | 减仓至50%，暂停交易1-2天 |

## 改进计划闭环

```
发现问题 → 记录到错误模式库 → 复习对应知识 → 制定改进措施
    ↓                                                    ↓
    └──────────── 下周校准验证 ← 执行改进措施 ←────────────┘
```

## 错误模式库

| 错误类型 | 典型表现 | 解决方案 |
|----------|----------|----------|
| 过早入场 | 信号K线未收盘就入场 | 等待信号K线完全收盘 |
| 追涨杀跌 | 趋势过度延伸后追入 | 等回撤入场 |
| 不止损 | 亏损后移动止损 | 设置后不动 |
| 过度交易 | 窄区间中频繁交易 | 窄区间不交易 |
| 报复性交易 | 亏损后加大仓位 | 亏损后冷静15分钟 |
| 过早止盈 | 剥头皮思维在波段行情中 | 按计划分批止盈 |
| 逆势交易 | 区间中逆趋势方向 | 顺势优先 |
