## Playbook 1：突破（Breakout）

**趋势强度：极强 · Always In：单向**

| 维度 | 规则 |
|------|------|
| **识别确认** | 连续3+根大趋势K线 · 实体间几乎无重叠 · 无影线或极小 · 急迫感 · 20+根K线不触及EMA |
| **优先信号** | ① **H1/L1顺势入场**（强趋势中H1最可靠）· ② **微趋势线突破失败入场**（Micro Trendline Breakout Failure）· ③ **任何小回调处的市价追入** |
| **信号K线** | 趋势方向的强趋势K线（大实体、小尾巴）· 强趋势中不完美信号K线也可接受——因为趋势方向已经明确，不需要完美信号来确认 |
| **入场** | 信号K线极值外1 tick止损单 · 或在回调K线收盘时市价入场（不等待完美回调） |
| **止损** | 信号K线反向极值外1 tick · 或最近的微摆动点外 |
| **目标** | **最小目标：**前摆动高/低点 · **延伸目标：**测量移动=突破前区间高度 · 趋势强可摆动持有 |
| **仓位** | 初始仓位50-75% · 趋势确认后加至100% · 绝不逆势 |
| **管理** | 突破阶段**不刮头皮**——摆动持有至少到通道阶段出现 · 追踪止损用微趋势线 · 出现第一根重叠K线时将止损移至盈亏平衡 |
| **退出条件** | 出现3+根重叠K线（突破→窄通道转换）· 或大逆势K线突破微趋势线 |
| **禁用信号** | 任何逆势信号 · ii形态逆势突破 · 楔形反转 · 双顶/底做反转 |

## Playbook 2：窄通道/微通道（Tight Channel）

**趋势强度：强 · Always In：单向 · 80%突破通道边界失败**

| 维度 | 规则 |
|------|------|
| **识别确认** | 2-3根K线可画出趋势线 · 回撤仅1-3根K线 · 多数K线触及趋势线 · 回调幅度极小 · 微趋势线频繁出现 |
| **优先信号** | ① **H1在微趋势线假突破处**（最可靠）· ② **H2在趋势线附近**（顺势）· ③ **双底多头旗/双顶空头旗**（通道底部测试） |
| **信号K线** | 趋势方向的强反转K线 · 在微趋势线精确位置 · 下影线（多头）或上影线（空头）触及趋势线后反转 |
| **入场** | 信号K线极值外1 tick止损单 · 微趋势线假突破后入场最佳 |
| **止损** | 信号K线反向极值外1 tick · 或通道趋势线反向侧1 tick |
| **目标** | **最小目标：**通道对侧（趋势通道线）· **延伸目标：**突破通道线加速 |
| **仓位** | 正常仓位75% · 绝不逆势（逆势仓位=0%） |
| **管理** | 顺势刮头皮+部分摆动 · 趋势线附近入场→通道线附近部分获利 · 通道线附近可小仓位逆势刮头皮（仅限微利润） |
| **退出条件** | 回撤加深到3-5根K线（窄通道→宽通道转换）· 或趋势线被有效突破 |
| **禁用信号** | L1/L2做空（多头窄通道中）· ii逆势突破 · 任何逆势摆动交易 |

## Playbook 3：宽通道/阶梯（Broad Channel）

**趋势强度：弱 · Always In：单向但对手活跃 · 双向交易可行**

| 维度 | 规则 |
|------|------|
| **识别确认** | 趋势线和通道线之间距离较宽 · 3+区间组成 · 回撤超出突破点 · 有明显ABC修正 · 阶梯式推进 |
| **优先信号** | ① **H2/L2在趋势线处顺势入场**（最优先）· ② **H3/L3 = 楔形旗**（收缩阶梯出现时）· ③ **双底多头旗/双顶空头旗**（趋势线附近）· ④ **通道线处DBL/DBS逆势刮头皮**（仅限刮头皮） |
| **信号K线** | 趋势线处：顺势方向的强反转K线 · 通道线处：逆势方向的强反转K线（仅刮头皮）· 警惕**收缩阶梯**——突破越来越小=反转预警 |
| **入场** | 顺势方向：信号K线极值外1 tick止损单 · 通道线逆势刮头皮：信号K线极值外1 tick限价单（仅小仓位） |
| **止损** | 顺势：信号K线反向极值外1 tick · 逆势刮头皮：通道线反向侧1-2 tick |
| **目标** | **顺势最小目标：**通道对侧 · **逆势刮头皮：**到趋势线（通道内反向）· **延伸目标：**通道突破加速 |
| **仓位** | 顺势100%仓位 · 逆势刮头皮<=25%仓位 · 优先顺势方向 |
| **管理** | 顺势摆动持有 · 逆势刮头皮快速获利了结 · 出现**收缩阶梯**时停止逆势交易——准备反转 |
| **退出条件** | 收缩阶梯→趋势线突破→转为大反转/MTR评估 · 或通道升级为窄通道（加速） |
| **禁用信号** | 通道线处的逆势摆动交易 · 趋势线处的逆势入场 · 收缩阶梯出现后的顺势追入 |

## Playbook 4：大反转 / MTR（Major Trend Reversal）

**胜率约40% · 回报数倍于风险 · 需要3+理由**

| 维度 | 规则 |
|------|------|
| **识别确认** | ① 趋势线被强势突破（必须）· ② 测试趋势极端（更高高点/双顶/更低高点）· ③ 测试时出现强反转K线 · ④ 二次确认信号 · **至少3个理由**支持反转 |
| **优先信号** | ① **楔形反转**（趋势线突破后的三推=最强MTR形态）· ② **双顶/双底在趋势线突破后**（测试极端）· ③ **ii形态逆势突破**（最终旗形反转）· ④ **趋势线突破后的H2/L2二次入场** |
| **信号K线** | 必须是**强反转K线**——大实体、小尾巴、收盘价反转多条先前K线 · 最佳：反转K线收盘价反转了多条K线的收盘价和高点/低点 |
| **入场** | **等待第二个信号**——不急于第一信号入场 · 在第二个信号K线极值外1 tick止损单入场 |
| **止损** | 测试极端的反向侧（更高高点上方/更低低点下方）1 tick |
| **目标** | **最小目标：**测量移动=楔形/形态高度 · **延伸目标：**前主要摆动点 · **最终目标：**原趋势起点方向 |
| **仓位** | <=50%仓位（胜率仅40%）· 分两批入场：第一信号25% + 第二信号25% |
| **管理** | 入场后立即设止损 · 第一目标到达后移止损至盈亏平衡 · 摆动持有剩余仓位 · 如果二次入场失败→趋势恢复→立即退出 |
| **退出条件** | 二次入场失败（趋势恢复）→立即退出 · 或到达测量移动目标 |
| **禁用信号** | 无趋势线突破的"反转"信号 · 仅靠单一理由入场 · 在1分钟图上寻找反转 |

## Playbook 5：小反转 / 失败（Minor Reversal / Failure）

**顺势约70%延续 · 逆势入场需被套交易者止损**

| 维度 | 规则 |
|------|------|
| **识别确认** | 失败信号又失败 · 无趋势线突破 · 小反转出现在趋势中 · 逆势K线缺乏跟进 · 市场在"假反转" |
| **优先信号** | ① **被套交易者止损处入场**（核心策略）——在逆势交易者被套的位置顺势入场 · ② **失败的ii/ioi顺势**（小反转失败=顺势入场）· ③ **失败的双顶/底**→顺势方向入场 |
| **信号K线** | 顺势方向的趋势K线 · 逆势方向出现"失败"信号后反向入场 · 入场在被套交易者的止损区域 |
| **入场** | 在逆势信号K线反向极值外1 tick设顺势止损单 · 等价于在被套交易者止损位入场 |
| **止损** | 顺势方向最近的摆动点外 |
| **目标** | **最小目标：**前趋势极端（测试）· **延伸目标：**创新极端 |
| **仓位** | 正常仓位75%——这是顺势交易，胜率约70% |
| **管理** | 顺势摆动持有 · 如果小反转升级为大反转（趋势线突破）→重新评估 |
| **退出条件** | 趋势线被突破（小反转升级）→立即退出顺势仓位 |
| **禁用信号** | 在小反转方向追加入场 · 将小反转误判为大反转做逆势摆动 |

## Playbook 6：宽区间（Broad Trading Range）

**80%突破失败 · 双向交易 · 高抛低吸**

| 维度 | 规则 |
|------|------|
| **识别确认** | 边界清晰 · 振幅足够大（有利润空间）· 价格在支撑和阻力间来回 · 区间中部的K线重叠多 · 突破尝试频繁但大多失败 |
| **优先信号** | ① **区间底部：H2买入 + 双底 + DBS**（做多）· ② **区间顶部：L2做空 + 双顶 + DBL**（做空）· ③ **区间边界处的ii/ioi逆势突破**· ④ **区间内的楔形**（第一个信号即可入场） |
| **信号K线** | 区间底部：强多头反转K线（下影线、大实体）· 区间顶部：强空头反转K线（上影线、大实体）· **区间中间位置的任何信号=不可靠** |
| **入场** | 使用**限价单**在区间边界入场（而非止损单）· 在信号K线极值处设限价单 |
| **止损** | 区间边界外1-2 tick · 止损距离较小（因为区间边界清晰） |
| **目标** | **最小目标：**区间对侧边界（刮头皮）· **延伸目标：**如果区间突破成功，摆动持有 |
| **仓位** | 正常仓位100% · 可适当增大（止损距离小）· 双向交易但每次只做一个方向 |
| **管理** | 刮头皮为主——到达对侧边界时获利了结 · 区间中间不交易 · 80%突破失败→可以在边界处逆势交易突破 |
| **退出条件** | 区间被有效突破（强趋势K线+后续跟进）→停止区间交易→转为突破模式 |
| **禁用信号** | 区间中间位置的所有信号 · 区间边界处的顺势突破追入 · 窄区间中的所有信号 |

## Playbook 7：窄区间 / 铁丝网（Tight Range / Barbwire）

**不交易 · 等待能量积累 · 突破前的最佳策略是观望**

| 维度 | 规则 |
|------|------|
| **识别确认** | 大量重叠K线 · 十字星多 · 振幅极小 · 利润空间不足 · 突破方向无法判断 · 双向都缺乏动量 |
| **优先信号** | **没有任何信号是可靠的。**H1/H2/L1/L2/ii/ioi/双顶底——全部不可靠。 |
| **信号K线** | 不评估——所有信号K线在此状态都是噪音 |
| **入场** | **不入场。**等待窄区间被有效突破后再进入Playbook 1（突破模式） |
| **止损** | 不适用 |
| **目标** | 不适用——但如果窄区间持续时间长（能量积累），突破后的**测量移动=区间宽度x2-3** |
| **仓位** | 0%——空仓等待 |
| **管理** | **关注"窄区间持续多久了"**——新形成的窄区间：继续等待 · 持续时间久（能量积累）：准备突破入场 · 当看到大实体K线+收盘极端+急迫时→切换到Playbook 1 |
| **退出条件** | 窄区间被有效突破→进入Playbook 1 |
| **禁用信号** | 所有信号——在窄区间中交易会在一小时内亏掉一周利润 |

## 趋势强弱判断（来自思维导图）

### 上升趋势与下降趋势

```
上升趋势：高低点不断抬高
- 更高高点（HH）+ 更高低点（HL）
- 低点更加关键：低点被强势突破 → 创新高
- 趋势线向上倾斜

下降趋势：高低点不断降低
- 更低高点（LH）+ 更低低点（LL）
- 高点更加关键：高点被强势向下突破 → 创新低
- 趋势线向下倾斜
```

| 趋势类型 | 关键点位 | 突破含义 |
|----------|----------|----------|
| 上升趋势 | 低点 | 低点被强势突破后大概率创新高 |
| 下降趋势 | 高点 | 高点被强势跌破后大概率创新低 |

### 强趋势

```
强趋势特征：
- 突破：第一次反转 80% 概率失败
- 窄通道：阳线/阴线数量少，存在影线但回调极小，通道强度高
- 2nd leg up/down：强趋势经常走出第二段行情
- 好的趋势：顺势方持续买入/卖出，逆势方持续割肉
```

| 特征 | 强上升趋势 | 强下降趋势 |
|------|-----------|-----------|
| K线 | 大阳线多，回调K线小 | 大阴线多，反弹K线小 |
| 回撤 | 1-3根K线，幅度小 | 1-3根K线，幅度小 |
| EMA | 价格远离EMA运行 | 价格远离EMA运行 |
| 反转尝试 | 第一次大多失败 | 第一次大多失败 |
| 交易者心理 | 空头持续止损 | 多头持续止损 |

**强趋势交易策略：**
- 只做顺势方向
- 优先波段（swing），也可剥头皮（scalp）
- 等待第一次反转失败后的H2/L2入场
- 不要逆势

### 弱趋势

```
弱趋势特征：
- 宽通道：多空都可获利，趋势容易反转，回调幅度深
- 窄通道：下跌中阳线少，阳线后紧跟大阴线，阳线体积大，趋势较弱
```

| 特征 | 弱上升趋势 | 弱下降趋势 |
|------|-----------|-----------|
| K线 | 阳线和阴线交错，阳线后常有阴线 | 阴线和阳线交错，阴线后常有阳线 |
| 回撤 | 深且持续多根K线 | 深且持续多根K线 |
| 通道 | 宽通道为主 | 宽通道为主 |
| 双向交易 | 多空都可获利 | 多空都可获利 |
| 反转风险 | 较高 | 较高 |

**弱趋势交易策略：**
- 宽通道：趋势线顺势 + 通道线逆势刮头皮
- 不重仓追势
- 到达目标及时获利
- 警惕趋势反转

### 趋势持续时间的思考

```
每次判断趋势时，问自己：
1. 当前是上涨还是下跌？
2. 是强趋势还是弱趋势？
3. 趋势已经运行了多少根K线？（是否超过20根？）
4. 当前趋势还能持续多久？
5. 是否有反转迹象？
```

## 突破质量评估：真突破、弱突破、假突破

### 真突破（Strong Breakout）

```
真突破的特征：
1. 突破K线体积大，实体明显大于近期平均
2. 收在最低/最高，几乎没有影线
3. 离之前的区间足够远
4. 有急迫感，突破过程迅速
5. 突破后有跟进K线确认
6. 成交量/动能配合

交易策略：
- 顺势追入或等待小幅回调
- 回调不超过突破K线实体的50%
- 止损设在突破K线极值外或突破点下方
- 目标：测量移动位（MM）
```

| 特征 | 真突破 | 假突破 |
|------|--------|--------|
| 实体 | 大 | 可能大但无跟进 |
| 影线 | 小 | 可能长 |
| 收盘价 | 极端 | 回到区间内 |
| 距离 | 远离区间 | 未能远离 |
| 跟进 | 有 | 无 |
| 急迫感 | 强 | 弱 |

### 弱突破（Weak Breakout）

```
弱突破的特征：
1. 突破K线实体较小
2. 有较长影线
3. 突破后回踩较深
4. 未能远离突破点
5. 后续K线迅速回到区间内或附近

交易策略：
- 不追入
- 等待回踩测试突破点
- 如果回踩后获得支撑/阻力 → 可顺势入场
- 如果完全回踩突破点 → 突破失效，回到区间策略
```

### 假突破（False Breakout）

```
假突破的特征：
1. 出现在震荡行情中的第二段陷阱
2. 市场一直尝试突破，弱势一方在让步
3. 大部分人看起来像要突破了一样
4. 但很多都是陷阱
5. 突破后价格迅速回到区间内
6. 突破K线收盘不极端，或很快被反转

常见位置：
- 震荡区间的第二段陷阱
- 区间边界附近的诱多/诱空
- 趋势末端的高潮K线

交易策略：
- 不追突破
- 准备反向交易
- 止损设在假突破极值外
- 目标：区间对侧边界
```

### 突破回踩的三种情况

```
情况1：突破后没有回踩
- 代表趋势非常强势
- 缺口越大，上涨/下跌趋势越强势
- 不要等待回踩，直接追入或放弃

情况2：突破后小幅回踩（<50%）
- 正常强势表现
- 回踩是入场机会
- 止损设在回踩低点下方

情况3：突破后大幅回踩（>50%或完全回踩）
- 突破较弱或失败
- 多空概率回到50对50
- 重新评估，不急于入场
```

## 不看周期的交易方式（来自思维导图）

```
核心思想：无论当前处于哪个具体周期阶段，都可以按以下原则交易。
          关键是识别当前价格行为的"类型"，而不是精确判断周期位置。
```

### 宽通道中的交易方式

| 策略 | 适用条件 | 具体做法 |
|------|----------|----------|
| 顺势波段 | 趋势方向明确 | 在趋势线附近H2入场，摆动持有 |
| 高抛低吸 | 边界清晰 | 通道线附近逆势刮头皮到趋势线 |
| 等待突破 | 趋势动能减弱 | 等突破通道线后追入或等待回踩 |

### 窄通道中的交易方式

```
原则：只做单一方向

- 多头窄通道：只做多，不逆势做空
- 空头窄通道：只做空，不逆势做多
- 入场点：微趋势线假突破、H1/H2、EMA回撤
- 仓位：标准或略加重
```

### 突破中的交易方式

```
原则：好信号K线进场，强突破等 2nd leg 回调入场

- 一般突破：突破K线收盘极端后追入
- 强突破：不追第一波，等第一次回调后的H2/L2
- 止损：突破K线极值外
- 目标：测量移动位（MM）
```

### 震荡中的交易方式

```
原则：高抛低吸 + 等待突破

- 宽震荡：区间边界处逆势交易
- 窄震荡：不交易，等待突破
- 二三十根K线震荡后：优先做突破单
- 止损：区间边界外
- 目标：区间对侧边界或突破后的MM位
```

### 不看周期交易总览

| 市场类型 | 主策略 | 次策略 | 禁忌 |
|----------|--------|--------|------|
| 宽通道 | 顺势波段 | 通道线逆势刮头皮 | 重仓逆势摆动 |
| 窄通道 | 只做单一方向 | 小仓位顺势 | 任何逆势交易 |
| 突破 | 好信号K追入 | 等2nd leg回调 | 追弱突破 |
| 震荡 | 高抛低吸 | 等待突破 | 区间中部交易 |

## 状态转换规则

| 从 | 到 | 关键信号 |
|----|-----|----------|
| 突破 → 窄通道 | 回撤出现、K线开始重叠 | 持续持有/等H1入场 |
| 窄通道 → 宽通道 | 回撤加深、触及通道线 | 调整止损/目标 |
| 宽通道 → 大反转 | 收缩阶梯、破趋势线 | 准备反转仓位 |
| 宽区间 → 突破 | 引爆点、连续突破K线 | 追入突破方向 |
| 窄区间 → 突破 | 能量积累释放、缺口 | 突破方向入场 |

---

## 关键原则

**每个状态只有2-3个优先信号。不要在所有信号中挑选——使用该状态专属的Playbook。**
