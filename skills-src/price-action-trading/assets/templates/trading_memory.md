# 记忆提取与更新指引（AI自动执行）

> **核心原则**：记忆更新是AI的自动行为，不需要用户手动触发。AI应在每笔交易后、每周回顾时、每月回顾时自动执行以下操作。

---

## 一、每笔交易后即时更新

### 1.1 设置有效性更新（→ pattern_effectiveness.md）

```
输入：交易日志中的设置类型、结果（盈/亏）、盈亏比
操作：
  1. 在 pattern_effectiveness.md 对应设置类型的统计行中更新：
     - 总交易次数 +1
     - IF 盈利 → 胜利次数 +1
     - 累计盈亏比更新
  2. IF 该设置类型尚无 MEM-NNN 条目 且 一致结果≥3次：
     创建新 MEM-NNN 条目
```

### 1.1b 环境分层更新（→ pattern_effectiveness.md 分层子表）

```
输入：交易日志中的市场环境标注（市场类型+波动率）
操作：
  1. 在对应设置类型的"按市场环境分层"子表中更新对应行
  2. 在对应设置类型的"按波动率分层"子表中更新对应行
  3. IF 某环境分层样本量≥20：
     标注该环境下的置信度为"中等"
  4. IF 某环境分层样本量≥30：
     标注该环境下的置信度为"高"
  5. IF 某环境下胜率>60%且样本量≥20：
     标记为"✅ 该环境下的优势策略"
  6. IF 某环境下胜率<40%且样本量≥20：
     标记为"❌ 该环境下的劣势策略"
```

### 1.2 错误模式更新（→ error_patterns.md）

```
输入：交易日志中的规则违反、错误描述
操作：
  1. IF 交易违反了某条规则（BAN/SA/SL/RM等）：
     检查 error_patterns.md 是否有匹配的 ERR-NNN 条目
     IF 存在 → 更新频率计数
     IF 不存在 且 同类错误≥2次 → 创建新 ERR-NNN 条目
  2. IF 用户描述了情绪化交易行为：
     记录到 trader_profile.md 的情绪触发模式
```

### 1.3 假设验证更新（→ strategy_hypotheses.md）

```
输入：交易结果
操作：
  1. 检查 strategy_hypotheses.md 中是否有活跃假设与此交易相关
  2. IF 存在 → 更新验证进度（验证次数+1）
  3. IF 验证次数达到验证标准 → 更新状态为"已验证"
  4. IF 结果与假设矛盾 且 达到证伪标准 → 更新状态为"已证伪"
```

### 1.4 改进计划更新（→ improvement_tracker.md）

```
输入：复盘中的改进项
操作：
  1. IF 复盘中提出新改进项：
     创建新 IMP-NNN 条目，写入 improvement_tracker.md
  2. IF 复盘中评估了已有改进计划：
     更新对应 IMP-NNN 的评估记录（记录关联错误本周频率）
  3. IF 改进计划关联的错误连续4周频率为0：
     移至"已完成"区域
  4. IF 改进计划连续3周未执行：
     标记为"需要重新评估"，在周度回顾中提醒
  5. IF 改进计划累计≥4周且关联错误频率无下降：
     在月度回顾中标记"需调整"
```

## 二、每周回顾时自动提炼

### 2.1 设置统计聚合

```
输入：本周所有 L2 交易记录
操作：
  1. 按设置类型聚合：总次数、胜率、平均盈亏比
  2. 与 pattern_effectiveness.md 现有数据合并
  3. 识别本周表现最好和最差的设置类型
```

### 2.2 错误模式汇总

```
输入：本周所有错误记录
操作：
  1. 按错误类型聚合：频率、根因分布
  2. 与 error_patterns.md 现有数据合并
  3. IF 某错误频率≥3次/月 → 生成改进建议
```

### 2.3 新发现记录

```
输入：本周交易中的新观察
操作：
  1. IF 发现新的市场规律 → 创建 market_wisdom.md 条目
  2. IF 发现品种差异 → 更新 cross_instrument.md
  3. 将周度总结写入 memory/L3_weekly/YYYY/WNN_week_summary.md
```

## 三、每月回顾时自动审查

### 3.1 记忆晋升与归档

```
操作：
  1. 审查所有"待验证"条目：
     - 初步观察（≥5次，<20次）→ 仅作参考，不作为决策依据
     - 已验证（≥20次）→ 可作为决策参考依据
     - 高度验证（≥30次）→ 晋升为L5永久记忆
     - 90天未更新 → 归档至 memory/archive/
  2. 审查所有"已证伪"条目：
     - 记录教训 → 归档
  注：与第四节统计显著性标准一致
```

### 3.2 自我升级建议生成

```
操作：
  1. 分析 pattern_effectiveness.md：
     - 识别优势策略（胜率≥60%，R:R≥2:1）→ 建议专注
     - 识别劣势策略（胜率<40%）→ 建议避免
  2. 分析 error_patterns.md：
     - 识别高频错误 → 生成改进措施
     - 检查"已克服"错误是否复发
  3. 分析 trader_profile.md：
     - 更新能力评估（7维度）
     - 识别最需要改进的维度
  4. 生成月度自我升级建议报告
  5. 将月度审查写入 memory/L4_monthly/YYYY/MM_month_review.md
```

## 四、记忆质量检查

### 4.1 去重规则
- 创建新条目前，搜索是否已存在相同描述的条目
- IF 存在 → 合并数据而非创建新条目

### 4.2 冲突检测
- 当新数据与已有数据矛盾时（如同一设置在不同文件中胜率不同）
- 保留最新数据，在条目中标注"⚠️ 与<<其他ID>>存在数据冲突"

### 4.3 统计显著性标准
- 样本量<5：不做概率判断，标记"数据不足"
- 样本量5-20：标记"初步观察"
- 样本量20-30：标记"趋势确认"
- 样本量≥30：标记"已验证"

## 五、知识复习触发规则

> 基于交易数据的客观触发，不基于主观感觉

```
IF 交易中方程式计算错误或未计算：
  → 推荐复习 strategy_workflow.md Ch11 交易者方程式速查表
  → 在下次交易决策时，AI主动检查方程式是否被计算

IF 某错误类型（认知型）频率连续2周上升：
  → 推荐复习对应的 references/knowledge/themeN.md 章节

IF 某设置类型连续3次方程式为负：
  → 推荐复习该设置的详细知识章节
  → 检查是否遗漏了关键前提条件

IF 月度知识评估某主题掌握度 < 5：
  → 推荐安排专项复习

IF 改进计划关联错误频率连续4周无下降：
  → 推荐重新审视改进方案，可能需要知识补充
```
