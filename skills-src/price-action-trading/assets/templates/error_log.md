# 错误交易日志

## ID格式与记忆桥梁说明

- **错误ID格式**：`YYYY-MM-DD-ERR-NNN`（如 `2026-04-17-ERR-001`）
  - `YYYY-MM-DD`：错误发生日期
  - `ERR`：错误记录标识
  - `NNN`：当日错误序号（三位数，从001开始）
- **记忆桥梁**：每条错误记录应评估是否需要写入记忆库（`memory/` 目录）。若需要，填写对应的记忆ID（格式 `MEM-NNN`），实现错误日志与长期记忆的关联追踪。

> **引用说明**：ERR-NNN 引用错误模式条目，MEM-NNN 引用设置有效性条目。当错误与特定设置相关时，应同时引用两者。
