# 交易日志模板（AI-First 设计）

> **设计理念**：人类只做极简输入，AI 完成所有分析、评级与复盘草稿。
> 人类输入区在顶部，AI 自动生成区在下方。所有 AI 生成内容均可由人类审核修正。
> 每个含主观判断的 AI 字段均标注置信度（高/中/低），低置信度时提示人类确认。

---

## ID 格式说明

- **交易ID格式**：`YYYY-MM-DD-TRD-NNN`（如 `2026-04-17-TRD-001`）
  - `YYYY-MM-DD`：交易日期
  - `TRD`：交易记录标识
  - `NNN`：当日交易序号（三位数，从001开始）

## 9. 决策质量评级

> AI 综合分析交易全过程，独立于盈亏结果评估决策质量。

| 字段 | 内容 | 置信度 |
|------|------|--------|
| **决策质量评级** | A / B / C / D / E | |
| **评级理由** | | |

**评级标准**：

| 评级 | 含义 | 说明 |
|------|------|------|
| **A** | 优秀 | 完全按计划执行，设置可靠，多理由叠加，方程式正期望，情绪稳定 |
| **B** | 良好 | 基本按计划执行，设置合理，方程式正期望，有轻微可改进之处 |
| **C** | 一般 | 部分偏离计划，设置勉强可接受，方程式接近盈亏平衡 |
| **D** | 较差 | 明显偏离计划，设置质量低，方程式负期望，或情绪明显影响决策 |
| **E** | 失败 | 严重违反规则，冲动交易，无合理设置，情绪失控 |
