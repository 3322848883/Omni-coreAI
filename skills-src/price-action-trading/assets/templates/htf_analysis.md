## 1. Al Brooks HTF 使用原则

> 引用 Theme8 Ch13

1. **HTF 提供背景，交易TF提供入场**：更高时间框架（HTF）决定交易方向和概率优势，交易时间框架（交易TF）决定具体入场时机。永远不要在交易TF上寻找与HTF趋势方向相反的交易，除非HTF出现明确的反转信号（趋势线突破+测试旧极端+强反转K线）。

2. **HTF 的每个K线模式都会在交易TF上产生对应的价格行为**：HTF上的双顶在交易TF上表现为阻力位，HTF上的趋势K线在交易TF上表现为急速通道，HTF上的外包K线在交易TF上表现为突破回测。这种分形递归关系是价格行为分析的核心。

3. **HTF 关键价位是交易TF的磁铁和边界**：HTF支撑阻力位、HTF EMA20、HTF缺口和HTF测量移动目标都会在交易TF上产生磁性效应。当交易TF价格接近这些HTF价位时，反转概率显著增加，应调整止损和目标。

## 3. HTF 趋势阶段判断标准表

| 趋势阶段 | 判断标准 | 对交易TF的影响 | 仓位建议 |
|---------|---------|--------------|---------|
| **早期（Early）** | 趋势刚刚开始，首次突破关键价位，第1-2腿推动，EMA20开始转向，回撤浅（1-2根K线） | 交易TF上顺势回撤入场概率最高，是最佳交易时段 | 标准仓位或加仓（100%） |
| **中期（Middle）** | 趋势已确认，有3-5腿推动，EMA20角度稳定，回撤规律（2-3根K线），测量移动目标部分达成 | 交易TF上顺势回撤入场仍然可靠，但需注意回撤可能加深 | 标准仓位（75-100%） |
| **晚期（Late）** | 趋势运行已久（5+腿），回撤开始加深（3-5根K线），K线重叠增加，EMA20开始走平，接近测量移动目标 | 交易TF上顺势入场概率下降，逆势反转信号开始出现，需收紧止损 | 减仓（50-75%） |
| **衰竭（Exhaustion）** | 连续高潮（3次+），抛物线加速，通道线被超越，测量移动目标已达成或超越，出现强反转K线 | 交易TF上反转概率显著上升，应考虑获利了结或寻找反转机会 | 大幅减仓或跳过（25-50%） |

## 4. 5层一致性量化评估

### 一致性评分

| 一致性层级 | 评分标准 | 方向置信度 | 仓位建议 | 说明 |
|-----------|---------|-----------|---------|------|
| **全部一致（5/5）** | 月线、周线、日线、60分钟、15分钟全部方向一致 | 极高（90%+） | 100%标准仓位 | 最强交易条件，可积极入场 |
| **高度一致（4/5）** | 4个时间框架方向一致，仅1个矛盾 | 高（75-85%） | 75-100%标准仓位 | 强交易条件，矛盾层通常为最短期 |
| **部分一致（3/5）** | 3个时间框架方向一致，2个矛盾 | 中（60-70%） | 50-75%标准仓位 | 可交易但需谨慎，检查矛盾层原因 |
| **低一致性（2/5）** | 仅2个时间框架方向一致 | 低（50-55%） | 25-50%标准仓位或跳过 | 边缘交易，除非有⭐⭐⭐⭐⭐设置 |
| **矛盾（0-1/5）** | 大多数时间框架方向矛盾 | 极低（<50%） | **禁止交易** | 无方向优势，等待一致性恢复 |

### 一致性评估流程

```
Step 1: 填写5层分析表格（第2节）
Step 2: 统计方向一致的层数
Step 3: 根据上表确定仓位大小
Step 4: 如果一致性 < 3/5，检查是否有⭐⭐⭐⭐⭐设置
Step 5: 如果无高星级设置且一致性 < 3/5 → 不交易
```

### 价位使用原则

1. **多层价位重叠时概率最高**：当日线支撑与周线支撑接近时，该价位极难突破
2. **HTF价位优先于交易TF价位**：周线阻力 > 日线阻力 > 60分钟阻力
3. **价位作为止损参考**：HTF支撑/阻力位外侧是放置止损的天然位置
4. **价位作为目标参考**：HTF测量移动目标是摆动交易的首选出场目标
5. **价位作为过滤条件**：如果交易TF信号方向指向HTF阻力位，应缩小仓位或跳过

## 6. 日内交易者 vs 摆动交易者 HTF 使用说明

### 日内交易者（Day Trader）

| 项目 | 说明 |
|------|------|
| **核心HTF** | 日线（主HTF）、周线（背景HTF） |
| **交易TF** | 5分钟或15分钟 |
| **分析频率** | 每日开盘前分析日线和周线 |
| **关键关注** | 日线趋势方向、日线Always In、日线EMA20、日线关键价位 |
| **日内使用** | 日线方向决定当日只做多或只做空；日线关键价位标注在交易TF图表上作为磁铁 |
| **周线作用** | 提供大方向背景，周线趋势与日线一致时概率更高 |
| **月线作用** | 仅在极端情况参考（月线关键价位附近） |

### 摆动交易者（Swing Trader）

| 项目 | 说明 |
|------|------|
| **核心HTF** | 周线（主HTF）、月线（背景HTF） |
| **交易TF** | 日线或4小时 |
| **分析频率** | 每周开始时分析周线和月线 |
| **关键关注** | 周线趋势方向、周线Always In、周线EMA20、周线关键价位 |
| **摆动使用** | 周线方向决定摆动方向；周线回撤到EMA20是摆动入场机会 |
| **月线作用** | 提供大周期背景，月线趋势与周线一致时概率更高 |
| **日线作用** | 作为入场时间框架，在日线回撤中寻找具体入场点 |

### 共同原则

1. **永远不要与HTF趋势方向逆势交易**，除非HTF出现完整的MTR四条件
2. **HTF关键价位标注在交易TF图表上**，作为不可忽视的磁铁和边界
3. **HTF趋势阶段决定仓位大小**：早期标准仓位，晚期减仓，衰竭跳过
4. **HTF一致性越高，交易TF入场信号越可靠**：5/5一致性时可积极入场
5. **HTF EMA20是趋势过滤器**：价格在HTF EMA20上方只做多，下方只做空
