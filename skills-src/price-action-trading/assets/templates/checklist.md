## A. 交易前必检项

### 市场状态
- [ ] 🤖 AI可自动检查 | 市场状态已正确识别（趋势/区间/反转）
- [ ] 🤖 AI可自动检查 | Always In方向已判断
- [ ] 🤖 AI可自动检查 | 如果是趋势，已识别趋势类型（7种日类型）
- [ ] 🤖 AI可自动检查 | 如果是区间，已识别区间类型（宽松/紧密/铁丝网/三角形）

### 交易方向
- [ ] 🤖 AI可自动检查 | 交易方向与Always In方向一致
  - 如果逆势交易，至少有3个以上理由支持
- [ ] 🤖 AI可自动检查 | 不在铁丝网(Barb Wire)中交易
- [ ] 🤖 AI可自动检查 | 不在紧密区间中部交易
- [ ] 🤖 AI可自动检查 | 不在紧密区间中交易（除非在极端位置且有强信号）

### 设置质量
- [ ] 🤖 AI可自动检查 | 设置类型已识别（趋势/反转/突破/区间/组合形态）
- [ ] 🤖 AI可自动检查 | 至少有2个理由支持交易
- [ ] 🤖 AI可自动检查 | 信号K线质量为B级或以上
  - C级需要3个以上理由
  - D级禁止交易

### 交易者方程式
- [ ] 🤖 AI可自动检查 | 交易者方程式为正：P(win) × Reward > P(loss) × Risk
- [ ] 🤖 AI可自动检查 | 收益风险比合理（刮头皮≥1:1，摆动≥1:1.5）
- [ ] 🤖 AI可自动检查 | 预估胜率与设置可靠性匹配

### 风险管理
- [ ] 🤖 AI可自动检查 | 止损位置已确定
- [ ] 🤖 AI可自动检查 | 单笔风险 ≤ 账户的2%
- [ ] 🤖 AI可自动检查 | 仓位大小已根据止损距离计算
- [ ] 🤖 AI可自动检查 | 不在连续亏损后加大仓位
- [ ] 🤖 AI可自动检查 | 不在报复性心态下交易

### 净值曲线管理
- [ ] 🤖 AI可自动检查 | 今日累计亏损未超过账户3%
- [ ] 🤖 AI可自动检查 | 本周累计亏损未超过账户6%
- [ ] 🤖 AI可自动检查 | 本月累计亏损未超过账户10%
- [ ] 🤖 AI可自动检查 | 未处于连续亏损5笔的状态
- [ ] 🤖 AI可自动检查 | 未处于盈利高峰回撤20%的状态

## B. 交易中检查项

> ⚠️ 必须人类执行 — AI无法替代以下操作

### 入场后
- [ ] 入场成交后立即设置保护性止损
- [ ] 第一目标已设置限价单
- [ ] 交易已记录在交易日志中

### 持仓管理
- [ ] 如果是刮头皮：在第一目标处全部获利
- [ ] 如果是摆动交易：
  - [ ] 第一目标到达：平1/3到1/2仓位
  - [ ] 第二目标到达：再平1/3仓位
  - [ ] 剩余仓位使用追踪止损
- [ ] 追踪止损已按规则更新
- [ ] 不因恐惧而过早获利了结
- [ ] 不因贪婪而忽略止损

---

## C. 交易后检查项

### 止损触发后
- [ ] 不立即反向交易（避免情绪化决策）
- [ ] 分析失败原因
- [ ] 等待下一个清晰的设置

### 获利了结后
- [ ] 记录实际盈亏
- [ ] 复盘交易过程（ADV-08）
- [ ] 识别改进点

## D. 禁止事项检查

> 🤖 AI自动检查 — 无需人类逐条勾选，AI自动检测违规行为

### 绝对禁止 ❌
- [ ] 不使用止损 → **禁止交易**
- [ ] 在铁丝网中交易 → **禁止交易**
- [ ] 在强趋势中逆势交易（初学者）→ **禁止交易**
- [ ] 基于新闻交易 → **禁止交易**
- [ ] 单笔风险 > 2% → **禁止交易**
- [ ] 追逐市场（FOMO入场）→ **禁止交易**
- [ ] 在1分钟图上作为主时间框架交易 → **不建议**（1分钟图仅可用于入场时机确认和微观结构识别，参考theme8 Ch13）
- [ ] 连续亏损后加大仓位 → **禁止交易**
- [ ] D级信号入场 → **禁止交易**（BAN-05）
- [ ] 紧凑区间止损入场 → **禁止交易**（BAN-06）
- [ ] 无明确市场状态时入场 → **禁止交易**（BAN-09）
- [ ] 重仓赌单笔 → **禁止交易**（BAN-10）
- [ ] 移动止损远离入场价 → **禁止交易**（BAN-12）
- [ ] 忽略交易者方程式 → **禁止交易**（BAN-13）
- [ ] 重大新闻前建仓 → **禁止交易**（BAN-14）

### 强烈不建议 ⚠️
- [ ] 反向刮头皮 → **强烈不建议**
- [ ] 在信号K线看起来很好时入场（可能是陷阱）→ **不建议**
- [ ] 在不确定时交易 → **等待更好的设置**
- [ ] 过度交易（一天超过合理数量）→ **控制交易频率**
- [ ] 忽略交易计划 → **严格执行计划**
- [ ] 在第一根K线交易 → **不建议**（ADV-02）
- [ ] 不设目标随意持仓 → **不建议**（ADV-04）
- [ ] 在弱信号上加仓 → **不建议**（ADV-06）
- [ ] 忽略Always In方向 → **不建议**（ADV-07）

### 注意事项 ⚡
- [ ] 收盘前最后 5 分钟交易 → 减小仓位或避免（WARN-01）
- [ ] 周五尾盘持仓过周末 → 平仓或大幅减仓（WARN-02）
- [ ] 趋势已运行很久后顺势入场 → 减小仓位，收紧止损（WARN-03）
- [ ] 多个时间框架信号冲突 → 等待一致信号（WARN-04）
- [ ] 连续盈利后过度自信 → 保持固定风险管理（WARN-05）

## E. 78条交易指南关键检查

> 🤖 AI自动筛选 — AI基于当前交易场景自动筛选相关条目，无需逐条阅读

> 完整78条指南见 references/knowledge/theme8_daytrading.md 第25章

以下是最关键的检查项：

### 基础认知
- [ ] 理解市场永远在趋势和区间之间循环
- [ ] 理解每个模式都是更高时间框架模式的分形
- [ ] 理解大多数反转失败并进入区间

### 交易执行
- [ ] 趋势中只顺势交易
- [ ] 区间中只在极端位置交易
- [ ] 等待两个或更多理由
- [ ] 使用保护性止损
- [ ] 让利润运行（摆动交易）

### 风险管理
- [ ] 收益≥风险时才交易
- [ ] 单笔风险≤2%
- [ ] 不报复性交易
- [ ] 不追逐市场
