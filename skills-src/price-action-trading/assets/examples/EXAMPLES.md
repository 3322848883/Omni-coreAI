## 关键模式

### 市场状态判断
- Q1-Q7 决策树：4H/1H/5M 三层 Always In 判定
- 4H 5/6 = 强趋势 → 第3章趋势引擎
- 4H 2-3/6 = 无明确趋势 → Q3 HTF方向 → 仅⭐⭐⭐⭐⭐形态

### 信号棒评估
- SB 系列：SB-01/02/06/08/10 逐条检查
- CT 系列：CT-01/03/05/07/09/13 逐条检查
- 无 P1/P2 信号棒 = 不交易

### 止损校验（Step 4.0）
- SA-04：止损 ≥ 1 tick（原文规则）
- SA-05：止损 ≤ 日均波幅 × 20%（原文规则）
- 参考 `instrument_crypto_specifics.md §5.1` 的典型止损距离作为合理性检查
- 高波动（>1.5x）：放宽 1.5x，仓位 × 50%
- 极端波动（>2.5x）：放宽 2x，仓位 × 25%
- 不合规则 → 直接拒绝，不进入方程

### 阶段五管理（Step 7.1-7.4）
- 7.1 追踪止损（TS-01~05）
- 7.2 目标管理（EX/PP）
- 7.3 仓位缩放（SI/SO）
- 7.4 动态监控（Q1-Q6）

### 阶段六-七（Step 8-9）
- Step 8：21.1 止损后流程 + 21.2 FB 分类 + 21.4 FL 纪律
- Step 9：22.1 评估 + 22.3 分支 + 22.4 闭环 + 23.2 PS 检查
