# 分析验收规范（Analysis Acceptance Spec）

> **版本**：v34.2 | **适用**：price-action-trading 技能的一切行情分析交付物  
> **地位**：与 references/SOUL.md「执行规范（强制）」配套。SOUL 管「必须做什么」，本文管「做完如何判定合格」。  
> **依据**：references/SOUL.md 执行规范 · SKILL.md 执行摘要 · references/skill-pitfalls.md · references/pitfalls-v32.md · assets/templates/step_checklist.md · assets/examples/ · references/knowledge/strategy_workflow.md · references/knowledge/instrument_crypto_specifics.md  
> **原则**：流程合规可硬性打分；深度分级可标注；禁止用「感觉还行」代替勾选。

## 0. 验收对象与分级

### 0.1 什么必须验收

| 交付物类型 | 是否走本规范 | 最低门禁 |
|------------|:------------:|----------|
| **完整行情分析**（用户要求分析某品种 / 26步 / 完整技能） | 是 | **G0 + G1 全项** + 文末验收表 |
| **路径 A1/A2 快速更新**（旧计划仍有效） | 是（裁剪版） | **G0-A + G0-C**；G1 仅更新位与触发状态 |
| **路径 D 持仓管理** | 是（裁剪版） | **G0-D** + 管理步骤有规则 ID |
| **知识问答**（概念/缩写/规则出处） | 否 | 标注来源章节即可 |
| **规则合规检查**（用户丢来一个计划） | 部分 | G0 规则引用 + BAN/SA/方程检查项 |
| **交易复盘** | 另表 | 另见 assets/templates/trade_review.md + Pitfall 16 写入清单 |

### 0.2 完整分析的「满血 / 标准 / 摘要」标签

文末必须自我标注深度档，供验收对照：

| 标签 | 含义 | 允许场景 |
|------|------|----------|
| **满血** | G0 全过 + G1 全过 + 对齐 examples 紧凑密度 | 用户点名「完整/26步/examples深度」 |
| **标准** | G0 全过 + G1 全过（含 **G1-13～16**：周期/20根/四技能/MM；逐K可为 10 根） | **默认完整分析必须达到** |
| **摘要** | G0 全过，G1 有缺项 | 仅限 A1/A2/D 裁剪路径，或用户明确要快速摘要 |
| **不合格** | G0 任一硬项失败 | 禁止作为交易决策依据；须补做或标注作废 |

> 多品种时：**每个品种独立打分**，禁止「BTC 满血、其余摘要」仍写「全部完成」。

## 1. 门禁总览

```text
交付分析
   │
   ▼
G0 硬性合规 ──失败──► 退回补做 / 标注「不合格·不可执行」
   │ 通过
   ▼
G1 深度完整 ──有缺──► 标注「摘要」或补做；完整分析路径必须过
   │ 通过
   ▼
G2 闭环与数据 ──缺账户/数据源──► 可出「条件分析」但须降级声明
   │ 通过
   ▼
文末粘贴《验收表》→ 算入 market_state / logs
```

**判定规则**：

| 结果 | 条件 |
|------|------|
| **PASS（标准/满血）** | G0 全过；G1 全过；G2 按场景过或合法降级 |
| **PASS-DEGRADED（降级通过）** | G0 全过；G1 缺 ≤2 项且已标注摘要；或 G2 数据源/账户未核验已声明 |
| **FAIL（不合格）** | G0 任一项 ❌；或完整分析路径下 G1 缺项 &gt;2 且未标注 |
| **HOLLOW（空壳）** | 表面 26 步齐全，但规则 ID&lt;10 或未读 memory/strategy 章节（Pitfall 7/11） |

## 7. 验收执行方式（AI 自检 + 人工抽检）

### 7.1 AI 自检（每次完整分析结束前强制）

1. 对照 G0 表逐项勾选，任一 ❌ → **先补做再输出**，或输出时总判定写 FAIL 并说明缺口。  
2. 统计规则 ID / SB / CT / BAN / Steps 覆盖。  
3. 判定深度标签。  
4. 粘贴第 6 节验收表。  
5. 更新 market_state 时写入：`验收总判定 + 深度标签 + 0.5b 路径`。

### 7.2 人工/会话抽检（用户或复盘时）

| 抽检动作 | 合格信号 | 不合格信号 |
|----------|----------|------------|
| 随机点开 2 个规则 ID | 能在 strategy_workflow 中找到且用法正确 | 编造或用错章节 |
| 看 Step 3.2 | 表格逐条有判定 | 「无信号」一句带过 |
| 看 Step 4.0 | 有数字与 SA-04/05 | 只写「止损合理」 |
| 看结论 | 价位可挂单或规则拒绝清晰 | 模糊方向建议 |
| 看验收表 | 有且与正文一致 | 缺失或自相矛盾 |
| 对照 examples | 结构相似、密度相当 | 冗长空话或严重缺步 |
