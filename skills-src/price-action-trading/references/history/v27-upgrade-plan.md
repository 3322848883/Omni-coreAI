### 3.3 Step 1.8 新增：开盘区间专项分析

**位置**：Step 1.5 逐bar评估之后、Step 2 之前

#### Step 1.8：开盘区间专项分析
→ 完整规则见 [references/knowledge/workflow.md](../knowledge/workflow.md) 阶段二（步骤2.1-2.3）、[references/knowledge/theme14_trend_day_types.md](../knowledge/theme14_trend_day_types.md)

> 开盘是日内交易最重要的时段。开盘模式为全天定下基调。

**1.8.1 开盘区间评估**：
- [ ] 开盘区间大小：< 25%日均区间→强趋势日；≈ 33-50%→趋势型区间日；> 50%→急速通道日
- [ ] 开盘第一棒类型：强趋势棒→方向信号；十字星→区间日征兆
- [ ] 开盘模式：缺口高开/低开？铁丝网开盘？趋势开盘？区间开盘？

**1.8.2 开盘概率数据**：

| 条件 | 概率 |
|------|:----:|
| 第一棒成为当日高/低点 | 20% |
| 高/低点在头5棒内形成 | 50% |
| 高/低点在1-2小时内形成 | 90% |
| 早期反转成为当日高/低点 | 30-40% |
| 双重顶/底引出波段 | 40-50% |

**1.8.3 开盘交易策略**：
- 趋势开盘→顺势入场；铁丝网开盘→等待突破
- 大型缺口（>日均区间50%）→假定强趋势日，缺口即尖峰
- 开盘第一小时是找到2-3倍风险回报交易的最佳时段

**1.8.4 关键时间策略**：

| 时间段 | 策略 |
|--------|------|
| 开盘第一小时 | 波段较大，机会最多 |
| 8:30-11:00 | 通常为交易区间，减少交易 |
| 11:00-11:30 | 警惕止损扫荡 |
| 收盘前 | 风险管理者平仓，波动加剧 |

> 80%概率第一段走势会被反转（开盘反转定理）；60%概率BOM会失败，等待回测再入场
```

#### Step 4.5：决斗线交易规则

**决斗线定义**：短期趋势（回撤）在长期趋势的支撑/阻力位结束的形态。所有回撤都是决斗线。

**识别条件**：
- [ ] 回撤被趋势通道线包含？
- [ ] 回撤在趋势线/支撑/阻力处结束？
- [ ] 回撤有楔形外形或三推结构？（最可靠形式）

**交易规则**：
- 等待回撤刺穿趋势线并反转的信号棒收盘
- 在信号棒高点/低点外1 tick使用止损单入场
- 止损设在信号棒另一端1 tick或决斗线形态极值外
- 目标：通道另一侧（趋势通道线）或测量移动

> "当一波回撤受到趋势通道线限制，而且在更高时间框架的支撑线或阻力线停止时，便形成一个决斗线形态，结果常常形成较大趋势方向上的一笔可靠交易。"（V2_B05 P224）
```
