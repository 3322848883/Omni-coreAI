## 一、升级背景

### 1.1 问题诊断

对 SKILL.md v25 工作流与原文知识库（workflow.md 阶段零~七、V2 第五部分第24-32章）进行逐行核对，发现以下结构性缺口：

| 原文阶段 | 步骤数 | SKILL.md 覆盖率 | 缺口性质 |
|---------|:------:|:--------------:|---------|
| 阶段零：盘前准备 | 8步 | **0%** | 完全缺失 |
| 阶段一：市场分析 | 6步 | ~40% | 名称级覆盖，缺量化标准 |
| 阶段二：开盘专项 | 3步 | **0%** | 完全缺失 |
| 阶段三：信号识别 | 8步 | ~30% | 缺信号棒评估深度体系 |
| 阶段四：交易执行 | 4步 | ~25% | 缺入场方式选择框架 |
| 阶段五：交易管理 | 5步 | **0%** | 完全缺失 |
| 阶段六：交易复盘 | 4步 | ~90% | 基本完整 |
| 阶段七：再决策 | 4步 | **0%** | 完全缺失 |

**核心结论**：v25 的工作流只覆盖了交易生命周期的 **入场前分析** 阶段，缺少 **盘前准备、入场后管理、失败处理、再决策闭环** 四大环节。

### 1.2 升级目标

1. 补全交易生命周期闭环：盘前 → 分析 → 入场 → 管理 → 平仓 → 再决策
2. 保持 SKILL.md 精简风格：每步 3-15 行摘要，通过引用指向原文详细内容
3. 不破坏现有结构：在 Step 0-6 基础上扩展，不修改已有步骤的核心内容
4. 功能三（规则检查清单）同步扩展：增加持仓中检查和再入场检查

### 1.3 不升级的部分

| 部分 | 原因 |

### 3.5 Step 7 新增：入场后管理

**位置**：SKILL.md 第 696 行 `---` 之后（功能一工作流结束之前）

**插入点**：在 `---` 之前，Step 6 之后

**插入内容**：

```markdown

#### Step 7：入场后管理
→ 完整规则见 [references/knowledge/workflow.md](../knowledge/workflow.md) 阶段五（步骤5.1-5.3）、[references/knowledge/theme7_management.md](../knowledge/theme7_management.md) Ch29-31

> 入场后立即执行以下操作，然后每根K线收盘后执行动态监控。

**7.1 入场后立即执行**：
- [ ] 确认成交价格、时间、仓位大小
- [ ] 立即设置保护性止损（不使用心理止损）
- [ ] 设置第一目标限价单
- [ ] 评估入场K线质量：强趋势棒→收紧止损至入场K线外1-2 tick；十字星→保持原始止损

**7.2 入场后止损调整逻辑**（原文V2_B09第29章）：
- [ ] 入场棒为强趋势棒（与交易方向一致）→ 止损移至入场棒另一端外1 tick
- [ ] 入场棒为十字星 → 不调紧止损，允许1-2 tick回撤
- [ ] 入场棒为外包棒（与交易方向一致）→ 止损移至外包棒另一端外1 tick
- [ ] 入场棒为内包棒 → 保持信号棒止损（内包棒是单棒交易区间）
- [ ] 市场向有利方向运动约利润目标的一半 → 止损移至盈亏平衡点

**7.3 追踪止损规则**：
- 多头：每次创新高后，止损移至最近波段低点下方1 tick
- 空头：每次创新低后，止损移至最近波段高点上方1 tick
- 判断方法：想象自己是空仓，是否愿意以当前价格和止损建仓？不愿意→退出

**7.4 持仓中动态监控**（每根K线收盘后检查）：

| 检查项 | 触发条件 | 响应动作 |
|--------|---------|---------|
| Always In方向改变 | 连续3根K线收盘在EMA另一侧 | 评估是否提前平仓 |
| 反转信号出现 | 双顶/双底/楔形/高潮 | 收紧止损 |
| 触及关键磁铁 | 到达EMA/前高/测量移动目标 | 部分获利或移动止损 |
| 达到第一目标 | 价格到达第一目标位 | 平1/3-1/2仓位，止损移至保本 |
| 达到第二目标 | 价格到达第二目标位 | 再平1/3仓位 |
| 市场进入铁丝网 | 3根+K线大量重叠+十字星 | 考虑全部获利了结 |
| 方程式重算为负 | 当前R:R使方程式为负 | 评估是否提前平仓 |

**7.5 仓位缩放**：
- 加仓：强趋势+回撤到关键支撑/阻力；永远不要对亏损仓位加仓（除非对大局有信心）
- 减仓：第一目标平1/3-1/2，第二目标再平1/3，剩余用追踪止损让利润运行
```

**设计说明**：

### 3.6 Step 8 新增：失败处理与平仓

```markdown
#### Step 8：失败处理与平仓
→ 完整规则见 [references/knowledge/workflow.md](../knowledge/workflow.md) 步骤5.4、[references/knowledge/theme5_reversals.md](../knowledge/theme5_reversals.md) 第9章

**8.1 止损触发后**：
- [ ] 立即确认止损成交
- [ ] **不要立即反向交易**（情绪化决策）
- [ ] 分析失败原因：市场状态判断错误？建仓形态识别错误？信号K线质量不够？止损太紧？
- [ ] 等待下一个清晰的建仓形态

**8.2 失败突破处理**：
- 突破失败是否创造逆势建仓形态？
- 是否有"失败之失败"机会？（最佳入场机会之一）
- 双方是否都被困？（高概率建仓形态）
- 失败突破后通常至少有两腿反向移动

**8.3 失败突破分类**：

| 类型 | 特征 | 处理方式 |
|------|------|---------|
| 一tick失败 | 突破信号K线1 tick后反转 | 在被套者止损处入场，反向刮头皮 |
| 五tick失败 | 触及利润目标但未穿过（5跳动） | 动量丧失信号，考虑移至保本或反向 |
| 九tick失败 | 触及利润目标但未穿过（9跳动） | 常成为反转第一个征兆，考虑反向入场 |

**8.4 连续亏损纪律**：

| 连续亏损 | 正确行动 | 禁止行为 |
|:-------:|---------|---------|
| 1-2次 | 正常交易，遵守规则 | 不要急于翻本 |
| 3次 | 降低仓位50% | ❌ 禁止加仓 |
| 4次 | 暂停交易，休息15-30分钟 | ❌ 禁止输后加倍 |
| 5次+ | 停止当日交易 | ❌ 禁止赌博式交易 |

**8.5 平仓记录**：
- 使用 [assets/templates/order_log.md](../../assets/templates/order_log.md) 四阶段日志记录（挂单→成交→修改→平仓）
```

**位置**：Step 8 之后

**插入内容**：

```markdown

#### Step 9：再决策（平仓后闭环）
→ 完整规则见 [references/knowledge/workflow.md](../knowledge/workflow.md) 阶段七

> 平仓不是终点，而是下一个决策的起点。

**9.1 平仓后即时评估**：
- [ ] **平仓性质**：止损平仓→进入冷却期评估；目标位平仓→评估同向再入场；手动平仓→评估合理性
- [ ] **市场环境扫描**：趋势是否仍在继续？是否有新设置形成？Always In方向是否改变？
- [ ] **情绪状态检查**：是否有报复性交易冲动？心理状态是否适合立即再入场？

**9.2 冷却期判断**：

| 触发条件 | 冷却期时长 | 冷却期活动 |
|---------|-----------|-----------|
| 连续2笔亏损 | 15-30分钟 | 记录交易、简要复盘、深呼吸 |
| 连续3笔亏损 | 30-60分钟 | 完整复盘前3笔、检查交易计划 |
| 单笔大亏（>2R） | 1-2小时 | 深度复盘、情绪恢复、可能停止当日交易 |
| 情绪化交易 | 至少30分钟 | 情绪管理练习、重新阅读交易规则 |
| 日亏损达上限 | 当日停止 | 完整日终复盘、明日计划准备 |

**9.3 再决策分支**：
- **同向再入场**：趋势仍在继续 + 新顺势设置 + 方程式为正 → 重新走 Step 1-6
- **反向交易**：趋势线突破 + 测试旧极端 + 强反转K线 + 至少3个理由（必须含趋势线突破）→ 减少仓位
- **观望等待**：市场不明确 / 区间中部 / 铁丝网 / 情绪不适合 → 继续观察

**9.4 闭环确认**（再入场前最终检查）：
- [ ] 市场状态重新确认（趋势/区间/Always In）
- [ ] 个人状态检查（情绪稳定、已从上笔交易学习）
- [ ] 新交易理由充分（≥2个）、信号K线通过评估、止损目标合理
- [ ] 风险在承受范围内（≤账户1-2%）
```

**设计说明**：
