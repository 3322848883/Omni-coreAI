### 修改 4: 扩展 Step 0.9 — 认知偏差详细应对策略

**位置**: Step 0.9 交易前心理准备  
**原文来源**: Theme9 Ch5  
**扩展内容** (~40行):

```markdown
**认知偏差详细应对策略**（原文Theme9 Ch5）:

| 偏差类型 | 交易表现 | 详细应对 |
|----------|----------|----------|
| **确认偏差** | 只看到支持自己观点的信号 | 主动寻找反面证据："如果我要反向交易，理由是什么？" |
| **锚定效应** | 被入场价/前高前低锚定 | 始终以当前市场行为为依据，问："如果我现在空仓，会入场吗？" |
| **处置效应** | 过早卖出盈利、持有亏损 | 使用追踪止损让利润运行；入场前设定止损绝不修改 |
| **沉没成本** | 因已亏损而拒绝止损 | 每笔交易独立；问："这笔交易如果现在入场，我会做吗？" |
| **近因偏差** | 最近事件影响过大 | 回顾周度/月度统计，以长期数据为依据 |
| **过度自信** | 连胜后加大仓位/放宽标准 | 固定仓位大小；连胜3笔后主动缩小仓位至50% |
| **可得性偏差** | 最近大亏后过度规避 | 以统计数据为依据，不以单次经历为依据 |
| **损失厌恶** | 亏损痛苦>盈利快乐 | 记住：小亏是交易成本，大亏才是致命的 |

**偏差检查清单**（入场前执行）:
- [ ] 我是否只看到支持自己方向的信号？（确认偏差）
- [ ] 我是否被某个价格锚定？（锚定效应）
- [ ] 我是否因为已有盈利/亏损而影响判断？（处置效应）
- [ ] 我是否因为最近的结果而过度自信/悲观？（近因偏差）
```

### 修改 5: 扩展 Step 8 — 连胜连亏心理管理深化

**位置**: Step 8 失败处理与平仓  
**原文来源**: Theme9 Ch6  
**扩展内容** (~35行):

```markdown
**连胜连亏心理管理深化**（原文Theme9 Ch6）:

**连胜3笔以上的风险**:
- 过度自信：开始觉得"看透了市场"
- 放宽标准：开始交易低质量建仓形态
- 加大仓位：觉得自己处于"状态中"
- 忽视风险：觉得"这次不一样"
- **典型结局**：一次大亏抹平所有盈利

**连胜应对策略**:
| 连胜笔数 | 应对动作 |
|:--------:|----------|
| 3笔 | 主动缩小仓位至50%作为"保护" |
| 5笔 | 强制休息15分钟，回顾规则 |
| 7笔+ | 当日停止交易，深度复盘 |

**连亏3笔以上的风险**:
- 自我怀疑：开始怀疑交易系统
- 恐惧入场：看到好建仓形态也不敢入场
- 过度分析：在入场前增加越来越多条件
- 改变规则：试图"修复"本不需要修复的系统
- **典型结局**：错过好建仓形态，或在恐惧中勉强入场再次亏损

**连亏应对策略**:
| 连亏笔数 | 应对动作 |
|:--------:|----------|
| 2笔 | 缩小仓位至50% |
| 3笔 | 停止交易当日 |
| 5笔+ | 停止交易一周，完整复盘 |

**核心原则**:
> "连胜是概率的正常波动，不是能力的证明；连亏是概率的正常波动，不是系统的失败"
```

**时间框架对比**（原文V3_B05 P205）:

| 头寸规模增大 | 保持5分钟图 | 避免滑移价差 |

> "只选一个时间框架，根据你面前的价格行为进行交易。如果你能够正确读图，并且认真交易，那么即便不知道其他图表上正在发生什么，也能够做得很好。" (V3_B05 P207)

### 修改 7: 扩展 Step 1.5 — 90棒均线替代法

**位置**: Step 1.5 逐bar评估  
**原文来源**: V3_B05 P206  
**扩展内容** (~25行):

```markdown
**90棒均线替代法**（原文V3_B05 P206）:

**用途**: 在1分钟图上模拟5分钟20棒EMA，用于精细入场时机

**原理**:
- 1分钟图上使用90棒EMA ≈ 5分钟图上20棒EMA
- 为什么是90棒而不是100棒？因为1分钟图上的均线在每条1分钟棒收盘后都要重新计算，而不是在每5棒收盘后重新计算，最新棒线的权重会使得100棒均线有点太过平坦

**应用场景**:
1. **逃逸型趋势中入场**: 5分钟图处于强趋势但已远离EMA，观察1分钟图寻找High 1/High 2回撤顺势入场
2. **股票趋势运动**: 股票做强趋势运动时，利用1分钟图均线处的High 1/High 2架构顺势交易，降低风险

**操作方法**:
- 在1分钟图上绘制90棒EMA
- 等待价格触及或刺穿该均线
- 寻找反转信号(High 1/High 2)
- 在信号棒外1 tick入场
```

### 修改 8: 新增时间框架冲突处理规则

**位置**: Step 1.11 之后  
**原文来源**: V3_B05 P207  
**新增内容** (~20行):

```markdown
**时间框架冲突处理规则**（原文V3_B05 P207）:

**冲突场景**:
- 日线图看跌，60分钟图看涨，5分钟图看跌 → 同时存在
- 等待所有时间框架同一方向是浪费时间（很少发生）

**处理原则**:
1. **只选一个时间框架，根据面前的价格行为交易**
2. **以交易时间框架为准**，不因其他时间框架矛盾而改变决策
3. **HTF用于方向偏向**，LTF用于入场时机

**冲突决策矩阵**:
| HTF方向 | LTF方向 | 交易策略 |
|:-------:|:-------:|----------|
| 多头 | 多头 | 积极做多 |
| 多头 | 空头 | 仅做刮头皮做空，主要等待做多机会 |
| 空头 | 多头 | 仅做刮头皮做多，主要等待做空机会 |
| 空头 | 空头 | 积极做空 |
| 区间 | 任意 | 区间交易，低买高卖 |

> "试图协调所有这些信息会把人搞糊涂，等待所有时间框架处于同一方向是浪费时间，因为那种情况很少发生，而且即便都处于同一方向，也不保证交易获利。" (V3_B05 P207)
```
