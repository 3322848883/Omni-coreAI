# 加密货币止损规则来源分析

> 2026-06-04 审计发现：SKILL.md Pitfall 3 中的"品种最小止损"规则（BTC≥$100, ETH≥$5, SOL≥$0.50）**没有 Al Brooks 原文支撑**，已删除硬编码规则，改为基于原文 SA-04/SA-05 的动态校验。

## 问题来源

### Al Brooks 原文规则

| 规则 | 内容 | 来源 |
|------|------|------|
| SA-04 | 止损距离 < 1 tick → 不交易 | Theme7 Ch24 |
| SA-05 | 止损距离 > 日均波幅 × 20% → 减仓或放弃 | Theme7 Ch24 |

### 加密货币"典型止损距离"（统计参考值）

**位置**: instrument_crypto_specifics.md §5.1

| 品种 | 典型止损距离 | 日均ATR参考 |
|------|------------|-----------|
| BTC | $100-200 | $150-300 |
| ETH | $5-10 | $8-15 |
| SOL | $0.50-1.00 | $0.80-1.50 |

**性质**: 统计参考值，用于评估价格结构止损是否合理

**原文说明**: "以下数值为5分钟图的统计参考值，实际止损应基于价格结构（信号K线另一端、前高/前低之外）"

### 问题本质

```
传统市场: SA-04 = 止损 < 1 tick → 不交易
加密货币: SA-04 = 止损 < $100 (BTC) / $5 (ETH) / $0.50 (SOL) → 不交易
                     ↑
                     这个替换没有明确的推导过程，已删除
```

## 修复方案（已实施）

### 删除硬编码，改为动态校验

**当前规则**（基于原文）：
1. SA-04：止损 ≥ 1 tick → 否则拒绝
2. SA-05：止损 ≤ 日均波幅 × 20% → 否则减仓或放弃
3. 合理性检查：参考 `instrument_crypto_specifics.md §5.1` 的典型止损距离
4. 波动率调整：高波动（>1.5x）→ 放宽 1.5 倍，仓位 ×50%

**优势**：
- 基于 Al Brooks 原文规则
- 动态调整，适应不同波动环境
- 保留合理性检查作为参考，而非硬性限制
