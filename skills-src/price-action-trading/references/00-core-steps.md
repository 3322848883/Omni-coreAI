## 26 主干步骤定义

每次分析必须走完全部 26 个主干 Steps，不可跳过：

```
阶段零: Step 0 → 0.5 → 0.9
```

编号口径（全文只用这两个数）：

- **26** = 主干步骤（本文，每轮必走）
- **53** = `workflow_*.md` 里 `### 步骤` 的细粒度步骤数（需要展开时按需 `skill_ref`）

即使判定「不交易」，Step 4.0/4.1/4.2 也必须给出条件性方案，并把条件写进 chip 的 `scenarios`。
