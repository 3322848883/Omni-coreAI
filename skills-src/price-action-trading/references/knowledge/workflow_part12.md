#### 入场后止损调整逻辑（原文：V2_B09 第29章）
- [ ] 如果 入场棒收盘为强趋势棒（与交易方向一致） → 则 将止损移至入场棒另一端外1个跳动
- [ ] 如果 入场棒收盘为十字星 → 则 不调紧止损；允许1-2个跳动回撤；保持初始止损直到市场向你的方向运动7个跳动
- [ ] 如果 入场棒为外包棒（与交易方向一致） → 则 止损移至外包棒另一端外1个跳动
- [ ] 如果 入场棒为内包棒 → 则 保持信号棒止损；内包棒是单棒交易区间，不要被止损踢出
- [ ] 如果 风险太高（信号棒太长） → 则 使用资金管理止损（信号棒高度的60%）或减小头寸
- [ ] 如果 市场向你的方向运动约利润目标的一半 → 则 把止损移至盈亏平衡点
→ 深度知识：[Theme7](theme7_management_part1.md)、原文V2_B09

### 步骤 5.2 追踪止损
→ [Theme7](theme7_management_part1.md) Ch29

#### 多头市场多头追踪止损规则
- [ ] 每次创新高后，将止损移到最近波段低点下方1 tick
- [ ] 如果形成双底，止损移到双底下方1 tick
- [ ] 如果价格到达通道上轨并反转，考虑全部获利
- [ ] 如果回撤到EMA20以下，收紧止损
- [ ] 许多交易者在达到约一半获利目标后将止损移至保本
- [ ] 如果交易达到2倍初始风险距离，退出约一半仓位

#### 空头市场空头追踪止损规则
- [ ] 每次创新低后，将止损移到最近波段高点上方1 tick
- [ ] 如果形成双顶，止损移到双顶上方1 tick
- [ ] 如果价格到达通道下轨并反弹，考虑全部获利
- [ ] 如果反弹到EMA20以上，收紧止损
- [ ] 如果交易达到2倍初始风险距离，退出约一半仓位

#### 追踪止损的判断方法
- [ ] 想象自己是空仓，考虑是否值得以当前价格和止损建仓
- [ ] 如果不愿意 → 当前持仓的方程是弱的或负的 → 退出
- [ ] 如果愿意 → 保持仓位

#### 追踪止损条件逻辑（原文：V2_B09 第29章）
- [ ] 如果 市场创出新的波段高点（多头） → 则 将止损跟踪调整至最近的波段低点下方1个跳动
- [ ] 如果 市场创出新的波段低点（空头） → 则 将止损跟踪调整至最近的波段高点上方1个跳动
- [ ] 如果 出现买进/卖出高潮（大型趋势棒后反转） → 则 预期市场进入交易区间；在止损被击中前退出头寸
- [ ] 如果 市场看起来将要进入交易区间 → 则 部分获利了结；切换到刮头皮模式；先前波段低点止损不再合乎逻辑
- [ ] 如果 市场到达利润目标的一半 → 则 将止损移至不次于盈亏平衡的位置
→ 深度知识：[Theme7](theme7_management_part1.md)、原文V2_B09

### 步骤 5.3 仓位缩放
→ [Theme7](theme7_management_part1.md) Ch31

#### 加仓（Scaling In）

- [ ] **适合加仓的情况**：
  - [ ] 强趋势 + 回撤到关键支撑/阻力
  - [ ] 在多头通道中每个回撤加仓多头
  - [ ] 在空头通道中每个反弹加仓空头
  - [ ] 加仓后重新计算平均止损
- [ ] **加仓的前提**：
  - [ ] 相信市场很快会朝有利方向转向
  - [ ] 永远不要对亏损仓位加仓，除非对大局有信心
  - [ ] 最好的情况是强趋势中加仓不断增长的回撤
- [ ] **逆势加仓的规则**：
  - [ ] 如果市场对你做了第二次反向走势 → 退出
  - [ ] 在交易日最后一小时左右逆势加仓是有风险的
  - [ ] 初学者不应加仓

#### 减仓（Scaling Out）

- [ ] **标准减仓方法**：
  - [ ] 第一目标到达：平1/3到1/2仓位
  - [ ] 第二目标到达：再平1/3仓位
  - [ ] 剩余仓位：使用追踪止损让利润运行
- [ ] **固定间隔减仓**：
  - [ ] 在初始风险的2倍处退出部分
  - [ ] 在3倍处再退出部分
- [ ] **基于价格行为的减仓**：
  - [ ] 在测量移动目标处
  - [ ] 在前期摆动高点/低点处
  - [ ] 在趋势线和通道线穿越反转处

### 步骤 5.4 失败处理
→ [Theme4](theme4_breakouts_part1.md) Ch5 + Theme5 Ch9

#### 止损触发后
- [ ] 立即确认止损成交
- [ ] 不要立即反向交易（情绪化决策）
- [ ] 分析失败原因：
  - [ ] 是市场状态判断错误？
  - [ ] 是建仓形态识别错误？
  - [ ] 是信号K线质量不够？
  - [ ] 是止损太紧？
- [ ] 等待下一个清晰的建仓形态

#### 失败突破的处理
- [ ] 突破失败是否创造逆势建仓形态？
- [ ] 是否有"失败之失败"机会？
- [ ] 双方是否都被困？（高概率建仓形态）
- [ ] 失败突破后通常至少有两腿反向移动

#### 一tick失败突破
- [ ] 市场突破信号K线一个tick后反转
- [ ] 被套的交易者被迫以亏损退出
- [ ] 反向移动通常足够大，至少可以进行刮头皮
- [ ] 在被套交易者放置止损的位置入场

#### 五tick/九tick失败（Emini）
- [ ] 市场触及利润目标但没有穿过（5或9个跳动）
- [ ] 在延长的趋势终点，5或9跳动的失败突破很常见，常常成为反转的第一个征兆
- [ ] 这是动量丧失的信号
- [ ] 考虑将止损移至保本
- [ ] 考虑在当前K线收盘后反方向入场

#### 不同品种的失败突破特征
- [ ] **Emini**：1 tick/5 tick/9 tick失败最常见
- [ ] **股票**：1-10美分失败（视股票价格和个性而定）
- [ ] **加密货币**：波动率大，失败突破幅度更大，需根据ATR调整判断标准

#### 失败的模式
- [ ] 失败的High 2 → 通常至少还有两腿修正
- [ ] 失败的楔形 → 趋势恢复，运行约楔形高度的测量移动
- [ ] 失败的最终旗形 → 趋势延续信号
- [ ] 失败的双底多头旗 → 两腿向下移动
- [ ] 失败的头肩 → 顺势建仓形态

#### 关键原则
- [ ] 失败是正常的，不代表交易系统有问题
- [ ] 失败的失败（Failed Failure）是二次入场，有优秀的成功机会
- [ ] 在被套者止损处入场
- [ ] 不要在没有趋势线突破的情况下逆势交易
- [ ] 在强趋势日只做顺势交易

#### 连续亏损后的纪律（来源：theme16_price_action_basics.md）

> "初学交易者常在连续亏损后进行赌博式交易。"
> "当面对亏损时，交易者们会去承担更高的风险而不是更低的风险，常常招致破产。"
> "输后加倍技术在理论上非常棒，但因为数学与情绪之间的冲突，它并不实用。"

**连续亏损应对规则**：

| 连续亏损次数 | 心理状态 | 正确行动 | 禁止行为 |
|:-----------:|---------|---------|---------|
| 1-2次 | 轻微挫折 | 正常交易，遵守规则 | 不要急于翻本 |
| 3次 | 沮丧开始 | 降低仓位50% | ❌ 禁止加仓 |
| 4次 | 明显沮丧 | 暂停交易，休息15-30分钟 | ❌ 禁止输后加倍 |
| 5次+ | 情绪失控风险 | 停止当日交易 | ❌ 禁止赌博式交易 |

**输后加倍陷阱**：

- [ ] **理论上的吸引力**：
  - [ ] "只要赢一次就能翻本"
  - [ ] "数学上期望值为正"
  
- [ ] **现实中的问题**：
  - [ ] 情绪影响执行质量
  - [ ] 资金限制无法无限加倍
  - [ ] 连续亏损5-6次的概率比想象的高
  - [ ] 一次爆仓=永久出局

**破产风险警示**：

> "当面对亏损时，交易者们会去承担更高的风险而不是更低的风险，常常招致破产。"

- [ ] **破产路径识别**：
  - [ ] 连续亏损后加大仓位
  - [ ] 放弃止损规则
  - [ ] 做没有计划的交易
  - [ ] 情绪驱动决策
  
- [ ] **避免破产措施**：
  - [ ] 预设日亏损上限（账户的3-5%）
  - [ ] 达到上限立即停止交易
  - [ ] 连续亏损后强制休息
  - [ ] 定期回顾交易纪律执行情况

**连胜连亏心理管理深化**（原文Theme9 Ch6）:

**连胜3笔以上的风险**:
- 过度自信：开始觉得"看透了市场"
- 放宽标准：开始交易低质量建仓形态
- 加大仓位：觉得自己处于"状态中"
- 忽视风险：觉得"这次不一样"
- **典型结局**：一次大亏抹平所有盈利

**连胜应对策略**:
| 连胜笔数 | 应对动作 |
|:--------:|----------|
| 3笔 | 主动缩小仓位至50%作为"保护" |
| 5笔 | 强制休息15分钟，回顾规则 |
| 7笔+ | 当日停止交易，深度复盘 |

**连亏3笔以上的风险**:
- 自我怀疑：开始怀疑交易系统
- 恐惧入场：看到好建仓形态也不敢入场
- 过度分析：在入场前增加越来越多条件
- 改变规则：试图"修复"本不需要修复的系统
- **典型结局**：错过好建仓形态，或在恐惧中勉强入场再次亏损

**连亏应对策略**:
| 连亏笔数 | 应对动作 |
|:--------:|----------|
| 2笔 | 缩小仓位至50% |
| 3笔 | 停止交易当日 |
| 5笔+ | 停止交易一周，完整复盘 |

**核心原则**:
> "连胜是概率的正常波动，不是能力的证明；连亏是概率的正常波动，不是系统的失败"

**失败嵌套场景处理矩阵**:

| 失败层级 | 场景描述 | 识别特征 | 处理策略 |
|----------|----------|----------|----------|
| **第一层: 入场失败** | 入场后未按预期运行 | 入场K线收盘不利、下一棒反向 | 立即评估是否提前离场 |
| **第二层: 止损失败** | 止损后价格反转 | 止损触发后形成反向信号 | 记录为"好止损"，等待再入场 |
| **第三层: 反转失败** | 反转信号失败 | 反转形态后延续原趋势 | 确认强趋势，顺势追单 |
| **第四层: 突破失败** | 突破后假突破 | 突破关键位后迅速回撤 | 反向交易，目标原区间 |
| **第五层: 多重嵌套** | 连续多层失败 | 多次信号失效，市场混乱 | 停止交易，等待清晰结构 |

**失败之失败处理** (Failed Failure):

1. **定义**: 失败信号本身又失败，形成"双重失败"
2. **示例**: 
   - 突破失败 → 反向入场 → 反向也失败 → 原趋势极强
3. **策略**: 
   - 第一次失败: 反向交易
   - 第二次失败(失败之失败): 确认原趋势极强，顺势追单

**被套交易恢复流程**:

1. **立即评估**:
   - 是否触及止损? → 执行止损
   - 是否仍在风险范围内? → 评估持有
   - 是否形成反转信号? → 考虑加仓摊平

2. **心理恢复** (触发冷却期):
   | 亏损程度 | 冷却期 | 恢复动作 |
   |----------|--------|----------|
   | 小幅(<0.5R) | 5-10分钟 | 深呼吸，回顾规则 |
   | 中等(0.5-1R) | 15-30分钟 | 离开屏幕，记录日志 |
   | 较大(1-2R) | 30-60分钟 | 完整复盘后再交易 |
   | 大额(>2R) | 当日停止 | 深度复盘，调整心态 |

3. **再入场条件**:
   - 情绪恢复平静
   - 市场结构清晰
   - 符合所有入场条件
   - 仓位可能降低

**原文引用**:
> "大部分交易日，交易者在抓住一个成功波段之前不得不选择一个以上的反转" (V3_B06 P253)

> "对于那些胜率相对较低的交易，小幅利润或小幅亏损产生非常棒的交易者方程" (V3_B06 P253)
