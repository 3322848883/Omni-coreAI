#### 月度分析决策逻辑（原文：V3_B09 第25章 指引64-77）
- [ ] 如果 上个月盈利 → 则 继续当前策略；可以考虑逐步增加头寸规模（指引77：每天两点即可）
- [ ] 如果 上个月亏损 → 则 执行月度亏损后规则：
  - [ ] 不做任何反转交易
  - [ ] 只做顺势交易（10棒中7棒在均线上方→只买进；10棒中7棒在均线下方→只做空）
  - [ ] 减小头寸规模
  - [ ] 回顾每日图表，找出亏损根因
- [ ] 如果 连续两个月亏损 → 则 大幅减小头寸规模；只做最简单的顺势回撤交易
- [ ] 如果 发现交易时持续紧张 → 则 交易风格可能不适合自己（指引64），需要重新评估
- [ ] 如果 发现某类架构持续亏损 → 则 从交易计划中移除该架构

### 步骤 6.4 自我升级引擎

> 核心：构建个人交易知识库，实现交易能力的持续自我升级
> 关键：基于数据验证，而非主观感觉

---

#### 经验验证状态流转

```
新观察/假设 → 待验证 → 验证中（≥20次样本） → 已验证/已证伪
     ↑                                              ↓
     └──────────── 持续迭代 ←←←←←←←←←←←←←←←←←←←←←┘
```

- [ ] **待验证**：新观察或假设，等待首次应用
- [ ] **验证中**：已应用但样本不足（<20次），持续追踪
- [ ] **已验证**：≥20次样本，统计显著有效，纳入交易规则
- [ ] **已证伪**：≥20次样本，统计显著无效，标记避免使用

---

#### 经验应用优先级

| 优先级 | 经验类型 | 应用规则 | 样本要求 |
|--------|----------|----------|----------|
| **P0** | Al Brooks核心原则 | 始终遵循，除非有强反证 | 经典理论 |
| **P1** | 个人已验证规则 | 严格执行，作为交易基础 | ≥20次验证 |
| **P2** | 验证中规则 | 谨慎应用，持续评估 | 10-19次样本 |
| **P3** | 待验证假设 | 小仓位测试，记录结果 | <10次样本 |
| **P4** | 观察笔记 | 参考但不作为决策依据 | 单次观察 |

#### 自我升级触发条件

| 触发条件 | 自动执行动作 | 输出 |
|----------|--------------|------|
| 连续3笔亏损 | 检索相关记忆 + 知识库对照 | 根因分析报告 |
| 单笔大亏（>2R） | 深度复盘 + 规则检查 | 改进建议 |
| 连续5笔盈利 | 提取成功模式 + 验证假设 | 经验提炼报告 |
| 周胜率<40% | 全面审查 + 策略评估 | 策略调整建议 |
| 月胜率>65% | 模式识别 + 规模评估 | 升级建议 |
| 新市场状态首次遇到 | 知识库检索 + 案例匹配 | 应对策略 |
| 记忆库新增条目 | 关联分析 + 冲突检测 | 知识整合报告 |

  - [ ] 目标位平仓 → 记录为"盈利交易"，评估是否继续同向交易

- [ ] **平仓后市场环境扫描**：
  - [ ] 市场是否仍在趋势中？
  - [ ] 是否有新的设置正在形成？
  - [ ] Always In方向是否改变？
- [ ] **情绪状态检查**：
  - [ ] 是否有报复性交易冲动？
  - [ ] 是否有过度自信或沮丧情绪？
  - [ ] 当前心理状态是否适合立即再入场？

#### 即时决策分支
```
平仓后
│
├── 亏损平仓
│   ├── 连续2笔亏损？→ 强制冷却期（步骤7.2）
│   ├── 单笔大亏（>2R）？→ 强制冷却期 + 深度复盘
│   └── 正常亏损 → 短暂停顿后评估再入场
│
├── 盈利平仓
│   ├── 趋势仍在继续？→ 寻找同向再入场机会
│   ├── 趋势可能反转？→ 等待确认或反向评估
│   └── 到达关键磁铁？→ 观望或反向评估
│
└── 手动平仓
    └── 评估平仓合理性 → 决定下一步行动
```

### 步骤 7.2 冷却期判断

#### 强制冷却期触发条件
- [ ] 连续2笔或更多亏损交易
- [ ] 单笔亏损超过2倍初始风险（>2R）
- [ ] 情绪化交易后（愤怒、恐惧、贪婪明显）
- [ ] 违反交易规则后
- [ ] 日亏损达到预设上限（如账户的5%）

#### 冷却期时长规则

| 触发条件 | 冷却期时长 | 冷却期活动 |
|----------|------------|------------|
| 连续2笔亏损 | 15-30分钟 | 记录交易、简要复盘、深呼吸 |
| 连续3笔亏损 | 30-60分钟 | 完整复盘前3笔、检查交易计划 |
| 单笔大亏（>2R） | 1-2小时 | 深度复盘、情绪恢复、可能停止当日交易 |
| 情绪化交易 | 至少30分钟 | 情绪管理练习、重新阅读交易规则 |
| 日亏损达上限 | 当日停止 | 完整日终复盘、明日计划准备 |

#### 冷却期检查清单
- [ ] 情绪是否恢复平静？
- [ ] 是否已记录和分析导致亏损的交易？
- [ ] 是否回顾了相关交易规则？
- [ ] 是否重新评估了市场状态？
- [ ] 是否准备好遵守纪律再次交易？

---

### 步骤 7.3 再决策分支

#### 分支A：同向再入场

**适用条件**：
- [ ] 趋势仍在继续（Always In方向未变）
- [ ] 出现新的顺势设置（High 2 / Low 2等）
- [ ] 信号K线通过步骤3.6评估体系确认（强/中强度）
- [ ] 交易者方程式仍为正

**执行步骤**：
- [ ] 重新评估市场状态（回到阶段一）
- [ ] 识别新的交易设置（阶段三）
- [ ] 确认多理由支持（至少2个）
- [ ] 计算新的止损和目标
- [ ] 执行入场（阶段四）

#### 分支B：反向交易评估

**适用条件**：
- [ ] 出现趋势线突破
- [ ] 测试旧极端 + 强反转K线
- [ ] 楔形/高潮等反转形态
- [ ] 至少3个理由支持逆势（必须包含趋势线突破）

**执行步骤**：
- [ ] 确认反转条件满足（附录C决策树）
- [ ] 评估反转设置质量
- [ ] 确认信号K线通过步骤3.6评估体系确认（逆势交易需满足13条逆势规则）
- [ ] 计算风险回报比（逆势交易需要更高回报）
- [ ] 减少仓位（逆势交易风险更高）

#### 分支C：观望等待

**适用条件**：
- [ ] 市场状态不明确
- [ ] 处于区间中部
- [ ] 形成铁丝网或紧密区间
- [ ] 情绪状态不适合交易

**执行步骤**：
- [ ] 继续观察市场演变
- [ ] 等待价格到达极端位置
- [ ] 等待明确的突破信号
- [ ] 利用等待时间进行复盘学习

### 步骤 7.4 闭环确认

#### 再入场前最终检查
- [ ] **市场状态重新确认**：
  - [ ] 趋势/区间判断是否与平仓前一致？
  - [ ] Always In方向是否改变？
  - [ ] 关键磁铁位置是否变化？
- [ ] **个人状态检查**：
  - [ ] 情绪是否稳定？
  - [ ] 是否已从上笔交易中学习？
  - [ ] 是否准备好遵守规则？
- [ ] **交易计划确认**：
  - [ ] 新交易的理由是否充分（≥2个）？
  - [ ] 信号K线是否通过步骤3.6评估体系确认？
  - [ ] 止损和目标是否合理？
  - [ ] 风险是否在承受范围内（≤账户1-2%）？

#### 闭环记录要求
- [ ] 记录平仓到再决策的时间间隔
- [ ] 记录冷却期是否执行及执行效果
- [ ] 记录再决策分支选择（A/B/C）及理由
