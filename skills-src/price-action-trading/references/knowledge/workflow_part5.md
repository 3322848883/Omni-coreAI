**通道强度10条规则**（原文V1_B05 P228）：

1. 斜率越大、通道线越接近，通道越强，动能越大
2. 当通道陡峭而紧凑时，称为紧凑通道（Tight Channel）
3. 当通道很强时，在第一个突破处做逆势交易是非常冒险的
4. 如果陡峭空头通道内大多数回撤只是单棒回撤，最好不要在前一棒上方突破时买进
5. 如果没有回撤，市场快速上涨，继续上涨的几率较高，等待约5棒内的回撤
6. 如果反弹超越均线且第一次回撤保持在均线之上，多头交易获利几率较高
7. 通道位置影响成功率：通道下半部分买入成功率高于上半部分
8. 通道突破后通常至少有两腿反向移动
9. 当通道处于交易区间下半部分时，交易者可以考虑买进
10. 交易者应该准备在通道底部附近买进

#### 1.5.1 决斗线（Dueling Lines）定义与交易规则

> 来源：V2_B05_P201-250.md P224-227

**概念定义**：

| 中文 | English | 定义 |
|------|---------|------|
| 决斗线 | Duel Line | 短期趋势（回撤）在长期趋势的支撑/阻力位结束的形态 |
| 趋势通道线 | Trend Channel Line | 与趋势线平行的通道边界线 |
| 趋势线 | Trend Line | 连接波段低点（多头趋势）或波段高点（空头趋势）的线 |

**核心规则**：

| # | 规则原文 | 交易应用 |
|---|---------|---------|
| 1 | 当一波回撤受到趋势通道线限制，而且在更高时间框架的支撑线或阻力线停止时，便形成一个决斗线形态 | 识别决斗线形态 |
| 2 | 所有回撤都结束于决斗线形态 | 所有回撤都是决斗线 |
| 3 | 多头趋势中的回撤总是在支撑位结束 | 寻找支撑线 |
| 4 | 空头趋势中的回撤总是在阻力位结束 | 寻找阻力线 |
| 5 | 最可靠的形式：当回撤出现在通道内，而且拥有一个楔形的外形或三推时 | 高可靠性形态 |
| 6 | 回撤结束的信号棒是刺穿趋势线并反转的那一棒 | 确认信号棒 |
| 7 | 支撑线可能是一条水平线（经过先前的波段低点），也可能表现为均线的形式 | 支撑形式多样 |

**决斗线形态识别**：

```
多头趋势中的决斗线：
    价格
     ↑    ↗ 趋势通道线（阻力）
     │   /  
     │  /   ↘ 回撤（小型空头趋势）
     │ /      ↘
     │/    决斗点 ← 两条线交叉处
     └──────────→ 时间
        趋势线（支撑）

空头趋势中的决斗线（镜像）：
    价格
     │    ↘ 趋势通道线（支撑）
     │     \
     │      ↗ 回撤（小型多头趋势）
     │     /
     │ 决斗点 ← 两条线交叉处
     └──────────→ 时间
        趋势线（阻力）
```

**交易规则**：

1. **识别阶段**：
   - 观察回撤是否出现在通道内
   - 检查回撤是否有楔形外形或三推结构
   - 确认回撤是否同时测试趋势通道线和趋势线/支撑/阻力

2. **入场时机**：
   - 等待回撤刺穿趋势线并反转的信号棒收盘
   - 如果上涨/下跌比较陡峭，等待更高低点/更低高点处的二次入场
   - 在信号棒高点/低点上方/下方1个跳动处使用止损单入场

3. **止损设置**：
   - 设在信号棒低点/高点另一侧1个跳动处
   - 或设在决斗线形态极值另一侧

4. **目标位置**：
   - 通道另一侧（趋势通道线）
   - 测量运动目标
   - 前一波段高点/低点

**重要原则**：

> "当一波回撤受到趋势通道线限制，而且在更高时间框架的支撑线或阻力线停止时，便形成一个决斗线形态，结果常常形成较大趋势方向上的一笔可靠交易。它是一段短期趋势（一波回撤），在长期趋势的支撑位（在多头趋势中）或阻力位（在空头趋势中）结束。"（V2_B05 P224）

> "尽管长期支撑不容易看到，但所有回撤都结束于决斗线形态。回撤是一段小型趋势，它的方向与较大趋势的方向相反。所有回撤都是因某个理由结束的，多头回撤总是结束于某个较长期的支撑，比如趋势线、测量运动、或先前的某个波段高点或低点。"（V2_B05 P224）

**90棒均线替代法**（原文V3_B05 P206）:

**用途**: 在1分钟图上模拟5分钟20棒EMA，用于精细入场时机

**原理**:
- 1分钟图上使用90棒EMA ≈ 5分钟图上20棒EMA
- 为什么是90棒而不是100棒？因为1分钟图上的均线在每条1分钟棒收盘后都要重新计算，而不是在每5棒收盘后重新计算，最新棒线的权重会使得100棒均线有点太过平坦

**应用场景**:
1. **逃逸型趋势中入场**: 5分钟图处于强趋势但已远离EMA，观察1分钟图寻找High 1/High 2回撤顺势入场
2. **股票趋势运动**: 股票做强趋势运动时，利用1分钟图均线处的High 1/High 2架构顺势交易，降低风险

**操作方法**:
- 在1分钟图上绘制90棒EMA
- 等待价格触及或刺穿该均线
- 寻找反转信号(High 1/High 2)
- 在信号棒外1 tick入场

**微型趋势线回撤规则**:

1. **微型趋势线定义**: 利用2-3条连续棒线构造的陡峭趋势线
2. **失败突破入场**: 微型通道突破后立即反转 → 顺势入场架构
3. **时间框架规则**: 5分钟图上的微型趋势线失败突破，无需观察1分钟图
4. **重要性阈值**: 持续约1小时的趋势线比较重要

**2HM规则** (远离EMA两小时):
> "如果价格远离EMA两小时或更久，则淡化EMA和第一EMA缺口K线" (Theme13 Ch4)

- **触发条件**: 价格持续在EMA一侧运行≥2小时
- **规则**: 不追EMA回撤入场，等待更大幅度回撤或反转信号
- **原因**: 极度延伸后，首次EMA回撤往往失败

**回撤深度评估表**:

| 回撤深度 | 特征 | 交易策略 |
|----------|------|----------|
| 浅回撤(<38.2%) | 1-3根棒，强势趋势 | 激进顺势入场 |
| 正常回撤(38.2%-50%) | 3-5根棒，标准结构 | 标准顺势入场 |
| 深回撤(50%-61.8%) | 5+根棒，趋势减弱 | 谨慎入场，收紧止损 |
| 过度回撤(>61.8%) | 可能反转 | 等待反转确认或观望 |

### 步骤 1.8 开盘区间专项

**日内时间分段概率**（原文Theme11 Ch10）:

| 时间段 | 机会特征 | 概率特征 | 交易策略 |
|--------|----------|----------|----------|
| **开盘第一小时** | 波段最大，机会最多 | 90%有盈利摆动交易 | 最佳交易时段 |

| **收盘前30-60分钟** | 风险管理者平仓 | 强趋势日方向加速 | 顺势交易 |
| **最后三分之一时段** | 趋势恢复或反转 | 取决于日线趋势 | 谨慎交易 |

**关键时间节点**:
- **Bar 7**: 约1小时，90% HOD/LOD在此时段内形成
- **Bar 12**: 10:30 EST，70% HOD/LOD已形成
- **11:00-11:30**: 警惕止损扫荡
- **收盘前30-60分钟**: 日线强趋势收盘规则生效

### 步骤 1.11 时间框架选择决策矩阵
→ 完整规则见 docs/pa-source/V3_反转/V3_B05_P201-250.md P205-207

**时间框架对比**（原文V3_B05 P205）:

| 时间框架 | 每日入场机会 | 止损大小 | 胜率 | 适用风格 |
|----------|:------------:|:--------:|:----:|----------|
| **5分钟图** | ~10+个 | 8跳动 | 最高 | 刮头皮+波段 |
| **3分钟图** | ~20个 | 6跳动 | 较低 | 刮头皮 |
| **1分钟图** | ~30个 | 4跳动 | 最低 | 高级刮头皮 |
| **15分钟图** | 较少 | 较大 | 高 | 波段 |

**时间框架选择原则**:
1. **时间框架越小，错过的好交易越多，胜率越低**
2. **专注于5分钟图上的最佳交易，努力增加头寸规模**
3. **最佳交易的形成和触发非常迅速，容易错过**
4. **几乎每个较高时间框架波段都从1分钟和3分钟图上的反转开始**

**时间框架切换规则**:
| 场景 | 切换动作 | 原因 |
|------|----------|------|
| 错过太多交易 | 切换到较慢时间框架(15分钟) | 读图速度不足 |
| 止损太大 | 考虑切换到更快时间框架(3分钟) | 降低单笔风险 |
| 胜率下降 | 切换到较慢时间框架(5分钟/15分钟) | 提高胜率 |
| 头寸规模增大 | 保持5分钟图 | 避免滑移价差 |

> "只选一个时间框架，根据你面前的价格行为进行交易。如果你能够正确读图，并且认真交易，那么即便不知道其他图表上正在发生什么，也能够做得很好。" (V3_B05 P207)

**时间框架冲突处理规则**（原文V3_B05 P207）:

**冲突场景**:
- 日线图看跌，60分钟图看涨，5分钟图看跌 → 同时存在
- 等待所有时间框架同一方向是浪费时间（很少发生）

**处理原则**:
1. **只选一个时间框架，根据面前的价格行为交易**
2. **以交易时间框架为准**，不因其他时间框架矛盾而改变决策
3. **HTF用于方向偏向**，LTF用于入场时机

**冲突决策矩阵**:
| HTF方向 | LTF方向 | 交易策略 |
|:-------:|:-------:|----------|
| 多头 | 多头 | 积极做多 |
| 多头 | 空头 | 仅做刮头皮做空，主要等待做多机会 |
| 空头 | 多头 | 仅做刮头皮做多，主要等待做空机会 |
| 空头 | 空头 | 积极做空 |
| 区间 | 任意 | 区间交易，低买高卖 |

> "试图协调所有这些信息会把人搞糊涂，等待所有时间框架处于同一方向是浪费时间，因为那种情况很少发生，而且即便都处于同一方向，也不保证交易获利。" (V3_B05 P207)
