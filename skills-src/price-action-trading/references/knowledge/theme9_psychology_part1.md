## 第1章：交易心理概述

### 1.1 为什么70%的交易是心理

Al Brooks在78条交易指南中多次强调："交易80%是心理，只有20%是市场分析。"（第74条）

核心观点：
- 市场分析是客观的——K线、趋势线、信号K线都有明确的规则
- 但执行交易的是人——恐惧、贪婪、希望、后悔都会干扰决策
- 大多数交易者知道正确的做法，但在关键时刻做不到
- **成功的交易者不是预测更准的人，而是纪律更好的人**

### 1.2 Al Brooks关于心理的核心观点

从78条交易指南中提取的心理相关条目：

| 条目编号 | 核心观点 |
|---------|---------|
| 第1条 | 每笔交易只是众多交易中的一笔，不要对任何单笔交易过度在意 |
| 第2条 | 不要试图预测市场，而是对市场行为做出反应 |
| 第3条 | 如果建仓形态看起来完美且容易，通常意味着趋势不强 |
| 第5条 | 趋势做一切事情来阻止交易者入场 |
| 第6条 | 在任何时间点，市场要么在趋势中，要么在区间中 |
| 第7条 | 不要基于新闻交易 |
| 第8条 | 不要报复性交易 |
| 第9条 | 不要反向刮头皮 |
| 第10条 | 不要追逐市场 |
| 第13条 | 大多数交易者亏损是因为他们无法等待好的建仓形态 |
| 第14条 | 最好的交易者是最有耐心的交易者 |
| 第15条 | 市场在大多数时间都在测试交易者的耐心 |
| 第74条 | 交易80%是心理，只有20%是市场分析 |
| 第75条 | 如果你不能遵守规则，就不应该交易 |
| 第76条 | 最好的交易者不是最聪明的人，而是最有纪律的人 |
| 第77条 | 每天打印5分钟图表并在图表上标记每个setup |
| 第78条 | 如果你违反了规则，立即停止交易 |

### 1.3 情绪如何影响决策

| 情绪 | 常见表现 | 后果 |
|------|---------|------|
| 恐惧 | 不敢入场好的建仓形态、过早获利 | 错过盈利机会、利润被截断 |
| 贪婪 | 过度交易、忽视风险、仓位过大 | 单笔大亏抹平多次盈利 |
| 希望 | 持有亏损仓位期待反转 | 小亏变大亏 |
| 后悔 | 错过建仓形态后追逐入场 | FOMO入场，通常亏损 |
| 报复 | 亏损后立即加大仓位翻本 | 连续亏损螺旋 |
| 自满 | 连续盈利后放松纪律 | 一次大亏抹平所有盈利 |

## 第2章：交易前心理准备Routine

### 2.1 五分钟准备流程

每天开盘前执行以下5步心理准备：

**第1步：回顾昨日教训（1分钟）**
- 打开记忆库（决策日志目录），回顾昨日最大错误和今日特别注意事项
- 确认没有带着昨日的情绪进入今天

**第2步：确认今日计划（1分钟）**
- 打开今日交易计划
- 确认已完成的盘前分析
- 确认预期的市场状态和交易场景

**第3步：检查风险参数（1分钟）**
- 确认账户净值
- 确认单笔最大风险
- 确认今日最大亏损上限（账户3%）
- 确认净值曲线管理状态（周亏损、月亏损）

**第4步：心理状态自评（1分钟）**
使用以下量表评估当前心理状态：

| 维度 | 评分(1-10) | 最低要求 |
|------|-----------|---------|
| 专注度 | ___ | ≥7 |
| 信心 | ___ | ≥5 |
| 耐心 | ___ | ≥7 |
| 纪律承诺 | ___ | ≥8 |

如果任何维度低于最低要求，考虑减少交易或只观察不交易。

**第5步：纪律确认（1分钟）**
默念或写下今天的纪律承诺：
- "我只会交易计划中的建仓形态"
- "我不会在铁丝网中交易"
- "我不会报复性交易"
- "每笔交易都会设止损"
- "如果违反规则，立即停止交易"

### 2.2 不适合交易的信号

如果出现以下任何情况，**只观察不交易**：
- 疲劳或睡眠不足
- 情绪激动（无论正面或负面）
- 分心（有其他重要事情待处理）
- 连续亏损后急于翻本
- 连续盈利后过度自信
- 未完成盘前准备
- 净值曲线管理已触发（日/周/月止损线）

## 第3章：交易中情绪管理

### 3.1 入场前的最后确认

在执行每笔交易前，快速检查：
1. 这笔交易在我的计划中吗？
2. 我完成了检查清单吗？
3. 我的情绪状态正常吗？（平静/专注）
4. 我设好止损了吗？
5. 交易者方程式为正吗？

如果任何一项不满足，**不交易**。

### 3.2 持仓中的常见情绪陷阱

#### 浮盈时的陷阱：过早获利（处置效应）
- **表现**：价格向有利方向移动一点就急于平仓
- **原因**：害怕利润消失，"落袋为安"心理
- **应对**：
  - 入场前确定目标位，不到目标不平仓
  - 使用追踪止损保护利润，而不是手动平仓
  - 记住：让利润运行是摆动交易的核心

#### 浮亏时的陷阱：移动止损或拒绝止损（沉没成本）
- **表现**：价格触及止损时移动止损，或取消止损订单
- **原因**：不接受亏损，"再等等也许会回来"
- **应对**：
  - 止损在入场前设定，持仓中绝不修改
  - 如果总是移动止损，说明仓位过大——减小仓位
  - 记住：小亏是交易成本的一部分，大亏才是致命的

#### 错过入场时的陷阱：FOMO追逐
- **表现**：看到好的建仓形态已经启动，追着入场
- **原因**：害怕错过机会，后悔心理
- **应对**：
  - 错过的交易已经过去了，等待下一个建仓形态
  - 市场每天都有机会，不需要抓住每一个
  - 如果FOMO强烈，设置一个"错过计数器"，达3次强制休息30分钟

#### 连续亏损后的陷阱：报复性交易
- **表现**：亏损后立即加大仓位或频繁交易试图翻本
- **原因**：愤怒、不甘心、想证明自己
- **应对**：
  - 连续亏损2笔后，强制缩小仓位至50%
  - 连续亏损3笔后，停止交易当日剩余时间
  - 记住：报复性交易是账户毁灭的最快路径

### 3.3 每笔交易后的10秒复盘

每笔交易平仓后，花10秒钟问自己：
1. 我是否按计划执行了？
2. 如果没有，违反了哪条规则？
3. 我当时的情绪状态是什么？

如果发现违反规则，立即记录到错误日志。

## 第4章：亏损后情绪恢复流程

### 4.1 五步恢复流程

当发生亏损（特别是大亏或连续亏损）时，按以下步骤恢复：

**第1步：立即停止交易（至少30分钟）**
- 关闭交易平台
- 离开电脑屏幕
- 做几次深呼吸

**第2步：分析亏损原因（5分钟）**
问自己：这笔亏损是因为什么？
- **市场原因**：建仓形态正确但市场反转 → 正常交易成本，无需自责
- **个人错误**：违反规则、情绪化交易 → 需要记录和改进
- **运气不好**：低概率事件 → 无法控制，接受它

**第3步：如果是个人错误，记录到错误日志**
- 使用 决策日志 模板
- 明确错误类型、触发条件和预防措施
- 不要模糊地写"下次注意"，要写具体的预防规则

**第4步：等待下一个清晰的建仓形态**
- 不要急于翻本
- 好的建仓形态值得等待
- 如果30分钟后仍感到情绪不稳定，当天不再交易

**第5步：以小仓位重新入场，重建信心**
- 下一笔交易使用正常仓位的50%
- 只交易最高置信度的建仓形态（5星）
- 如果这笔交易盈利，逐步恢复正常仓位
- 如果继续亏损，停止交易当日

### 4.2 恢复时间表

| 亏损程度 | 恢复动作 | 恢复时间 |
|----------|---------|---------|
| 单笔小亏（<1%） | 正常继续 | 无需恢复 |
| 单笔中亏（1-2%） | 下一笔缩小50%仓位 | 下一笔交易 |
| 单笔大亏（>2%） | 停止交易，分析原因 | 至少30分钟 |
| 连续亏损2笔 | 缩小仓位至50% | 当日 |
| 连续亏损3笔 | 停止交易当日 | 次日 |
| 触发日亏损上限（3%） | 停止交易当日 | 次日 |
| 触发周亏损上限（6%） | 降低仓位至50% | 连续两周盈利后 |
| 触发月亏损上限（10%） | 停止交易一周 | 一周后 |

## 第5章：常见认知偏差在交易中的表现

### 5.1 确认偏差（Confirmation Bias）
- **定义**：只看到支持自己观点的信号，忽视反面证据
- **交易中的表现**：做多后只看到牛信号，忽略熊信号
- **应对**：主动寻找反面证据——"如果我要做空，理由是什么？"

### 5.2 锚定效应（Anchoring）
- **定义**：被某个参考价格（如入场价、前高/前低）锚定，无法客观评估
- **交易中的表现**：因为"已经亏了这么多"而拒绝止损，或因为"已经赚了这么多"而急于平仓
- **应对**：始终以当前市场行为为依据，不以入场价为参考

### 5.3 处置效应（Disposition Effect）
- **定义**：倾向于过早卖出盈利、持有亏损
- **交易中的表现**：小利就跑，亏损死扛
- **应对**：使用追踪止损让利润运行，入场前设定止损绝不修改

### 5.4 沉没成本（Sunk Cost）
- **定义**：因为已投入的时间/金钱而拒绝放弃
- **交易中的表现**：在明显错误的交易中继续加仓，因为"已经亏了这么多"
- **应对**：每笔交易都是独立的，过去的亏损不应影响当前决策

### 5.5 近因偏差（Recency Bias）
- **定义**：最近发生的事件对判断的影响过大
- **交易中的表现**：连续盈利后过度自信（放松纪律），连续亏损后过度悲观（不敢入场好的建仓形态）
- **应对**：回顾周度和月度统计，以长期数据为依据

### 5.6 过度自信（Overconfidence）
- **定义**：高估自己的能力和判断的准确性
- **交易中的表现**：连续盈利后加大仓位、放宽入场标准、忽视风险
- **应对**：固定仓位大小，不因近期结果改变规则

### 5.7 可得性偏差（Availability Bias）
- **定义**：容易想起的事件被认为更常见
- **交易中的表现**：最近一次大亏后过度规避类似建仓形态，即使概率仍然有利
- **应对**：以统计数据（周度/月度胜率）为依据，不以单次经历为依据

## 第6章：连胜与连亏的心理影响

### 6.1 连胜3笔以上的风险

连胜是危险的，因为：
- **过度自信**：开始觉得自己"看透了市场"
- **放宽标准**：开始交易低质量的建仓形态
- **加大仓位**：觉得自己处于"状态中"
- **忽视风险**：觉得"这次不一样"

**典型结局**：一次大亏抹平所有盈利，甚至更多。

**应对策略**：
- 固定仓位大小，连胜期间不加大
- 严格执行交易计划，不放宽入场标准
- 连胜3笔后，主动缩小仓位至50%作为"保护"
- 记住：连胜是概率的正常波动，不是能力的证明

### 6.2 连亏3笔以上的风险

连亏是危险的，因为：
- **自我怀疑**：开始怀疑自己的交易系统
- **恐惧入场**：看到好的建仓形态也不敢入场
- **过度分析**：在入场前增加越来越多的条件
- **改变规则**：试图"修复"本不需要修复的系统

**典型结局**：错过好的建仓形态，或者在恐惧中勉强入场再次亏损。

**应对策略**：
- 固定仓位大小，连亏期间不缩小（除非触发净值曲线管理）
- 严格执行交易计划，不增加额外的入场条件
- 连亏3笔后停止交易当日，次日以正常仓位恢复
- 回顾周度统计：连亏在正常概率范围内吗？

### 6.3 连胜/连亏的概率知识

假设胜率50%：
- 连续3笔盈利的概率：12.5%
- 连续3笔亏损的概率：12.5%
- 连续5笔盈利的概率：3.1%
- 连续5笔亏损的概率：3.1%

这意味着在100笔交易中，大约会出现12次3连胜和12次3连亏。**这是正常的概率波动，不代表你的系统有问题。**

## 第7章：情绪追踪方法

### 7.1 交易日志中的情绪字段

在每笔交易日志中记录：
- 入场时情绪：平静 / 轻微焦虑 / FOMO / 恐惧 / 报复心态
- 持仓中情绪变化：平稳 / 焦虑加剧 / 恐惧加剧 / 贪婪加剧
- 是否完成检查清单：是 / 部分 / 否
- 是否违反任何规则：是 / 否

### 7.2 每周情绪模式分析

使用 决策日志 中的"情绪与纪律"部分：
- 本周最佳交易日的情绪状态
- 本周最差交易日的情绪状态
- 是否有违反交易计划的情况
- 是否有报复性交易

### 7.3 情绪与交易绩效的相关性分析

每月进行一次情绪-绩效相关性分析：

| 情绪状态 | 交易次数 | 胜率 | 平均盈亏 | 结论 |
|----------|---------|------|---------|------|
| 平静 | | | | |
| 轻微焦虑 | | | | |
| FOMO | | | | |
| 恐惧 | | | | |
| 报复心态 | | | | |

**预期结论**：平静状态下的胜率和盈亏应该显著优于负面情绪状态。如果数据不支持这一结论，说明情绪管理需要加强。

### 7.4 使用交易记忆库

使用 决策日志 长期追踪：
- 反复出现的错误模式
- 已克服的错误
- 最佳交易模式
- 有效规则自定义
- 市场状态记忆

交易记忆库是连接"每日复盘"和"长期成长"的桥梁——它不是记录每笔交易，而是记录从交易中提炼出的**规律和教训**。

## 第8章：交易心理本土化概念

> 以下概念来自中文价格行为学社区的精华提炼，与Al Brooks心理理念互补。

### 8.1 40-60定律
- 交易中约40%的时间会面临亏损或挫折
- 约60%的时间是等待或平庸状态
- 只有极少数时间（<5%）是高光时刻
- **启示**：接受"亏损是交易的主旋律"，不要期望每笔都赢

### 8.2 对手盘与多解性
- 每笔交易都有对手盘，对方可能比你更有理由
- 市场始终存在多种合理解读（多解性）
- **启示**：保持谦逊，不要对任何一笔交易过度自信

### 8.3 看对做不对
- 看对方向但做不对（入场时机、仓位、止损）是常态
- 交易成功=方向判断+执行管理+心理控制
- **启示**：不要只关注方向判断，执行和心理同样重要

### 8.4 知耻而后勇
- 诚实面对错误是进步的前提
- 记录每笔亏损交易的原因，比记录盈利更有价值
- **启示**：建立错误日志（error_log.md），定期回顾
