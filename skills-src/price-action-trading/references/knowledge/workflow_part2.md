#### HTF决策逻辑（原文：V3_B05 第15章、V3_B04 第11章）
- [ ] 如果 60分钟图处于多头趋势且位于均线上方 → 则 只在5分钟图上寻找买进架构（不做空）
- [ ] 如果 60分钟图处于空头趋势且位于均线下方 → 则 只在5分钟图上寻找做空架构（不做多）
- [ ] 如果 60分钟图处于交易区间（均线水平） → 则 5分钟图上双向交易，低买高卖
- [ ] 如果 日线图为强多头趋势（多头棒数量 > 空头棒数量） → 则 预期收盘高于开盘，最后30-60分钟尝试反弹
- [ ] 如果 日线图为强空头趋势 → 则 预期收盘低于开盘，收盘前常常下跌
- [ ] 如果 昨日最后一个Always In头寸为多头 → 则 开盘前初始偏见为多头，直到出现两条强度合理的空头趋势棒才翻转
- [ ] 如果 盘中出现两条强度合理的同方向趋势棒 → 则 形成新的HTF方向判断

#### 昨日趋势日类型判断（原文：V1_B07 第21-22章、V1_B08 第23章）
- [ ] 如果 昨日大部分棒线在均线同侧，回撤幅度 < 日均区间20-30% → 则 昨日为趋势日，今日延续趋势概率较高
- [ ] 如果 昨日为尖峰和通道趋势日 → 则 今日通道起点是磁石目标，可能被测试
- [ ] 如果 昨日收盘处于交易区间（均线水平，棒线重叠多） → 则 昨日为区间日，今日关注区间突破方向
- [ ] 如果 昨日开盘区间 < 近期日均区间25% → 则 昨日可能是强趋势日（小幅回撤日）
- [ ] 如果 昨日开盘区间 ≈ 近期日均区间33%-50% → 则 昨日可能是趋势型交易区间日
- [ ] 如果 昨日大型缺口开盘 → 则 趋势日概率增加（60%顺缺口方向，40%逆缺口方向）
- [ ] 如果 昨日大部分反转尝试失败 → 则 确认为强趋势日
- [ ] 如果 昨日存在大量双向交易（紧凑区间、大量十字星） → 则 确认为区间日
→ 深度知识：[Theme14](theme14_trend_day_types.md)、原文V1_B07、原文V1_B08

#### 盘前走势决策逻辑（原文：V3_B05 第14章、V3_B07 第20章）
- [ ] 如果 盘前形成明确的高点和低点 → 则 这些极点常常是白天时段的测试目标
- [ ] 如果 盘前走势为趋势运动（连续同方向趋势棒） → 则 白天时段可能延续该趋势（作为尖峰的一部分）
- [ ] 如果 盘前为横盘交易区间 → 则 白天时段关注区间突破方向
- [ ] 如果 开盘缺口为大型缺口（> 近5天最大缺口 或 > 日均区间50%） → 则 假定将出现强趋势日，积极波段化
- [ ] 如果 盘前5:30有报告发布 → 则 等待计算机优势消失后再交易（约1-3小时后）
→ 深度知识：[Theme8](theme8_daytrading_part1.md)、原文V3_B05、原文V3_B07

#### 机构算法交易分析（原文：V3_B06 P261-263）

> 计算机拥有明显的优势，而且它们是你的竞争对手。当你的对手拥有巨大的优势时，不要参与竞争。等待他们的优势消失，当速度不再重要时交易。

**机构行为识别**：
- [ ] **报告后算法交易**：
  - [ ] 报告后数分钟内的交易是由计算机程序主宰的
  - [ ] 很多计算机几乎瞬间便收到了报告的数字版本，并且使用那些数据来产生交易
  - [ ] 最后在入场前等上一两棒，等待计算机优势消失
- [ ] **机构开盘前订单执行**：
  - [ ] 机构交易员有些订单要在一天开盘前执行，他们希望在尽可能好的价位执行
  - [ ] **买入真空**：如果机构感觉较低的开盘代表着不会持续多长时间的很高的价值，那么他们将会立即买进
  - [ ] **卖出真空**：如果机构认为市场将会小幅下跌，那么他们会等着在更低价位买进，这就产生一个卖出真空
- [ ] **真空效应识别**：
  - [ ] 快速下跌至买方愿意入场的价位 = 卖出真空
  - [ ] 快速上涨至卖方愿意出场的价位 = 买入真空
  - [ ] 真空效应结束后常出现快速反转
→ 深度知识：原文V3_B06 P261-263

### 步骤 0.4 分析缺口
→ [Theme4](theme4_breakouts_part1.md) Ch6 + Theme8 Ch20

- [ ] **判断今日开盘是否有缺口**：
  - [ ] 缺口高开（Gap Up）：开盘 > 昨日高点
  - [ ] 缺口低开（Gap Down）：开盘 < 昨日低点
  - [ ] 无缺口：开盘在昨日范围内
- [ ] **评估缺口类型**：
  - [ ] 突破缺口（Breakout Gap）：沿盘前/昨日趋势方向 → 趋势延续信号
  - [ ] 测量缺口（Measuring Gap）：缺口中点可能是趋势中点
  - [ ] 衰竭缺口（Exhaustion Gap）：逆趋势方向 → 可能反转
  - [ ] 普通缺口（Common Gap）：区间内形成
- [ ] **缺口作为磁铁**：
  - [ ] 未填充的缺口会吸引价格回测
  - [ ] 缺口越大，磁力越强
  - [ ] 标记缺口顶部和底部
- [ ] **缺口交易策略预判**：
  - [ ] 如果缺口高开 + 第一根K线是多头趋势K线 → 寻找回调买入
  - [ ] 如果缺口高开 + 第一根K线是反转K线 → 考虑做空
  - [ ] 如果缺口低开 + 第一根K线是空头趋势K线 → 寻找回调卖出
  - [ ] 如果缺口低开 + 第一根K线是反转K线 → 考虑做多
- [ ] **缺口测量移动计算**（如适用）：
  - [ ] 从缺口底部到缺口中点的距离 = ____
  - [ ] 从缺口中点向上/下投影相同距离 = ____
- [ ] **记录缺口分析**：
  - [ ] 缺口类型：____
  - [ ] 缺口大小：____
  - [ ] 缺口交易策略：____

### 步骤 0.5 标记关键时间
→ [Theme8](theme8_daytrading_part1.md) Ch11

- [ ] **标记所有关键时间点**：

| 时间 (PST) | 事件 | 交易策略 |
|------------|------|----------|
| 5:30 a.m. | 经济报告发布 | 不交易（计算机优势太大） |
| 6:30 a.m. | 正式开盘 | 最活跃时段，关注开盘模式 |
| 7:00-7:30 a.m. | 常见反转时间 | 警惕反转信号 |
| 8:30-11:00 a.m. | 中间时段 | 通常为交易区间，减少交易 |
| 11:00-11:30 a.m. | 常见强趋势日逆势恐慌 | 警惕止损扫荡 |
| 12:00 p.m. | 收盘前一小时 | 趋势可能加速，重要交易时段 |
| 1:15 p.m. | 收盘 | 最后几分钟可能有急剧波动 |

- [ ] **关键时间交易规则**：
  - [ ] 开盘第一小时：波段较大，机会最多，但也最容易亏钱
  - [ ] 中间时段：新手应避免在日波幅中部交易
  - [ ] 11:30 a.m. PST：强趋势日可能出现逆势恐慌运动（止损扫荡）
  - [ ] 收盘时段：趋势往往加速，风险管理者的平仓会加剧波动
- [ ] **今日特别关注**：
  - [ ] 今天是否有经济报告发布？
  - [ ] 发布时间：____
  - [ ] 对策：不交易报告期间行情

#### 时段动态决策逻辑（原文：V3_B04 第11章、V2_B04 第15章）
- [ ] 如果 处于第一个三分之一时段（开盘头1-2小时） → 则 最重要时段，积极交易；约90%的当日高低点在此形成
- [ ] 如果 处于中间三分之一时段（PST 8:30-11:30） → 则 精挑细选或避免交易；最常出现紧凑交易区间；止损入场环境可怕
- [ ] 如果 处于最后三分之一时段（PST 11:30至收盘） → 则 准备趋势恢复或反转；机构开始最后交易
- [ ] 如果 PST 7:00/7:30 有经济报告 → 则 等待计算机优势消失后再交易
- [ ] 如果 PST 11:00-11:30 → 则 强趋势日中常出现逆势恐慌运动（止损猎杀），之后趋势恢复
- [ ] 如果 最后30-60分钟 + 日线强多头趋势 → 则 预期收盘靠近当日高点，寻找反弹入场
- [ ] 如果 最后30-60分钟 + 日线强空头趋势 → 则 预期收盘靠近当日低点，避免抄底
→ 深度知识：[Theme8](theme8_daytrading_part1.md)、原文V3_B04、原文V2_B04
