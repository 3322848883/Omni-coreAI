#### 0.7.1 刮头皮vs波段完整决策框架

> 来源：V2_B07_P301-350.md P308-312

**概念定义**：

| 中文术语 | 英文术语 | 定义 |
|----------|----------|------|
| 刮头皮者 | Scalper | 日内交易者，持有头寸1到15分钟左右，通常使用限价单在利润目标离场 |
| 日内波段交易者 | Intraday Swing Trader | 持有头寸经历回撤，努力捕捉一天中的2到4个较大的波段，头寸持有时间从15分钟到一整天 |
| 交易者方程 | Trader's Equation | 胜率 x 回报 vs 败率 x 风险的数学关系 |

**刮头皮交易核心规则**：

| # | 规则原文 | 数学基础 |
|---|---------|---------|
| 1 | 刮头皮者潜在回报与风险规模大致相等 | 回报/风险 ≈ 1:1 |
| 2 | 对于刮头皮交易，如果胜率不能达到60%以上，那么交易者方程就是负的 | 最低胜率要求：60% |
| 3 | 对于1点刮头皮交易，必须有67%以上的交易盈利才能保证不赔 | 1点刮头皮胜率门槛：67% |
| 4 | 两点止损是目前（每日平均区间为10到15点）最可靠的 | 推荐止损：2点 |
| 5 | 利润目标也至少应该是两点 | 推荐目标：≥2点 |
| 6 | 刮头皮交易至少需要70%的成功率，否则是失败的策略 | 成功刮头皮胜率：≥70% |
| 7 | 刮头皮交易利润目标通常为最小波段利润目标的一半，但风险通常相同 | 风险不变，目标减半 |

**波段交易核心规则**：

| # | 规则原文 | 数学基础 |
|---|---------|---------|
| 1 | 日内波段交易者潜在回报通常至少为风险的两倍 | 回报/风险 ≥ 2:1 |
| 2 | 日内波段交易者类似于使用日线图的投资者，愿意持有头寸经历回撤 | 需承受回撤心理 |
| 3 | 大部分波段架构到达利润目标概率40%-50% | 波段胜率：40-60% |
| 4 | 波段交易者需要这些大的赢利，因为波段交易的成功率常常不到50% | 低胜率需高回报补偿 |

**刮头皮vs波段决策框架**：

| 决策因素 | 选择刮头皮 | 选择波段 |
|---------|-----------|---------|
| 市场状态 | 交易区间、无明确趋势 | 明确趋势日 |
| 交易方向 | 逆势交易、双向交易 | 顺势交易 |
| 信号质量 | 信号较弱、不确定性高 | 信号强劲、高确定性 |
| 时间框架 | 1-15分钟持仓 | 15分钟-整天持仓 |
| 胜率要求 | ≥70% | 40-60%即可 |
| 回报/风险 | 约1:1 | ≥2:1 |
| 心理承受 | 不希望持有经历回撤 | 愿意持有经历回撤 |

**关键概率数据**：

| 场景 | 数据 | 来源 |
|------|------|------|
| 刮头皮交易基础胜率要求 | 60% | V2_B07 P309 |
| 1点刮头皮最低胜率要求 | 67%以上 | V2_B07 P310 |
| 刮头皮交易成功胜率 | 至少70% | V2_B07 P311 |
| 波段架构胜率范围 | 40%-50% | V2_B07 P311 |
| 90%交易日最低区间 | 5点 | V2_B07 P311 |
| 90%交易日至少有一个 | 4点波段 | V2_B07 P311 |

**刮头皮交易风格选择检查清单**：

- [ ] 不会在明确的总在场内方向上做刮头皮交易（V2_B07 P311）
- [ ] 如果在刮头皮，那么肯定是认为当前没有趋势，或者是在逆势操作（V2_B07 P311）
- [ ] 每当看到市场在一个信号之后回撤三四个跳动时，就可认为那是大型玩家认为市场很可能不会出现大幅运动的征兆（V2_B07 P311）
- [ ] 交易者应仅考虑做交易区间交易或逆势交易，而不是做趋势交易（V2_B07 P311）
- [ ] 做逆势交易时有时选择较小的头寸（比如一半），希望在市场向不利方向运动时加仓（V2_B07 P311）

**重要原则**：

> "坚持自己的时间框架是很重要的。一种常见的亏损原因是，入场一笔交易，看着它变为亏损交易，但是却没有在计划的止损点离场，而是说服自己，把交易变为投资是不错的选择。如果作为交易入场，就要作为交易认赔出场。"（V2_B07 P308）

> "希望不是交易的一部分。"（V2_B07 P311）

- [ ] **选择交易风格**：

| 交易风格 | 持仓时间 | 回报/风险比 | 成功概率 | 适用场景 |

| 摆动交易 (Swinging) | 15分钟-整天 | 约2:1或更大 | 40-60% | 趋势日、顺势交易 |
| Always-In波段 | 大部分时间持仓 | 2:1或更大 | 40-60% | 明确趋势方向时 |

#### 交易纪律规则（来源：theme16_price_action_basics.md）

> 交易与赌博有本质区别——成功的交易者以规则为基础交易。

**核心纪律原则**：

| # | 纪律规则 | 来源 | 违反后果 |
|---|---------|------|---------|
| 1 | 交易与赌博有本质区别——成功的交易者以规则为基础交易 | theme16 | 违背规则=赌博 |
| 2 | 当交易者违背规则时，他们是在根据希望而非逻辑交易，那便是赌博 | theme16 | 情绪化决策 |
| 3 | 初学交易者常在连续亏损后进行赌博式交易 | theme16 | 亏损扩大 |
| 4 | 当面对亏损时，交易者们会去承担更高的风险而不是更低的风险，常常招致破产 | theme16 | 破产风险 |
| 5 | 输后加倍技术在理论上非常棒，但因为数学与情绪之间的冲突，它并不实用 | theme16 | 情绪失控 |
| 6 | 在交易中，刚刚发生的事情将会继续反复发生的几率大于70%或更高 | theme16 | 忽视惯性 |

**纪律检查清单**：

- [ ] **交易前纪律**：
  - [ ] 是否制定了明确的交易计划？
  - [ ] 是否确定了最大风险金额？
  - [ ] 是否标记了关键入场区域和止损位置？
  - [ ] 是否评估了今日市场状态？
  
- [ ] **交易中纪律**：
  - [ ] 是否严格按照计划执行？
  - [ ] 止损被触发后是否立即离场？
  - [ ] 是否避免了情绪化加仓或摊平亏损？
  - [ ] 是否避免了输后加倍行为？
  
- [ ] **风险管理纪律**：
  - [ ] 单笔风险是否控制在账户1-2%以内？
  - [ ] 日亏损达到限制后是否停止交易？
  - [ ] 连续亏损后是否降低仓位或暂停交易？
  - [ ] 是否避免了亏损后增加风险的行为？

**赌博 vs 交易对比**：

| 特征 | 赌博 | 专业交易 |
|------|------|---------|
| 决策基础 | 希望、情绪 | 规则、逻辑 |
| 风险管理 | 无或随意 | 严格、预先设定 |
| 亏损应对 | 加仓摊平、输后加倍 | 立即止损、遵守计划 |
| 连续亏损后 | 加大赌注试图翻本 | 降低仓位或暂停 |
| 结果预期 | 一夜暴富 | 长期稳定盈利 |

#### 初学者交易规则清单（原文：V3_B08 P249）

> 对于刚入市的交易者来说，最佳选择是开盘区间内形成的趋势、强趋势反转和强趋势中的回撤。

| 规则编号 | 规则内容 | 原因 |
|:-------:|---------|------|
| 1 | 仅做回报至少与风险一样大的交易 | 正的交易者方程 |
| 2 | 专注于回撤至少是风险两倍的交易 | 更好的风险回报比 |
| 3 | 只选择认为可能成功的架构，假定胜率至少60% | 确保正期望值 |
| 4 | 只使用止损入场 | 入场时市场正在向你的方向运动 |
| 5 | 总要设好保护性止损 | 信念和希望不会保护你 |
| 6 | 设一张获利了结限价单 | 防止贪婪导致利润消失 |
| 7 | 仅在多头棒上方买进和空头棒下方做空 | 确保信号棒方向正确 |
| 8 | 只交易较小的头寸规模——进入"我不在乎"状态 | 减少情绪干扰 |
| 9 | 一天只寻找3到5笔合理的交易 | 减少决策压力 |
| 10 | 寻找简单的策略——行情不清晰时等待 | 避免勉强交易 |

- [ ] 我是否只交易了简单的架构？
- [ ] 我是否在行情不清晰时选择了等待？

### 步骤 0.9 交易前心理准备

**认知偏差详细应对策略**（原文Theme9 Ch5）:

| 偏差类型 | 交易表现 | 详细应对 |
|----------|----------|----------|
| **确认偏差** | 只看到支持自己观点的信号 | 主动寻找反面证据："如果我要反向交易，理由是什么？" |
| **锚定效应** | 被入场价/前高前低锚定 | 始终以当前市场行为为依据，问："如果我现在空仓，会入场吗？" |
| **处置效应** | 过早卖出盈利、持有亏损 | 使用追踪止损让利润运行；入场前设定止损绝不修改 |
| **沉没成本** | 因已亏损而拒绝止损 | 每笔交易独立；问："这笔交易如果现在入场，我会做吗？" |
| **近因偏差** | 最近事件影响过大 | 回顾周度/月度统计，以长期数据为依据 |
| **过度自信** | 连胜后加大仓位/放宽标准 | 固定仓位大小；连胜3笔后主动缩小仓位至50% |
| **可得性偏差** | 最近大亏后过度规避 | 以统计数据为依据，不以单次经历为依据 |
| **损失厌恶** | 亏损痛苦>盈利快乐 | 记住：小亏是交易成本，大亏才是致命的 |

**偏差检查清单**（入场前执行）:
- [ ] 我是否只看到支持自己方向的信号？（确认偏差）
- [ ] 我是否被某个价格锚定？（锚定效应）
- [ ] 我是否因为已有盈利/亏损而影响判断？（处置效应）
- [ ] 我是否因为最近的结果而过度自信/悲观？（近因偏差）
