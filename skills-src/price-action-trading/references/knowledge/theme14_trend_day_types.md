## 14.1 尖峰和通道趋势日 (Spike and Channel Trend Day)

> 来源：V1_B07_P301-350.md 第21章 P325

### 定义

尖峰和通道趋势是最常见的一类趋势，它几乎存在于每天和每轮趋势中。它有两个组成部分：**尖峰期**和**通道期**。

### 尖峰13条规则

1. 有一个由一条或多条趋势棒构成的尖峰，它发出的信号是市场正在突破进入一个清晰的总在场内（Always In）的行情。在尖峰期间，有一种紧迫感，交易者在努力交易时加大了头寸规模。该尖峰实际上是一个逃逸缺口（Runaway Gap）。
2. 尖峰通常在第一个小时内形成，而且常常是在当天一开始的几棒内。
3. 突破越强，就越可能出现通道形式的坚持到底（follow-through），通道就可能行进得越远。
4. 当突破很强时，它常常会成为一波测量运动（Measured Move）的基础，而通道则可能在测量运动处结束。
5. 紧随尖峰之后的是一个回撤，该回撤可以短到只有一棒，也可以长到几十棒。
6. 趋势以通道的形式恢复。在通道期内，有一种忧虑和不确定的感觉，这要归功于双向交易（Two-sided Trading）。
7. 当市场在通道内行进时，最好像趋势型交易区间一样交易（在多头通道内，最好在前一棒的低点下方买进，部分持有，等待波段）。
8. 通道极少会顺势突破，但是当顺势突破出现时，突破通常会在五棒内失败，然后市场反转。
9. 通道在某个测量运动目标处结束，而且常常是在第三推（Third Push）结束。
10. 如果通道逆势突破，通常最终是逆势突破，那么不要在突破时入场，而是等待回撤。
11. 市场通常会回调至通道起点，形成一个对缺口的测试（所有尖峰都是缺口）。
12. 然后，当市场尝试形成一个交易区间时，它至少会在趋势方向上回撤25%。
13. 当市场较弱时，它或许更像是一个趋势型交易区间日。

### 尖峰三种后续可能

| 可能性 | 描述 | 概率 |
|--------|------|------|
| 趋势恢复 | 市场回撤几棒或十几棒，然后趋势恢复，形成通道 | 最常见 |
| 进入交易区间 | 回撤延伸超过10棒，市场进入交易区间，可能向任意方向突破 | 较少见 |
| 趋势反转 | 市场形成反向尖峰，进入交易区间后多空双方争夺通道方向 | 最少见 |

> 如果回撤延伸超过10棒，那么就产生第二种可能性。一般而言，几率总是倾向于交易区间向与原趋势相同的方向突破。

### 通道交易5条规则

1. 激进的交易者们将使用限价单在通道内入场，顺势交易，直到双向交易变得非常明显。
2. 当通道靠近支撑位时，注意观察：棒线是否存在更多重叠、是否出现更多更强的反向趋势棒、是否出现更多十字星、是否出现更大的回撤。
3. 机构和拥有大额账户的交易者们，可以对逆势头寸逐步加仓，预期市场测量通道起点。
4. 大多数交易者只应顺势操作，直到出现明确的反转征兆。
5. 如果是下午在通道内对逆势头寸逐步加仓，风险更高，因为常常会没有足够的时间操作。

### 变种类型

| 变种类型 | 描述 |
|---------|------|
| 缺口尖峰和通道 | 开盘缺口作为尖峰，随后形成通道 |
| 连续高潮 | 多个尖峰连续出现，形成更大的调整 |
| 抛物线通道 | 通道斜率不断增加，呈现抛物线形状，是高潮行为 |
| 尖峰和通道嵌套 | 较小的尖峰和通道趋势嵌套在较大的尖峰和通道趋势中 |
| 通道即反向旗形 | 多头通道是空头旗形，空头通道是多头旗形 |
| 陡峭通道成为尖峰 | 在较高时间框架图表上，陡峭通道本身成为一个尖峰 |

### 关键概率数据

| 指标 | 数据 |
|------|------|
| 通道顺势突破后失败时间 | 通常在五棒内 |
| 通道逆势回撤幅度 | 至少25% |
| 通道结束位置 | 常常在第三推结束 |
| 开盘后识别形态的时间 | 30到60分钟内 |

## 14.2 趋势型交易区间日 (Trending Trading Range Day)

> 来源：V1_B07_P301-350.md 第22章 P359

### 定义

由一系列交易区间和短暂突破构成的趋势日，双向交易明显。由于每一轮趋势都有回撤，而且每一个回撤都可看做小型交易区间，所以在每一个趋势日内都会表现出某种形式的趋势型交易区间日特征。

### 8条特征

1. 开盘区间约为最近几日区间的三分之一到二分之一。
2. 一两个小时后出现一个突破，然后市场再次形成交易区间。
3. 由于存在交易区间，所以通常有机会在两个方向上做交易。
4. 有时会形成多个突破和交易区间，但是当这种情况发生时，最好把那一天看作是更为强势类型的趋势日，只做顺势交易。
5. 当第二个交易区间开始形成后，通常会出现一个回撤来测试之前的交易区间。
6. 测试常常会突破，返回之前的交易区间。
7. 有时市场会一路穿过之前的区间，形成一个反转日。
8. 当突破非常强时，这一天很可能会成为一个弱势尖峰和趋势通道。

### 5条交易规则

1. 当首次突破产生时，市场波幅逐渐达到平均每日区间，不要认为测量运动肯定会形成。
2. 在大约1/3的情况下，市场会向一个方向突破并超出区间一点儿，然后反转，在相反方向上突破。
3. 如果初始区间为5点（近期平均12点），在当天结束时就要为突破做好准备。
4. 不要放弃，认为当天的区间不会超过5点，因为在90%的情况下，区间将在收盘前放大。
5. 因为突破产生得非常晚，所以常常没有足够的时间形成一个不错的交易区间。

### 关键概率数据

| 指标 | 数据 |
|------|------|
| 开盘区间大小 | 约为最近几日区间的1/3到1/2 |
| 突破后测量运动 | 接近两倍日区间 |
| 首次突破后不形成测量运动 | 约1/3的情况 |
| 小区间（5点）在收盘前放大 | 90%的情况 |
| 出现频率 | 每周至少出现几次 |

## 14.3 开盘起趋势日和小幅回撤趋势日 (Trends from the Open and Small Pullback Trends)

> 来源：V1_B08_P351-400.md 第23章 P383

### 开盘起趋势日特征

1. 多头趋势日的低点和空头趋势日的高点在头天前几棒内形成。
2. 如果当日开盘区间小于近日平均每日区间的25%，那么可能是多头趋势日的一个双重底，或者空头趋势日的一个双重顶。
3. 当日开盘可能是一个持续很多棒的强势尖峰，也可能是一个小型开盘区间。
4. 如果市场从第一棒左右就表现出趋势，而且初始尖峰持续三棒或更多棒，那么在第一个回撤入场通常是不错的选择。
5. 如果开盘出现一个很强的尖峰，持续很多棒，波幅为很多点，那么那一天通常会成为一个尖峰和通道趋势日。
6. 大型缺口开盘常常引起从开盘起的一个趋势日。当出现一个大型上涨缺口时，那一天大约60%的时间里会成为一个多头趋势日，40%的时间里会形成一个空头趋势日。
7. 开盘起趋势日具有紧迫感，从开始便很确定，通常是最强的趋势，回撤幅度最小。

### 小幅回撤趋势日（最强类型的趋势日）

- 所有回撤幅度都小于近期平均每日区间的20%到30%。
- 当天晚些时候，通常会出现一次回撤，幅度约比先前回撤大150%到200%。
- 电子迷你中的回撤可能只有10到12个跳动（平均每日区间的10%到30%）。
- 开盘起趋势日大约一周出现一两次，但小幅回撤日一月只出现一两次。

### 交易策略

- 在强劲的多头趋势中，准备在前一棒的低点买进，或者在它的低点下方一两个跳动处买进。
- 使用止损单在高点1和高点2架构上方1个跳动处买进。
- 观察自趋势开始后的回撤幅度，使用限价单在当日高点下方5到7个跳动处买进。
- 在很强的空头趋势中，在前一棒的高点或它上方一两个跳动处做空。

### 强趋势日通用规则

1. 一旦认为当天处于一轮趋势之中，就必须至少建立一个小型头寸。
2. 只要趋势强劲，就要拒绝获利了结，直到利润至少达到初始风险的两倍。
3. 强趋势日逆势规则：仅当有很好的趋势线突破和很强的反转棒时才考虑逆势交易。
4. 在强趋势中，不需要入场架构，可以在一天中的任意时间在市价入场。

### 关键概率数据

| 指标 | 数据 |
|------|------|
| 大型上涨缺口后形成多头趋势日 | 约60% |
| 大型上涨缺口后形成空头趋势日 | 约40% |
| 经验丰富的交易者波段架构成功率 | 70%或更高 |
| 小幅回撤日出现频率 | 约一月一两次 |
| 开盘起趋势日出现频率 | 约一周一两次 |

## 14.4 反转日 (Reversal Day)

> 来源：V1_B08_P351-400.md 第24章 P415

### 定义

市场先向一个方向做趋势运动，然后向相反方向做趋势运动，进入收盘。

### 核心特征

1. 市场向一个方向做趋势运动，然后向相反方向做趋势运动，进入收盘。
2. 大多数是作为趋势型交易区间日开始的。
3. 如果反转是在最后几个小时开始，而且很强，那么通常将在第二天或接下来的几天有坚持到底运动。

### 交易策略

- 一旦识别出逃逸型趋势状态，必须快速入场，把大部分头寸波段化。
- 注意拥有很强的逆势尖峰的回撤，警惕趋势反转。
- 在楔形反转时，在更高低点或失败的低点2上方买进通常更为安全。

> 一些最强的趋势是从一天的午盘或收盘开始的。有时，它们起源于交易区间突破或高潮趋势反转。在这两种情况下，市场都可能进入逃逸型趋势状态。

> 大多数反转日都是从趋势型交易区间日开始的。

## 14.5 趋势恢复日 (Trend Resumption Day)

> 来源：V1_B08_P351-400.md 第25章 P423

### 定义

第一小时形成趋势，进入交易区间数小时后趋势恢复的交易日。

### 核心特征

1. 市场在第一个小时左右形成一轮强劲趋势，然后进入交易区间。
2. 交易区间持续数小时，常常哄骗交易者们认为当天将会平静地进入收盘。
3. 趋势在最后一两个小时恢复。
4. 第二条腿的大小差不多与第一条相同。
5. 延长的交易区间常常是非常紧凑的交易区间。
6. 当天晚些时候常常出现那个交易区间的突破，尝试令趋势反转，但那通常是一个陷阱。
7. 对于没有在早期或突破入场的交易者们，常常有一个突破回撤入场。

### 交易策略

- 在太平洋标准时间上午11点到正午之间，常常出现失败的短暂一两棒强势反转突破，把交易者们套进错误的方向。
- 趋势恢复形态常常会持续两天或更长时间。
- 虽然5分钟图上看起来可能是这些天内形成了巨大的波段，但是在60分钟图上，它们可能只是形成一个ABC形态。

## 14.6 台阶形态：宽通道趋势 (Stair Patterns: Broad Channel Trends)

> 来源：V1_B08_P351-400.md 第26章 P431

### 定义

台阶日是趋势型交易区间日的一个变种，至少包含三段交易区间。

### 核心特征

1. 当天出现很宽的波段，但是波段高点和低点呈现出趋势变化。
2. 因为波段较大，所以交易者通常能够在两个方向下单，但是应尽量把部分或全部顺势交易波段化。
3. 几乎每次突破之后都会形成超越突破点的回撤（突破测试），所以相邻波段之间存在一些重叠。
4. 如果每个突破都比前一个小一点，那么就形成一个逐渐收缩的台阶形态，表明动能正在衰退。

### 三大变体

| 变体 | 英文 | 核心特征 | 交易含义 |
|------|------|---------|---------|
| 空头台阶 | Bear Stairs | 向下通道中每次新低后回撤超越突破点 | 在通道线附近双向交易 |
| 台阶加速 | Stair Acceleration | 台阶突破通道后加速进入强趋势 | 楔形顶部失败后向上加速 |
| 收缩台阶 | Contracting Staircase | 每次突破幅度递减，动能衰退 | 预示反转到来 |

### 交易策略

1. 逆突破交易：观察突破超越波段点的跳动数，在趋势通道线附近逐步加仓。
2. 经验分级：通道内双向交易仅适用于经验丰富的交易者；初学者应停止入场。
3. 三次下推：不保证反转，需结合买压力度、高潮反转等信号综合判断。
4. 楔形失败：楔形顶部失败后市场一般向上加速，目标为楔形高度的测量运动。
5. 收缩台阶：每个突破小于前一个时动能衰退，可做逆势刮头皮交易。
6. 安全入场：使用止损单在市场反转时入场比限价单更安全。

## 补充：趋势日确认规则与尖峰后走势（V1原文补充）

> 来源：V1_B06_P251-300.md P291-295; V1_B08_P351-400.md P386

### 趋势日确认规则

1. 大部分交易者在棒5或棒7形成后，就把那一天看作一个趋势日。
2. **一旦认为当天处于一轮趋势之中，就必须至少建立一个小型头寸。**
3. **只要趋势强劲，就要拒绝获利了结，直到利润至少达到初始风险的两倍。**

### 尖峰后三种走势详细分类

| 走势 | 描述 | 概率 |
|------|------|------|
| 耗尽型高潮行为 | 尖峰后立即出现异常强劲的突破，但可能是高潮 | 已行进30棒+时风险增加 |
| 趋势恢复日 | 回撤后趋势恢复，形成通道 | 最常见 |
| 尖峰和通道趋势日 | 回撤短暂，通道持续 | 常见 |

### 台阶形态补充规则

1. 如果上个波段低点比前面的波段低点低14个跳动，那么多头准备在波段低点下方10个跳动左右开始逐步加仓。
2. 当每个突破都小于前一个时，趋势的动能正在衰退，不久将会出现更深的回撤或反转。
3. 一旦市场开始形成下降的台阶形态，可以在每条收盘低于前一空头台阶的空头趋势棒收盘后做多，做刮头皮交易。
