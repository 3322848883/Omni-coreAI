## 阶段二：开盘专项分析（3个步骤）

> 开盘是日内交易中最重要的时段。开盘模式为全天定下基调。

---

### 步骤 2.1 开盘模式识别
→ [Theme8](theme8_daytrading_part1.md) Ch19

- [ ] **分析开盘前几根K线**：
  - [ ] 第一根K线是什么类型？（趋势K线/十字星/反转K线）
  - [ ] 前三根K线的方向是什么？
  - [ ] 是否形成微观通道？
- [ ] **识别开盘模式类型**：
  - [ ] 缺口高开（Gap Up）：开盘 > 昨日高点
  - [ ] 缺口低开（Gap Down）：开盘 < 昨日低点
  - [ ] 铁丝网开盘（Barb Wire on Open）：紧密交易区间
  - [ ] 趋势开盘：从第一根K线开始有明确方向
  - [ ] 区间开盘：在前几根K线内双向波动
- [ ] **评估开盘区间（Opening Range）**：
  - [ ] 开盘区间大小：
    - [ ] 小开盘区间 → 将跟随突破
    - [ ] 约平均日波幅一半 → 测量移动和趋势区间日
    - [ ] 大开盘区间 → 急速通道趋势日可能
  - [ ] 开盘区间高点：____
  - [ ] 开盘区间低点：____
- [ ] **开盘反转信号**：
  - [ ] 开盘后是否向一个方向急剧运动然后反转？
  - [ ] 反转是否在测试重要支撑/阻力位后发生？
  - [ ] 是否有两次失败尝试后反转？
- [ ] **突破回调（Breakout Pullback）识别**：
  - [ ] 开盘后的突破是否已经回调？
  - [ ] 回调是否提供低风险入场机会？
- [ ] **开盘模式交易策略**：
  - [ ] 如果是趋势开盘 → 顺势入场
  - [ ] 如果是铁丝网开盘 → 等待突破

#### 开盘模式决策逻辑（原文：V3_B07 第19-20章、V1_B08 第23章）
- [ ] 如果 开盘为大型缺口（> 近5天最大缺口 或 > 日均区间50%） → 则 假定强趋势日，积极波段化；缺口即尖峰
- [ ] 如果 开盘缺口 + 头几棒为同方向趋势棒 → 则 缺口方向即为趋势日方向
- [ ] 如果 开盘缺口 + 头几棒为反方向趋势棒 → 则 可能形成缺口反转日
- [ ] 如果 开盘为带刺铁丝形态（水平均线、大型重叠棒线） → 则 耐心等待突破；突破常失败（最终旗形）；准备反向入场
- [ ] 如果 开盘区间 < 日均区间25% → 则 预期强趋势日（小幅回撤日）
- [ ] 如果 开盘区间 ≈ 日均区间33%-50% → 则 预期趋势型交易区间日
- [ ] 如果 开盘第一棒为强趋势棒 → 则 该棒方向可能指示趋势日方向
- [ ] 如果 开盘第一棒为十字星 → 则 双向交易征兆，当日可能为区间日
→ 深度知识：[Theme14](theme14_trend_day_types.md)、原文V3_B07、原文V1_B08

#### 开盘区间反转概率数据（原文：V3_B06 P253-260/P286-289）

**当日高低点形成概率**：

| 条件 | 概率 | 说明 |
|------|:----:|------|
| 第一棒成为当日高点或低点 | 20% | 当天第一棒大约有20%的可能成为当日高点或低点 |
| 强趋势棒第一棒成为当日高/低点 | 30% | 如果第一棒是一条没有长尾线的强趋势棒，那么就有30%的可能成为当日高点或低点 |
| 高点或低点在头5棒内形成 | 50% | 50%的交易日中，高点或低点都在头5棒内形成 |
| 高点或低点在开盘1-2小时内形成 | 90% | 90%的交易日中，高点或低点在开盘一两个小时内形成 |

**开盘反转成功概率**：

| 条件 | 概率 | 说明 |
|------|:----:|------|
| 早期反转成为当日高/低点 | 30%-40% | 第一两个小时内的反转可能只有30%到40%的可能成为当日高点或低点 |
| 确认后反转概率 | 50%-60% | 如果出现不错的信号棒，那么几率可能快速上升至50%到60% |
| 双重顶/底引出波段 | 40%-50% | 一旦一个双重顶或双重底形成，那么就有大约40%到50%的几率引出一个波段 |

**开盘区间交易要点**：
- [ ] 第一两个小时很可能是一天中让交易者找到一笔利润为风险两到三倍的交易的时间
- [ ] 当日高点通常从某种类型的双重顶开始，尽管双重顶很少是完美的
- [ ] 当日低点通常从某种类型的、并不完美的双重底开始
- [ ] 开盘常常预示着交易日的类型
- [ ] 如果第一棒是一个十字星，或者头几棒重叠并且拥有突出的尾线，那么那个交易日比较可能出现大量的双向交易
→ 深度知识：原文V3_B06 P253-260、P286-289

**Globex与日内时段交互规则**:

1. **Globex时段特征**:
   - 交易量低，流动性差
   - 价格波动可能被放大
   - 算法交易主导

2. **Globex形态延续规则**:
   | Globex形态 | 日内延续概率 | 交易策略 |
   |------------|--------------|----------|
   | Globex趋势明确 | 70%延续 | 顺势交易 |
   | Globex交易区间 | 60%延续 | 区间策略 |
   | Globex剧烈波动 | 50%反转 | 等待确认 |

3. **Globex突破处理**:
   - Globex高点/低点作为关键磁铁
   - 日内突破Globex极值需确认
   - 假突破概率高于正常时段

4. **时段切换规则** (P272):
   > "全球期货交易系统(Globex)与日内时段的信号可能不同，需分别评估"
   
   - 9:30开盘时重新评估趋势
   - 不盲目延续Globex判断
   - 观察头3-5棒确认方向

**原文引用**:
> "全球期货交易系统与日内时段的信号对比" (V3_B06 P273-274)

  - [ ] 如果是区间开盘 → 等待突破方向

**第一小时扩展概率数据**:

| 场景 | 概率 | 来源 | 交易含义 |
|------|------|------|----------|
| 开盘区间反转成功 | 40-50% | V3_B06 P256 | 需要选择1个以上反转才能抓住波段 |
| 报告后数分钟内趋势延续 | <50% | V3_B06 P253 | 等待1-2棒后再入场 |
| 计算机程序主导时段获利 | 低 | V3_B06 P253 | 避免与算法竞争速度 |

| 刮头皮胜率要求 | ≥60% | V3_B06 P256 | <60%需更大回报风险比 |

**报告后交易规则** (V3_B06 P253):

1. **7:00 PST报告时间**:
   - 市场行为常像有报告发布
   - 计算机瞬间接收数据并交易
   - 人类交易者处于劣势

2. **应对策略**:
   - 等待1-2棒让算法交易完成
   - 速度不再重要后再入场
   - 当对手有巨大优势时，不要参与竞争

**原文引用**:
> "太平洋标准时间上午7:00常常会有报告发布。即便报告没有在网上列出，市场的行为通常也像是有报告发布"

> "当你的对手拥有巨大的优势时，不要参与竞争。等待他们的优势消失，当速度不再重要时交易"

### 步骤 2.4 开盘区间逐棒分析
→ 完整规则见 references/knowledge/source/V3_反转/V3_B06_P251-300.md P251-252

**目的**: 系统化分析开盘区间头5-10棒的微观结构，预判当日趋势类型

**逐棒分析流程** (头10棒):

| 棒号 | 分析重点 | 关键判断 |
|------|----------|----------|
| **棒1** | 开盘位置、实体大小、影线 | 多头/空头/十字星开盘 |
| **棒2** | 与棒1关系、方向确认 | 延续或反转信号 |
| **棒3** | 趋势确立、EMA位置 | 是否形成明确趋势 |
| **棒4-5** | 波动范围、高低点形成 | 当日极值概率评估 |
| **棒6-10** | 结构演变、形态识别 | 趋势日/区间日判断 |

**开盘区间形态识别**:

1. **趋势日开盘特征** (V3_B06 P288-289):
   - 头2棒同向，实体较大
   - 第3棒延续，收于极值
   - 波动范围快速扩展
   - 当日高/低点在头5棒内形成

2. **区间日开盘特征**:
   - 头3棒重叠，影线突出
   - 双向交易明显
   - 围绕开盘价震荡
   - 需要更多棒线确认方向

3. **反转日开盘特征**:
   - 开盘与昨日收盘方向相反
   - 头几棒形成双重顶/底
   - 突破昨日极值后回撤

**关键概率数据** (V3_B06 P253):

| 条件 | 概率 | 交易含义 |
|------|------|----------|
| 当日高/低点在头5棒形成 | 50% | 早期确认趋势日 |
| 当日高/低点在头2小时形成 | 90% | 开盘区间至关重要 |
| 第一棒成为高/低点 | 20% | 强趋势棒时30% |
| 双重顶/底引出波段 | 40-50% | 等待确认后入场 |

**实战要点**:
- 每根新棒收盘后立即更新判断
- 结合前一根棒线评估信号强度
- 关注形态演变而非单一棒线
- 开盘区间反转是当日最重要交易机会
