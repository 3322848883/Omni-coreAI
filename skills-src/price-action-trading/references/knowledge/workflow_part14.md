### 附录B：K线类型识别清单

> 本附录替代原有的A/B/C/D评级体系，采用K线类型识别方法，更准确地评估信号K线的交易价值。

---

#### K线类型识别表格

| K线类型 | 识别特征 | 交易含义 | 适用场景 |
|---------|----------|----------|----------|
| **趋势K线** | 实体大、影线小、收盘接近K线极端 | 强势信号，可作为入场基础 | 趋势交易首选 |
| **反转K线** | 收盘反转多于一根K线的收盘价和低点、影线方向正确 | 趋势可能反转的信号 | 反转交易、极端位置 |
| **十字星** | 实体极小、上下影线接近等长 | 不确定性高，谨慎使用 | 仅在极端位置+第二个理由时使用 |
| **内包K线** | 完全包含在前一根K线范围内 | 可能为突破前兆，等待确认 | 结合ii/iii形态使用 |
| **外包K线** | 完全包含前一根K线 | 强势突破信号 | 突破交易 |
| **ii形态** | 连续两根内包K线 | 突破即将发生，等待方向确认 | 刮头皮、波段 |
| **iii形态** | 连续三根内包K线 | 强突破信号，可靠性较高 | 刮头皮或波段 |
| **ioi形态** | 内包-外包-内包 | 通常是突破模式形态 | 刮头皮 |
| **oio形态** | 外包-内包-外包 | 波动性增加，方向不确定 | 谨慎使用 |
| **两K线反转** | 第一根顺势，第二根反转收盘超过第一根实体 | 反转信号，结合趋势位置判断 | 刮头皮或波段 |
| **三K线反转** | 三根K线中第一和第三是两K线反转 | 更强的反转信号 | 波段 |
| **光头光脚K线** | 一端或两端没有影线 | 单边强势，趋势延续信号 | 强趋势中 |
| **双顶双胞胎** | 两根连续K线相同高点（强趋势中） | 短期阻力，可能回调 | 刮头皮 |
| **双底双胞胎** | 两根连续K线相同低点（强趋势中） | 短期支撑，可能反弹 | 刮头皮 |

#### 信号K线使用原则

##### 核心原则

1. **趋势K线优先**：在趋势交易中，优先选择趋势K线作为信号K线
2. **十字星谨慎使用**：十字星信号K线仅在极端位置且有第二个理由时才考虑交易
3. **反转K线需确认**：反转K线需要结合趋势线突破或其他确认信号
4. **组合形态增强**：ii、iii、两K线反转等组合形态可增强信号可靠性

##### 顺势交易信号K线选择

| 市场状态 | 首选信号K线 | 避免的信号K线 |
|----------|-------------|---------------|
| 强趋势 | 趋势K线（任何质量） | 无 |
| 中等趋势 | 趋势K线、两K线反转 | 单独十字星 |
| 弱趋势 | 趋势K线+良好特征 | 十字星、内包K线 |
| 趋势回撤 | High 2/Low 2处的趋势K线 | High 3+/Low 3+ |

##### 逆势交易信号K线选择

| 条件 | 要求 | 备注 |
|------|------|------|
| 必须有 | 趋势线突破 | 无趋势线突破不逆势交易 |
| 首选 | 强反转K线 | 实体大、影线方向正确 |
| 次选 | 两K线反转/三K线反转 | 组合形态更可靠 |
| 需要 | 至少3个理由 | 比顺势交易多一个理由 |
| 避免 | 单独十字星 | 除非在极端位置+多理由 |

##### 区间交易信号K线选择

| 位置 | 多头信号 | 空头信号 |
|------|----------|----------|
| 区间底部 | 牛趋势K线、双底、反转K线 | 避免 |
| 区间顶部 | 避免 | 熊趋势K线、双顶、反转K线 |
| 区间中部 | 避免 | 避免 |

##### 特殊情形处理

**强趋势中的差信号**：
- 在强趋势中，信号K线外观不重要
- 差信号=强趋势（因为趋势太强，没有好的回撤让逆势交易者创建好的信号K线）
- 只要趋势明确，即使信号K线不完美也可入场

**极端位置的十字星**：
- 在趋势极端位置（如趋势通道线超越处）
- 有第二个理由支持（如趋势线突破、双顶/双底）
- 可考虑交易，但需减少仓位

**内包K线和外包K线**：
- 单独内包K线不作为交易信号
- ii形态（连续两根内包）等待突破方向
- iii形态（连续三根内包）突破可靠性较高
- 外包K线本身可作为信号，但需结合位置

#### 快速参考：信号K线决策流程

```
识别信号K线类型

    │   ├── 弱势Low 1/Low 2？→ 用限价单买入
    │   └── 无信号 → 等待
    ├── 价格在中间？
    │   ├── 是紧密区间？→ 不交易
    │   ├── 是铁丝网？→ 不交易
    │   └── 一般区间中间 → 不交易（等待到达极端）
    └── 突破信号？
        ├── 强突破 + 后续跟进？→ 顺势入场
        ├── 弱突破？→ 可能是失败突破，等待
        └── 失败突破本身也失败？→ 失败之失败（最高概率）
```

#### 信号K线 → 入场决策

```
信号K线质量如何？
│
├── 强趋势信号棒（强趋势K线 + 完美特征）
│   ├── 与Always In一致？
│   │   ├── 是 → 标准仓位入场
│   │   └── 有3+理由 → 可以考虑摆动交易
│   └── 逆势？
│       ├── 有强势趋势线突破？→ 减少仓位入场
│       └── 无趋势线突破 → 跳过
│
├── 一般信号棒（趋势K线 + 大部分特征）
│   ├── 与Always In一致？
│   │   ├── 是 → 标准仓位入场
│   │   └── 有2+理由 → 标准入场
│   └── 逆势？
│       ├── 有强势趋势线突破 + 多理由 → 减少仓位
│       └── 其他 → 跳过
│
├── 弱信号棒（趋势K线但特征不明显）
│   ├── 与Always In一致 + 2个理由？→ 减少仓位
│   ├── 与Always In一致 + 3个理由？→ 标准仓位
│   └── 其他情况 → 跳过

```

#### 交易者方程式 → 决策

```
计算交易者方程式
│
├── 方程式为正（P(win) x Reward > P(lose) x Risk）
│   ├── 概率60%+ 且 回报>=风险 → 交易
│   ├── 概率50% 且 回报>=1.5倍风险 → 交易
│   └── 概率40% 且 回报>=2倍风险 → 交易
│
├── 方程式为负
│   └── 不交易
│
└── 不确定
    └── 不交易（等待更好的建仓形态）
```

### 附录D：禁止事项清单

#### 绝对禁止

- [ ] 不使用止损
- [ ] 在铁丝网（Barb Wire）中交易
- [ ] 在紧密交易区间（Tight Trading Range）中用止损入场
- [ ] 在强趋势中逆势交易（初学者）
- [ ] 基于新闻交易
- [ ] 过度交易（一天超过合理数量）
- [ ] 在单笔交易上冒超过2%的风险
- [ ] 追逐市场（FOMO入场）
- [ ] 在1分钟图上交易（大多数交易者会亏钱）
- [ ] 使用心理止损（不使用实际在市场中的止损）
- [ ] 在亏损后将交易转换为投资（不遵守止损）
- [ ] 在连续亏损后加大仓位（报复性交易/Martingale）
- [ ] 在经济报告发布期间交易
- [ ] 不遵守交易计划
- [ ] 在没有至少2个理由的情况下交易
- [ ] 十字星信号K线入场（除非极端位置+第二个理由）→ 禁止交易（BAN-05）
- [ ] 在区间中间用止损入场
- [ ] 在不明确的图表中交易
- [ ] 试图预测顶部和底部（初学者）
- [ ] 在交易区间日做摆动交易（初学者）

#### 强烈不建议

- [ ] 在第一小时之后才开始交易（错过最佳机会）
- [ ] 在日波幅中部交易（新手）
- [ ] 使用限价入场（初学者应只用止损入场）
- [ ] 加仓（初学者）
- [ ] 在没有趋势线突破的情况下逆势交易
- [ ] 在交易区间中做摆动交易
- [ ] 在没有测量移动目标的情况下做摆动交易
- [ ] 在连续亏损后继续交易（应停止当天交易）
- [ ] 在盈利后放松纪律
- [ ] 在不记录交易日志的情况下交易
- [ ] 在市场状态不明确时强行交易
- [ ] 使用超过2点的止损（Emini）而不增加目标
- [ ] 在收盘前最后一小时逆势加仓

#### 需要特别注意

- [ ] 在11:30 PST附近交易（强趋势日可能有止损扫荡）
- [ ] 在区间顶部做多（除非有强突破信号）
- [ ] 在区间底部做空（除非有强突破信号）
- [ ] 在高潮后立即反转交易（等待确认）
- [ ] 在第一根K线收盘前入场
- [ ] 在连续3次或更多失败交易后继续交易
- [ ] 在没有更高时间级别确认的情况下做大方向决策
- [ ] 在交易计划之外的时间段交易
