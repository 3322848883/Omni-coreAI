## 第17章：限价单入场规则（Limit Order Entry Rules）

### 17.2.1 限价单入场规则（Limit Order Entry Rules）

> 限价单（Limit Order）入场是Al Brooks体系中重要的入场方式，尤其适用于交易区间和回调交易。以下8条规则涵盖主要的限价单入场场景。**注意：部分规则仅限经验丰富的交易者使用。**

| 规则ID | 优先级 | IF（条件） | THEN（动作） | EXCEPT（排除条件） | 适用人群 | 知识库依据 |
|--------|--------|-----------|-------------|-------------------|---------|-----------|
| LE-01 | P2 | 弱势突破 + 平静市场 + 接近等距投影 | 在前一根K线高点或上方限价卖出 | 突破过强；市场波动剧烈 | 仅限经验丰富 | 概率总结P5 |
| LE-02 | P2 | 强劲反转后新多头趋势 / 交易区间底部 + L1/L2弱信号K线 | 在弱信号K线低点或下方限价买入 | 无反转确认；信号棒质量差 | 仅限经验丰富 | 概率总结P5 |
| LE-03 | P2 | 强劲反转后新空头趋势 / 交易区间顶部 + H1/H2弱信号K线 | 在弱信号K线高点或上方限价卖出 | 无反转确认；信号棒质量差 | 仅限经验丰富 | 概率总结P5 |
| LE-04 | P3 | MA附近平静多头旗 + 前一根K线低点 | 在前一根K线低点或下方限价买入 | 多头旗被跌破；趋势已反转 | 所有交易者 | 概率总结P5 |
| LE-05 | P3 | MA附近平静空头旗 + 前一根K线高点 | 在前一根K线高点或上方限价卖出 | 空头旗被突破；趋势已反转 | 所有交易者 | 概率总结P5 |
| LE-06 | P3 | 多头旗突破 + 多头K线 | 在多头K线下方限价买入，预期突破回调（BOPB） | 突破无跟进；突破K线为Doji | 所有交易者 | 概率总结P5 |
| LE-07 | P3 | 空头旗突破 + 空头K线 | 在空头K线上方限价卖出，预期突破回调（BOPB） | 突破无跟进；突破K线为Doji | 所有交易者 | 概率总结P5 |
| LE-08 | P4 | 区间突破 + 接近等距投影（MM） | 在等距投影价位限价卖出，目标测试突破点 | 突破过强；区间高度不足 | 仅限经验丰富 | 概率总结P5 |

#### 限价单入场关键原则

1. **限价单优于止损单的场景**：在交易区间中，80%的突破尝试会失败（P-12），因此限价单比突破止损单更优
2. **弱信号K线是限价单的最佳时机**：当信号K线较弱但背景有利时，限价单可以在更好价格入场
3. **平静市场中的限价单**：在低波动（平静）市场中，限价单更容易成交且滑点更小
4. **经验要求**：LE-01/02/03/08仅限经验丰富的交易者，因为需要快速判断突破强度和市场状态
5. **与止损单的配合**：限价单入场后，止损仍应放在信号K线的另一极端+1 tick
6. **二次入场优先**：区间顶部/底部使用限价单时，二次入场（Second Entry）的概率更高（60%+ vs 50%）

| 2 | **市场具有惯性** | PDF第8章 | 市场会重复之前的行为，80%打破惯性的尝试都会失败 |
| 3 | **趋势中只顺势** | PDF第8章 | 在趋势中只做顺势交易，直到有明确证据表明趋势结束 |
| 4 | **震荡区间BLiSHS** | PDF第8章 | 在震荡区间中低买高卖，空头止损，直到被真突破 |
| 5 | **等待两个或更多理由** | PDF第5章 | 至少需要2个理由才能交易（顺势），逆势至少3个 |
| 6 | **交易者方程式必须为正** | PDF第5章 | P(win)×Reward > P(loss)×Risk，否则不交易 |
| 7 | **不要在铁丝网中交易** | PDF第5章 | 铁丝网=无方向=无利润，等待突破 |
| 8 | **第二段陷阱** | PDF第1章 | 震荡区间内第二段往往是陷阱，不要追仓 |
| 9 | **保护至少一部分利润** | PDF第1章 | 有利润时至少保护一部分，不要让盈利变亏损 |
| 10 | **忽略新闻** | PDF第5章 | 新闻是噪音，价格行为才是真相 |

## 第19章：Trade What You See — 核心交易哲学

> 来源：PDF第1章 P11（第496-498行）

### 核心原则

**Trade What You See!!!** — 这是Al Brooks最核心的交易原则之一。

| 原则 | 英文 | 描述 |
|------|------|------|
| **交易你看到的** | Trade What You See | 基于图表上的实际价格行为做决策 |
| **不要问为什么** | Don't Ask Why | 不要试图解释市场为什么在移动 |
| **市场周期变化的信号** | Signals of Market Cycle Change | 价格行为本身就是市场周期变化的信号 |

### 实战规则

1. **不要问为什么**：不要试图用新闻、基本面或逻辑来解释价格行为。图表告诉你需要知道的一切
2. **只交易你看到的**：如果图表显示趋势，做趋势交易；如果显示区间，做区间交易。不要交易你"认为"应该发生的事
3. **接受不确定性**：价格行为始终在灰色迷雾中，接近就足够接近了
4. **市场周期信号**：当价格行为出现变化（如惊喜K线、趋势线突破、高潮反转），这就是市场周期变化的信号，据此调整策略
5. **不要预测**：预测是输家的游戏。交易者应该对正在发生的事情做出反应，而不是预测将要发生的事情

### 与规则引擎的关系

- Trade What You See 是所有规则引擎的底层哲学
- 决策树（第2章）的每一步都是基于"你看到了什么"，而非"你认为会怎样"
- 当价格行为与你的预期矛盾时，永远相信价格行为

## 第20章：入场后管理决策树

> **定位**：入场后立即执行，并每根K线收盘后动态监控。这是交易生命周期闭环的关键环节。

### 20.1 入场后立即执行

```
入场成交后立即执行:
│
├── [1] 确认成交价格、时间、仓位大小
├── [2] 立即设置保护性止损（不使用心理止损）
├── [3] 设置第一目标限价单
└── [4] 评估入场K线质量
    ├── 强趋势棒（与交易方向一致）→ 止损移至入场棒另一端外1 tick
    ├── 十字星 → 不调紧止损，允许1-2 tick回撤
    ├── 外包棒（与交易方向一致）→ 止损移至外包棒另一端外1 tick
    └── 内包棒 → 保持信号棒止损（内包棒是单棒交易区间）
```

### 20.2 持仓中动态监控决策树

```
每根K线收盘后执行:
│
├── Q1: Always In方向是否改变？
│   ├── 连续3根K线收盘在EMA另一侧 → 评估提前平仓
│   │   EXCEPT 趋势极强且仅1-2根K线反向
│   └── 无明显改变 → 继续持仓
│
├── Q2: 是否出现反转信号？
│   ├── 双顶/双底/楔形/高潮出现 → 收紧止损至信号K线极端
│   │   EXCEPT 反转信号在铁丝网中（不可靠）
│   └── 无反转信号 → 继续
│
├── Q3: 是否触及关键磁铁？
│   ├── 到达EMA/前高/测量移动目标 → 部分获利或移动止损
│   └── 未触及 → 继续
│
├── Q4: 是否达到目标位？
│   ├── 达到第一目标 → 平1/3-1/2仓位，止损移至保本
│   ├── 达到第二目标 → 再平1/3仓位
│   └── 未达到 → 继续
│
├── Q5: 市场是否进入铁丝网？
│   ├── 3根+K线大量重叠+十字星 → 考虑全部获利了结
│   └── 否 → 继续
│
└── Q6: 交易者方程式是否仍为正？
    ├── 当前R:R使方程式为负 → 评估提前平仓
    └── 为正 → 继续持仓
```

### 20.3 追踪止损规则

| 规则ID | 优先级 | IF（条件） | THEN（动作） | EXCEPT | 知识库依据 |
|--------|--------|-----------|-------------|--------|-----------|
| TS-01 | P1 | 多头持仓 + 创新高 | 止损移至最近波段低点下方1 tick | 趋势明显减弱 | Theme7 Ch29 |
| TS-02 | P1 | 空头持仓 + 创新低 | 止损移至最近波段高点上方1 tick | 趋势明显减弱 | Theme7 Ch29 |
| TS-03 | P2 | 价格达到1R盈利 | 止损移至盈亏平衡点 | 无 | Theme7 Ch24 |
| TS-04 | P2 | 价格达到2R盈利 | 止损移至1R盈利位置 | 无 | Theme7 Ch24 |
| TS-05 | P3 | 持仓超过5根K线未达目标 | 考虑收紧止损或平仓 | 目标即将触及 | Theme7 Ch24 |

### 20.4 仓位缩放决策

```
仓位调整判断:
│
├── 加仓条件:
│   ├── 强趋势 + 回撤到关键支撑/阻力 + 高概率建仓形态 → 可加仓
│   │   EXCEPT 总风险超过日上限；已有亏损仓位
│   └── 否则 → 不加仓
│
└── 减仓条件:
    ├── 达到第一目标 → 平1/3-1/2
    ├── 达到第二目标 → 再平1/3
    ├── 市场进入铁丝网 → 全部获利了结
    └── 方程式转负 → 至少平50%
```

> **核心原则**：永远不要对亏损仓位加仓（除非对大局有信心）。加仓后总风险不得超过日风险上限。
