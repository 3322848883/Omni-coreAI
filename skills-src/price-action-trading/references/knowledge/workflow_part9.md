#### 3.6.1 信号棒评估基础框架（9条核心规则）

> 来源：theme15_signal_bar_standards.md 第15.1章（行24-34）

| # | 核心规则 | 交易应用 |
|---|---------|---------|
| 1 | 架构是一种图表形态，由一条或多条棒线构成，使交易者相信可以设定胜率较高的订单 | 识别有效架构是入场前提 |
| 2 | 图表上的每一棒都是一个架构，因为下一棒总可能是任一方向上的强势运动的开始 | 保持对每根K线的警觉 |
| 3 | 信号棒总是在事后标注的，是在该棒已经收盘和交易已经入场之后 | 不要在K线形成过程中预判 |
| 4 | 入场订单一执行，前一棒便成了信号棒，当前棒便是入场棒 | 明确信号棒→入场棒→坚持到底棒的时序关系 |
| 5 | 入场之后的棒线是坚持到底棒，当在你的入场方向上又出现一棒时总要好一些 | 评估入场后的跟进质量 |
| 6 | 多方的买进止损单位于前一棒高点上方，空方的卖出止损单位于同一棒低点的下方 | 止损位设定的标准位置 |
| 7 | 每一棒都是信号棒，多方和空方都在顶部和底部突破时入场 | 理解多空双方的行为逻辑 |
| 8 | 每一棒都可以看作是一个单棒交易区间 | 单棒交易区间的判断依据 |
| 9 | 无论你对自己决策多么自信，总有一个同样聪明的人认为相反的情况会发生 | 保持谦逊，严格风控 |

#### 3.6.3 逆势交易信号棒选择规则（13条）

> 来源：theme15_signal_bar_standards.md 第15.3章（行77-91）

| # | 规则原文 | 应用要点 |
|---|---------|---------|
| 1 | 初学交易者应该仅在信号棒同时也是交易方向上的趋势棒时入场，而且应该仅在趋势方向上交易 | 初学者只做顺势交易 |
| 2 | 与趋势回撤和交易区间交易所需的信号棒相比，交易者应该对趋势反转入场要求更强的信号棒 | 逆势交易需要更强的信号棒 |
| 3 | 这是因为大多数逆势交易失败，你需要尽一切可能来提升成功率 | 理解逆势交易的高失败率 |
| 4 | 最强的趋势通常有着外观丑陋的信号棒，但交易仍然是极好的 | 强趋势中不要苛求完美信号棒 |
| 5 | 如果一个架构太明显，那么市场将迅速修正那种矛盾 | 警惕"过于明显"的架构 |
| 6 | 波段交易架构通常只有50%或更低的胜率 | 波段交易需要更大回报补偿 |
| 7 | 强趋势会竭尽所能地把交易者排除在外，迫使他们在市场无情前进时追逐趋势 | 强趋势中不要等待完美回撤 |
| 8 | 交易区间顶部的二次入场反转架构常常拥有具有多头实体的信号棒，而底部的买进架构常常拥有具有空头实体的信号棒 | 区间交易中信号棒可能不完美 |
| 9 | 由于大多数趋势反转尝试会失败，所以交易者应该仅在一切看起来完美的情况下考虑反转交易 | 反转交易需要完美条件 |
| 10 | 除了绝对强劲的逆势交易之外，初学者应该避开所有逆势交易 | 初学者避免逆势交易 |
| 11 | 任何交易者应该仅在整体图表都支持反转时才考虑逆势交易 | 整体图表支持是逆势前提 |
| 12 | 最低限度，交易者应该等待趋势线的强势突破后的回撤，并且仅在强势反转棒出现时交易 | 趋势线突破+回撤+强反转棒 |
| 13 | 趋势的持续时间一般比大多数交易者所认为的要长得多，结果导致大多数反向交易失败 | 趋势持续时间往往超预期 |

#### 3.6.4 最佳反转棒特征

> 来源：theme15_signal_bar_standards.md 第15.4-15.5章

##### 多头反转棒

**最小特征**（必须满足）：
- [ ] 收盘价高于开盘价（多头实体），**或者**
- [ ] 收盘价高于其中点

**最佳特征**（越多越好）：
- [ ] 特征1：开盘价接近或低于前一棒线的收盘价，收盘价高于开盘价，并且高于前一棒线的收盘价
- [ ] 特征2：下尾线长度约为棒线高度的三分之一到二分之一，上尾线较短或不存在
- [ ] 特征3：与前一条或前面多条棒线没有重叠
- [ ] 特征4：信号棒之后的棒线不是一条十字星内包棒线，而是一条强势入场棒线（实体相对较大、尾线相对较短的多头趋势棒）
- [ ] 特征5：收盘价反转了多于一条棒线的收盘价和最高价

##### 空头反转棒

**最小特征**（必须满足）：
- [ ] 收盘价低于开盘价（空头实体），**或者**
- [ ] 收盘价低于其中点

**最佳特征**（越多越好）：
- [ ] 特征1：开盘价接近或高于前一棒线的收盘价，收盘价远低于前一棒线的收盘价
- [ ] 特征2：上尾线长度约为棒线高度的三分之一到二分之一，下尾线较短或不存在
- [ ] 特征3：与前一条或前面多条棒线没有重叠
- [ ] 特征4：信号棒之后的棒线不是一条十字星内包棒线，而是一条强势入场棒线
- [ ] 特征5：收盘价反转了多于一条棒线的收盘价和低点

#### 3.6.5 反转棒强度判断与陷阱识别（10条规则）

> 来源：theme15_signal_bar_standards.md 第15.6章（行137-148）

| # | 规则原文 | 判断要点 |
|---|---------|---------|
| 1 | 收盘价反转了多于一条棒线的收盘价和最高价/低点的反转棒，通常比仅反转前一棒的反转棒更强 | 反转范围越大，信号越强 |
| 2 | 市场可能在任意棒线之后趋势上涨或下跌，因此每一棒都是既可用于多头入场又可用于空头入场的架构棒 | 保持双向思维 |
| 3 | 仅当交易在下一棒入场时，架构棒变成信号棒 | 等待确认 |
| 4 | 架构棒本身并不是进入交易的一个理由，必须与它前面的棒线联系在一起观察 | 结合上下文 |
| 5 | 因为顺势交易总是最明智的选择，所以当信号棒是交易方向上的强势趋势棒时，交易最有可能成功 | 顺势信号棒优先 |
| 6 | 趋势越强，顺势交易对强信号棒的要求就越低，逆势交易对强信号棒的要求就越高 | 趋势强度与信号棒要求成反比（顺势）/正比（逆势） |
| 7 | 在正确的一方至少已经控制了信号棒后入场总是要好得多 | 等待信号棒确认 |
| 8 | 当信号棒较大，而且与前两棒或三棒有较大重叠时，它是交易区间的一部分 | ⚠️**陷阱信号：重叠过多=交易区间** |
| 9 | 当多头反转棒的中点高于前一棒低点时，重叠可能过多，表明交易区间正在形成 | ⚠️**陷阱信号：中点重叠** |
| 10 | 大约60%的时间里，恰在均线上方的多头旗形中如果有三条或多条基本重叠的大棒线，那么通常都是陷阱 | ⚠️**陷阱信号：60%概率陷阱** |

#### 3.6.6 外包棒详细规则（8条核心规则）

> 来源：V1_B04_P151-200.md 第7章（行487-552）

| # | 规则原文 | 交易应用 |
|---|---------|---------|
| 1 | 根据定义，因为外包棒与前一棒完全重叠，所以每条外包棒都是交易区间的一部分 | 外包棒=交易区间信号 |
| 2 | 在5分钟外包棒的突破入场，几乎总是不明智的，特别是当外包棒的波幅较大时 | ⚠️**禁止在外包棒突破入场** |
| 3 | 交易者不应在外包棒上入场反转交易，除非它前面的棒线是一条不错的信号棒 | 外包棒反转需要前置信号棒支持 |
| 4 | 如果外包棒出现在交易区间的中间价位，那么它就毫无价值 | 中间价位的外包棒忽略 |
| 5 | 关于外包棒，最重要的一点是，每当交易者不确定做什么时，最佳决策是等待更多的价格行为形成 | 不确定时等待 |
| 6 | 当顺势外包棒出现在趋势反转的第一条腿中，而且先前的趋势很强时，那么它的作用就类似一条强趋势棒 | 特殊情境下的强信号 |
| 7 | 外包棒与前一棒完全重叠 | 定义确认 |
| 8 | 外包棒的多种变体形式（需结合具体图表分析） | 灵活应用 |

#### 3.6.9 术语速查引用

> 来源：theme12_abbreviations.md

**核心术语标准化**（AI分析时使用）：

| 缩写 | 英文全称 | 中文 | 定义 |
|-----|---------|------|------|
| AIL | Always In Long | 始终做多 | 持续持有多头头寸，相信价格会持续上涨 |
| AIS | Always In Short | 始终做空 | 持续持有空头头寸，相信价格会持续下跌 |
| BOP | Breakout Pullback | 突破回撤 | 价格突破关键水平后的回调或回撤，常用于确认趋势 |
| BW | Barbwire | 铁丝网 | 紧凑的交易区间，K线重叠严重且方向不明确，不应交易 |
| MTR | Major Trend Reversal | 主要趋势反转 | 需满足四个条件：趋势线突破、测试旧极端、反转走得足够远、新趋势建立 |

#### 只需一个理由的例外（来源：V2_B08_P351-400.md P364）

> "无论什么时候出现一轮强趋势，你必须在不是高潮或最终旗形反转之后形成的每个回撤入场。"

**核心规则**：

| 场景 | 规则 | 原因 |
|------|------|------|
| 强趋势中的回撤 | 每个回撤都是入场机会 | 趋势惯性，延续概率高 |
| 非高潮后 | 必须入场 | 错过回撤=错过趋势 |
| 非最终旗形后 | 必须入场 | 趋势尚未结束 |

**应用检查清单**：

- [ ] **强趋势确认**（满足多个条件）：
  - [ ] 趋势持续超过20棒
  - [ ] 大多数K线为顺势趋势K线
  - [ ] 回撤幅度小（<38.2%）
  - [ ] Always In方向明确
  
- [ ] **排除条件**（任一满足则暂停）：
  - [ ] 刚出现买进/卖出高潮
  - [ ] 刚出现最终旗形反转
  - [ ] 趋势通道线严重过冲
  - [ ] 出现强反转K线组合
  
- [ ] **入场执行**：
  - [ ] 回撤出现即准备入场
  - [ ] 不需要等待完美信号棒
  - [ ] 可以使用市价单或限价单
  - [ ] 止损设在回撤极值点
