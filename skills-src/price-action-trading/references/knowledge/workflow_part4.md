#### 市场惯性原则（来源：theme16_price_action_basics.md）

> 在交易中，刚刚发生的事情将会继续反复发生的几率大于70%或更高。

**惯性规则应用**：

| 市场状态 | 惯性概率 | 交易含义 |
|---------|:-------:|---------|
| 强趋势中 | >70% | 趋势延续概率高，顺势交易优先 |
| 交易区间中 | >70% | 区间延续概率高，双向交易或等待突破 |
| 突破尝试 | ~60% | 突破失败概率约40%，谨慎追涨 |
| 反转尝试 | ~80% | 反转失败概率高，等待确认 |

**惯性交易原则**：

- [ ] **趋势惯性**：
  - [ ] 强趋势中，反转尝试失败概率约80%
  - [ ] 不要在强趋势中期待快速反转
  - [ ] 顺势回撤入场优于逆势反转交易
  
- [ ] **区间惯性**：
  - [ ] 交易区间中，突破失败概率约80%
  - [ ] 区间顶部做空、底部做多
  - [ ] 不要在区间中点入场（概率50%）
  
- [ ] **决策应用**：
  - [ ] 默认假设：当前状态将继续
  - [ ] 需要强证据才预期状态改变
  - [ ] 反转交易需要至少2-3个确认信号

### 步骤 1.2 判断 Always In 方向
→ [Theme8](theme8_daytrading_part1.md) Ch15

- [ ] **核心问题**：如果必须此刻入场，你会选择多头还是空头？（最低标准：只需51%的确定性；大部分此类信号有60%或更高确定性）
- [ ] **判断依据**：
  - [ ] 趋势方向上的急速是否存在？
  - [ ] 最近的主要走势方向是什么？
  - [ ] EMA20的位置和斜率？
  - [ ] 最近10根K线中有多少根主要在EMA上方/下方？
  - [ ] 连续的趋势K线是否表明Always In方向？
  - [ ] 突破后的跟随（Follow-Through）是否确认方向？
- [ ] **判断方法**：
  - [ ] 趋势突破重要交易区间或趋势线 → 确认方向
  - [ ] 极端位置形成强反转K线 → 方向可能翻转
  - [ ] 移动平均线斜率向上 + 大多数K线在上方 → Always In Long
  - [ ] 移动平均线斜率向下 + 大多数K线在下方 → Always In Short
- [ ] **Always In 方向结论**：
  - [ ] Always In Long → 只寻找买入建仓形态
  - [ ] Always In Short → 只寻找卖出建仓形态
  - [ ] 不确定 → 减少仓位或等待
- [ ] **Always In 方向变更信号**（⚠️80%的反转尝试都会失败，变更需要强证据）：
  - [ ] 趋势线被强势突破
  - [ ] 趋势通道线超越（Overshoot）后反转
  - [ ] 强反转K线在极端位置
  - [ ] 双顶/双底形成 + 趋势线突破确认
  - [ ] 最终旗形（Final Flag）突破失败

#### Always In量化判断标准（原文：V3_B05 第15章）
- [ ] 如果 近期大部分棒线收盘在均线上方 → 则 Always In = 多头
- [ ] 如果 近期大部分棒线收盘在均线下方 → 则 Always In = 空头
- [ ] 如果 交易区间之前的运动是上涨 → 则 Always In 偏向多头
- [ ] 如果 交易区间之前的运动是下跌 → 则 Always In 偏向空头
- [ ] 如果 连续出现两条强度合理的同方向趋势棒 → 则 形成新的Always In方向
- [ ] 如果 不能确定方向 → 则 市场处于交易区间内，准备低买高卖
- [ ] 如果 市场处于紧凑交易区间 → 则 不使用Always In方法
→ 深度知识：[Theme2](theme2_trends_part1.md)、原文V3_B05

### 步骤 1.3 识别趋势类型（7种日类型）
→ [Theme2](theme2_trends_part1.md) Ch21-26 | [Theme14](theme14_trend_day_types.md) 完整趋势日交易方法

- [ ] **类型1：急速与通道趋势（Spike and Channel）** → [Theme2](theme2_trends_part1.md) Ch21
  - [ ] 有明显的急速突破阶段
  - [ ] 后续是通道运行
  - [ ] 急速高度提供测量移动目标
  - [ ] 通道中可以开始考虑逆势交易（经验丰富者）
  - [ ] 变体：急速与高潮、缺口急速、陡峭通道即急速
- [ ] **类型2：趋势区间日（Trending Trading Range Day）** → [Theme2](theme2_trends_part1.md) Ch22
  - [ ] 当天以一个交易区间开始
  - [ ] 然后突破进入更高的或更低的交易区间
  - [ ] 通常在当天晚些时候回撤
  - [ ] 两个方向的交易都有机会，但应专注于顺势交易
  - [ ] 头两个小时的区间通常约为平均每日区间的一半
  - [ ] 有时会形成多个突破和交易区间
  - [ ] 当突破非常强时，可能成为弱势尖峰和通道趋势
- [ ] **类型3：从开盘开始的趋势（Trend from the Open）** → [Theme2](theme2_trends_part1.md) Ch23
  - [ ] 从第一根或最初几根K线开始
  - [ ] 延伸很多K线没有回撤
  - [ ] 趋势起点保持为当天极端之一
  - [ ] 最强的趋势日类型
  - [ ] 一旦识别，必须至少持有一个小头寸
- [ ] **类型4：小回撤趋势日（Small Pullback Trend）** → [Theme2](theme2_trends_part1.md) Ch23
  - [ ] 最大回撤非常小
  - [ ] 买入信号看起来很差但趋势很强
  - [ ] 经验丰富的交易者坚持买入
  - [ ] 没有一个回撤会触及两点资金止损
- [ ] **类型5：反转日（Reversal Day）** → [Theme2](theme2_trends_part1.md) Ch24
  - [ ] 当天以一种趋势开始
  - [ ] 然后进入交易区间
  - [ ] 最终以相反方向的趋势收盘
  - [ ] 开盘在一个极端，收盘在另一个极端
  - [ ] ⚠️大多数反转日都是从趋势型交易区间日开始的
- [ ] **类型6：趋势恢复日（Trend Resumption Day）** → [Theme2](theme2_trends_part1.md) Ch25
  - [ ] 早上有强趋势（急速）
  - [ ] 然后进入交易区间数小时（尤其是紧凑的交易区间）
  - [ ] 趋势在最后一两个小时恢复（进入收盘）
  - [ ] 最终恢复前通常有顶部突破的失败
  - [ ] ⚠️在午盘令人厌倦的交易区间中不要放弃，最后一小时左右可能出现很强的趋势
- [ ] **类型7：阶梯/宽通道趋势（Stairs / Broad Channel Trend）** → [Theme2](theme2_trends_part1.md) Ch26
  - [ ] 至少三个交易区间，宽幅摆动，但有趋势高点和低点
  - [ ] 类似倾斜的交易区间
  - [ ] **三种变体**：
    - [ ] 空头台阶（Bear Stairs）：向下通道中每次新低后回撤超越突破点
    - [ ] 台阶加速（Stair Acceleration）：台阶突破通道后加速进入强趋势（积极信号）
    - [ ] 收缩阶梯（Contracting Staircase）：每次突破幅度递减，动量衰退（减弱信号）

**台阶形态具体交易规则**（原文V1_B09）：

**空头台阶规则**：
1. 交易者们要注意突破超越最近波段点的跳动数，然后利用那个数据在随后的突破做逆突破交易，预期出现突破测试
2. 如果上个波段低点比它前面的波段低点低14个跳动，那么准备在最近的波段低点下方10个跳动左右开始对多头头寸逐步加仓
3. 如果最近的突破回撤幅度约为15个跳动，那么准备在低点上方10到15点处获利了结
4. 这种类型的交易只适用于经验丰富的交易者。初学者应该约束自己停止入场，让市场继续行进

**台阶加速规则**：
> "台阶形态可能加速进入更强的趋势。当价格在通道内形成三个或更多更高高点和低点后，可能突破通道进入强趋势。"

**收缩台阶规则**：
> "当每个突破都小于前一个时，趋势的动能正在衰退，不久将会出现更深的回撤或反转。"

#### 1.4.2 失败反转入场价位 = 磁力位

> 来源：V2_B03_P101-150.md P114

**核心规则**：

> "失败的早期反转的入场价位，常常成为后来的成功反转的一个磁力位。"

**应用示例**：
- 如果出现一轮空头趋势，在市场继续下跌的过程中出现几个失败的多头入场
- 一旦市场最后成功向上反转，之前的每个入场价位和每条信号棒的高点都将成为市场运动的目标
- 反转后第一个可能的顶部是早先那些多头入场价位

**交易者心理模式**：
- 在亏损头寸上加仓的交易者以盈亏平衡为退出目标
- 这创造了可预测的支撑/阻力水平
- 当价格上次到达那里时方向概率偏向空头，再次到达时通常再次偏向空头

#### 1.4.3 充分测试阈值

> 来源：V2_B03_P101-150.md P109

**核心规则**：

> "除非市场至投影目标的距离不超过1-2个跳动，否则目标仍没有得到足够的测试。"

**充分测试判断标准**：

| 条件 | 是否充分测试 | 交易含义 |
|------|-------------|---------|
| 市场距离目标 ≤ 1-2个跳动 | 是 | 目标已测试，关注反转信号 |
| 市场距离目标 > 2个跳动 | 否 | 目标未测试，继续顺势交易 |
| 市场过冲目标后反转 | 是 | 测试完成，可能反转 |
| 市场未及目标即反转 | 否 | 测试不充分，可能再次测试 |
