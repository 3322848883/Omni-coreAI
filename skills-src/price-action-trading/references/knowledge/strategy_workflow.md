# Al Brooks 价格行为交易 — 策略决策树与规则引擎

## 第1章：总览

### 1.1 使用说明

本文档定位为**策略决策层**，与 Al Brooks 价格行为交易知识库互补使用：

- **知识库**：提供概念定义、原理分析和案例说明（"为什么"）
- **本文档**：提供可执行的决策流程和规则引擎（"做什么"和"怎么做"）
- **交易工作流**：完整的7阶段交易流程（盘前→分析→开盘→信号→执行→管理→复盘）见 [workflow.md](workflow.md)

建议使用方式：先通过知识库理解概念，再通过本文档进行实战决策。

### 1.2 设计原则

1. **基于知识库实际内容**：所有规则和概率数据均可追溯至知识库具体章节
2. **概率数据可追溯**：每条规则标注来源（Theme + Chapter）
3. **通用框架用占位符**：具体数值参数用 `[占位符]` 表示，交易者根据自身市场和经验填充
4. **IF-THEN-EXCEPT 结构**：每条规则包含触发条件、执行动作和排除条件
5. **优先级分级**：P0（禁止）到 P5（最低），高优先级规则优先执行

### 1.3 决策树使用方法

1. 从第2章的市场状态判断决策树开始，确定当前市场环境
2. 根据市场状态，进入对应的规则引擎（第3-5章）
3. 使用第6章的入场信号优先级表选择具体建仓形态
4. 执行交易后，遵循第7-9章的止损、出场和仓位管理规则
5. 始终遵守第10章的风控规则和第12章的禁止交易清单和第13章的冲突处理规则

### 1.4 规则引擎格式说明

**规则格式**：`IF [条件] THEN [动作] EXCEPT [排除条件]`

**优先级体系**：

| 优先级 | 含义 | 说明 |
|--------|------|------|
| P0 | 禁止/强制 | 必须遵守，违反则不交易或立即平仓 |
| P1 | 最高 | 高概率建仓形态，优先执行 |
| P2 | 高 | 常用可靠建仓形态 |
| P3 | 中 | 可用建仓形态，需额外确认 |
| P4 | 低 | 谨慎使用，需要多个确认 |
| P5 | 最低 | 仅在特殊条件下使用 |

**信号棒评估标准**（来源：[Theme15](theme15_signal_bar_standards.md) V1第4-6章 P111-P138）：

> ⚠️ 以下为原文信号棒评估标准，使用描述性语言（强/弱/可靠），非量化评级。

**信号棒基础规则**：
1. 架构是一种图表形态，使交易者相信可以设定胜率较高的订单
2. 实际上，图表上的每一棒都是一个架构
3. 信号棒总是在事后标注的（该棒收盘和交易入场之后）
4. 入场订单一执行，前一棒便成了信号棒
5. 入场之后的棒线是坚持到底棒
6. 多方的买进止损单位于前一棒高点上方，空方的卖出止损单位于同一棒低点下方
7. 每一棒都是信号棒，多方和空方都在顶部和底部突破时入场
8. 每一棒都可以看作是一个单棒交易区间
9. 无论你对自己决策多么自信，总有一个同样聪明的人认为相反的情况会发生

**信号棒选择核心原则**：
- 初学交易者应仅在信号棒同时也是交易方向上的趋势棒时入场
- 与趋势回撤相比，对趋势反转入场要求更强的信号棒（因为大多数逆势交易失败）
- 如果一个架构太明显，市场将迅速修正
- 波段交易架构通常只有50%或更低的胜率
- 趋势越强，顺势交易对强信号棒的要求越低，逆势交易对强信号棒的要求越高

**最佳多头反转棒5条特征**：
1. 开盘价接近或低于前一棒收盘价，收盘价高于开盘价且高于前一棒收盘价
2. 下尾线长度约为棒线高度的1/3到1/2，上尾线较短或不存在
3. 与前一条或前面多条棒线没有重叠
4. 信号棒之后的棒线不是十字星内包棒，而是强势入场棒
5. 收盘价反转了多于一条棒线的收盘价和最高价

**最佳空头反转棒5条特征**：
1. 开盘价接近或高于前一棒收盘价，收盘价远低于前一棒收盘价
2. 上尾线长度约为棒线高度的1/3到1/2，下尾线较短或不存在
3. 与前一条或前面多条棒线没有重叠
4. 信号棒之后的棒线不是十字星内包棒，而是强势入场棒
5. 收盘价反转了多于一条棒线的收盘价和低点

**信号棒强度判断**：
- 收盘价反转了多条棒线的反转棒，比仅反转前一棒的更强
- 当信号棒较大且与前两三棒有较大重叠时，它是交易区间的一部分
- 在正确的一方至少已经控制了信号棒后入场总是要好得多
- 大约60%的时间，恰在均线上方的多头旗形中如果有三条或多条基本重叠的大棒线，通常都是陷阱

> **注意**：以下"80%"概率适用于不同场景——区间突破失败率80%（Theme4 Ch21）、趋势中反转失败率80%（Theme1+Theme8）、通道底部突破失败~80%（趋势篇Ch14）、反转模式失败≥80%（反转篇），不可混用。

## 1.5 Always In 判断标准（权威定义）

> **Always In（始终在场）** 是 Al Brooks 价格行为交易的核心概念。市场始终处于某种状态——要么 Always In Long（AIL，始终做多），要么 Always In Short（AIS，始终做空）。判断当前 Always In 方向是所有交易决策的基础。

### 判断条件

| 条件 | AIL（Always In Long） | AIS（Always In Short） |
|------|----------------------|----------------------|
| 最近趋势方向 | 最近的高点高于前高，低点高于前低 | 最近的低点低于前低，高点低于前高 |
| EMA20位置 | 价格在EMA20上方，EMA20向上倾斜 | 价格在EMA20下方，EMA20向下倾斜 |
| K线颜色比例 | 最近10根K线中，多头K线≥6根 | 最近10根K线中，空头K线≥6根 |
| 突破行为 | 向上突破尝试成功，向下突破失败 | 向下突破尝试成功，向上突破失败 |
| 整体印象 | 市场看起来像在做多 | 市场看起来像在做空 |

### 判断规则

1. **不需要满足所有条件**：通常满足3-4个条件即可确定 Always In 方向
2. **区间中可能不确定**：在铁丝网或紧凑区间中，Always In 方向可能不明确——此时应减少交易或不交易
3. **Always In 可以切换**：方向不是固定的，当条件反转时应更新判断
4. **与交易时间级别绑定**：Always In 方向是针对当前交易时间级别的，不同时间级别可能有不同方向
5. **HTF优先**：当交易TF的Always In方向与HTF矛盾时，优先参考HTF方向

### Always In 的交易含义

| Always In方向 | 交易倾向 | 入场偏好 |
|--------------|---------|---------|
| AIL | 优先做多 | 在回撤中买入，避免做空 |
| AIS | 优先做空 | 在反弹中卖出，避免做多 |
| 不确定 | 减少交易 | 仅在极端位置限价单入场 |

> **注意**：其他文件中出现的 Always In 相关内容均为本定义的补充说明，具体应用请参考本章节。知识库依据：趋势篇 Ch22、日内交易篇 Ch15

### 4.2 区间交易关键原则

1. **区间中间不交易**：80%的区间突破会失败（Theme4 Ch21），在中间位置入场风险极高
2. **仅在极端交易**：接近上轨做空，接近下轨做多
3. **预期区间行为**：不要预期突破，除非有强突破信号
4. **铁丝网绝对禁止**：铁丝网中止损距离小但被扫概率极高
5. **失败之失败是最佳建仓形态**：在区间中，失败之失败的成功率可达65-70%（Theme5 Ch9）

### 4.3 限价单市场 vs 止损单市场（LOM vs SOM）

> **核心概念**：Al Brooks 将市场状态分为两大类——限价单市场（Limit Order Market, LOM）和止损单市场（Stop Order Market, SOM）。这决定了入场方式的选择。

| 维度 | 限价单市场（LOM） | 止损单市场（SOM） |
|------|-------------------|-------------------|
| **定义** | 用限价单比用止损单更容易赚钱的市场 | 用止损单比用限价单更容易赚钱的市场 |
| **典型状态** | 区间、铁丝网、趋势区间过渡 | 强趋势、急速期、突破 |
| **入场方式** | 在极端位置用限价单入场（区间顶部卖出、底部买入） | 用止损单顺势入场（突破方向） |
| **胜率特征** | 约50%，偏向限价单 | 约50%，偏向止损单 |
| **合理架构频率** | 约20个或更多/天 | 约10个/天 |
| **交易风格** | 刮头皮为主 | 波段为主 |

**判断标准**：

| 条件 | 偏向LOM | 偏向SOM |
|------|---------|---------|
| 趋势强度 | 无趋势或弱趋势 | 强趋势（连续趋势K线） |
| K线重叠 | 大量重叠 | 极少重叠 |
| 突破行为 | 突破频繁失败（>80%） | 突破成功跟进 |
| EMA20 | 价格围绕EMA20波动 | 价格远离EMA20 |
> **深回撤量化参考**（经验值，因品种和时间级别而异）：
>
> | 回撤级别 | 量化标准（5分钟图） | 趋势状态 | 建议操作 |
> |---------|-------------------|---------|---------|
> | 极浅 | ≤2根K线，未触及EMA20 | 极强趋势 | 积极顺势，正常仓位 |
> | 浅 | 2-5根K线，触及EMA20 | 强趋势 | 正常顺势入场 |
> | 中等 | 5-10根K线，短暂跌破EMA20 | 趋势减弱 | 仓位减至50% |
> | 深 | 10-20根K线，跌破趋势线 | 趋势可能结束 | 仅限价单极端入场 |
> | 极深 | >20根K线或回撤>趋势幅度50% | 趋势已结束 | 切换至区间/反转规则 |
>
| 回撤深度 | 深回撤（趋势减弱信号） | 浅回撤（1-3根K线） |

**关键原则**：
1. 大部分突破尝试失败，因此成功的限价单入场一般更为可靠，但很难设定
2. 盲目在每个止损信号入场是失败策略，盲目在每个信号反向使用限价单也是失败策略
3. 中间时段（美盘8:30-11:30 PST）是止损入场最差的环境，经验丰富的交易者会在区间顶部用限价单卖出、底部用限价单买入
4. 强趋势中应使用止损单入场，通道/区间中更倾向于使用限价单入场
5. 初学者应优先使用止损单入场（最可靠的方法），限价单入场需要更多经验

### 5.4 反转交易关键原则

1. **反转是最低概率的趋势交易**：成功率仅40-50%（Theme5 Ch1-3）
2. **趋势中尝试反转的失败率约80%**（Theme1 + Theme8）
3. **初学者应避免反转交易**（V-012）
4. **反转需要更多理由**：至少2-3个理由叠加才考虑入场
5. **反转的R:R必须更高**：因为胜率低，需要2:1以上的风险收益比

│   ├── 9 tick未穿过 → 九tick失败（FM-03）

## 第11章：交易者方程式速查表

### 11.1 通用公式

**交易者方程式（Trader's Equation）**：

```
期望值 = (胜率 x 平均盈利) - (败率 x 平均亏损)

期望值 > 0 → 交易可行
期望值 < 0 → 不应交易
期望值 = 0 → 边缘交易，需要更多理由
```

**简化版本（以R为单位）**：

```
期望值(R) = (胜率 x R:R) - (败率 x 1)

其中：R:R = 平均盈利 / 平均亏损（以R为单位，亏损=1R）
      败率 = 1 - 胜率
```

### 11.2 快速判断规则

| 规则编号 | 规则描述 | 公式/条件 | 说明 |
|--------|---------|----------|------|
| TE-01 | 最低胜率要求 | 胜率 > 1 / (1 + R:R) | 例如R:R=1:1时，胜率需>50% |
| TE-02 | 刮头皮要求 | 胜率 > 70%（R:R<1:1） | 刮头皮（Theme7 Ch24） |
| TE-03 | 波段要求 | 胜率 > 40%（R:R=2:1） | 标准摆动交易 |
| TE-04 | 反转要求 | 胜率 > 33%（R:R=2:1+） | 反转交易需要更高R:R补偿低胜率 |
| TE-05 | 多理由提升 | 每增加一个理由，胜率约+5-10% | 2-3个理由叠加可显著提升概率 |

## 第13章：多建仓形态冲突处理（Signal Conflict Resolution）

### 13.1 通用优先级原则

当多个建仓形态同时出现且方向矛盾时，按以下优先级选择：

| 优先级 | 原则 | 说明 |
|--------|------|------|
| 1 | 顺势 > 逆势 | 始终优先考虑与Always In方向一致的建仓形态 |
| 2 | 多时间级别一致 > 单时间级别 | HTF和交易TF方向一致时，信号更可靠 |
| 3 | 高星级 > 低星级 | ⭐⭐⭐⭐⭐ > ⭐⭐⭐ > ⭐⭐ |
| 4 | 更多理由 > 更少理由 | 3个理由的建仓形态 > 2个理由的建仓形态 |
| 5 | 等待 > 强行选择 | 如果无法判断，不交易 |

### 13.2 常见冲突场景

#### 场景1：顺势信号 vs 逆势信号
- **示例**：多头趋势中有H2做多信号，同时出现双顶空头旗做空信号
- **处理**：优先H2做多（顺势）。逆势信号仅在趋势线突破+强反转K线时考虑
- **规则**：IF 顺势信号存在 THEN 忽略逆势信号 EXCEPT 趋势线已突破且有强反转K线

#### 场景2：区间顶部/底部的双向信号
- **示例**：区间顶部有牛信号K线，但同时接近阻力位
- **处理**：不交易（区间中部），等待更接近极端位置
- **规则**：IF 在区间中间30%区域 THEN 不交易 EXCEPT 有强突破信号

#### 场景3：HTF与交易TF方向矛盾（三级判断）

- **示例**：日线看空但5分钟图出现H2做多信号
- **处理**：根据HTF一致性程度进行三级判断：

| 判断级别 | HTF一致性 | 处理方式 | 仓位 | 说明 |
|---------|----------|---------|------|------|
| **一致** | HTF 3/5+方向与交易TF信号一致 | 正常入场 | 100%标准仓位 | HTF提供方向优势，交易TF信号可靠 |
| **中性** | HTF 2/5方向一致或HTF为区间 | 可交易但需额外确认 | 50%标准仓位 | 仅在有⭐⭐⭐⭐建仓形态时交易，需2-3个理由叠加 |
| **矛盾** | HTF 0-1/5方向一致或HTF强趋势逆势 | **禁止交易**或跳过 | 0% | 无方向优势，等待HTF方向确认或一致性恢复 |

- **规则**：
  - IF HTF一致性 ≥ 3/5 THEN 正常入场 EXCEPT 交易TF信号棒质量差
  - IF HTF一致性 = 2/5 THEN 仓位减半 EXCEPT 交易TF信号为⭐⭐⭐⭐⭐（可用75%仓位）
  - IF HTF一致性 ≤ 1/5 THEN 禁止交易 EXCEPT HTF处于区间且有⭐⭐⭐⭐⭐建仓形态（可用25%仓位）
  - IF HTF处于强趋势且交易TF信号逆势 THEN 绝对禁止（RM-11，P0级）

#### 场景4：多个顺势信号同时出现
- **示例**：同时有H2做多和均线回撤做多
- **处理**：选择理由更多的那个，或合并为更强的建仓形态
- **规则**：IF 多个顺势信号同方向 THEN 合并理由，选择最佳入场点

#### 场景5：强趋势中的弱逆势信号 vs 弱趋势中的强逆势信号
- **示例**：强多头趋势中的弱双顶 vs 弱多头趋势中的强楔形顶
- **处理**：都不交易。强趋势中不逆势，弱趋势中等待更多确认
- **规则**：IF 趋势强度不明确 THEN 等待趋势方向确认 EXCEPT 有⭐⭐⭐⭐⭐建仓形态

### 13.3 冲突处理决策树

```
多个建仓形态同时出现？
│
├── 同方向 → 合并理由，选择最佳入场点
│
└── 反方向
    ├── 有顺势信号吗？
    │   ├── 是 → 优先顺势，忽略逆势
    │   └── 否 → 继续判断
    │
    ├── HTF方向一致吗？
    │   ├── 是 → 可以交易，正常仓位
    │   └── 否 → 缩小仓位或跳过
    │
    ├── 在区间中间30%吗？
    │   ├── 是 → 不交易
    │   └── 否 → 可以考虑
    │
    └── 建仓形态星级≥⭐⭐⭐⭐吗？
        ├── 是 → 可以考虑交易
        └── 否 → 不交易，等待更清晰的建仓形态
```

## 第14章：深回撤 vs 浅回撤分析

### 14.1 回撤深度与趋势强度

> 回撤的深度和持续时间提供关于趋势强度的信息。小幅回撤表明强趋势，大幅回撤表明趋势可能减弱。

| 回撤类型 | 定义 | 趋势含义 | 策略建议 |
|---------|------|---------|---------|
| 极浅回撤 | 1-2根K线，未触及EMA20 | 极强趋势 | 积极顺势入场，可在前一根K线极端+1 tick入场 |
| 浅回撤 | 2-5根K线，触及或接近EMA20 | 强趋势 | 在EMA20附近用限价单入场（T-009/T-109） |
| 中等回撤 | 5-10根K线，跌破EMA20后回升 | 趋势减弱信号 | 减小仓位至50%，等待更多确认 |
| 深回撤 | 10+根K线，跌破趋势线 | 趋势可能结束 | 仅限价单在极端入场，或等待区间形成 |
| 极深回撤 | 回撤超过趋势幅度的50% | 趋势大概率已结束 | 切换至区间或反转规则引擎 |

### 14.2 深回撤的关键规则

1. **深回撤改变市场性质**：一旦强劲趋势出现较大回撤，那些回撤的行为越像是交易区间，而非趋势旗形
2. **深回撤后突破方向不确定**：深回撤形成的交易区间中，突破的方向变得不那么确定
3. **机构行为变化**：深回撤后，机构仅在更深的回撤位置买入，表明信心下降
4. **概率下降**：深回撤后顺势入场的胜率从60%降至约50%或更低

### 14.3 浅回撤趋势日的特征

- 回撤都是小幅回撤，市场从未返回均线
- 价格持续缓慢远离开盘价
- 全天最大回撤很小（如仅9个跳动）
- 逆势做空是胜率非常低的交易
- 经验丰富的交易者准备在前一棒低点买进

> **知识库依据**：趋势篇 Ch7-8、概率总结

## 第15章：K线宽度与趋势强度分析

### 15.1 K线实体大小与趋势

| K线特征 | 趋势含义 | 说明 |
|---------|---------|------|
| 大实体趋势K线（趋势方向） | 趋势强劲 | 实体越大，趋势越可能延续 |
| 大实体逆趋势K线 | 可能反转信号 | 需要后续确认K线 |
| 小实体K线（窄幅棒） | 趋势减弱或犹豫 | 常见于铁丝网、ii/iii形态 |
| 长尾线小实体 | 不确定 | 必须放在先前价格行为背景中研判 |
| 实体之间无重叠 | 极强趋势 | 连续K线实体形成缺口 |

### 15.2 急速期 vs 通道期的K线特征

| 阶段 | K线特征 | 交易策略 |
|------|---------|---------|
| 急速期（Spike） | 大实体、极少重叠、短尾线 | 止损单顺势入场 |
| 通道期（Channel） | 双向交易、回撤形式 | 限价单在回撤入场 |

### 15.3 窄幅棒（Narrow Range Bar）的类型

- 内包棒（Inside Bar）
- ii/iii形态中的窄幅棒
- 宽幅棒或交易区间高点/低点附近的窄幅棒
- ioi形态中的窄幅棒

> **注意**：窄幅棒本身不是交易信号，必须结合市场背景研判。在强趋势中的窄幅棒回撤是高概率入场机会。

> **知识库依据**：趋势篇 Ch5-8、反转篇 Ch32

#### 限价单入场关键原则

1. **限价单优于止损单的场景**：在交易区间中，80%的突破尝试会失败（P-12），因此限价单比突破止损单更优
2. **弱信号K线是限价单的最佳时机**：当信号K线较弱但背景有利时，限价单可以在更好价格入场
3. **平静市场中的限价单**：在低波动（平静）市场中，限价单更容易成交且滑点更小
4. **经验要求**：LE-01/02/03/08仅限经验丰富的交易者，因为需要快速判断突破强度和市场状态
5. **与止损单的配合**：限价单入场后，止损仍应放在信号K线的另一极端+1 tick
6. **二次入场优先**：区间顶部/底部使用限价单时，二次入场（Second Entry）的概率更高（60%+ vs 50%）

## 第19章：Trade What You See — 核心交易哲学

> 来源：PDF第1章 P11（第496-498行）

### 核心原则

**Trade What You See!!!** — 这是Al Brooks最核心的交易原则之一。

| 原则 | 英文 | 描述 |
|------|------|------|
| **交易你看到的** | Trade What You See | 基于图表上的实际价格行为做决策 |
| **不要问为什么** | Don't Ask Why | 不要试图解释市场为什么在移动 |
| **市场周期变化的信号** | Signals of Market Cycle Change | 价格行为本身就是市场周期变化的信号 |

### 实战规则

1. **不要问为什么**：不要试图用新闻、基本面或逻辑来解释价格行为。图表告诉你需要知道的一切
2. **只交易你看到的**：如果图表显示趋势，做趋势交易；如果显示区间，做区间交易。不要交易你"认为"应该发生的事
3. **接受不确定性**：价格行为始终在灰色迷雾中，接近就足够接近了
4. **市场周期信号**：当价格行为出现变化（如惊喜K线、趋势线突破、高潮反转），这就是市场周期变化的信号，据此调整策略
5. **不要预测**：预测是输家的游戏。交易者应该对正在发生的事情做出反应，而不是预测将要发生的事情

### 与规则引擎的关系

- Trade What You See 是所有规则引擎的底层哲学
- 决策树（第2章）的每一步都是基于"你看到了什么"，而非"你认为会怎样"
- 当价格行为与你的预期矛盾时，永远相信价格行为

## 第20章：入场后管理决策树

> **定位**：入场后立即执行，并每根K线收盘后动态监控。这是交易生命周期闭环的关键环节。

### 20.1 入场后立即执行

```
入场成交后立即执行:
│
├── [1] 确认成交价格、时间、仓位大小
├── [2] 立即设置保护性止损（不使用心理止损）
├── [3] 设置第一目标限价单
└── [4] 评估入场K线质量
    ├── 强趋势棒（与交易方向一致）→ 止损移至入场棒另一端外1 tick
    ├── 十字星 → 不调紧止损，允许1-2 tick回撤
    ├── 外包棒（与交易方向一致）→ 止损移至外包棒另一端外1 tick
    └── 内包棒 → 保持信号棒止损（内包棒是单棒交易区间）
```

### 20.2 持仓中动态监控决策树

```
每根K线收盘后执行:
│
├── Q1: Always In方向是否改变？
│   ├── 连续3根K线收盘在EMA另一侧 → 评估提前平仓
│   │   EXCEPT 趋势极强且仅1-2根K线反向
│   └── 无明显改变 → 继续持仓
│
├── Q2: 是否出现反转信号？
│   ├── 双顶/双底/楔形/高潮出现 → 收紧止损至信号K线极端
│   │   EXCEPT 反转信号在铁丝网中（不可靠）
│   └── 无反转信号 → 继续
│
├── Q3: 是否触及关键磁铁？
│   ├── 到达EMA/前高/测量移动目标 → 部分获利或移动止损
│   └── 未触及 → 继续
│
├── Q4: 是否达到目标位？
│   ├── 达到第一目标 → 平1/3-1/2仓位，止损移至保本
│   ├── 达到第二目标 → 再平1/3仓位
│   └── 未达到 → 继续
│
├── Q5: 市场是否进入铁丝网？
│   ├── 3根+K线大量重叠+十字星 → 考虑全部获利了结
│   └── 否 → 继续
│
└── Q6: 交易者方程式是否仍为正？
    ├── 当前R:R使方程式为负 → 评估提前平仓
    └── 为正 → 继续持仓
```

### 20.3 追踪止损规则

| 规则ID | 优先级 | IF（条件） | THEN（动作） | EXCEPT | 知识库依据 |
|--------|--------|-----------|-------------|--------|-----------|
| TS-01 | P1 | 多头持仓 + 创新高 | 止损移至最近波段低点下方1 tick | 趋势明显减弱 | Theme7 Ch29 |
| TS-02 | P1 | 空头持仓 + 创新低 | 止损移至最近波段高点上方1 tick | 趋势明显减弱 | Theme7 Ch29 |
| TS-03 | P2 | 价格达到1R盈利 | 止损移至盈亏平衡点 | 无 | Theme7 Ch24 |
| TS-04 | P2 | 价格达到2R盈利 | 止损移至1R盈利位置 | 无 | Theme7 Ch24 |
| TS-05 | P3 | 持仓超过5根K线未达目标 | 考虑收紧止损或平仓 | 目标即将触及 | Theme7 Ch24 |

### 20.4 仓位缩放决策

```
仓位调整判断:
│
├── 加仓条件:
│   ├── 强趋势 + 回撤到关键支撑/阻力 + 高概率建仓形态 → 可加仓
│   │   EXCEPT 总风险超过日上限；已有亏损仓位
│   └── 否则 → 不加仓
│
└── 减仓条件:
    ├── 达到第一目标 → 平1/3-1/2
    ├── 达到第二目标 → 再平1/3
    ├── 市场进入铁丝网 → 全部获利了结
    └── 方程式转负 → 至少平50%
```

> **核心原则**：永远不要对亏损仓位加仓（除非对大局有信心）。加仓后总风险不得超过日风险上限。

## 第21章：失败处理决策树

> **定位**：止损触发后或交易失败后的处理流程。这是交易纪律的核心环节。

### 21.1 止损触发后决策树

```
止损触发后:
│
├── Step 1: 立即确认止损成交
│
├── Step 2: 情绪管理
│   ├── 不要立即反向交易（情绪化决策）
│   └── 深呼吸，保持冷静
│
├── Step 3: 失败原因分析
│   ├── 市场状态判断错误？→ 重新评估市场状态
│   ├── 建仓形态识别错误？→ 记录错误模式
│   ├── 信号K线质量不够？→ 提高信号棒筛选标准
│   ├── 止损设置太紧？→ 调整止损策略
│   └── 入场时机不对？→ 等待更清晰的信号
│
└── Step 4: 等待下一个清晰的建仓形态
    └── 不追单，不报复性交易
```

### 21.2 失败突破分类处理

| 失败类型 | 定义 | 处理策略 | 规则ID |
|---------|------|----------|--------|
| **一tick失败** | 突破信号K线1 tick后立即反转 | 在被套者止损处入场，反向刮头皮 | FB-01 |
| **五tick失败** | 触及5 tick利润目标但未穿过 | 动量丧失信号，移至保本或考虑反向 | FB-02 |
| **九tick失败** | 触及9 tick利润目标但未穿过 | 常成为反转第一个征兆，考虑反向入场 | FB-03 |
| **失败之失败** | 失败信号本身又失败 | 确认原趋势极强，顺势追单 | FB-04 |

### 21.3 失败突破后机会识别

```
失败突破后:
│
├── Q1: 失败突破是否创造逆势建仓形态？
│   ├── 是 → 评估反向入场机会
│   └── 否 → 继续
│
├── Q2: 是否有"失败之失败"机会？
│   ├── 是 → 最佳入场机会之一（65-70%成功率）
│   └── 否 → 继续
│
├── Q3: 双方是否都被困？
│   ├── 是 → 高概率建仓形态
│   └── 否 → 等待
│
└── Q4: 失败突破后通常至少有两腿反向移动
    └── 等待第一腿完成后再评估
```

### 21.4 连续亏损纪律

```
连续亏损处理:
│
├── 1-2次亏损:
│   └── 正常交易，遵守规则，不急于翻本
│
├── 3次亏损:
│   ├── 降低仓位至50%
│   └── 禁止加仓
│
├── 4次亏损:
│   ├── 暂停交易15-30分钟
│   ├── 回顾前3笔交易
│   └── 检查是否偏离交易计划
│
└── 5次+亏损:
    ├── 停止当日交易
    ├── 完整复盘所有交易
    └── 次日重新开始
```

| 规则ID | 优先级 | IF（条件） | THEN（动作） | 知识库依据 |
|--------|--------|-----------|-------------|-----------|
| FL-01 | P0 | 连续亏损3笔 | 仓位减至50%，禁止加仓 | Theme9 Ch6 |
| FL-02 | P0 | 连续亏损4笔 | 暂停交易15-30分钟 | Theme9 Ch6 |
| FL-03 | P0 | 连续亏损5笔 | 停止当日交易 | Theme9 Ch6 |
| FL-04 | P1 | 单笔亏损>2R | 冷却1-2小时，深度复盘 | Theme9 Ch6 |
| FL-05 | P0 | 日亏损达上限 | 当日停止交易 | RM-01 |

### 21.5 被套交易处理

```
被套后评估:
│
├── Q1: 是否触及止损？
│   ├── 是 → 执行止损（不要移动止损）
│   └── 否 → 评估持有
│
├── Q2: 是否仍在风险承受范围内？
│   ├── 是 → 评估是否有反转信号
│   └── 否 → 立即减仓或平仓
│
├── Q3: 是否形成反转信号？
│   ├── 是 → 考虑加仓摊平（仅限经验丰富者）
│   └── 否 → 等待
│
└── Q4: 心理状态是否适合继续交易？
    ├── 否 → 平仓，进入冷却期
    └── 是 → 继续观察
```

## 第23章：心理状态检查决策树

> **定位**：交易前/中/后的心理状态评估。心理因素是交易成功的关键变量。

### 23.1 交易前心理准备（5分钟流程）

```
交易前心理检查:
│
├── [1] 身体状态
│   ├── 休息充足？
│   ├── 饮食正常？
│   └── 无酒精/药物影响？
│
├── [2] 情绪状态
│   ├── 平静/焦虑/兴奋/沮丧？
│   └── 是否适合交易？
│
├── [3] 心理准备
│   ├── 接受今日可能亏损
│   ├── 遵守计划
│   └── 不报复性交易
│
├── [4] 交易计划确认
│   ├── 今日偏向方向？
│   ├── 关键价位？
│   └── 风险上限？
│
└── [5] 认知偏差检查
    ├── 锚定效应？
    ├── 确认偏差？
    └── 过度自信？
```

### 23.2 不适合交易的信号

| 信号 | 判断标准 | 处理方式 | 规则ID |
|------|---------|----------|--------|
| 疲劳 | 睡眠<6小时或明显疲劳感 | 只观察不交易 | PS-01 |
| 情绪激动 | 愤怒/恐惧/过度兴奋 | 只观察不交易 | PS-02 |
| 分心 | 无法专注15分钟以上 | 只观察不交易 | PS-03 |
| 急于翻本 | 连亏后想"一把翻回来" | 只观察不交易 | PS-04 |
| 过度自信 | 连胜后觉得"看透市场" | 减仓50% | PS-05 |
| 未完成准备 | 盘前检查未完成 | 只观察不交易 | PS-06 |
| 净值曲线触发 | 净值曲线管理规则触发 | 只观察不交易 | PS-07 |

### 23.3 认知偏差应对策略

| 偏差类型 | 交易表现 | 应对策略 | 规则ID |
|---------|---------|---------|--------|
| **确认偏差** | 只看到支持自己方向的信号 | 主动寻找反面证据："如果我要反向交易，理由是什么？" | CB-01 |
| **锚定效应** | 被入场价/前高前低锚定 | 问："如果我现在空仓，会入场吗？" | CB-02 |
| **处置效应** | 过早卖出盈利、持有亏损 | 使用追踪止损让利润运行；入场前设定止损绝不修改 | CB-03 |
| **沉没成本** | 因已亏损而拒绝止损 | 每笔交易独立；问："这笔交易如果现在入场，我会做吗？" | CB-04 |
| **近因偏差** | 最近事件影响过大 | 回顾周度/月度统计，以长期数据为依据 | CB-05 |
| **过度自信** | 连胜后加大仓位/放宽标准 | 固定仓位大小；连胜3笔后主动缩小仓位至50% | CB-06 |
| **可得性偏差** | 最近大亏后过度规避 | 以统计数据为依据，不以单次经历为依据 | CB-07 |
| **损失厌恶** | 亏损痛苦>盈利快乐 | 记住：小亏是交易成本，大亏才是致命的 | CB-08 |

### 23.4 连胜连亏心理管理

```
连胜处理:
│
├── 连胜3笔:
│   └── 主动缩小仓位至50%作为"保护"
│
├── 连胜5笔:
│   └── 强制休息15分钟，回顾规则
│
└── 连胜7笔+:
    └── 当日停止交易，深度复盘
```

```
连亏处理:
│
├── 连亏2笔:
│   └── 缩小仓位至50%
│
├── 连亏3笔:
│   └── 停止交易当日
│
└── 连亏5笔+:
    └── 停止交易一周，完整复盘
```

> **核心原则**：连胜是概率的正常波动，不是能力的证明；连亏是概率的正常波动，不是系统的失败。

# 第24章：交易执行规则引擎（v33 新增）

> 基于 account-watcher 实际工具能力。
> 所有规则引用原文出处，遵循先执行后写入原则。

## 24.1 执行硬约束（HC-01~10）

```
IF HC-01 交易者方程式为正值 → 通过
  ELSE → ❌ 不下单（V2 P281）

IF HC-02 止损 ≥ 品种最小精度 → 通过
  ELSE → ❌ 不下单（SA-04）

IF HC-03 止损 ≤ ATR14 × 2 → 通过
  ELSE → ⚠️ 减仓50%（SA-05）

IF HC-04 BAN清单无冲突 → 通过
  ELSE → ❌ 不下单（BAN-01~15）

IF HC-05 止盈订单已计算 → 通过
  ELSE → ❌ 不下单（V2_B09 P412）

IF HC-06 止损订单已计算 → 通过
  ELSE → ❌ 不下单（V2_B09 P403）

IF HC-07 当前持仓数 ≤ 2 → 通过
  ELSE → ❌ 不下单（PM-10）

IF HC-08 当日亏损 ≤ 3% → 通过
  ELSE → ❌ 不下单（RM-02）

IF HC-09 连续亏损 ≤ 3次 → 通过
  ELSE → ⚠️ 减仓50%（FL-01~05）

IF HC-10 不在冷却期内 → 通过
  ELSE → ❌ 不下单（CD-01~05）
```

## 24.2 场景B执行规则

```
IF 场景B（无仓无单有机会）:
  IF HC-01~10 全部通过:
    获取持仓模式 → 构建三单 → 提交入场单 → 提交止盈单 → 提交止损单
    → 写入 logs/orders/ → 更新 market_state.md
  ELSE:
    记录未通过约束 → 推送原因 → 不下单
```

## 24.3 场景C挂单管理规则

```
IF 场景C（无仓有单）:
  评估5项有效性 → 
  IF 5/5有效 → 保持
  IF 3-4/5有效 → 修改价格（DELETE旧+POST新）
  IF 1-2/5有效 → 取消挂单（DELETE）
  IF 0/5+新机会 → 取消旧+新挂单
```

## 24.4 场景D持仓管理规则

```
IF 场景D（有仓）:
  方向一致性检查 →
  IF 一致:
    止盈止损管理（TS-01~05）
    IF 达1R → 止损移至保本（SA-02）
    IF 达2R → 平50%+止损移至1R（SA-03+PP-01）
    IF 铁丝网 → 全部获利了结
  IF 不一致:
    评估平仓 → 市价平仓 → 写入 order_log.md 阶段四 → 写入 trade_review.md → 更新 memory/*.md
```
