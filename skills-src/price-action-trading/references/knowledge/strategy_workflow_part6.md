## 第21章：失败处理决策树

> **定位**：止损触发后或交易失败后的处理流程。这是交易纪律的核心环节。

### 21.1 止损触发后决策树

```
止损触发后:
│
├── Step 1: 立即确认止损成交
│
├── Step 2: 情绪管理
│   ├── 不要立即反向交易（情绪化决策）
│   └── 深呼吸，保持冷静
│
├── Step 3: 失败原因分析
│   ├── 市场状态判断错误？→ 重新评估市场状态
│   ├── 建仓形态识别错误？→ 记录错误模式
│   ├── 信号K线质量不够？→ 提高信号棒筛选标准
│   ├── 止损设置太紧？→ 调整止损策略
│   └── 入场时机不对？→ 等待更清晰的信号
│
└── Step 4: 等待下一个清晰的建仓形态
    └── 不追单，不报复性交易
```

### 21.2 失败突破分类处理

| 失败类型 | 定义 | 处理策略 | 规则ID |
|---------|------|----------|--------|
| **一tick失败** | 突破信号K线1 tick后立即反转 | 在被套者止损处入场，反向刮头皮 | FB-01 |
| **五tick失败** | 触及5 tick利润目标但未穿过 | 动量丧失信号，移至保本或考虑反向 | FB-02 |
| **九tick失败** | 触及9 tick利润目标但未穿过 | 常成为反转第一个征兆，考虑反向入场 | FB-03 |
| **失败之失败** | 失败信号本身又失败 | 确认原趋势极强，顺势追单 | FB-04 |

### 21.3 失败突破后机会识别

```
失败突破后:
│
├── Q1: 失败突破是否创造逆势建仓形态？
│   ├── 是 → 评估反向入场机会
│   └── 否 → 继续
│
├── Q2: 是否有"失败之失败"机会？
│   ├── 是 → 最佳入场机会之一（65-70%成功率）
│   └── 否 → 继续
│
├── Q3: 双方是否都被困？
│   ├── 是 → 高概率建仓形态
│   └── 否 → 等待
│
└── Q4: 失败突破后通常至少有两腿反向移动
    └── 等待第一腿完成后再评估
```

### 21.4 连续亏损纪律

```
连续亏损处理:
│
├── 1-2次亏损:
│   └── 正常交易，遵守规则，不急于翻本
│
├── 3次亏损:
│   ├── 降低仓位至50%
│   └── 禁止加仓
│
├── 4次亏损:
│   ├── 暂停交易15-30分钟
│   ├── 回顾前3笔交易
│   └── 检查是否偏离交易计划
│
└── 5次+亏损:
    ├── 停止当日交易
    ├── 完整复盘所有交易
    └── 次日重新开始
```

| 规则ID | 优先级 | IF（条件） | THEN（动作） | 知识库依据 |
|--------|--------|-----------|-------------|-----------|
| FL-01 | P0 | 连续亏损3笔 | 仓位减至50%，禁止加仓 | Theme9 Ch6 |
| FL-02 | P0 | 连续亏损4笔 | 暂停交易15-30分钟 | Theme9 Ch6 |
| FL-03 | P0 | 连续亏损5笔 | 停止当日交易 | Theme9 Ch6 |
| FL-04 | P1 | 单笔亏损>2R | 冷却1-2小时，深度复盘 | Theme9 Ch6 |
| FL-05 | P0 | 日亏损达上限 | 当日停止交易 | RM-01 |

### 21.5 被套交易处理

```
被套后评估:
│
├── Q1: 是否触及止损？
│   ├── 是 → 执行止损（不要移动止损）
│   └── 否 → 评估持有
│
├── Q2: 是否仍在风险承受范围内？
│   ├── 是 → 评估是否有反转信号
│   └── 否 → 立即减仓或平仓
│
├── Q3: 是否形成反转信号？
│   ├── 是 → 考虑加仓摊平（仅限经验丰富者）
│   └── 否 → 等待
│
└── Q4: 心理状态是否适合继续交易？
    ├── 否 → 平仓，进入冷却期
    └── 是 → 继续观察
```

## 第22章：再决策树（平仓后闭环）

> **定位**：平仓不是终点，而是下一个决策的起点。这是交易生命周期闭环的最后一环。

### 22.1 平仓后即时评估

```
平仓后:
│
├── Q1: 平仓性质？
│   ├── 止损平仓 → 进入冷却期评估（Step 22.2）
│   ├── 目标位平仓 → 评估同向再入场（Step 22.3）
│   └── 手动平仓 → 评估合理性
│
├── Q2: 市场环境扫描
│   ├── 趋势是否仍在继续？
│   ├── 是否有新设置形成？
│   └── Always In方向是否改变？
│
└── Q3: 情绪状态检查
    ├── 是否有报复性交易冲动？
    └── 心理状态是否适合立即再入场？
```

### 22.2 冷却期判断

| 触发条件 | 冷却期时长 | 冷却期活动 | 规则ID |
|---------|-----------|-----------|--------|
| 连续2笔亏损 | 15-30分钟 | 记录交易、简要复盘、深呼吸 | CD-01 |
| 连续3笔亏损 | 30-60分钟 | 完整复盘前3笔、检查交易计划 | CD-02 |
| 单笔大亏（>2R） | 1-2小时 | 深度复盘、情绪恢复、可能停止当日交易 | CD-03 |
| 情绪化交易 | 至少30分钟 | 情绪管理练习、重新阅读交易规则 | CD-04 |
| 日亏损达上限 | 当日停止 | 完整日终复盘、明日计划准备 | CD-05 |

### 22.3 再决策分支

```
冷却期结束后:
│
├── 分支A: 同向再入场
│   ├── 条件:
│   │   ├── 趋势仍在继续
│   │   ├── 新顺势设置出现
│   │   └── 方程式为正
│   └── 动作: 重新走 Step 1-6（市场分析→信号识别→入场）
│
├── 分支B: 反向交易
│   ├── 条件:
│   │   ├── 趋势线突破
│   │   ├── 测试旧极端
│   │   ├── 强反转K线
│   │   └── 至少3个理由（必须含趋势线突破）
│   └── 动作: 减少仓位（50%），使用反转规则引擎
│
└── 分支C: 观望等待
    ├── 条件:
    │   ├── 市场不明确
    │   ├── 区间中部
    │   ├── 铁丝网
    │   └── 情绪不适合
    └── 动作: 继续观察，不交易
```

### 22.4 闭环确认（再入场前最终检查）

```
再入场前最终检查:
│
├── [1] 市场状态重新确认
│   ├── 趋势/区间/Always In方向
│   └── 与平仓前是否一致？
│
├── [2] 个人状态检查
│   ├── 情绪稳定？
│   ├── 已从上笔交易学习？
│   └── 冷却期已过？
│
├── [3] 新交易理由充分
│   ├── ≥2个理由支持
│   ├── 信号K线通过评估
│   └── 止损目标合理
│
└── [4] 风险在承受范围内
    ├── ≤账户1-2%
    └── 日风险未超限
```

| 规则ID | 优先级 | IF（条件） | THEN（动作） | EXCEPT | 知识库依据 |
|--------|--------|-----------|-------------|--------|-----------|
| RD-01 | P1 | 冷却期未过 | 不交易 | 无 | Theme9 Ch6 |
| RD-02 | P1 | 情绪不稳定 | 不交易 | 无 | Theme9 Ch6 |
| RD-03 | P2 | 同向再入场 + 趋势延续 + 新设置 + 方程式为正 | 重新走Step 1-6 | 无 | SKILL Step 9.3 |
| RD-04 | P2 | 反向交易 + 趋势线突破 + 测试旧极端 + 强反转K线 + ≥3理由 | 减仓50%入场 | 初学者不做反转 | SKILL Step 9.3 |
| RD-05 | P1 | 市场不明确/区间中部/铁丝网/情绪不适合 | 观望等待 | 无 | SKILL Step 9.3 |

## 第23章：心理状态检查决策树

> **定位**：交易前/中/后的心理状态评估。心理因素是交易成功的关键变量。

### 23.1 交易前心理准备（5分钟流程）

```
交易前心理检查:
│
├── [1] 身体状态
│   ├── 休息充足？
│   ├── 饮食正常？
│   └── 无酒精/药物影响？
│
├── [2] 情绪状态
│   ├── 平静/焦虑/兴奋/沮丧？
│   └── 是否适合交易？
│
├── [3] 心理准备
│   ├── 接受今日可能亏损
│   ├── 遵守计划
│   └── 不报复性交易
│
├── [4] 交易计划确认
│   ├── 今日偏向方向？
│   ├── 关键价位？
│   └── 风险上限？
│
└── [5] 认知偏差检查
    ├── 锚定效应？
    ├── 确认偏差？
    └── 过度自信？
```

### 23.2 不适合交易的信号

| 信号 | 判断标准 | 处理方式 | 规则ID |
|------|---------|----------|--------|
| 疲劳 | 睡眠<6小时或明显疲劳感 | 只观察不交易 | PS-01 |
| 情绪激动 | 愤怒/恐惧/过度兴奋 | 只观察不交易 | PS-02 |
| 分心 | 无法专注15分钟以上 | 只观察不交易 | PS-03 |
| 急于翻本 | 连亏后想"一把翻回来" | 只观察不交易 | PS-04 |
| 过度自信 | 连胜后觉得"看透市场" | 减仓50% | PS-05 |
| 未完成准备 | 盘前检查未完成 | 只观察不交易 | PS-06 |
| 净值曲线触发 | 净值曲线管理规则触发 | 只观察不交易 | PS-07 |

### 23.3 认知偏差应对策略

| 偏差类型 | 交易表现 | 应对策略 | 规则ID |
|---------|---------|---------|--------|
| **确认偏差** | 只看到支持自己方向的信号 | 主动寻找反面证据："如果我要反向交易，理由是什么？" | CB-01 |
| **锚定效应** | 被入场价/前高前低锚定 | 问："如果我现在空仓，会入场吗？" | CB-02 |
| **处置效应** | 过早卖出盈利、持有亏损 | 使用追踪止损让利润运行；入场前设定止损绝不修改 | CB-03 |
| **沉没成本** | 因已亏损而拒绝止损 | 每笔交易独立；问："这笔交易如果现在入场，我会做吗？" | CB-04 |
| **近因偏差** | 最近事件影响过大 | 回顾周度/月度统计，以长期数据为依据 | CB-05 |
| **过度自信** | 连胜后加大仓位/放宽标准 | 固定仓位大小；连胜3笔后主动缩小仓位至50% | CB-06 |
| **可得性偏差** | 最近大亏后过度规避 | 以统计数据为依据，不以单次经历为依据 | CB-07 |
| **损失厌恶** | 亏损痛苦>盈利快乐 | 记住：小亏是交易成本，大亏才是致命的 | CB-08 |

### 23.4 连胜连亏心理管理

```
连胜处理:
│
├── 连胜3笔:
│   └── 主动缩小仓位至50%作为"保护"
│
├── 连胜5笔:
│   └── 强制休息15分钟，回顾规则
│
└── 连胜7笔+:
    └── 当日停止交易，深度复盘
```

```
连亏处理:
│
├── 连亏2笔:
│   └── 缩小仓位至50%
│
├── 连亏3笔:
│   └── 停止交易当日
│
└── 连亏5笔+:
    └── 停止交易一周，完整复盘
```

> **核心原则**：连胜是概率的正常波动，不是能力的证明；连亏是概率的正常波动，不是系统的失败。

# 第24章：交易执行规则引擎（v33 新增）

> 基于 account-watcher 实际工具能力。
> 所有规则引用原文出处，遵循先执行后写入原则。

## 24.1 执行硬约束（HC-01~10）

```
IF HC-01 交易者方程式为正值 → 通过
  ELSE → ❌ 不下单（V2 P281）

IF HC-02 止损 ≥ 品种最小精度 → 通过
  ELSE → ❌ 不下单（SA-04）

IF HC-03 止损 ≤ ATR14 × 2 → 通过
  ELSE → ⚠️ 减仓50%（SA-05）

IF HC-04 BAN清单无冲突 → 通过
  ELSE → ❌ 不下单（BAN-01~15）

IF HC-05 止盈订单已计算 → 通过
  ELSE → ❌ 不下单（V2_B09 P412）

IF HC-06 止损订单已计算 → 通过
  ELSE → ❌ 不下单（V2_B09 P403）

IF HC-07 当前持仓数 ≤ 2 → 通过
  ELSE → ❌ 不下单（PM-10）

IF HC-08 当日亏损 ≤ 3% → 通过
  ELSE → ❌ 不下单（RM-02）

IF HC-09 连续亏损 ≤ 3次 → 通过
  ELSE → ⚠️ 减仓50%（FL-01~05）

IF HC-10 不在冷却期内 → 通过
  ELSE → ❌ 不下单（CD-01~05）
```

## 24.2 场景B执行规则

```
IF 场景B（无仓无单有机会）:
  IF HC-01~10 全部通过:
    获取持仓模式 → 构建三单 → 提交入场单 → 提交止盈单 → 提交止损单
    → 写入 logs/orders/ → 更新 market_state.md
  ELSE:
    记录未通过约束 → 推送原因 → 不下单
```

## 24.3 场景C挂单管理规则

```
IF 场景C（无仓有单）:
  评估5项有效性 → 
  IF 5/5有效 → 保持
  IF 3-4/5有效 → 修改价格（DELETE旧+POST新）
  IF 1-2/5有效 → 取消挂单（DELETE）
  IF 0/5+新机会 → 取消旧+新挂单
```

## 24.4 场景D持仓管理规则

```
IF 场景D（有仓）:
  方向一致性检查 →
  IF 一致:
    止盈止损管理（TS-01~05）
    IF 达1R → 止损移至保本（SA-02）
    IF 达2R → 平50%+止损移至1R（SA-03+PP-01）
    IF 铁丝网 → 全部获利了结
  IF 不一致:
    评估平仓 → 市价平仓 → 写入 order_log.md 阶段四 → 写入 trade_review.md → 更新 memory/*.md
```
