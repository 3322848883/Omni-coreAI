### 步骤 4.1 入场方式选择
→ [Theme7](theme7_management_part1.md) Ch27-28

#### 止损入场（Stop Entry）-- 最可靠的方式

- [ ] **适用场景**：
  - [ ] 趋势中的顺势入场
  - [ ] 突破入场
  - [ ] 回撤后的顺势入场
  - [ ] 反转入场
- [ ] **操作方法**：
  - [ ] 买入：在信号K线高点上方1 tick放置买入止损
  - [ ] 卖出：在信号K线低点下方1 tick放置卖出止损
- [ ] **优势**：
  - [ ] 确认方向
  - [ ] 被困交易者提供燃料
  - [ ] 初学者应限制自己只使用这种方式
- [ ] **六tick移动才能赚四tick**（Emini）：
  - [ ] 入场买单在信号K线高点以上1 tick
  - [ ] 4 tick获利限价单在入场价以上4 tick
  - [ ] 限价单通常不会被成交，除非市场移动超过它1 tick
  - [ ] 因此总共需要信号K线以上6 tick的移动

#### 限价入场（Limit Entry）-- 需要更多经验

- [ ] **适用场景**：
  - [ ] 区间底部的买入
  - [ ] 区间顶部的卖出
  - [ ] 均线回撤买入
  - [ ] 通道中的逆向操作
  - [ ] 楼梯形态中的回撤
- [ ] **操作方法**：
  - [ ] 买入：在目标价格放置限价买单
  - [ ] 卖出：在目标价格放置限价卖单
- [ ] **优势**：
  - [ ] 更好的入场价格
  - [ ] 更大的收益风险比
- [ ] **风险**：
  - [ ] 大多数突破尝试失败
  - [ ] 限价入场通常是逆至少短期趋势的交易
  - [ ] 建仓形态数量通常是止损入场的两倍，但风险更大

#### 限价单入场策略（来源：V3_B08_P351-400.md P248）

> "利用限价单入场需要更熟练的读图技能。交易者们应该只使用限价单在趋势方向上交易。"

**核心规则**：

| # | 规则内容 | 说明 |
|---|---------|------|
| 1 | 交易者们应该只使用限价单在趋势方向上交易 | 顺势限价单，逆势用止损单 |
| 2 | 只在市场是总在场内多头时使用限价单买进 | AIL=Long时，限价买入 |
| 3 | 只在市场是总在场内空头时使用限价单卖出 | AIS=Short时，限价卖出 |
| 4 | 当使用限价单逆势交易时，成功率太低 | 逆势限价单胜率不足 |
| 5 | 低胜率将使得交易者方程为负 | 数学上不划算 |

**限价单入场检查清单**：

- [ ] **趋势方向确认**：
  - [ ] Always In方向：____（Long/Short）
  - [ ] 限价单方向与AIL一致？____（是/否）
  - [ ] 如果不一致 → ❌ 改用止损单或放弃交易
  
- [ ] **入场位置选择**：
  - [ ] 多头趋势中：在前一棒低点或下方限价买入
  - [ ] 空头趋势中：在前一棒高点或上方限价卖出
  - [ ] 回撤幅度：____%（建议<50%）
  
- [ ] **风险控制**：
  - [ ] 限价单未成交怎么办？→ 等待下一个回撤或改用止损单
  - [ ] 限价单成交后止损设在何处？→ 回撤极值点另一侧
  - [ ] 是否预留更宽的止损空间？→ 限价单入场可能需要更宽止损

**限价单 vs 止损单决策矩阵**：

| 市场状态 | 推荐入场方式 | 原因 |
|---------|-------------|------|
| 强趋势回撤 | 限价单（顺势） | 更好的入场价格，顺势胜率较高 |
| 趋势初期突破 | 止损单 | 确认方向，避免假突破 |
| 交易区间 | 限价单（区间边界） | 区间边界限价单风险回报比较好 |
| 反转入场 | 止损单 | 需要确认反转方向 |
| 不确定状态 | 止损单或观望 | 避免错误方向的限价单被套 |

#### 有利方向概率时立即入场（来源：V2_B08_P351-400.md P354）

> "一旦你自信地认为出现对自己有利的方向概率...而且你认为市场将继续向有利方向运动几棒，那么你就要立即入场，这一点非常重要。"

**核心原则**：

| 条件 | 行动 | 原因 |
|------|------|------|
| 有利方向概率确认 | 立即入场 | 延迟=错过 |
| 预期继续运动几棒 | 立即入场 | 犹豫=成本 |
| 高置信度设置出现 | 立即入场 | 机会窗口有限 |

  - [ ] 评估依据：____（多理由/强信号/趋势支持等）
  - [ ] 置信度：____（高/中/低）
  
- [ ] **持续运动预期**：
  - [ ] 预期运动棒数：____棒
  - [ ] 预期运动幅度：____点/ticks
  - [ ] 目标位置：____
  
- [ ] **入场执行**：
  - [ ] 不要等待更低/更高价格
  - [ ] 不要等待"确认"（突破信号棒就是确认）
  - [ ] 使用市价单或止损单立即入场
  - [ ] 设置好止损后立即关注下一个目标

**常见犹豫陷阱**：

| 犹豫行为 | 后果 | 正确做法 |
|---------|------|---------|
| 等待更好价格 | 错过整个运动 | 有利概率时立即入场 |
| 等待更多确认 | 入场位置变差 | 信号出现即行动 |
| 想等回撤入场 | 趋势直接延续 | 突破时直接追 |
| 担心假突破 | 错过真突破 | 设好止损，接受小亏损 |

**刮头皮 vs 波段细化决策框架**:

**决策矩阵**:

| 评估维度 | 刮头皮条件 | 波段条件 |
|----------|------------|----------|
| **胜率要求** | ≥60% | 可接受<50% |
| **回报风险比** | 1:1 至 2:1 | ≥2:1 |
| **趋势强度** | 强趋势 | 中等趋势或反转初期 |
| **时间框架** | 5分钟图 | 5分钟+60分钟图 |
| **头寸规模** | 可全仓 | 建议分批 |
| **止损设置** | 2点 | 2-4点 |

**混合策略** (4+合约时):

1. **部分刮头皮、部分波段**:
   - 50%头寸: 刮头皮目标(2-4跳动)
   - 50%头寸: 波段目标(测量移动)
   - 刮头皮部分获利后，移动波段部分止损至保本

2. **动态调整**:
   - 趋势明确 → 增加波段比例
   - 趋势不明 → 增加刮头皮比例
   - 达到第一目标 → 平1/3-1/2，余下波段化

**原文引用**:
> "对于大部分交易者来说，如果他们自己认为的好架构，依靠自己的保护性止损，允许出现回撤，仅当反向强信号形成时离场，那么获利的可能性就较大" (V3_B06 P256)

> "4个或更多合约时，可以部分刮头皮、部分波段化" (V3_B06 P256)

#### 止损设置原则
- [ ] 止损必须在入场前确定
- [ ] 风险不应超过账户的1-2%
- [ ] 止损不能太紧（容易被噪音触发）
- [ ] 止损不能太松（风险过大）
- [ ] 在铁丝网中不交易（止损容易被触发）
- [ ] 最好让止损在市场中工作（不使用心理止损）
- [ ] 入场K线收盘后调整止损（从初始信号K线止损调整）：
  - [ ] 如果入场K线强劲（趋势K线而非十字星） → 收紧至入场K线以外1-2 tick
  - [ ] 如果入场K线是十字星 → 保持原始信号K线止损

#### 按交易类型的止损策略（原文：V2 Ch29 P274-P282）

| 交易类型 | 止损特征 | 风险/回报 | 原文依据 |
|----------|---------|----------|---------|
| **刮头皮** | 紧止损（信号K线+1 tick） | 风险≈利润目标（1:1） | "风险约两点，利润目标通常为1到3点" |
| **波段交易** | 宽松止损（信号K线+1 tick 或 波段低点） | 风险<利润目标（至少1:2） | "至少为风险两倍的回报" |
| **趋势回撤入场** | 可用宽松止损（Emini 5点） | 顺势概率高（≥60%） | "宽松的止损将允许他待在交易之中...胜率至少是60%" |
| **区间突破反向** | 宽松止损（5点风险博5点利润） | 1:1，但成功率>60% | "以5点的风险去博取5点的利润，预期市场会测试突破点" |
| **反转交易** | 止损≈信号棒高度（~10跳动） | 目标为测量移动 | "风险约等于那一棒的高度...初始利润目标将是测试那一棒的底部" |
| **尖峰末期入场** | 小止损+大仓位做刮头皮 | 回撤概率高 | "使用较大的头寸和较小的止损做刮头皮交易" |
| **高潮反转** | 止损≈高潮棒高度 | 目标为测量移动 | "空头所冒风险约等于那一棒的高度" |

#### Emini实用止损指南
- [ ] 5分钟图，平均日波幅10-15点时，大多数交易日8 tick效果良好
- [ ] 密切关注第一小时所需的最大止损
- [ ] 如果止损超过8 tick，可能也能增加获利目标

### 步骤 4.3 仓位计算
→ [Theme7](theme7_management_part1.md) Ch25

#### 仓位计算公式

```
仓位大小 = 最大风险金额 / 止损距离

示例（Emini）：
- 账户资金：$10,000
- 最大风险：2% = $200
- 止损距离：8 ticks = 2 points
- 每点价值：$50
- 仓位大小 = $200 / (2 x $50) = 2份合约

示例（股票）：
- 账户资金：$10,000
- 最大风险：2% = $200
- 止损距离：$0.50
- 仓位大小 = $200 / $0.50 = 400股
```

  - [ ] 止损价：____

### 步骤 4.4 盈利目标设置
→ [Theme7](theme7_management_part1.md) Ch30 + Theme6 Ch7-8

#### 按交易类型的止盈策略（原文：V2 Ch29 P274-P282）

| 交易类型 | 止盈特征 | 典型目标（Emini） | 原文依据 |
|----------|---------|-----------------|---------|
| **刮头皮** | 小利润目标，OCO包围单 | 1-3点（4-12 tick） | "利润目标通常为1到3点" |
| **波段交易** | 大利润目标（≥2倍风险） | 4点+（测量移动/趋势极点） | "寻求至少为风险两倍的回报" |
| **区间交易** | 对称目标（区间顶部/底部） | 区间高度（1:1风险回报） | "以5点风险博5点利润" |
| **趋势交易** | 分批止盈 | 1/2@2x风险 → 1/4@3x → 1/4自由奔跑 | "入场点下方4点了结一半...6点再了结1/4...最后1/4自由奔跑" |
| **反转交易** | 测量移动目标 | AB=CD、双顶高度、通道起点 | "下一目标是下跌测量运动的终点" |

#### 按交易类型的止损调整策略（原文：V2 Ch29 P278-P290）

| 交易类型 | 止损调整策略 | 原文依据 |
|----------|------------|---------|
| **刮头皮** | 入场后立即设OCO（止损+止盈），不手动调整 | "一入场，刮头皮者们就常常设好双向订单（OCO）" |
| **波段-趋势中** | 到达利润目标一半时移至盈亏平衡 | "一旦一笔波段交易到达约利润目标的一半，很多交易者就会把保护性止损移至盈亏平衡点" |
| **波段-趋势转区间** | 从波段切换为刮头皮（收紧止损，减小目标） | "交易者可能切换到交易区间型的交易，也就是说以刮头皮交易取代波段交易" |
| **波段-预期改变** | 可从波段降级为刮头皮离场 | "仅仅以刮头皮交易退出它的多头头寸...如果他认为市场正在到达顶部" |
| **入场棒是十字星** | 不要过早调紧止损，允许1-2跳动回撤 | "十字星是单棒交易区间，市场常常会反转并超越它们一两个跳动" |

#### 目标层级

| 层级 | 目标类型 | 操作 | 依据 |
|------|----------|------|------|
| 第一目标 | 刮头皮利润（1:1或1:2） | 平1/3到1/2仓位 | 信号K线质量/市场状态 |
| 第二目标 | 测量移动目标 | 平1/3仓位 | Leg 1 = Leg 2 / 缺口中点 / 区间高度 |
| 第三目标 | 主要磁铁/通道边界 | 剩余仓位用追踪止损 | 趋势通道线/前波段高/低点 |

#### 刮头皮 vs 摆动交易决策

**刮头皮核心原则**（原文关键规则）：
- [ ] ⚠️不会选择在明确Always In方向上做刮头皮交易
- [ ] 如果在刮头皮，说明认为当前没有趋势，或者是在逆势操作
- [ ] 即使在趋势中回撤入场时做刮头皮，意味着相信趋势即将结束

**刮头皮条件**（满足任一）：
- [ ] 信号K线质量一般（弱信号棒）
- [ ] 只有2个理由
- [ ] 接近强阻力/支撑
- [ ] 市场状态不确定
- [ ] 交易区间日

#### 赚4跳动需6跳动运动（来源：V2_B08_P351-400.md P372）

> "为了赚取4个跳动的刮头皮利润，通常需要市场做出超越信号棒6个跳动的运动。"

**核心计算**（以Emini 4-tick刮头皮为例）：

| 项目 | 计算 | 说明 |
|------|------|------|
| 入场点 | 信号棒高点 + 1 tick | 止损单入场 |
| 目标点 | 入场价 + 4 ticks | 刮头皮利润目标 |
| 限价单位置 | 入场价 + 4 ticks | 止盈限价单 |
| 实际成交要求 | 信号棒高点 + 6 ticks | 市场需超越限价单1 tick |

**关键理解**：

- [ ] **刮头皮目标设定**：
  - [ ] 4 tick目标需要市场运动6 tick才能成交
  - [ ] 考虑滑点和执行成本，实际可能需要更大运动
  - [ ] 目标设定时要预留额外空间
  
- [ ] **目标调整原则**：
  - [ ] 如果信号棒太大（>6 ticks），考虑缩小目标或放弃交易
  - [ ] 如果预期运动空间有限，选择更小目标或放弃刮头皮
  - [ ] 在强趋势中，可以考虑更大目标（8-12 ticks）

**不同品种应用**：

| 品种 | 典型刮头皮目标 | 所需市场运动 | 备注 |
|------|--------------|-------------|------|
| Emini | 4 ticks (1点) | 6 ticks | 标准刮头皮 |
| 股票 | $0.10-$0.20 | $0.15-$0.30 | 视股票价格调整 |
| 加密货币 | 0.1%-0.3% | 0.15%-0.45% | 考虑波动率 |
| 外汇 | 5-10 pips | 8-15 pips | 考虑点差 |
