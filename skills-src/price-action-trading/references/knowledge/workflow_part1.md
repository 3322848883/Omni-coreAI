## 第0章：交易前市场大背景分析（Pre-Market Analysis）

> 来源：V1引言 + V1第18-19章 + V2第1章
> 所有内容均为原文整理，非自创内容。

### 0.1 每日交易前检查清单

在开始交易之前，交易者应该完成以下市场大背景分析：

1. **昨日收盘分析**：
   - 昨日是趋势日还是区间日？
   - 收盘价相对于EMA20的位置（上方/下方/附近）
   - 收盘时是否有强劲的坚持到底运动？
   - 昨日是否形成了可能影响今日的架构（如楔形顶/底、测量运动目标）？

2. **日线图分析**：
   - 日线级别的趋势方向（多头/空头/区间）
   - 日线Always In状态（Long/Short/不确定）
   - 日线EMA20位置和价格关系
   - 近期是否有重要的支撑/阻力位
   - 日线是否接近测量运动目标

3. **缺口分析**：
   - 今日开盘是否有缺口？
   - 缺口类型：突破缺口/测量缺口/衰竭缺口
   - ⚠️品种差异：加密货币现货24/7交易无缺口；CME比特币期货有周末缺口；Globex期货缺口回补时均线方向可能与日内时段相反
   - 大型上涨缺口后（前提：开盘起趋势形成时）：约60%成为多头趋势日，40%成为空头趋势日
   - 缺口是否可能被回补？

4. **周线图背景**：
   - 周线趋势方向
   - 本周是否处于周线级别的回撤中？
   - 周线关键支撑/阻力位

### 0.2 市场状态预判

根据大背景分析，预判今日可能的市场状态：

| 预判条件 | 可能的市场状态 | 交易策略 |
|---------|--------------|---------|
| 昨日强趋势收盘 + 今日缺口同向 | 强趋势日 | 顺势为主，寻找回撤入场 |
| 昨日趋势 + 今日缺口反向 | 趋势恢复日或反转日 | 等待首次回撤确认方向 |
| 昨日区间收盘 + 今日无缺口 | 趋势型交易区间日 | 双向交易，刮头皮+波段 |
| 昨日小区间 + 今日无缺口 | 可能出现突破 | 等待突破方向确认 |
| 周线回撤中 + 日线区间 | 紧凑交易区间 | 减少交易，等待突破 |

### 0.3 关键原则

> 来源：V1_B02_P051-100.md P80, P84

1. 市场经常表现出惯性，倾向于继续做刚刚在做的事情。
2. 对于市场方向，你很少能有60%的确定性。
3. 大多数趋势只是更高时间框架图表上的交易区间的一部分。
4. 如果市场处于趋势中，大多数反转尝试都将失败。
5. 如果市场处于交易区间中，大多数突破形成趋势的尝试都将失败。
