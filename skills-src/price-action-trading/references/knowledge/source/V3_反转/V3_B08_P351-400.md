## 一、市场本质与交易哲学

### 1.1 市场的一维本质

> 市场是线性的——它只会上涨或下跌。当你把它画在水平轴为时间的传统图表上时，你就增加了第二个维度，但是市场本身只有价格，也就是说它只有一个维度。你可以把多头实体和空头实体设定为不同的颜色，把成交量包含在实体宽度中，或者添加各种各样的指标，增加维数，但是市场本身是一维的。

| 概念 | 英文 | 中文定义 |
|------|------|----------|
| Market linearity | Market is one-dimensional | 市场是线性的——只会上涨或下跌 |
| Trading range | Trading range | 交易区间——对当前市场价值一致认同的区域 |
| Breakout | Breakout | 突破——从交易区间中突破而出，进入趋势 |
| Fundamental factors | Fundamentals | 基本面因素——交易者感觉重要的任何东西 |
| Trader's Equation | Trader's Equation | 交易者方程——胜率与回报的乘积 vs 败率与风险的乘积 |
| Positive Edge | Positive edge | 正的优势——正的交易者方程 |
| Protective stop | Protective stop | 保护性止损 |

### 1.2 交易者方程的核心地位

> 如果交易在击中他的保护性止损之前到达他的利润目标的概率，大于市场在到达他的目标之前击中止损的概率，那么便出现一个优势（正的交易者方程）。拥有优势便给了他一个下单赚钱的机会。

**交易者方程公式：**

| 条件 | 公式 | 结果 |
|------|------|------|
| 正的交易者方程 | 胜率 × 回报 > 败率 × 风险 | 拥有优势，可以交易 |
| 负的交易者方程 | 胜率 × 回报 < 败率 × 风险 | 无优势，不应交易 |
| 盈亏平衡 | 胜率 × 回报 = 败率 × 风险 | 无优势，不应交易 |

### 1.3 每种市场环境的挑战

> 每一种类型的市场都会有些行为令交易变得困难。市场中充满了非常聪明的人们，他们试图从你们的账户中赚钱的努力程度，同你们试图从他们的账户中赚钱的努力程度是一样的，所以没有什么非常容易的事情。

## 二、不同市场环境下的交易行为

### 2.1 趋势通道期的挑战

> 一旦趋势进入它的通道期，总是看起来像在反转。举例说明，在一轮多头趋势中，将有很多次反转尝试，但是几乎每一次都迅速演变为多头旗形。大多数多头通道中将出现弱势买进信号棒，那些信号将迫使那些喜欢止损入场的多头在弱势通道的顶部买进。这是一种低胜率多头交易，尽管市场还在继续上扬。

### 2.2 交易区间的挑战

> 一旦通道期结束，市场便进入交易区间，其中有很多向顶部快速运动的强多头尖峰和向底部快速运动的强空头尖峰。交易者们常常只盯着强尖峰，认为突破将会成功。结果他们高买低卖，刚好与获利交易者的做法相反。

### 2.3 交易区间内的概率数据

| 交易类型 | 成功率 | 说明 |
|----------|--------|------|
| 交易区间内大部分交易 | 约50% | 成功率在50%左右徘徊 |
| 偶尔出现的架构 | 约60% | 很少有高胜率架构 |
| 低胜率事件 | <50% | 反转看起来不怎么好但仍引出大波段 |
| 强尖峰后未坚持到底 | <50% | 大量低胜率事件发生 |

## 三、多头趋势中的交易者行为模式

### 3.1 随意型交易者的方法

> 每一张图上的每一秒，在所有时间框架上，都有交易者们为了各种各样的理由而交易。那么在多头趋势中，随意型交易者（不管是机构还是个人）一般会采用什么方法呢？

**多头趋势各阶段的交易行为：**

| 阶段 | 交易者行为 | 说明 |
|------|-----------|------|
| 突破开始 | 带有紧迫感而买进 | 在市价、小幅回撤、棒线收盘价、前一棒上方买进 |
| 通道期 | 在前一棒低点下方买进 | 低点1和低点2信号棒下方，预期反转尝试失败 |
| 旗形突破后 | 在回撤买进 | 在市场突破小型多头旗形之后的回撤买进 |
| 强趋势中 | 在空头微型通道第一次被突破时买进 | 知道可能不会出现突破回撤架构 |
| 双向交易增加时 | 在波段高点上方卖出 | 先获利了结，后开始做空刮头皮 |
| 进入交易区间 | 低买高卖，大部分刮头皮 | 寻找高点1/高点2做空，信号棒上方做空 |

### 3.2 交易区间中的具体交易策略

> 多头将在交易区间底部的合理架构买进，比如在更高高点2买进架构、楔形多头旗形、更高时间框架趋势线、以及测量运动目标。

**关键规则：**

1. 交易者们认识到，交易区间只是更高时间框架图表上的一个回撤
2. 在5分钟图表上，尖峰和通道陡峭时，一起构成更高时间框架图表上的一个尖峰
3. 5分钟图上的交易区间通常只是15或60分钟图上的一波回撤
4. 多头在5分钟交易区间底部买进时，很多人会持有头寸，预期形成上涨波段

## 四、交易区间中的详细规则

### 4.1 微型通道与突破规则

> 如果一条腿是在一条强微型通道内，持续了4棒或更多棒，那么不要在突破入场。等等看突破是否强劲。如果突破强劲，那么就在突破回撤入场。

**微型通道交易规则：**

| 情形 | 操作 | 说明 |
|------|------|------|
| 微型空头通道到达区间底部 | 等待多头突破，回撤买进 | 无论形成更高低点、微型双重底还是更低低点 |
| 微型多头通道到达区间顶部 | 等待回撤做空 | 在更低高点、微型双重顶或更高高点回撤做空 |
| 紧凑交易区间 | 等待突破 | 紧凑交易区间会吞噬一切 |
| 紧凑区间内使用止损入场 | 失败的策略 | 架构总是看起来值得一做，但不应交易 |

### 4.2 突破后的交易循环

> 如果市场成功突破整个交易区间的顶部，那么上述过程便又重新开始。交易者们会把突破看作一个尖峰，他们预期至少出现一波向上的测量运动。

**突破后的完整交易流程：**

1. 向上突破 → 视为尖峰 → 预期测量运动
2. 突破失败 → 市场反转 → 视为多头趋势中的最终旗形
3. 向下突破交易区间 → 研判突破力度
4. 突破很强 → 反方向重复整个过程
5. 交易区间可能是其他反转架构（双重顶、三重顶、头肩顶、三角形）

## 五、最佳交易完整清单

### 5.1 最佳交易架构列表（P248）

| 最佳交易类型 | 具体条件 | 成功率 | 回报/风险比 |
|-------------|----------|--------|------------|
| 架构很强的开盘反转（波段交易） | 回报至少是风险的两倍 | 50%-60% | ≥2:1 |

| 强反转 | 回报至少是风险的两倍 | 50%-60% | ≥2:1 |
| 多头趋势中向均线回撤的高点2买进 | — | 60%+ | ≥1:1 |
| 空头趋势中向均线回撤的低点2卖出 | — | 60%+ | ≥1:1 |
| 楔形多头旗形回撤买进 | — | 60%+ | ≥1:1 |
| 楔形空头旗形回撤卖出 | — | 60%+ | ≥1:1 |
| 多头旗形突破后的突破回撤买进 | — | 60%+ | ≥1:1 |
| 空头旗形突破后的突破回撤卖出 | — | 60%+ | ≥1:1 |
| 交易区间顶部做空（二次入场） | — | 50%-60% | ≥1:1 |
| 交易区间底部买进（二次入场） | — | 50%-60% | ≥1:1 |

### 5.2 强反转的具体类型

> **重要趋势反转 (Major Trend Reversal)**：很强的趋势线突破之后，预期弱趋势恢复在测试趋势极点时失败；反转信号棒应该很强。

| 反转类型 | 多头趋势后做空条件 | 空头趋势后做多条件 |
|----------|-------------------|-------------------|
| 重要趋势反转 | 在更高高点、双重顶或更低高点做空 | 在更高低点、双重底或更低低点买进 |
| 强最终旗形反转 | 交易区间或弱通道内上涨波段之后 | 交易区间或弱通道内下跌波段之后 |
| 空头台阶形态中的买进 | 第三次或第四次下推买进 | 预期测试前一次下推的低点 |
| 多头台阶形态中的做空 | 第三次或第四次上推做空 | 预期测试前一次上推的高点 |
| 测量运动目标处交易 | 尖峰和通道到达测量运动目标时 | 运动正在变弱时交易 |

### 5.3 尖峰中的顺势交易

> 多头趋势的强多头尖峰中，在高点1回撤买进，但是不要在强买进高潮后买进。

> 空头趋势的强空头尖峰中，在低点1回撤卖出，但是不要在强卖出高潮后卖出。

## 六、限价单入场策略

### 6.1 限价单入场的核心原则

> 利用限价单入场需要更熟练的读图技能，因为交易者正在进入的市场的运动方向，与他的交易方向相反。交易者们应该只使用限价单在趋势方向上交易。

**限价单使用规则：**

| 规则编号 | 规则内容 |
|----------|----------|
| 1 | 只在市场是总在场内多头时使用限价单买进 |
| 2 | 只在市场是总在场内空头时使用限价单卖出 |
| 3 | 当使用限价单逆势交易时，成功率太低 |
| 4 | 低胜率将使得交易者方程为负 |
| 5 | 趋势中令人惊讶的通常是趋势的方向 |

### 6.2 经验丰富的交易者的限价单交易

| 交易场景 | 入场方式 | 说明 |
|----------|----------|------|
| 强多头尖峰 | 市价买进或限价单在前一棒低点/下方买进 | 需要更宽的止损，速度很快 |
| 强空头尖峰 | 市价卖出或限价单在前一棒高点/上方卖出 | 需要更宽的止损，速度很快 |
| 强势向上反转后 | 限价单在低点1或2弱势信号棒/下方买进 | 可能的新多头趋势 |
| 强势向下反转后 | 限价单在高点1或2弱势信号棒/上方卖空 | 可能的新空头趋势 |
| 均线处平静的多头旗形 | 限价单在前一棒低点或其下方买进 | 高胜率架构 |
| 均线处平静的空头旗形 | 限价单在前一棒高点或其上方做空 | 高胜率架构 |

### 6.3 更多限价单交易规则（P249）

| 规则编号 | 规则内容 |
|----------|----------|
| 1 | 在向上突破多头旗形的一条多头棒下方买进，预期突破回撤 |
| 2 | 在向下突破空头旗形的一条空头棒下方卖出，预期突破回撤 |
| 3 | 多头趋势中做波段交易时，在突破测试时买进或加仓 |
| 4 | 空头趋势中做波段交易时，在突破测试时卖出或卖出更多 |
| 5 | 强多头趋势中，在下跌等于或略小于先前平均回撤幅度后买进 |
| 6 | 强空头趋势中，在上涨等于或略小于先前平均回撤幅度后卖出 |
| 7 | 多头趋势即将突破进入空头趋势时，在多头突破棒收盘卖出 |
| 8 | 空头趋势即将突破进入多头趋势时，在空头突破棒收盘卖出 |

## 七、初学者指导方针

### 7.1 初学者必须遵守的规则

| 规则编号 | 规则内容 | 原因 |
|----------|----------|------|
| 1 | 仅做回报至少与风险一样大的交易 | 正的交易者方程 |
| 2 | 专注于回撤至少是风险两倍的交易 | 更好的风险回报比 |
| 3 | 只选择认为可能成功的架构 | 假定胜率至少60% |
| 4 | 只使用止损入场 | 入场时市场正在向你的方向运动 |
| 5 | 总要设好保护性止损 | 信念和希望不会保护你 |
| 6 | 设一张获利了结限价单 | 防止贪婪导致利润消失 |
| 7 | 仅在多头棒上方买进和空头棒下方做空 | 确保信号棒方向正确 |
| 8 | 只交易较小的头寸规模 | 进入"我不在乎"状态 |
| 9 | 一天只寻找3到5笔合理的交易 | 减少决策压力 |
| 10 | 寻找简单的策略 | 行情不清晰时等待 |

### 7.2 初学者最佳交易选择

> 对于刚入市的交易者来说，最佳选择是开盘区间内形成的趋势、强趋势反转和强趋势中的回撤。

## 八、交易风格比较

### 8.1 刮头皮 vs 波段交易

| 比较维度 | 刮头皮交易 (Scalping) | 波段交易 (Swing Trading) |
|----------|----------------------|-------------------------|
| 利润目标 | 与风险一样大或更小 | 至少是风险的两倍 |
| 成功率要求 | 80%才能以交易为生 | 40%-50%即可产生正方程 |
| 交易频率 | 每天20-40笔 | 每天1-3笔 |
| 最佳架构出现速度 | 出现太快，难以捕捉 | 有时间分析和准备 |
| 适合人群 | 极少数经验丰富的交易者 | 大部分交易者 |
| 初学者建议 | 基本上所有交易者都应避免 | 推荐的交易方式 |

### 8.2 刮头皮的真相

> 刮头皮的最大问题之一是，在60%的交易中盈利是相当容易的。这带给交易者们希望，他们认为自己离发财不远了。然而，他们实际上必须在80%左右的微型刮头皮中盈利，才能以刮头皮为生，虽然他们认为自己很接近那个胜率，但是却永远达不到。

> 初学者常常错误的认为某个架构的胜率是80%。他们的很多交易的胜率实际上至多只有60%。初学者可能认为自己只需要稍加练习便能将胜率提升到80%，而事实是他们永远不会变得那么优秀，因为即便最优秀的交易者也极少达到那么高的水平。那就是真相。

### 8.3 波段交易的优势

> 与刮头皮交易相比，另一极端是为了至少为风险两倍大的利润而做波段交易，一天只寻找一两笔好交易。这些架构中的大部分只有40%到50%的确定性，但是那就足以产生一个不错的交易者方程。当一个架构看起来有50%到60%的成功率时，它是一个最佳架构。

## 十一、市场循环的本质

> 市场要么是确定的，价格强劲，在趋势中运动，寻找一个人们意见一致的区域（交易区间），要么是处于一个一致区域内，等待分歧（突破）形成。

**市场循环过程：**

1. 趋势前进 → 暂停 → 再次突破
2. 交易者们认为走得太远 → 在突破时反向操作
3. 多头趋势中 → 形成双重顶和最终多头旗形
4. 空头趋势中 → 形成双重底和最终空头旗形
5. 一致意见在交易区间内达成 → 市场再次突破
6. 大约50%情况下数学偏向于突破，另外50%偏向失败的突破和反转

## 十二、交易心理学与纪律

### 12.1 消防员比喻

> 消防员们每天都在等待，永远不知道什么时候警报将会响起，但是当警报响起时，他们必须立即行动，而且是完美地行动。他们是专业的，因为正确地完成工作而获得报酬。交易者们也要等待那些只会偶然出现的事件，但是他们必须是专业的，而且在时间到来时，必须快速地、准确地做出响应。

### 12.2 避免逆势刮头皮

> 一位朋友曾经告诉我，在他停止做逆势刮头皮之前，他一直亏损了很多年，从来没赚到过钱。他现在一年能赚到100多万美元。

> 除了选择强反转架构之外，交易者们应该只在市场基本上位于均线上方时买进，在近期棒线大部分处于均线下方时卖出。

### 12.3 避免使用1分钟图

> 另一种常见的错误是观察1分钟图或其他较小时间框架图表。一天结束后，交易架构是很容易看出的，但是大部分很难实时交易。最佳架构出现得太快，极易错过。

> 如果你的目标是赚钱（那应该是你的目标），那么就只选择最佳交易，避开1分钟图。然而，如果交易只是你寻求刺激的一种爱好，那么记住爱好是要花钱的，而且有很多价格低廉、同样有趣的爱好可供选择。

## 十三、交易者方程的数学分析

### 13.1 刮头皮者的困境（AAPL案例）

> 比如说你在5分钟图上交易AAPL，正冒着$1.00的风险去博取50美分的利润，而且你的胜率是60%；如果你做这种类型的交易10次，那么你可能会盈利6次，赚到$3.00，亏损4次，亏损$4.00，也就是说每笔交易亏损10美分，还要加上佣金。

| 交易类型 | 风险 | 回报 | 胜率 | 每笔交易期望 |
|----------|------|------|------|-------------|
| AAPL刮头皮 | $1.00 | $0.50 | 60% | 亏损$0.10/笔 |
| 80%胜率刮头皮 | $0.80 | $0.40 | 80% | 盈利$0.16/笔 |
| 波段交易（最低要求） | $1.00 | $1.00 | 60% | 盈利$0.20/笔 |

### 13.2 交易者方程的重要含义

| 胜率假设 | 最低利润要求（风险=$1.00） | 说明 |
|----------|--------------------------|------|
| 50%（不确定） | ≥$1.00 | 假定50%胜率时的最低要求 |
| 60%（比较自信） | ≥$0.67 | 60-40胜率时的最低要求 |
| 70%（特别自信） | ≥$0.43 | 可在交易者方程中使用70% |

## 十四、通道交易的挑战

> 通道是很难交易的，由于市场大部分时间是在通道内，所以在一天的大部分时间里是很难交易的。

| 通道类型 | 交易建议 | 说明 |
|----------|----------|------|
| 疲弱多头通道 | 最好不要在棒线上方买进 | 交易者方程极少超过零点 |
| 紧凑通道 | 大部分交易者应该等待突破 | 很难找出最佳交易 |
| 较宽波段的通道 | 寻找回撤中的最佳交易架构 | 可能产生最佳交易 |
| 空头尖峰期 | 做空成功率通常60%或更高 | 常常是最佳交易 |

## 十六、趋势反转交易的详细分析

### 16.1 重要趋势反转的必要条件

> 对于重要趋势反转，必须有对重要趋势线的强势突破，第一条反转腿显示出大量动能，而且拥有一条强反转棒。

**重要趋势反转检查清单：**

1. 对重要趋势线的强势突破
2. 第一条反转腿显示出大量动能
3. 拥有一条强反转棒
4. 等待对趋势极点的测试
5. 在成功测试时入场
6. 信号棒是一条强反转棒

### 16.2 趋势反转的概率数据

| 反转类型 | 成功率 | 回报/风险比 | 出现频率 |
|----------|--------|------------|----------|

| 开盘趋势内的反转 | 约30%（2倍回报） | ≥2:1 | 常见 |
| 开盘区间内最佳架构 | 约60% | ≥1:1 | 至少一个 |

### 16.3 开盘区间交易

## 十七、回撤交易的深度分析

### 17.1 回撤交易为什么困难

> 如果在多头趋势中的回撤买进是这样棒的交易，那么为什么作为交易者赚钱还那么有挑战性呢？那是因为每个架构都存在问题，而且在一个架构触发并行进一两棒之前，很难相信它是真正的好架构。

### 17.2 回撤交易的关键数据

| 数据项 | 数值 |
|--------|------|
| 趋势中反转尝试失败的概率 | 约80% |
| 趋势中的回撤本质 | 失败的趋势反转尝试 |
| 回撤交易可靠性 | 使绝大多数成功交易者最常使用的方法 |
| 向均线两条腿回撤 | 最容易识别的架构 |

### 17.3 趋势日中的交易管理

> 在强趋势日，重要的是把每个顺势入场的一部分波段化，尽管那意味着有时你的盈亏平均止损将在交易的波段部分被击中。不过，大的运动足以弥补这种损失。

**加仓策略：**

1. 在每个新的架构，加回刮头皮部分
2. 或在当前未平仓波段头寸顶部设置完整头寸
3. 部分刮头皮退出后，波段部分是正常规模的两倍
4. 大部分交易者发现只加回刮头皮合约更简单

## 十八、强趋势日中的回撤交易

### 18.1 强趋势日的特征

> 有些架构出现在强趋势日，大部分棒线都位于均线一侧，而且一天中只有一两次均线回撤。这些最强的趋势日一个月只出现一两次，但是几乎每一天都会出现可靠的趋势。

### 18.2 股票回撤交易的具体管理（以$3日区间为例）

| 管理步骤 | 操作 | 说明 |
|----------|------|------|
| 入场 | 在超出信号棒的位置设置保护性止损 | 通常风险<60美分 |
| 入场棒收盘 | 把止损移至略微超出入场棒的位置 | 入场棒成为趋势棒时 |
| 账面利润60-80美分 | 把止损移至盈亏平衡点 | 如$120.10买进→$120.80时止损移至$120.07 |
| 账面利润$1.00 | 使用限价单了结一半头寸 | 依靠盈亏平衡止损 |
| 利润$2.00 | 再了结一点 | 跟踪调整保护性止损 |
| 最后部分 | 自由奔跑 | 直到止损被击中或明确反向信号 |

## 十九、交易区间中的详细策略

### 19.1 交易区间突破的陷阱

> 初学者们不应使用止损单在交易区间突破入场，因为大部分突破尝试失败，不管它们看起来有多好。

> 交易区间经常出现强多头尖峰，快速运动至顶部，看起来肯定会突破，底部经常会出现强空头尖峰，看起来是一个强向下突破的起点，但是两种突破都会失败，不久便反转。

### 19.2 交易区间中的正确做法

| 正确做法 | 错误做法 |
|----------|----------|
| 低买高卖 | 高买希望价格上涨 |
| 在二次信号入场 | 在一次信号入场 |
| 等待明确突破后在回撤入场 | 在突破时使用止损入场 |
| 在强尖峰后的弱旗形中交易 | 在强尖峰方向追入 |

### 19.3 交易区间中的概率

| 事件 | 概率 |
|------|------|
| 突破尝试失败 | 约80% |
| 强尖峰后快速反转 | 60%-80% |
| 大部分交易成功率 | 约50% |
| 向区间顶部/底部的强尖峰看起来会突破 | 大部分时间 |
| 实际成功突破 | 约20% |

## 二十二、核心规则与原则总结

### 22.1 交易决策规则

1. **总要考虑交易者方程**——仅在胜率与潜在回报的乘积明显大于败率与风险的乘积时交易
2. **如果不确定，假定50%胜率**——然后确保回报至少与风险一样大
3. **如果比较自信，假定60%胜率**——但常常会更高
4. **总要使用保护性止损**——60%的成功率意味着40%的失败率
5. **总要设获利了结限价单**——防止贪婪导致利润消失
6. **保持简单**——在每笔交易上做相同的事情，直到能够稳定获利
7. **只在多头棒上方买进，空头棒下方做空**
8. **交易较小的头寸规模**——进入"我不在乎"状态

### 22.2 市场判断规则

1. **不要与市场和自己的情绪相抗争**——待在舒适区内
2. **只专注于一个市场和一个时间框架**——比如5分钟图
3. **避开紧凑交易区间内的任意架构**——特别是日区间中部、靠近水平均线时
4. **避开逆势刮头皮**——拥有负的交易者方程
5. **避开1分钟图**——最佳架构出现太快，难以捕捉
6. **学会区分趋势和交易区间**——不确定时在强尖峰后的回撤入场

### 22.3 交易管理规则

1. **入场后不要改变计划**——不要将波段变刮头皮或反之
2. **如果发现自己改变计划**——设定包围订单，走开一小时
3. **如果设定交易就开始担心**——交易小得多的头寸规模
4. **如果总是迫切设置交易**——避免突破入场，只在回撤入场
5. **限制一天只做3笔交易**——培养耐心
6. **波段交易必须坚持持有并经历回撤**——只要最初预期仍然正确
7. **趋势恢复后把止损调紧到盈亏平衡点**
