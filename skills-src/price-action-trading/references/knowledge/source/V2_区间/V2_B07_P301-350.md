### P302

**章节标题：** 第23章 三角形 (Chapter 23: Triangles)

**概念定义：**

| 中文术语 | 英文术语 | 定义 |
|----------|----------|------|
| 三角形 | Triangle | 交易区间的一种，包含在两条线之间的价格行为区域，最低要求是拥有三次上推或下推 |
| 交易区间 | Trading Range | 包含在两条线之间的价格行为区域 |
| 通道 | Channel | 价格在两条平行或收敛线之间运动的区域 |
| 扩张三角形 | Expanding Triangle | 包含于两条发散的轨线之间，上轨线位于多头趋势中的高点之上（更高高点），下轨线位于空头趋势的低点下方（更低低点） |
| 收缩三角形 | Contracting Triangle | 包含于两条趋势线之间，市场同时位于小型空头趋势和小型多头趋势中 |
| 上升三角形 | Ascending Triangle | 上侧是一条阻力线，下侧是一条多头趋势线 |
| 下降三角形 | Descending Triangle | 下侧是一条支撑线，上侧是一条空头趋势线 |
| 楔形 | Wedge | 上升或下降的通道，趋势线和趋势通道线逐渐收敛，是三角形的一个变种 |
| 外包-外包形态 | Outside-Outside (oo) | 一条外包棒之后形成一条更大的外包棒，是一种小型的扩张三角形 |
| ii形态 | ii Pattern | 通常是更低时间框架图表上的小型三角形 |

**重要段落：**

> 三角形是交易区间，所以也是通道，因为它们也是包含在两条线之间的价格行为区域。交易区间可以叫做三角形的最低要求是，它拥有三次上推或下推。由于它们要么拥有更高低点或更低高点，要么像在扩张三角形中那样同时拥有更高低点和更低高点，所以它们也拥有一些趋势行为。

> 不像趋势通道和交易区间可以无限期地延伸下去，当市场处于三角形内时，它是处于突破状态，也就是说突破即将发生。突破或强或弱；它可能拥有紧凑到底，最终形成一轮趋势，也可能失败并反转，也可能只是横盘运动，演变为一个更大的交易区间。

> 像所有交易区间一样，三角形是趋势中的一次暂停，突破通常发生在三角形之前的趋势方向上。多头趋势中的三角形通常向上突破，空头三角形通常向下突破。

> 任何一个下降楔形的都像是多头趋势中的一波大型回撤，也就是说它的行为就像是一个多头旗形。向上突破是对屏幕上的空头趋势的反转，但那不是在预期的方向上，因为每条空头通道都只是一种多头旗形。

---

### P303

**规则条件：**

1. 三次上推或下推是交易区间被称为三角形的最低要求
2. 三推交易区间等同于三角形
3. 单推回撤（single-push pullback）、两推回撤（two-push pullback）和三推形态（three-push pattern）之间存在区别
4. 楔形（wedge）不等于三推形态（three-push pattern）——这是常见误解
5. 强突破入场规则参考第2章
6. 小型回撤可使用限价单入场

**重要段落：**

> 三推交易区间就是三角形，所以它们是通道。交易者们常常把三推形态与楔形混淆。它们是不同的。三推形态拥有三次上推或三次下推，但楔形是通道，其趋势线和趋势通道线逐渐收敛。

> 当突破发生时，如果突破很强，那么交易者们应在突破棒收盘后入场。如果突破不强，那么交易者们应等待回撤入场。

**规则条件：**

3. 在市场向下测试多头趋势线时买进

**概念定义：**

| 中文术语 | 英文术语 | 定义 |

## 第24章 刮头皮，做波段，交易和投资

### P308

**章节标题：** 第 24 章 刮头皮，做波段，交易和投资 (Chapter 24: Scalping, Swing Trading, Trading and Investment)

**概念定义：**

| 中文术语 | 英文术语 | 定义 |
|----------|----------|------|
| 投资者 | Investor | 根据基本面买进股票，持有时间为6个月到若干年，允许基本面因素在股价中反映出来 |
| 交易者 | Trader | 根据日线图和短期基本面因素交易，目的是捕捉持续一天到若干天的快速运动 |
| 刮头皮者 | Scalper | 日内交易者，持有头寸1到15分钟左右，通常使用限价单在利润目标离场 |
| 日内波段交易者 | Intraday Swing Trader | 持有头寸经历回撤，努力捕捉一天中的2到4个较大的波段，头寸持有时间从15分钟到一整天 |
| 高频交易 | HFT (High-Frequency Trading) | 终极日内交易者，成交量占市场最大份额 |

**规则条件：**

1. 投资者根据基本面买进，持有6个月到若干年
2. 交易者在第一个暂停处部分获利了结，然后把止损移至盈亏平衡点
3. 如果作为交易入场，就要作为交易认赔出场——不要把亏损交易变为投资
4. 刮头皮者潜在回报与风险规模大致相等
5. 刮头皮者不希望持有头寸经历任何回撤
6. 日内波段交易者潜在回报通常至少为风险的两倍
7. 日内波段交易者类似于使用日线图的投资者，愿意持有头寸经历回撤

**概率数据：**

| 场景 | 数据 |
|------|------|
| 刮头皮持有时间 | 1-15分钟 |
| 日内波段交易者每日波段数 | 2-4个 |
| 日内波段交易者持有时间 | 15分钟到一整天 |
| 日内波段交易者最低回报风险比 | 2:1 |

**重要段落：**

> 坚持自己的时间框架是很重要的。一种常见的亏损原因是，入场一笔交易，看着它变为亏损交易，但是却没有在计划的止损点离场，而是说服自己，把交易变为投资是不错的选择。如果作为交易入场，就要作为交易认赔出场。

> 上世纪90年代，媒体和机构投资者们都对日内交易者嗤之以鼻，认为刮头皮者们就像是漫无目的的赌徒。那些批评完全忽视了所有交易者提供的一项重要功能，那就是增加流动性，从而减小滑移价差，使每个人的交易价格都更便宜。

> HFT公司是终极日内交易者，他们使日内交易备受尊重。

**概念定义：**

| 价格水平参考 | — | 1254, 1252, 1256 |

**重要段落：**

> 交易者方程是交易决策的基础。对于刮头皮交易，如果胜率不能达到60%以上，那么交易者方程就是负的，不应进行交易。

### P310

**规则条件：**

1. 在5分钟电子迷你图表上做刮头皮交易，平均每日区间为8到15点的情况下，风险约两点，利润目标通常为1到3点
2. 对于1点刮头皮交易，必须有67%以上的交易盈利才能保证不赔
3. 仅当回报至少与风险一样大，仅当对交易比较自信时，才可选择交易
4. 如果自信，假定成功率至少为60%
5. 两点止损是目前（每日平均区间为10到15点）最可靠的
6. 利润目标也至少应该是两点
7. 如果认为两点是不切实际的目标，就不要做那笔交易
8. 使用OCO（One-Cancels-Other）双向订单：两点的保护性止损 + 两点的利润目标限价单
9. 下单后出去散步，大约一个小时以后再回来

**概率数据：**

| 场景 | 数据 |
|------|------|
| 1点刮头皮最低胜率要求 | 67%以上 |
| 自信交易者假定胜率 | 60% |
| 电子迷你平均日区间 | 8-15点（目前10-15点） |
| 推荐止损 | 2点 |
| 推荐最低利润目标 | 2点 |
| OCO订单止损 | 2点 |
| OCO订单利润目标 | 2点 |

**案例：**

> 多年以前我有个朋友，常常一次交易100张电子迷你合约，刮取两个跳动的利润，每天大约交易25次。因为他住在一套12,000平方英尺（约合1,115平方米）的房子里，所以我认为他可能做得非常出色。

> 另一位朋友曾告诉过我，有个人在华尔街上干代理人赚了几百万，但是做交易却全赔进去了。他开始在电子迷你中做100张合约的刮头皮交易，头几年便赔了200万美元。他可能一直很聪明，但却不够明智。

**重要段落：**

> 每个人都会碰到"摘樱桃"的问题。为每天做20笔交易，每笔交易赚1点而忧心忡忡，应该不如每天选择最好的三笔刮头皮交易，每笔交易赚1点吧？理论上是可行的，但实际上你不得不为了完美的交易等待很长时间。

> 如果你认为自己即将在一天中最好的一两个架构之一买进，那么你应该假定市场会同意那个架构很强。那就意味着总在场内头寸可能已经明确地变成了总在场内多头，很可能至少形成两条上涨腿，到达某个测量运动目标或磁力位，而且那一波运动至少应持续十几棒。

> 不要以为某个事情看起来容易就认为他实际上很容易。

### P311

**规则条件：**

1. 很多交易者会根据环境选择做刮头皮交易还是波段交易
2. 不会选择在明确的总在场内方向上做刮头皮交易
3. 如果在刮头皮，那么他们肯定是认为当前没有趋势，或者是在逆势操作
4. 即使市场正处于趋势之中，交易者们在回撤入场时如果做刮头皮，那么他们相信趋势即将结束
5. 每当看到市场在一个信号之后回撤三四个跳动时，就可认为那是大型玩家认为市场很可能不会出现大幅运动的征兆
6. 交易者应仅考虑做交易区间交易或逆势交易，而不是做趋势交易
7. 老手们会选择做刮头皮交易而非波段交易，低买高卖
8. 做逆势交易时有时选择较小的头寸（比如一半），希望在市场向不利方向运动时加仓
9. 刮头皮交易利润目标通常为最小波段利润目标的一半，但风险通常相同
10. 刮头皮交易至少需要70%的成功率，否则是失败的策略

**概率数据：**

| 场景 | 数据 |
|------|------|
| 刮头皮交易最低成功率 | 70% |
| 止损调整超出信号棒极点 | 1个跳动 |
| 盈亏平衡调整阈值 | 5个跳动 |
| 部分刮头皮者较宽止损 | 3到5点 |

**重要段落：**

> 如果在获得几点利润后部分获利了结，然后利用盈亏平衡止损把剩余部分做波段交易，那么所需胜率就有所降低。如果在入场棒收盘后把止损从信号棒极点调至入场棒极点（两种情况下都是超出1个跳动），然后在5个跳动后调至盈亏平衡点，那么就会进一步降低当天获利所需的胜率。

> 如果看到一个感觉胜率非常高的架构，那么那笔交易很可能是刮头皮，而不是波段交易。这是因为，每当出现这样明显的失衡时，市场都会迅速做出调整，所以高胜率、低风险情形的持续时间只有一两棒。

> 波段交易者所用架构和止损与刮头皮者所用架构和止损是相同的，但是他们把注意力集中在每天那几笔很可能至少包含两条腿运动的交易上。

### P312

**规则条件：**

1. 波段交易者每笔交易的部分头寸通常可以净赚4个点或4个点以上，然后把止损调至盈亏平衡点
2. 很多波段交易者会任由市场向不利方向运动，并且在更好的价位加仓
3. 波段交易者在建仓并获得合理利润后，可以在随后的每个信号增加同等规模的头寸
4. 整个头寸的止损就是最后增加的头寸的止损
5. 如果市场产生反向信号，通常在跟踪止损被击中前离场
6. 不断寻找刮头皮者们设定止损的价位，并且在那一位加仓，前提是形态依然准确

**概率数据：**

| 场景 | 数据 |
|------|------|
| 大部分波段架构到达利润目标概率 | 40%-50% |
| 提前离场或止损被触发概率 | 50%-60% |
| 电子迷你平均日区间 | 10-15点 |
| 99%的交易日最低区间 | 5点 |
| 90%的交易日至少有一个4点波段 | 90% |
| 约10%的交易日拥有5个4点波段 | ~10% |
| 每日波段交易机会 | 1-3个（使用止损单入场） |
| 每日交易总数（刮头皮为主） | 10-15笔 |
| 波段化头寸比例 | 四分之一到一半 |

**案例：**

> 对于像苹果（AAPL）这样可靠的股票，如果你打算在自己感知的运动低点买进，而且整个市场不是处于空头趋势日，那么就要考虑在交易时冒2到3美元的风险，然后在出现1到2美元的浮亏时加仓。然而，只有对自己的读图能力非常自信，并且拥有在读图错误时接受较大亏损的能力的老手，才可以尝试这样做。

**重要段落：**

> 每个人都希望得到非常高的胜率，但是极少有人能够一直保证自己有70%或更多的交易盈利。因此，只有非常少的人能够以在电子迷你中做利润目标为一两点的刮头皮交易为生。

> 对于大多数想要成功的交易者来说，他们不得不接受较低的胜率，并且培养做波段交易的耐心，允许交易过程中经历回撤。即便非常成功的交易者，除非他们愿意有时把交易波段化，否则他们通常不会加入到一些延长的趋势中，其中交易的成功率通常为60%或更低。

> 很多非常优秀的交易者在这些时间只是静静地坐着，等待高胜率的刮头皮交易，常常错失一波延长运动绝大部分。这是一种可以接受的交易方式，因为交易的目的是赚钱，而非不断交易。

2. 当趋势特别强时，可以通过在回撤或者在强尖峰中一棒的收盘入场而获得4点利润
3. 大部分波段交易者努力在某种类型的双重底做多，在某种类型的双重顶做空，或者在一天头几个小时内出现的某个可靠的开盘反转架构入场

> 波段交易者看到合理的架构后，他们必须选择交易。波段交易架构看起来几乎总是不如刮头皮架构确定，这种低胜率往往使交易者一直等待。

> 在突破或突破棒收盘后入场，是很难做到的，原因是突破尖峰通常非常大，交易者必须当机立断，接受比平常大得多的风险。

> 趋势尽其所能地把交易者们排斥在外，那是它们让交易者们在一整天的时间里一直在追逐市场的唯一方法。当一个架构简单明了时，其后的运动通常是小幅的快速刮头皮运动。如果一波运动打算运行较长时间，那么它必须是模糊的，很难把握的，使交易者们一直在旁观望，迫使他们追逐趋势。

## 第25章 交易的数学

### P323

**章节标题：** 第25章 交易的数学：我应该做这笔交易吗？如果做这笔交易，我会赚钱吗？ (Chapter 25: The Math of Trading: Should I Take This Trade? If I Take It, Will I Make Money?)

**概念定义：**

| 中文术语 | 英文术语 | 定义 |
|----------|----------|------|
| 交易数学 | Trading Mathematics | 交易完全基于数学，所有成功的交易者都对概率和交易数学有着透彻的理解 |
| 数学优势 | Mathematical Edge | 根据风险和回报大小，以及在保护性止损被触发前到达利润目标的概率得出的优势 |
| 完美交易 | Perfect Trade | 架构清晰，成功率高，风险小，回报大的交易——但极少存在 |
| 资金曲线 | Equity Curve | 交易账户净值随时间变化的曲线 |

**概率数据：**

| 场景 | 数据 |
|------|------|
| 传统机构年收益率目标 | 10-20% |
| 传统机构赚钱时间比例 | 70%以上 |
| HFT统计优势 | 5%或更低 |
| HFT与纯运气系统对比 | 小于55%胜率约等于5%优势 |
| HFT每周交易次数 | 成百上千万次 |
| 纯运气系统基准 | 50-50 |

**案例：**

> 我有一位朋友，他做交易30多年了，我认为他每天都要在电子迷你中赚10点或更多。他曾告诉我，普通的初学者一天至少应该能赚6点。我告诉他我不同意他的说法——如果初学者一直每天赚两点，那么他们就非常高兴。

**重要段落（加粗原文）：**

> **实际上，交易完全基于数学**，所有成功的交易者都对概率和交易数学有着透彻的理解。交易数学在每一跳动都在改变，对于不理解的人来说，它是一个障碍，但对于理解它的人来说，它是一个优势。

> 优势极少会很大，当三个变量中有一个变量异常好时，那么它将被另外一个或两个不好的变量所抵消。举例说明，如果潜在回报比风险大很多，也就是说风险相对较小，那么胜率通常也很低。如果胜率很高，那么回报通常会很小，风险通常会很高。

> 高频交易（HFT）公司的优势是他们拥有高度可靠的统计优势，或许只有5%或更低（与50-50纯运气系统相比，小于55%的胜率大约是5%的优势），但是他们一周要交易成百上千万次。这带给他们的是一种类似赌场的优势。

**趋势反转 (Trend Reversal)：**

1. 趋势线被强势突破后，寻找趋势极点测试后的反转，前提是那里出现一条不错的反转信号棒

4. 在空头台阶形态的第三次或第四次下推买进，预期市场测试前一下推的低点
5. 在多头台阶形态的第三次或第四次上推买进，预期市场测试前一上推的高点

**使用限价单入场 (Limit Order Entry)：**

6. 以市价或棒线收盘价在强多头突破的多头尖峰中买进，或者在前一棒的低点或低点下方使用限价单买进（尖峰入场需要较宽的止损，而且尖峰形成的速度很快）
7. 以市价或棒线收盘价在强空头突破的空头尖峰中卖出，或者在前一棒高点或高点上方使用限价单卖出
8. 在测量运动（目标）附近的空头突破买进，前提是那个突破不是太强——举例说明，如果电子迷你中的区间高度约为4点，那么就在区间下方4点处使用限价单买进，冒4点的风险，预期市场会测试突破点。**只有非常老练的交易者才可考虑这样操作**
9. 在测量运动（目标）附近的多头突破卖出，前提是那个突破不是太强——**只有非常老练的交易者才可考虑这样操作**
10. 在强势反转之后或交易区间底部可能形成的新多头趋势中，使用限价单在低点1或低点2弱信号棒下方买进
11. 在强势反转之后或交易区间顶部可能形成的新空头趋势中，使用限价单在高点1或高点2弱信号棒上方做空
12. 在均线处平静的多头旗形内，使用限价单在前一棒（低点）或其下方买进

### P326

**规则条件（续）：**

13. 在均线处平静的空头旗形内，使用限价单在前一棒（高点）或其上方做空
14. 在向上突破多头旗形的多头棒下方买进，预期出现突破回撤
15. 在向下突破空头旗形的空头棒上方做空，预期出现突破回撤

**胜率分类规则：**

**胜率约为50%（回报至少比风险大50%，才能打平）：**

1. 交易区间中准备逐步加仓的交易的初始入场
2. 在紧凑交易区间中买进或卖出，预期产生的突破会带来比风险大若干倍的利润
3. 当趋势可能正在向下反转时，在交易区间中的更低高点做空，或者当趋势可能正在向上反转时，在更高低点买进。由于入场点位于交易区间中部，所以胜率为50%，但回报通常是风险的两倍

**胜率为40%或更低（回报至少应为风险的两倍）：**

4. 在空头趋势的底部买进，或者在多头趋势的顶部做空，反转交易的风险很小，回报却非常大——举例说明，在市场上涨至明确阻力位时做空，使用限价单在阻力位下方1个跳动处入场，保护性止损位于阻力位上方一两个跳动处

**胜率为40~60%，取决于环境（当胜率只有40%时，回报至少为风险的两倍才能打平）：**

5. 当市场下跌时，使用限价单在多头趋势中的突破测试买进，或者当市场上涨时，使用限价单在空头趋势中的突破测试做空
6. 在新的多头趋势中，或者在交易区间的底部，使用限价单（一个潜在的更高低点）在低点1或低点2信号棒的下方买进，尽管它并不弱
7. 磁力位反向操作，比如在多头趋势中的上涨测量运动的目标处做空，在空头趋势中的下跌测量运动的目标处做多
8. 在一轮过度的空头趋势的支撑区内，在异常大型的空头趋势棒的收盘价附近的卖出高潮买进

**交易者方程详解：**

> 虽然大部分交易者不会用数学术语来研判交易架构，但所有成功交易者都使用交易者方程，至少是在潜意识中使用。

> 要想选择一笔交易，你必须相信交易者方程是有利的：**胜率乘以回报的积必须要大于败率乘以风险的积**。

**概率数据：**

| 场景 | 数据 |
|------|------|
| 不确信时假定胜率 | 50% |
| 自信时假定胜率 | 60% |

**重要段落：**

> 初学者们很快便了解到，趋势交易看起来是一种赚钱的极好方法。不过他们不久便发现，趋势交易实际上同其他任何类型的交易一样难。因为如果他们赚钱，肯定就有人要赔钱。市场是一种零和游戏，交易双方都有着数不尽的聪明人。

> 在趋势中，胜率通常比初学者预期的要低，而风险则高于他们的预期。在交易区间中，风险不是很大，但胜率和回报也不大。在反转中，虽然回报可能很大，但风险也很高，而且胜率较低。在刮头皮交易中，胜率很高，但是与风险相比，回报很低。

> 对于任意一笔交易，你都可以设定其回报和风险，潜在回报就是入场点到利润目标的距离，风险就是入场点到止损的距离。求解交易者方程的难点是给胜率赋一个值，从来不会确切地知道胜率有多大。

> 交易，无论规模多么大，都必须有一位买家站在交易的另一方。当成交量巨大时，买家肯定是机构，因为没有足够的小型交易者来补偿巨大的做空量。

> 某些买进程序正在买进，因为程序员已经用统计方法证明足够大的突破失败并快速反转，所以他们将通过在强空头突破买进而获利。

> 高频交易公司也在买进，做小型刮头皮交易，有些公司也在买进，对冲其他市场中的空头交易。当市场不是处于异常强劲的多头或空头尖峰中时，在每个跳动处都有机构买家和卖家。

> 每家公司都有自己的风险、回报、胜率组合，对于每一笔交易，都有自己预期的延续时间，而且很多公司会采用逐步入场和出场策略。

> 除非有大量的大型参与者，否则市场不会存在，而绝大部分的大型参与者肯定都是长期稳定获利的。

**案例：**

> 如果有一轮过度的强多头趋势，而且很可能出现回撤，那么强势多头可能在市价买进，并且在回撤期间继续持有，然后，一旦市场恢复上涨趋势，到达一个新的高点，他们就获利了结。在强势多头买进的同时，强势空头可能做空，并且在市场向均线下跌时获利。

> 另一个例子是当市场处于紧凑交易区间中时。比如说电子迷你处于一段只有5个跳动高的区间内。向上和向下突破的概率都约为50%。如果多头在区间中部买进，或者空头在区间中部卖出，任意一方都不得不冒着3个跳动的风险，去博取小幅突破带来的4个跳动或更多的利润。所以，每一方的回报都大于风险，而且胜率都约为50%，每一方都拥有一笔符合数学逻辑的交易，尽管他们是同时交易，尽管每一方都站在另一方交易的对面。

### P347

**概率数据：**

| 场景 | 数据 |
|------|------|
| 波段交易胜率 | 40-50% |
| 电子迷你平均日区间 | 10-15点 |
| 波段交易止损 | 约2点 |
| 波段交易利润目标 | 4点或更高 |
| 每日架构数量 | 约5个 |
| 每日最低交易数 | 3笔（保证至少一笔大盈利） |
| 部分交易盈亏 | 1-3点 |
| 2点利润目标所需胜率 | 60% |

**重要段落：**

> 如果你将一副扑克牌向空中投掷10次，然后记下哪些牌的正面朝上，那么你可能发现，有些牌10次中有9次正面朝上。当第11次把牌掷向空中时，你感觉有90%的确定性它将正面朝上吗？你认为概率实际上50-50吗？事实是毋庸置疑的。对于任意系统，如果你测试足够多的思想或足够多的输入，那么你会发现，有些10次中8次有效，有些10次中8次失败。那就是钟形曲线下面的结果分布，与实际的可能性毫不相干。

> 因此，很多交易者所用的系统，虽然在历史回测时非常棒，但是在实际交易中仍然亏钱。他们所认为的80%的可能性，实际上只有50-50，由于那就是事实，所以他们需要一个远大于风险的利润目标，才能有机会赚钱。

> 对于大部分交易者来说，应该寻找可能赚取波段利润的交易机会。当电子迷你的平均日区间约为10到15点时，交易者在一笔交易中通常可以承担大约两点的风险，而波段交易的利润则是4点或更高。

> 在实际交易中，大部分成功交易者都有自己的标准程序，在下单时不必考虑交易数学。举例说明，如果你一天只寻找几个4点波段，而且一直使用两点的止损，而且几年来你已经使用这种方法稳定获利，那么你很可能只需看某一个架构一眼，然后问自己它看起来怎么样，而不必去考虑概率。

### P349

**章节标题：** 方向概率 (Directional Probability)

**概念定义：**

| 中文术语 | 英文术语 | 定义 |
|----------|----------|------|
| 方向概率 | Directional Probability | 每一时刻下个跳动方向的概率；市场上涨还是下跌 |
| 等距运动 | Equidistant Movement | 幅度相等的上涨与下跌运动 |
| 几率偏向于 | Probability Bias | 交易者认为实现目标的几率远大于50% |

**概率数据：**

| 场景 | 数据 |
|------|------|
| 一天中大部分时间方向概率 | 约50% |
| 10个跳动等距运动方向概率 | 约50% |
| 20个跳动等距运动方向概率 | 约50% |
| 30个跳动等距运动方向概率 | 约50% |
| IBM向均线回撤买入概率 | 60%或更高 |
| 极度看涨时IBM概率 | 70%（$3.00风险博取$10回报） |
| 楔形多头旗形回撤50美分方向概率 | 60% |
| 楔形多头旗形回撤50美分博取$1.00方向概率 | 约57% |
| 电子迷你反转买入概率 | 60-40（4点利润/2点风险） |
| 10笔交易总利润 | 16点（6笔x4点-4笔x2点） |
| 每笔交易平均利润 | 1.6点 |

**案例：**

> 交易者们可能在IBM向日均线回撤时买进，因为他们认为几率偏向于在下跌$3.00前上涨$5.00。他们很可能认为那一几率是60%或更高。如果交易者们极度看涨，那么他们可能认为IBM在下跌$3.00前上涨$10的几率是70%。

> 如果有人交易电子迷你，正在一个离开一条长期（可能是50至200棒）多头趋势线的强势向上反转中买进，该反转形态出现在空头波段中一个最终空头旗形之后，那么这名交易者可能认为市场在下跌两点至他的保护性止损之前上涨4点至他的获利了结限价单的几率是60-40。

**重要段落：**

> 每一时刻，下个跳动的方向都有一个概率。市场是上涨还是下跌？在一天中的大部分时间里，那一概率在50%左右徘徊，也就是说下个跳动上涨的可能性与下跌的可能性相同。这是幅度为1个跳动的等距运动的当前方向概率。

> 5分钟图上，如果IBM处于一波楔形多头旗形回撤中，而且该回撤刚好位于均线和强多头趋势的多头趋势线处，那么下跌50美分之前上涨50美分的方向概率可能是60%，但是下跌50美分前上涨$1.00的方向概率可能略低，或许为57%，这带给交易者一个巨大的优势，说明回撤入场是非常棒的一种策略。

> 最常见的亏损原因之一是，未能充分考虑交易的数学基础。

### P350

**概念定义：**

| 中文术语 | 英文术语 | 定义 |
|----------|----------|------|
| 双向(OCO)订单 | One-Cancels-Other (OCO) Order | 两张订单同时设定，无论哪一张先执行，另一张都自动取消 |
| 包围单 | Bracket Order | 包含限价单和止损单的OCO订单 |

**概率数据：**

| 场景 | 数据 |
|------|------|
| 正交易者方程最低胜率 | 60% |
| IBM等距运动方向概率 | 约50% |
| IBM年上涨率 | 约8% |
| IBM日上涨幅度 | 约3.5美分 |
| 交易区间顶部买入上涨10跳动概率 | 约30% |
| 成功突破目标 | 上方60个跳动处磁力位 |
| 10次交易预期 | 3笔盈利（60跳动x3=180跳动），7笔亏损（10跳动x7=70跳动） |
| 净利润 | 110跳动，即每笔交易11个跳动 |

**规则条件：**

1. 几乎所有交易者都只应选择回报最低与风险一样大的交易
2. 在下单前需要考虑等距运动（回报与风险一样大的运动）的方向概率
3. 对于电子迷你买进架构，使用两点保护性止损时，有60%或更高可能性赚到两点利润才应交易
4. 做空AAPL时，使用$1.00保护性止损，需要有60%可能性赚到$1.00
5. 如果答案是肯定的，交易拥有正的交易者方程，是合理的交易
6. 如果答案是否定的，就不要做那笔交易
7. 最低起点总应是等于风险的回报
8. 如果看到一个架构很快认为不错，很可能认为赚得与风险一样大利润的概率最低是60%

**案例：**

> 以IBM为例，如果当前价格为$100，而且你既不观察图表，也完全忽略基本面和整个市场，那么当等距运动的方向概率在50%左右徘徊时，如果你买进100股IBM，然后设定双向(OCO)订单，在$101处使用卖出限价单离场，或者在$99处使用卖出止损单离场，无论哪一张先执行，另一张都自动取消，那么你赚到1美元的概率和亏掉1美元的概率都是50%左右。

> 如果在交易区间的顶部附近买进，那么市场在下跌10个跳动前上涨10个跳动的概率可能只有30%。假设成功突破将上涨至上方60个跳动处的一个磁力位，而且你在成功率只有30%时正在承担仅10个跳动的风险：如果你做10次这种交易，那么你将预期3笔盈利，每笔利润60个跳动，共计180个跳动的利润，7笔亏损，每笔亏损10个跳动，共计70个跳动的亏损。你的净利润将是110个跳动，即每笔交易11个跳动。

**重要段落：**

> 即便当等距运动的方向概率为50%时，通过采用逐步入场和出场策略，你仍然可以通过做多或做空赚钱。当一波对你有利的大型运动的方向概率约为50%时，如果那波运动相对于你的风险足够大，那么你也可以赚钱。甚至当等距运动的方向概率小于50%时，如果你在交易中坚持获取的利润足够大，那么你也可以赚钱。
