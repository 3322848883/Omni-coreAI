#### 3.2.1 头肩=延续形态（重要纠正）

> 来源：V2_B05_P201-250.md P228-230

⚠️ **重要概念纠正**：头肩顶/底实际上是**延续形态（旗形）**，而非反转形态。

**核心规则**：

| # | 规则原文 | 交易含义 |
|---|---------|---------|
| 1 | 由于趋势不断制造反转形态，而除了最后一个之外全部失败，所以认为这些经常讨论的形态是反转形态，是一种误导 | 趋势中大多数"反转形态"都会失败 |
| 2 | 更为准确的做法是把它们看作极少失败的延续形态 | 头肩形态应视为延续形态（旗形） |
| 3 | 所有的头肩顶和头肩底，实际上都是头肩延续形态（旗形） | 重要概念纠正 |
| 4 | 因为它们是交易区间，像所有交易区间一样，它们更可能在趋势方向上突破 | 突破方向与原来趋势一致 |
| 5 | 双重顶和双重底也是如此 | 同样适用于双重顶/底 |
| 6 | 头肩顶 = 楔形多头旗形 | 命名转换 |
| 7 | 头肩底 = 楔形空头旗形 | 命名转换 |

**头肩形态的三推结构**：

```
多头趋势中的头肩顶（实为楔形多头旗形）：

价格
  ↑    左肩（第一次上推）
  │   /
  │  /  头（第二次上推，更高高点）
  │ /     \
  │/       右肩（第三次上推，更低高点）
  └────────────────→ 时间
            颈线（连接两肩低点）
```

**交易规则**：

1. **命名策略**：
   - 当你在多头趋势中看到一个头肩形态时，最好把它看作一个**楔形多头旗形**
   - 把它叫做楔形多头旗形，因为那样你就会准备在多头趋势中的暂停买进
   - 那是一种可获利的策略

2. **入场规则**：
   - 不要期待头肩形态引发趋势反转
   - 把颈线突破失败视为顺势入场机会
   - 在突破失败方向入场（即原来趋势方向）

3. **突破行为**：
   - 很多头肩顶会向下突破颈线
   - 但那并不足以令交易者们相信趋势已经反转
   - 交易者们还希望看到坚持到底
   - 由于老手们知道大部分向下突破不会出现坚持到底
   - 所以他们把这些空头突破看作很棒的**买进机会**（顺势）

**双重顶/底同样适用**：

> "双重顶和双重底也是如此。举例说明，如果多头市场中出现一个头肩顶，那么对颈线的突破通道会失败，接下来市场几乎总是向上反转，形成一个顺势的向上突破，超越右肩。"（V2_B05 P228）

**双重顶/底K线距离量化**（原文V1_B01 P278-281）：
> "前一高点/低点可能就在一条棒线之前，也可能在20条或更多棒线之前。双重顶不一定非得出现在一天的高点处，而且通常形成于双重顶空头旗形中。"

| 距离 | 可靠性 | 说明 |
|------|:------:|------|
| 1-5棒间隔 | 高 | 微型双重顶/底，紧密排列 |
| 5-10棒间隔 | 中 | 标准双重顶/底 |
| 10-20棒间隔 | 中 | 较大间隔，仍有效 |
| 20+棒间隔 | 低-中 | 间隔过大，需更多确认 |

> "双重顶/底引出波段的概率为40-50%"（V3_B06 P286）

**重要原则**：

> "由于趋势不断制造反转形态，而除了最后一个之外全部失败，所以认为这些经常讨论的形态是反转形态，是一种误导。更为准确的做法是把它们看作极少失败的延续形态，但是，当延续形态失败时，就可能引起反转。"（V2_B05 P228）

> "把每个顶或底看作很棒的反转架构是错误的，因为如果你选择所有那些逆势入场，那么你的大部分交易将都是亏损交易，偶尔盈利的交易将不足以弥补你的亏损。"（V2_B05 P228）

#### 通道线过冲反转策略（原文：V3_B03 P101-102）

> 当通道陡峭时，在趋势通道线过冲处的每个反转买进是一种失败的策略。相反地，应该等待，直到出现对通道的强突破。

**核心规则**：
- [ ] **不要急于在过冲处逆势入场**：
  - [ ] 当通道陡峭时，在趋势通道线过冲处的每个反转买进是一种失败的策略
  - [ ] 应该等待对通道的强突破，然后准备在突破回撤买进
- [ ] **斜率增加警告**：
  - [ ] 一旦斜率增加，趋势就在加速，或许即将调整
  - [ ] 斜率的增加表明情绪越来越高涨，一旦情绪化交易者已经离场，就再没有人离场
- [ ] **楔形反转测量**：
  - [ ] 失败的楔形通常最低会引出一波约等于楔形高度的运动
  - [ ] 对通道的突破如果没有触及趋势通道线，反转尝试值得怀疑
- [ ] **反转确认条件**：
  - [ ] 大部分交易者会等待过冲，在没有过冲的情况下，他们会等待至少出现二次入场
  - [ ] 反转的第一条腿几乎总是会突破趋势线，如果它没有突破趋势线，那么该反转就值得怀疑

#### 失败Low 1/Low 2概念（原文：V3_B02 P51/P67-68）

> 失败的低点1、低点2：失败的双重底，即失败的低点1、低点2或三角形卖出信号。

**核心规则**：
- [ ] **失败Low 1/Low 2 = 顺势入场信号**：
  - [ ] 观察1分钟做空信号的唯一有效的理由是寻找做多（顺势）入场
  - [ ] 一旦做空信号触发，寻找保护性止损在哪里，然后把买单设在那里
  - [ ] 当被套的空头买回他们亏损的头寸时，将推动市场到达你的多头利润目标
- [ ] **Low 1做空架构限制**：
  - [ ] 低点1做空架构可靠的唯一时间是在强空头趋势的尖峰期中，决不是在反转形态之后
  - [ ] 那个低点1做空入场很可能不会跌破楔形低点，而是在两条腿向上调整中形成一个小幅更高低点
- [ ] **失败双重底/顶交易**：
  - [ ] 大部分可交易的反转都至少开始于微型双重底或双重顶、传统的双重底或双重顶、或者最终旗形反转
  - [ ] 仅仅因为市场形成一个双重底或双重顶，并不意味着应该做反转交易——交易决策必须以大的背景为基础
→ 深度知识：原文V3_B02 P51、P67-68

#### 扩张三角形（原文：V3_B03 P121-124）

> 扩张三角形可能是反转形态，也可能是延续形态，至少有五个波段构成（有时是七个波段，极少情况下是九个），每个波段都比前一个大。

**识别与交易规则**：
- [ ] **形态特征**：
  - [ ] 至少有五个波段构成（有时是七个波段，极少情况下是九个）
  - [ ] 每个波段都比前一个大
  - [ ] 所有扩张三角形都是重要趋势反转的变种
- [ ] **交易规则**：
  - [ ] 它的力量部分来自每个新突破处被套的交易者
  - [ ] 如果突破成功，下一个目标是一波向上的测量运动，约等于三角形中最后一条腿的高度
  - [ ] 如果突破失败，市场向下反转，那么它现在就是一个更大的扩张三角形顶，包含七条腿
  - [ ] 一般而言，市场在反转前会五次转向，但有时是七次
- [ ] **注意事项**：
  - [ ] 术语"三角形"容易引起误导，因为该形态常常看起来不像是三角形
  - [ ] 空头趋势中的扩张三角形底，后来常常演变为扩张三角形空头旗形
→ 深度知识：原文V3_B03 P121-124

#### 最终旗形深度规则（原文：V3_B02 P51/P87、V3_B03 P125-P132）

> 最终旗形是双重顶或双重底的一个变种。大部分被称为V形底的反转实际上是最终旗形反转。

**核心规则**：
- [ ] **最终旗形定义**：
  - [ ] 最终旗形是双重顶或双重底的一个变种
  - [ ] 最终旗形可以是任意大小的交易区间，包括只有一棒的交易区间，不过它通常至少包含5到10棒
  - [ ] 大部分被称为V形底的反转实际上是最终旗形反转
- [ ] **趋势持续时间与反转**：
  - [ ] 如果原来的趋势持续了50到100棒，那么反转更有可能演变为一个大旗形，而不是一轮反向趋势
  - [ ] 趋势拥有极大的惯性，倾向于拒绝所有反转尝试
  - [ ] 一般每次反转都比前一次大，最后，一次反转成功，令趋势反转
- [ ] **最终旗形突破三种方式**：
  - [ ] 突破强劲，向上超越多头趋势原有高点，然后市场在一个更高高点反转中向下反转
  - [ ] 突破可能较弱，市场可能在前一高点下方向下反转，形成一个更低高点反转
  - [ ] 可能根本没有突破多少，甚至没有向上突破
- [ ] **失败的最终旗形**：
  - [ ] 如果一个最终旗形反转触发，但是在一两棒内失败，那么它就成为一个失败的最终旗形
  - [ ] 失败的最终旗形是原来趋势恢复的架构，所以是一个突破回撤
→ 深度知识：原文V3_B02 P51、P87、原文V3_B03 P125-P132

#### 连续高潮与调整概率（原文：V3_B02 P70-75）

> 任意类型的非持续行为都应被视作一种高潮。

**高潮定义与规则**：
- [ ] **高潮定义**：
  - [ ] 任意类型的非持续行为都应被视作一种高潮
  - [ ] 每一条趋势棒都是一个高潮，尽管大部分趋势棒并不引起高潮反转
  - [ ] 高潮反转是随后出现一波迅猛的反向运动的高潮，都是对某个价位的失败的突破
- [ ] **连续高潮概率**：
  - [ ] 连续高潮增加了调整出现的几率
  - [ ] 两波连续的买进高潮形成两次上推，实际上是一个双重顶
  - [ ] 三波连续的买进高潮是一个楔形顶
  - [ ] 三波连续的买进高潮，市场通常至少形成两条腿调整，将至少持续10棒
- [ ] **趋势线与趋势通道线突破**：
  - [ ] 反转的第一条腿几乎总是会突破趋势线，如果它没有突破趋势线，那么该反转就值得怀疑
  - [ ] 大部分趋势通道线突破在五棒之内失败
  - [ ] 趋势线突破与趋势通道线突破具有相反的意义
- [ ] **真空效应**：
  - [ ] 卖出真空：快速下跌至买方愿意入场的价位
  - [ ] 买入真空：快速上涨至卖方愿意出场的价位
  - [ ] 当所有重要交易者卖出，而不再有买进时，市场向下反转，至少持续10棒，形成一两条腿形
→ 深度知识：原文V3_B02 P70-75
