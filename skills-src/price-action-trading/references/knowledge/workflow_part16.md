#### G.4 个股交易规则（V3 P225-P226）

**个股选择标准**：
- [ ] 日成交量500万股或更多
- [ ] 关注大整数磁铁（超越5%-10%后通常回撤至少一次）
- [ ] 确认做空可用性（部分经纪人无储备股票）
- [ ] 不同股票有不同个性（需观察适应）

**股票跳空开盘交易规则**（7条，V3 P225）：
1. [ ] 逆势交易时，目标应为1%-2%的刮头皮
2. [ ] 在昨日区间内开盘时风险较低
3. [ ] 不能观察时，跳空开盘最好略过
4. [ ] 能观察时，关注缺口回撤后入场
5. [ ] 向上跳空时，在开盘下跌后买入，止损设于今日低点下方
6. [ ] 入场失败后，等待二次架构再尝试一次
7. [ ] 不要在走势与预期不同的股票上花太多时间

#### G.7 加密货币适配参数（⚠️非原文，基于Brooks官网分析+通用原理）

**加密货币 vs 传统市场关键差异**：

| 维度 | 传统市场（Emini/股票） | 加密货币 |
|------|----------------------|---------|
| 交易时间 | 固定时段，有开盘/收盘 | 24/7，无休市 |
| 缺口 | 常见（开盘缺口、隔夜缺口） | 现货无缺口；CME期货有周末缺口 |
| 波动率 | VIX可衡量，相对稳定 | 极高且不稳定，日波幅可达5-15% |
| 流动性 | 集中在开盘/收盘 | 分散，但BTC/ETH流动性充足 |
| 杠杆 | 期货有内置杠杆 | 现货无杠杆；永续合约高杠杆 |
| 参与者 | 机构+散户混合 | 散户比例高，更容易恐惧/贪婪驱动 |
| 均线可靠性 | 开盘时段可靠 | 24/7连续，均线始终有效 |
| 趋势特征 | 趋势日+区间日混合 | 趋势更持久，波段幅度更大 |

**加密货币适配规则**：
1. [ ] **时间框架**：原文5分钟图原理完全适用；需自行定义"交易日"（如UTC 00:00重置）
2. [ ] **缺口**：现货无缺口，跳空开盘分析不适用；CME期货缺口可参考
3. [ ] **波动率**：需根据近期ATR调整止损和目标；高波动时扩大止损、减少仓位
4. [ ] **趋势**：加密货币趋势更持久（动量驱动），波段交易优于刮头皮
5. [ ] **参与者心理**：散户比例高→更多情绪化价格行为→更多假突破→需要更严格的信号棒标准
6. [ ] **流动性时段**：亚洲/欧洲/美洲时段交替，每个时段可能有不同趋势特征
7. [ ] **资金费率**：永续合约特有，高费率时可能影响短期价格行为
8. [ ] **大整数磁铁**：BTC的$100,000等整数关口是强磁铁（Brooks Trading Course官网2025年分析确认）

**BTC参考参数**（基于Brooks官网分析推算）：

| 参数 | 数值 | 说明 |
|------|------|------|
| 标准止损 | 0.1-0.3%（$100-300） | 视近期ATR调整 |
| 刮头皮目标 | 0.05-0.1%（$50-100） | 波段交易更优 |
| 波段目标 | 0.5-2%（$500-2,000） | 测量移动/前高前低 |
| 日均波幅 | 1-5% | 高波动期可达10%+ |
| 推荐时间框架 | 5分钟/15分钟 | 与原文一致 |
| 周线图 | 365日均线=公允价值 | Brooks官网使用 |
