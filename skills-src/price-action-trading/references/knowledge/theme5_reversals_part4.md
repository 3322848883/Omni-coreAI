### 第10章 日线图上的大成交量反转（Huge Volume Reversals on Daily Charts）

#### 核心概念

日线图上的大成交量反转是一种特殊的反转类型，通常标志着长期趋势的重要转折点。

#### 特征

- 出现在日线图上
- 成交量异常大，通常远超平均成交量
- 通常发生在趋势的极端
- 标志着机构的大规模重新定位

#### LEH（雷曼兄弟）案例

- 在日线图上形成大成交量反转
- 大成交量表明机构在积极重新定位
- 反转后通常有延伸的修正或趋势反转

#### BSC（贝尔斯登）案例

- 类似LEH的大成交量反转模式
- 大成交量K线是急速、高潮、突破和缺口
- 反转的强度与成交量大小相关

#### 关键规则

- 大成交量反转是长期趋势变化的重要信号
- 但不是所有大成交量K线都会导致反转
- 需要结合价格行为和其他信号来确认
- 反转后的第一腿通常会突破趋势线

### 高级趋势技术分析补充：反转强度量化评估

> 以下内容基于 Al Brooks《高级趋势技术分析》中的 24 个反转强度信号，整理为量化评分系统。所有术语已标准化。

**反转强度评分表 (Reversal Strength Score)**

| 信号类别 | 信号描述 | 分值 |
|---------|---------|------|
| 反转K线 | 有强反转K线，大实体小尾部 | 2分 |
| 后续跟进 | 接下来2-3根K线也有趋势实体 | 2分 |
| 急速规模 | 急速增长到5-10根K线 | 2分 |
| 急速质量 | 急速中K线低点=前根收盘价或仅低1跳 | 1分 |
| 缺口特征 | 急速中K线开盘价高于前根收盘价 | 1分 |
| 收盘位置 | 急速中K线收盘在极端或仅差1跳 | 1分 |
| 背景有利 | 整体背景使反转可能 | 2分 |
| 突破幅度 | 突破的第一或第二根K线收盘价高于许多前K线 | 1分 |
| 回撤延迟 | 第一次回撤仅在3根以上K线后发生 | 1分 |
| 回撤短暂 | 第一次回撤仅持续1-2根K线 | 1分 |
| 回撤浅 | 第一次回撤未触及保本止损 | 1分 |
| 突破阻力 | 急速突破多个阻力位 | 2分 |
| 紧迫感 | 有紧迫感，回撤迟迟不来 | 2分 |
| 二次信号 | 信号是过去几根K线内的第二次反转尝试 | 1分 |
| 趋势通道线 | 反转始于从旧趋势通道线过靶的反转 | 1分 |
| 关键水平 | 在重要摆动高点或低点反转 | 1分 |
| 回撤质量 | High 1/High 2回撤有强反转K线 | 1分 |
| 趋势性 | 具有趋势性的任何东西：收盘价、高点、低点或实体 | 1分 |
| 回撤方向 | 回撤小且横向 | 1分 |
| 趋势线突破 | 有先前的早期趋势线突破 | 1分 |
| 测试动量 | 测试极端的回撤缺乏动量 | 1分 |
| 测试失败 | 测试在移动平均线或旧趋势线处失败 | 1分 |
| 突破K线数 | 突破反转了许多近期收盘价和高点 | 2分 |

**评分解读**：
- **25-30分**：极强反转，摆动交易，可能主要趋势反转
- **18-24分**：强反转，可摆动部分仓位
- **10-17分**：中等反转，刮头皮为主
- **0-9分**：弱反转，可能失败，顺势交易更安全

### 缺口高级概念（来自高级反转技术分析 Ch20）

#### 缺口="看不见的趋势棒"
> 缺口在功能上等同于一根看不见的趋势棒。每一个缺口都是一个突破，每一个突破在功能上都是一个缺口。缺口应该像处理任何其他突破一样来处理——评估其强度信号，寻找突破回撤入场。

#### 大型缺口定义规则
> 大型缺口的定义标准（满足任一即可）：
> 1. 缺口幅度 > 平均日区间的一半
> 2. 缺口幅度 > 过去5天的最大缺口
> 大型缺口比小型缺口更可能跟随趋势运动，且运动幅度更大。

#### 90棒EMA替代法
> 在1分钟图上，可以使用90棒EMA来替代5分钟图的20棒EMA。这是因为1分钟图的90根K线大约等于5分钟图的18-20根K线（一个交易小时的约1/3）。这允许交易者在更低时间级别上使用相同的移动平均线分析技术。
