### 6.2 信号选择优先原则

1. **高概率建仓形态优先**：优先选择优先级1-8的建仓形态
2. **多理由叠加**：当多个建仓形态同时出现时，概率叠加
3. **市场状态匹配**：建仓形态必须与当前市场状态匹配
4. **信号质量优先**：强趋势信号棒 > 一般信号棒 > 弱信号棒，信号棒质量差不交易
5. **R:R 验证**：所有入场必须通过交易者方程式验证

## 交易者方程式速查表（第11章）

## 第11章：交易者方程式速查表

### 11.1 通用公式

**交易者方程式（Trader's Equation）**：

```
期望值 = (胜率 x 平均盈利) - (败率 x 平均亏损)

期望值 > 0 → 交易可行
期望值 < 0 → 不应交易
期望值 = 0 → 边缘交易，需要更多理由
```

**简化版本（以R为单位）**：

```
期望值(R) = (胜率 x R:R) - (败率 x 1)

其中：R:R = 平均盈利 / 平均亏损（以R为单位，亏损=1R）
      败率 = 1 - 胜率
```

### 11.2 快速判断规则

| 规则编号 | 规则描述 | 公式/条件 | 说明 |
|--------|---------|----------|------|
| TE-01 | 最低胜率要求 | 胜率 > 1 / (1 + R:R) | 例如R:R=1:1时，胜率需>50% |
| TE-02 | 刮头皮要求 | 胜率 > 70%（R:R<1:1） | 刮头皮（Theme7 Ch24） |
| TE-03 | 波段要求 | 胜率 > 40%（R:R=2:1） | 标准摆动交易 |
| TE-04 | 反转要求 | 胜率 > 33%（R:R=2:1+） | 反转交易需要更高R:R补偿低胜率 |
| TE-05 | 多理由提升 | 每增加一个理由，胜率约+5-10% | 2-3个理由叠加可显著提升概率 |

### 11.4 交易者方程式使用流程

```
Step 1: 确定建仓形态类型 → 查上表获取基准概率
Step 2: 评估信号质量 → 强趋势信号棒+5%, 一般信号棒+0%, 弱信号棒-5%, 信号棒质量差不交易
Step 3: 计算理由数量 → 每个额外理由+5-10%
Step 4: 确定R:R → 根据止损距离和目标计算
Step 5: 计算期望值 → 期望值 > 0 则交易可行
Step 6: 边缘判断 → 期望值接近0时，需要更多理由或跳过
```

### 12.4 BAN-15 详细说明

**BAN-15: 1分钟图作为主时间级别交易（P1）**
- IF 使用1分钟图作为主要交易时间级别 THEN 不建议交易
- 理由：止损距离太小、噪音太大、交易成本占比过高
- 例外：Al Brooks指出1分钟图可用于两种场景（参考theme8 Ch13）：①作为更精确的入场时机确认工具 ②在极低波幅的紧密区间中识别微观结构
