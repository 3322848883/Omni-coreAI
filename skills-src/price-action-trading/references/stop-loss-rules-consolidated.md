# 加密货币/贵金属止损规则速查

> 本文档整合 crypto 第五章、SKILL.md 行为准则、strategy_workflow 第7章中的止损规则，供分析时快速查阅。

## Step 4.0 止损校验清单

每笔交易**必须在计算交易者方程之前**完成以下校验：

```
1. SA-04 校验：止损距离 ≥ 1 tick？        → 否则拒绝交易
2. SA-05 校验：止损距离 ≤ 今日波幅 × 20%？ → 否则减仓或放弃
3. 合理性检查：与典型止损距离对比
4. 波动率环境？→ 按波动率调整规则处理
5. 校验结果：通过 → 继续方程计算；不通过 → 拒绝交易
```

## 原文止损规则

### 止损类型（SL 系列）

| 编号 | 止损类型 | 位置 | 适用 |
|------|---------|------|------|
| SL-01 | 信号K线止损 | 信号K线极端 + 1 tick | 所有止损入场（最常用） |
| SL-02 | 摆动极端止损 | 最近摆动高/低 + 1 tick | 摆动交易 |
| SL-04 | EMA20止损 | EMA20 + 1 tick | EMA回撤交易 |
| SL-06 | 时间止损 | 超5根K线未达目标 | 所有交易 |
| SL-07 | 追踪止损 | 摆动极端 + 1 tick（随价移动） | 趋势交易 |
| SL-08 | 硬止损 | 账户 2% 绝对上限 | 所有交易 |
| SL-10 | HTF关键价位止损 | HTF支撑/阻力 + 缓冲 | 入场点接近HTF关键位 |

### 止损调整规则（SA 系列）

| 编号 | 规则 | 条件 | 动作 |
|------|------|------|------|
| SA-01 | 只向有利方向移动 | 持仓盈利 | 绝不扩大止损 |
| SA-02 | 保本止损 | 达到 1R 盈利 | 移至入场价 + 1 tick |
| SA-03 | 阶段性获利 | 达到 2R 盈利 | 移至 1R 位置 |
| SA-04 | 止损不可过小 | < 1 tick | 不交易 |
| SA-05 | 止损不可过大 | > 日均波幅 × 20% | 减仓或放弃 |
| SA-06 | 铁丝网中加大止损 | 铁丝网区域 | 放在外侧 + 缓冲 |
| SA-07 | 突破交易止损 | 突破入场 | 突破K线另一端 |
| SA-08 | 反转交易止损 | 反转入场 | 反转K线极端 |

## 波动率调整规则

```
波动率比率 = 今日波幅% ÷ 品种日均波幅中值

BTC: 中值 3% | ETH: 中值 3.5% | SOL: 中值 5% | XAU: 中值 1% | XAG: 中值 1%
```

| 波动率环境 | 比率 | 止损调整 | 仓位调整 | R:R 要求 |
|-----------|------|---------|---------|---------|
| 低波动 | < 0.7 | 收窄至 80% | +20% | 标准 |
| 常规 | 0.7-1.5 | 标准 | 标准 | 标准 |
| 高波动 | 1.5-2.5 | **放宽 1.5x** | **×50%** | **≥3:1** |
| 极端波动 | > 2.5 | **放宽 2x** | **×25%** | **≥5:1** |

## 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 止损过紧（远小于典型值） | 被噪音扫掉 | 参考典型止损距离，考虑适当放宽 |
| 忘记波动率调整 | 高波动日用标准止损 | 查今日波幅%，按上表调整 |
| 不交易时跳过 Step 4.0/4.1/4.2 | 条件满足时无法快速执行 | 即使"不交易"也填写条件性方案 |
