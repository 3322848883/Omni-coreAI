## 3. 未采纳项（NG，Brooks 优先）

> 下列条目**不写入**策略主规则，**不作为**分析合格的必要条件；验收只要求「按 Brooks/技能」并写清市场状态。

### NG-01 二三十根 K 震荡「优先做突破单」

| 项 | 内容 |
|----|------|
| 导图 | 震荡二三十根后优先突破单 |
| 冲突 | 官网与 theme11：**区间中约 80% 突破尝试失败** |
| 技能约定 | 维持默认：不追突破；仅 **强突破+良好跟进**（R-005 类）或 **失败之失败**（R-007/V-005）等高概率形态；BAN/CT 仍适用 |
| 分析写法 | 周期=震荡时，方案可写「等待突破+跟进」或区间边界，**禁止**写「长震荡所以直接突破单」作为唯一理由 |

### NG-02 外包 K「预示趋势反转」

| 项 | 内容 |
|----|------|
| 导图 | out bar 高低点破前根 → 预示反转 |
| 冲突 | Glossary：outside bar **仅定义**外包范围；可延续、双向或反转 |
| 技能约定 | SB-06/07：顺势外包或极端位反转外包需**位置+跟进**；区间中部外包无价值 |
| 分析写法 | 识别外包后必须写位置与 AI 方向，不得单独「外包=反转信号」 |

### NG-03 绝对「不加仓」

| 项 | 内容 |
|----|------|
| 导图 | 规则三：不加仓（一刀切） |
| 冲突 | V1 原文允许强趋势远离 EMA 时限价 scale in；技能禁**亏损**加仓，非禁一切分批 |
| 技能约定 | 服从 **PM-04/SI 与第20章**：不对亏损仓加仓；顺势高概率回撤在日风险上限内可分批；高波动/HTF 弱时默认不加 |
| 分析写法 | Step 7.3 按 PM/SI/SO；个人若选「永不加仓」可在 trader_profile 声明，属风控收紧，**不是** Brooks 硬性原文 |

### NG-04 宽通道「75% 反转并测试通道起终点」

| 项 | 内容 |
|----|------|
| 导图 | 宽通道弱趋势 75% 反转 + 测起终点 |
| 冲突 | 多条 **不同** 75% 被混用 |
| 官方/技能中的 75%（勿合并） | ① 多头通道**上方突破**约 75% 在随后约 5 根内失败（theme11 P-19）② 多头通道视为熊旗：约 75% **跌破多头趋势线**（官网 10 patterns）③ 回撤达前腿 **≥75%** 时回到原趋势极点概率大打折扣（theme3「75%回撤规则」） |
| 技能约定 | 通道管理按 theme2 + strategy 趋势引擎；测磁铁/起终点用 theme6，**不**用「75% 必测起终点」作唯一规则 |
| 分析写法 | 若写 75%，必须标明是哪一条（上破失败 / 跌破趋势线 / 深回撤含义） |

### NG-05 「回调 50% → 约 60% 延续；回调 2/3 → 多空对半」

| 项 | 内容 |
|----|------|
| 导图 | 上述精确数字 |
| 核实 | 官网已取页面 + theme11 概率章 **未收录**该组精确表述 |

| 分析写法 | 可用「浅回撤偏强、深回撤偏弱」等定性语言；**禁止**标注「Brooks：回调 50%=60%」除非 docs/pa-source/ 页码可证 |

### NG-06 MM「均约 60% 抵达」

| 项 | 内容 |
|----|------|
