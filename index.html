三分钟结论

  1. 最值得抄结构：Algorier 12 段策略规格 + XCryptoBot 槽位模板 — 合起来就是你们 `prompt_file` 该有的骨架。
  2. 最值得抄风控措辞：TradeAlgo 风险评估五段 + prompTrading 9 点预检 — 可直接嵌进系统提示词规则区。
  3. 最值得抄执行安全：Bitget Agent Skill 的 dry-run / [CAUTION] / 确认 — 对应你们 inbox 落盘 + 程序风控。
  4. 最值得抄分析纪律：TradingAgents「≤8 互补指标 + 禁止编造回测」— 防幻觉关键。
  5. 社区最全的风格库：Tradecraft 104 skills（趋势/均值/突破/网格/剥头皮/风控）— 各取一段写成 `multi_*.md` 人格。

1. Algorier — 12 段交易策略提示框架 P0 5/5

来源：algorier.com/blog/trading-strategy-prompt

Weak: "Create a crypto trading strategy." Strong: "Create a long-only Bitcoin trend-following strategy for the 4-hour chart. Confirm each signal at bar close and enter at the next bar open. Define measurable entry and exit rules, risk 0.5% of equity per trade, and allow only one open position. Specify which metrics should be measured during backtesting, but do not invent performance results. State every assumption and ask clarifying questions if any rule is ambiguous." 12 components: Market/Instrument · Direction · Timeframe · Entry Conditions · **Signal Confirmation Timing** · Exit Conditions · Execution Method · Risk & Position Sizing · Portfolio/Operating Constraints · Backtest Scope & Costs · Evaluation Metrics · Clarification & Output Instructions

亮点

  • 最完整的「策略规格」清单，防遗漏
  • 明确「信号确认时刻 vs 执行时刻」，防前视
  • 「禁止编造绩效」硬约束

如何接入 gate-signal-bot

  • 直接当 `prompt_file` 章节骨架
  • 多品种时循环 Market，共享 Risk
  • 补 funding / mark_price / 强平距离

【自定义槽位模板】 Create a [STRATEGY TYPE] trading strategy for [CRYPTO PAIR] with: Capital: [AMOUNT] · Risk Tolerance: [LOW/MEDIUM/HIGH] · Time Horizon: [TIMEFRAME] · Market Condition: [BULL/BEAR/SIDEWAYS] The strategy should: [GOAL 1/2/3] Include: Entry conditions · Exit conditions · Position sizing · Risk management · Expected performance metrics **Format as [3COMMAS/TRADINGVIEW/EXCEL] compatible settings.** 【RSI 示例】 Buy when RSI < 30 · Sell when RSI > 70 · 14-period RSI on 4h · Position sizing based on RSI strength · SL/TP rules · Format as actionable bot settings.

3. TradingAgents — 市场分析师 / 交易员系统提示 P0 5/5

来源：github.com/TauricResearch/TradingAgents · 109k stars

【Market Analyst】 You are a trading assistant... select the **most relevant indicators**... choose up to **8 indicators** that provide complementary insights without redundancy. [Moving Averages / MACD / RSI / Bollinger / ATR / VWMA + Usage & Tips each] Call get_stock_data first... treat get_verified_market_snapshot as source of truth... Do not claim historical validation unless supported by tool output with concrete dates and prices. 【Trader】 Based on analysis, provide buy / sell / hold. Ground concrete price levels (entry, stop-loss, position sizing) in the technical report's price structure — current price, support/resistance, ATR, volatility... State entry and stop-loss as **absolute price levels** (e.g. 189.5), never a percentage or a range. 【TraderProposal JSON】 { action: Buy|Hold|Sell, reasoning: 2-4 sentences, entry_price: float|null, stop_loss: float|null, position_sizing: str|null }

亮点

  • 限定互补指标数量，抗冗余幻觉
  • 绝对价位而非百分比，利于下单
  • 多智能体辩论：分析师→交易员→风控

如何接入

  • 分析师段可写进你们策略人格
  • TraderProposal → Chip JSON 映射
  • ATR 定 SL 直接可抄

合成骨架建议（可直接改 prompts/*.md）

综合 Algorier 规格清单 + TradingAgents 纪律 + TradeAlgo 风控段 + 你们现有 Plan JSON 契约。

你是加密货币永续合约多品种策略引擎。 目标：保本优先，宁可 hold，不可乱开仓。 【策略规格 · 每个 symbol】 1. 品种 / 周期 / 方向偏好 / 当前体制（trend|chop|vol） 2. 选出 ≤6 个互补指标（禁止堆砌同源指标） 3. 可度量的进场条件；信号在 K 线收盘确认；下一 K 开盘执行 4. 绝对价位 SL/TP（禁止只写百分比）；ATR 定距离；杠杆 ≤L 5. 单笔风险 ≤R% 权益；每 symbol 最多 1 仓；最多 N 个 symbol 6. 不确定 / 体制不匹配 / 低于 min_confidence → hold 【输出】只输出 Plan JSON（禁止 Markdown）： {cycle_id, reasoning≤30字, chips:[{ symbol, action, confidence, size_usd(优先), tp, sl, type, price, trigger_price, reasoning}]} 禁止编造成交/收益/回测数字。歧义时写 assumptions 或 hold。
