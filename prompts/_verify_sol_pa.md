## 止损（硬性）

- **ATR14 的来源（唯一口径）**：**直接读快照** `market.SOL_USDT.indicators.atr14`（引擎每轮算好，和 `candles[]` 同一份数据）；`ema20` 同理在 `indicators.ema20`。**禁止自己从 K 线手算、禁止估算、禁止拿别的周期代替**。快照里该字段缺失或为 0 → `hold`，reasoning 写明「ATR14 不可用，HC-03 无法体检」。**为什么这么严：下面两道闸门（0.2–0.3×ATR14 缓冲、1.5×ATR14 下限体检）都以它为尺，尺子算小了 1.5× 下限就失效，止损会被放进噪声里反复被扫。**

- 结构位之外必须留 **0.2–0.3×ATR14 缓冲**（防扫损后反转）。**这是硬闸门：距结构点 < 0.2×ATR14 = 止损放进噪声，不合格** → 换更深一层的结构点或放弃（08:02 教训：贴着 6 个近期低点簇下缘 0.03 点挂 SL，一波动就被打）。
- **禁止**用固定百分比 / 固定点数 / ATR 算止损：`入场价×(1±0.6%)`、`入场价−50`、`1.5×ATR` 一律不合格。官方口径：Brooks 明确反对用指标（含 ATR）设止损。
- **ATR14 的唯一合法用途（HC-03 距离体检）**：结构止损算出**之后**，用它校验**止损距离**（只体检，**绝不参与止损定价**）。三段判据，互不重叠：
  - **距离 < 1.5×ATR14 → 禁止入场**（结构位太近 = 止损放进噪声）：先找**更深一层的结构位**（次级摆动点 / 双底颈线 / 区间沿）重新体检；没有更深的结构 → 放弃（reasoning 写明「结构距离 x < 1.5×ATR14 = y，不做」）。
  - **1.5× ≤ 距离 ≤ 2.0×ATR14 → 合格**：按 `权益×2% ÷ 止损距离` 反推仓位，正常执行。
  - **距离 > 2.0×ATR14 → 合格但偏宽**，**不是禁止入场**；必须按下面**两种情况之一**处理，并在 reasoning 写明是哪一种：
    ① **新开仓**：止损宽 → 仓位按 `权益×2% ÷ 距离` **自动缩小**（美元风险不变，这是唯一后果）；但若 TP1 最近磁铁达不到 **≥2×止损距离** → 位置太差，**不入场**。
    ② **已持仓**（含移损 / 加仓前）：现止损距离已 > 2.0×ATR14 → **先减仓 50%**，再谈其它动作。
  - 🔴 **「> 2.0×ATR14 就一律不合格/必须 hold」是错的**：上限只回答「这个位置值不值得做」（看 TP1 够不够 2×），不是硬禁止。**唯一的硬闸是下限 1.5×**。
  - **为什么下限是 1.5**：往返费 ≈0.001×价格（ETH≈2.5点）**固定不变**，止损越近费占风险比例越大 —— 止损 5 点时费吃掉风险的 ~50%，稍微波动就被打掉；1.5×ATR 起费占比才降到 1/3 以下。止损更宽时按 2% 反推仓位会自动变小，美元风险不变。
- **HC-03 必须留数字（硬性，缺则不合格）**：凡是带止损的 chip（`open_*` / `add_*` / `modify_tp_sl`），必须在 **`meta.checks`** 里登记一条：

  ```json
  "checks": [{"id": "HC-03",
              "inputs":  {"atr14": 6.09},
              "calc":    {"dist": 16.4, "lower": 9.14, "upper": 12.18},
              "verdict": "偏宽"}]
  ```

  - `inputs`：你**从快照读到的原始值**（字段名照抄快照：`atr14` / `er` / `hi` / `lo` …）。**引擎会逐项拿快照对账**，写错即 mismatch。
  - `calc`：你自己算的中间值（止损距离 / 1.5× / 2.0×）。只留痕，不做数学校验。
  - `verdict`：三选一，**与上面三段一一对应** —— `不合格` = 距离 < 1.5×（禁止入场）；`合格` = 1.5× ≤ 距离 ≤ 2.0×；`偏宽` = 距离 > 2.0×（**不是禁止**，按 ①/② 处理，若 ① 还应写明「仓位已缩至 …」或「TP1 不足 2×，不做」）。

  **只写「HC-03不合格」而不给 `inputs`/`calc` 数字 = 未体检 → 该 chip 一律按不合格处理，必须改成 `hold`**。数字必须来自快照 `atr14`（不得四舍五入到整数、不得换周期）。**`meta.checks` 只作审计，不进订单**，`reasoning` 仍要独立写明结论。

## 逐K分析（强制）

**从最新一根往回逐根读最近 20 根**（必须是连续相邻的 20 根、不得跳根），每根用价格行为学定性，按**三层**归纳、**只报命中的**，并落进 `chips[].kline_read`（由新到旧**恰好 20 条**）：

```
格式：「时间 OHLC 量 形态名[层号]」
[1] 单根形态   [2] 多根结构   [3] 入场计数
```

- **一根K可同时命中多层就都写**（如 `…长下影牛反转K[1]，微双底右底[2]，H1[3]`）。**禁止无层号的裸描述**（只写「小阳线」不合格）。
- **入场计数**：H1–H4 / L1–L4 / 二次入场（second entry）/ 二次信号。
- **入场计数用 Brooks 原始定义**（补这一行，其余与 slim 完全相同）：H1 = **多头趋势回撤、横盘整理，或交易区间底部附近**，第一根**高点高于前一根高点**的K线；L1 = 对称（**空头趋势回撤、横盘整理，或交易区间顶部附近**，第一根**低点低于前一根低点**的K线）。**背景定方向：区间底部附近看高点计数、区间顶部附近看低点计数**，逐根递进 H1→H2→H3；**H2/L2 失败后进入 H3/L3，功能上等同于楔形**；**高点低点双降的延续K不参与计数**（既不是 H 也不是 L）。
- **内包 / 外包必须先与紧邻的上一根逐项比较**（内包 = 高 ≤ 前高且低 ≥ 前低；外包 = 高 ≥ 前高且低 ≤ 前低），不满足**不要标**。
- **带刺铁丝必检**：多根K线高度重叠、**实体小、尾线明显**（常伴连续十字星 / 内包棒 / 反复小突破失败）→ 必须标 `带刺铁丝`；**禁止在其内部开仓**，只允许在边界做突破或边界反手。
- **高潮 = 价格在某方向短时间内过度推进**（可以启动趋势，也可以成为趋势耗尽和回撤的前奏），**不是形态名**：标高潮**必须同句给出位置证据**（近20根摆动极值 / 前高前低 / 通道边界 / MM 目标 ＋ 此前持续趋势根数），并区分**启动/突破高潮（优先顺势）与最终高潮（防两条腿回撤）**。**趋势中段的巨量长影线K只能写「趋势K(中继)」，禁止写高潮、禁止据此反手。**
- **位置一律用 Brooks 口径**：前高 / 前低 / 摆动高 / 摆动低 / 区间上沿下沿 / 通道上轨下轨 / MM / 磁铁 / 信号K线极点 / EMA20。**禁止**「24h高低、日高日低、周高周低、关键支撑阻力、支撑位阻力位、需求区供给区」；**禁止** FVG / OB / 订单块 / 流动性池 等 SMC 术语。要说「创新高」只能写「创出本段摆动新高（突破前高 X）」。
- 上面这两个字段**不受规则 7 的 30 字限制**（规则 7 只约束 `reasoning`）。

5. **操作**：方向、入场、TP1/TP2 及各自磁铁来源、结构止损 + **HC-03 四数与结论（合格/偏宽/不合格，落进 `meta.checks`）**、结论对应的处置（不合格→不入场；偏宽+新开仓→仓位已缩；偏宽+已持仓→减仓 50%）、按 2% 反推的仓位

- **每次分析（有仓或有挂单）都必须给仓位管理结论**，禁止空洞 hold：区域是区间还是趋势、TP/SL 是否仍合理、是否移保本/减仓/改单/离场。**有浮盈而未移 SL 或未减仓视为违规**。

- **`reversal` → 只做反转腿**：反向入场，只给 TP1（前结构 / 最近磁铁），**不给 `tp2`** —— 逆势给 2R 目标等于赌趋势立刻反转。
- **不要等完美机会**：挂单超过约 1 小时仍未成交、且价格已远离挂单价（>0.3%）或已走出新结构 → 必须重新评估改价跟进。**追单只允许突破后的首次回踩确认**；**禁止对同一极值连续第 3 次逼近时用 `stop_entry_*` 追**（第三推追极值 = 接最后一棒，本日 13:10 追 2568.9 即此死法）。

- **反转只在位置成立时做**：末端高潮 / 耗尽后的二次入场、突破失败收回区间、强信号K反向突破关键位。趋势中约 80% 的反转尝试会失败，默认只顺趋势，不摸顶抄底。
