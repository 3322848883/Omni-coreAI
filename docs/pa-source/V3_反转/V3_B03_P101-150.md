## P101: 趋势通道线过冲与反转策略

### 原始章节
第4章 趋势通道线过冲（续）

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 逆势交易者 | Counter-trend traders | 在趋势方向相反方向入场的交易者 |
| 趋势通道线过冲 | Trend channel line overshoot | 价格短暂穿越趋势通道线外侧 |
| 二次入场 | Second entry | 等待第二次机会入场，提高成功率 |
| 20缺口棒做空架构 | 20-gap-bar short setup | 实体完全位于指数均线上方的大型棒线 |
| 第一均线缺口棒 | First moving average gap bar | 价格远离均线的大型实体棒 |
| 卖出高潮 | Selling climax | 连续的强空头运动，可能引起向上反转 |
| 突破回撤 | Breakout pullback | 突破后的回撤入场机会 |

### 核心规则
1. 当通道陡峭时，在趋势通道线过冲处的每个反转买进是一种失败的策略
2. 应该等待对通道的强突破，然后准备在突破回撤买进
3. 聪明的空头将设定限价单在前一棒高点或其上方做空，在过于急切的多头买进的位置
4. 失败的楔形通常最低会引出一波约等于楔形高度的运动
5. 对通道的突破如果没有触及趋势通道线，反转尝试值得怀疑

### 图表描述
- 图表: TradeStation ESU08.D 5分钟图，2008年9月2日
- 价格范围: 约1,248.00至1,296.00
- 显示下降趋势通道，棒1-10标注
- 包含20周期EMA线

### 重要段落
> 逆势交易者们总是在绘制趋势通道线，希望出现过冲和反转，至少允许他们做一笔刮头皮交易，而最好是形成两条腿的逆势运动。当通道陡峭时，在趋势通道线过冲处的每个反转买进是一种失败的策略。相反地，应该等待，直到出现对通道的强突破，比如图4.13中截止棒5的大型上涨缺口，然后准备在突破回撤买进，比如棒8二次尝试反转昨日低点。

> 棒5在远高于空头通道处开盘，但它是一个20缺口棒做空架构，本质上是一条第一均线缺口棒（足够接近——它的实体很大，而且完全位于指数均线上方），形成一轮开盘起下跌趋势。

## P102: 斜率的增加与高潮情绪

### 原始章节
第4章 趋势通道线过冲（续）— 图4.14

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 过冲 | Overshoot | 价格短暂穿越趋势通道线 |
| 二次入场 | Second entry | 等待第二次机会入场 |
| 信号棒 | Signal bar | 触发入场的棒线 |
| 内包棒 | Inside bar | 高点低于前棒高点、低点高于前棒低点 |
| 开盘反转架构 | Opening reversal setup | 开盘后形成的反转形态 |
| 最终旗形 | Final flag | 趋势中最后一个旗形，预示反转 |
| 卖出高潮 | Selling climax | 连续强空头运动 |
| 双重底 | Double bottom | 两次测试同一低点 |
| 尖峰 | Spike | 快速大幅的价格运动 |

### 核心规则
1. 大部分交易者会等待过冲，在没有过冲的情况下，他们会等待至少出现二次入场
2. 信号棒是一个十字星，实体非常小，说明多头并不强
3. 一旦斜率增加，趋势就在加速，或许即将调整
4. 斜率的增加表明情绪越来越高涨，一旦情绪化交易者已经离场，就再没有人离场
5. 从棒13开始的下跌运动比它前面的空头通道陡峭，这波卖出高潮在棒15强多头趋势棒处向上反转

### 图表描述
- 图4.14: TradeStation @ES.D 5分钟图，E-mini S&P 500连续合约[Dec10]
- 棒1-23标注，时间轴从10:30到次日9:30
- 价格范围: 1161-1181
- 显示多头趋势后空头通道反转

### 重要段落
> 一旦斜率增加，趋势就在加速，或许即将调整。这是因为，斜率的增加表明情绪越来越高涨，一旦情绪化交易者已经离场，就再没有人离场，也没有人愿意入场，直到出现回撤。

> 棒8过冲了空头趋势通道线，信号棒是一条内包棒，拥有不错的多头实体。这个架构也是二次尝试反转昨日低点，形成一个可依赖的开盘反转架构，可能成为当日低点。

## P103: 反转需要动能

### 原始章节
第4章 趋势通道线过冲（续）— 图4.15

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 耗尽型卖出高潮 | Exhaustive sell climax | 非持续性行为终点的强空头运动 |
| 测量运动 | Measured move | 以形态高度为基准的等距运动 |
| 卖出真空 | Sell vacuum | 快速下跌至买方愿意入场的价位 |
| 双重底重要趋势反转 | Double bottom major trend reversal | 双重底处的重要趋势反转 |
| 更高低点重要趋势反转 | Higher low major trend reversal | 更高低点处的重要趋势反转 |
| 三角形 | Triangle | 三次下推的形态 |
| 高潮行为 | Climax behavior | 非持续性行为的终点 |

### 核心规则
1. 当棒14前面的大型空头趋势棒形成时，既可看作一个突破，也可看作一波耗尽型卖出高潮
2. 耗尽型卖出高潮可能引起向上反转，持续大约10棒和两条腿
3. 由于它形成于一系列陡峭的、没有调整的空头棒之后，所以很可能是高潮行为
4. 强多头反转棒和入场棒表明反转很强，卖家在一旁观望了大约10棒
5. 如果多头在停止于楔形顶部下方的反弹处将新的多头头寸获利了结，那么市场将形成一个更低高点

### 概率数据

| 概率 | 条件 | 说明 |
|------|------|------|
| ~10棒和两条腿 | 耗尽型卖出高潮后的向上反转 | 持续时间估计 |
| ~10棒 | 等待回撤的时间 | 多头和空头观望时间 |
| 6棒之后 | 买进入场时机 | 在棒22低点与棒17低点的双重底中 |

- 图4.15: TradeStation ESM08.D 5分钟图，E-mini S&P 500 Jun 2008
- 棒1-12标注
- 价格范围: 约1,388.00至1,426.00
- 显示下降通道后的反转

### 重要段落
> 当棒14前面的大型空头趋势棒形成时，既可看作一个突破，可能引起一波向下的测量运动，也可看作一波耗尽型卖出高潮，可能引起向上反转，持续大约10棒和两条腿。由于它形成于这样一系列陡峭的、没有调整的空头棒之后，所以很可能是非持续性行为的终点，因此是高潮行为。

## P104: 楔形反转与楔形回撤的区别

### 原始章节
第4章 趋势通道线过冲（续）— 图4.16

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 楔形反转 | Wedge reversal | 尝试令趋势反转的楔形形态 |
| 楔形回撤 | Wedge pullback | 趋势中的楔形回调 |
| 三推下跌形态 | Three-push down pattern | 三次向下推动的形态 |
| 连续卖出高潮 | Consecutive selling climaxes | 一系列高潮型卖出 |
| 趋势型交易区间 | Trending trading range | 带有趋势特征的交易区间 |

### 核心规则
1. 楔形反转不同于楔形回撤，需要注意形态出现的背景
2. 当楔形是反转时，它是一种逆势交易，应该在买进前等待一个更高低点
3. 在强空头趋势中努力去做多头刮头皮，是一种失败的策略
4. 每当出现一轮强空头趋势时，在出现一个更高低点之前，只寻找做空架构
5. 不要先于棒线操作；必须等待收盘和下一棒确认反转
6. 即便不知道这一点，在空头趋势通道线突破下方1个跳动处做空仍然是一笔明智的交易

### 图表描述
- 图4.16: TradeStation @ES.D 5分钟图，E-mini S&P 500连续合约[Sep08]
- 棒1-6标注
- 价格范围: 约1,331.00至1,361.00
- 显示下降趋势通道内的双向交易

### 重要段落
> 当一个高潮形态未能形成任何逆势动能时，假定你读图错误，正打算在错误的方向交易。楔形反转不同于楔形回撤，尽管它们看起来是一样的。你需要注意形态出现的背景。

> 每当你发现自己画了多条趋势通道线时，你难免会因不能相信正在发生的事情而变得焦躁不安，从而令你无法看清眼前发生的一切。保持耐心，只做顺势交易，直到反转非常清晰、非常强劲，以致于你无需画线便可看到那种过度。

## P106-P107: 第5章 楔形和其他三推反转形态

### 原始章节
**第5章 楔形和其他三推反转形态**（新章节开始）

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 三推形态 | Three-push pattern | 三次连续推动的形态 |
| 楔形 | Wedge | 收敛趋势通道内的三推形态 |
| 微型楔形 | Micro wedge | 由3-5条连续棒线构成的楔形 |
| 抛物线楔形 | Parabolic wedge | 斜率递增的楔形 |
| 四推楔形 | Four-push wedge | 包含四次推动的楔形 |
| 扩张三角形 | Expanding triangle | 发散趋势线的三角形 |
| 三重顶/底 | Triple top/bottom | 三次测试同一价位 |
| 头肩顶/底 | Head and shoulders top/bottom | 经典反转形态 |
| 收缩台阶形态 | Contraction stair pattern | 突破幅度递减的三推形态 |
| 紧迫感 | Urgency | 交易者急于入场的心理状态 |

### 核心规则
1. 当市场在某个方向形成三推，然后形成一个反转架构触发反转交易时，第一个目标是该形态的起点，下一个目标是以该形态的高度为基准的一波测量运动
2. 所有三推形态都是相同潜在市场行为的表象，而无论该形态的外形如何
3. 三推形态常常包含大型趋势棒，形成连续的高潮
4. 如果上推或下推是很强的一到三棒的尖峰，那么交易者们就会把它们看作高潮
5. 楔形回撤在第二本书的第18章和19章讨论过；楔形反转是逆势架构
6. 楔形旗形通常是较小的形态，大多数只持续10到20棒左右
7. 一个反转通常至少需要20棒，而且拥有一条清晰的趋势通道线
8. 趋势常常在测试极点时结束，测试常常包含两条腿

### 概率数据

| 概率 | 条件 | 说明 |
|------|------|------|
| 60%或更高 | 三波连续卖出高潮后 | 市场将试图形成更为复杂的调整（两条腿上涨，持续10棒或更多棒） |
| 10棒或更多棒 | 复杂两条腿向上调整 | 持续时间 |
| 10到20棒 | 楔形旗形 | 大多数楔形旗形的持续时间 |
| 两条腿和10棒 | 高潮反转 | 抛物线楔形反转后的持续时间 |

### 重要段落
> 所有三推形态都是相同潜在市场行为的表象，而无论该形态的外形如何。无论它是一个楔形、一个微型楔形、一个抛物线楔形、一个四推楔形、一个趋势或交易区间内的楔形回撤、一个楔形反转形态、另一种类型的三角形（包括扩张三角形）、一个三重顶或底、一个双重顶或底回撤、一个头肩顶或底、还是对双重顶的向下突破的失败、对双重底向上突破失败，都没有关系。在某个点处，趋势型交易者们放弃制造强突破，反转交易者们取得对市场的控制权。

> 当一条通道拥有楔形外形时，那是由紧迫感造成的（如果它拥有抛物线楔形外形，那么是由极度紧迫感造成的），常常引出高潮反转。

## P108-P109: 楔形顶的交易策略

### 原始章节
第5章 楔形和其他三推反转形态（续）

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 楔形顶 | Wedge top | 多头趋势顶部的楔形反转 |
| 低点2做空架构 | Low 2 short setup | 第二次回撤低点处的做空机会 |
| 卖出真空 | Sell vacuum | 缺少买方导致快速下跌 |
| 逆势架构 | Counter-trend setup | 与当前趋势方向相反的交易架构 |
| 顺势架构 | With-trend setup | 与当前趋势方向相同的交易架构 |
| 交易区间日 | Trading range day | 双向交易的横盘日 |
| 收缩台阶形态 | Shrinking stairs pattern | 突破幅度递减的形态 |

### 核心规则
1. 楔形反转是一个逆势架构，通常较好的做法是等待二次入场
2. 绝大多数三推形态是在过冲一条趋势通道线后反转，只此一条便可作为入场理由
3. 三推形态常常比趋势通道线过冲更容易看出
4. 这些形态很少拥有完美的外形，常常需要使用趋势线和趋势通道线才能使它们凸显出来
5. 如果形态很强，那么过冲后的反转足以作为入场理由
6. 在交易区间市场中，在突破处做逆向交易是一种很好的策略
7. 如果楔形触发一个入场但是楔形失败，市场又超越了楔形极点，那么常常会迅速形成一波测量运动

### 重要段落
> 绝大多数三推形态是在过冲一条趋势通道线后反转，只此一条便可作为入场理由，即便实际外形不是楔形。不过，三推形态常常比趋势通道线过冲更容易看出，所以值得与其他趋势通道线失败区分开来。

> 如果一个楔形触发一个入场，但是楔形失败，市场又超越了楔形极点一个或多个跳动，那么常常会迅速形成一波测量运动，测量基准是楔形高度。

## P110: 楔形反转的进阶交易规则

### 原始章节
第5章 楔形和其他三推反转形态（续）

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 收缩台阶形态 | Contraction stair pattern | 突破幅度依次变小的三推 |
| 楔形顶失败 | Failed wedge top | 楔形顶触发后趋势恢复 |
| 双重顶 | Double top | 两次测试同一高点 |
| 电子迷你 | E-mini | E-mini S&P 500期货 |
| 高点2买进架构 | High 2 buy setup | 第二次回撤高点处的买进机会 |
| 开盘反转形态 | Opening reversal pattern | 开盘后形成的反转 |
| 微型楔形 | Micro wedge | 由3-5条连续棒线构成的楔形 |
| 最终旗形 | Final flag | 趋势中最后一个旗形 |

### 核心规则
1. 当形成三推或更多推，而且突破依次变小时，那么这不仅是一个楔形，还是一个收缩台阶形态
2. 收缩台阶形态表明动能正在衰退，形成两条腿反转的几率增加
3. 如果在触发入场后突破幅度不够大，趋势恢复并超越该楔形，那么楔形顶就失败了
4. 当楔形顶成功时，第一个目标是测试楔形的底部，下一个目标是一波从那里开始的向下的测量运动
5. 当楔形顶失败时，第一个目标是一波向上的测量运动，测量基准也是楔形高度
6. 楔形是一段双向交易区，它的行为就像是交易区间，所以形成一种突破状态
7. 在电子迷你中，如果出现一个楔形顶，然后是一段简短的下跌，回撤常常精确地测试楔形顶部，形成一个完美的双重顶
8. 大部分失败的楔形顶都非常陡峭和紧凑，而且出现于强多头趋势中
9. 当交易者们过于急切地做逆势交易，没有等待明确的趋势线突破和逆势力量时，楔形几乎总是失败
10. 单单三推，特别是较小时，在先前没有趋势线突破或重要的趋势通道线过冲和反转时，很少会令趋势反转
11. 如果通道是紧凑的，即便它的外形是楔形，最好也不在反转入场
12. 楔形常常是开盘反转形态，在第一个小时内可能引起开盘反转
13. 微型楔形由三条连续棒线或四五条连续棒线中的三条构成，通常只会引起微小的调整

### 重要段落
> 当形成三推或更多推，而且突破依次变小时，那么这不仅是一个楔形，还是一个收缩台阶形态。举例说明，如果多头趋势中形成三次上推，第二次上推比第一次高出10个跳动，第三次只比第二次高出7个跳动，那么这是一个收缩台阶形态。它表明动能正在衰退，形成两条腿反转的几率增加。

> 如果在交易区间内出现一个楔形反转，那么它可能看起来更像一个楔形回撤，因为没有趋势要反转。在那种情况下，选择第一个信号通常是一种可获利的方法。

## P121-P122: 第6章 扩张三角形

### 原始章节

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 扩张三角形 | Expanding triangle | 每个波段都比前一个大的三角形 |
| 扩张三角形底 | Expanding triangle bottom | 空头趋势底部的扩张三角形反转 |
| 扩张三角形顶 | Expanding triangle top | 多头趋势顶部的扩张三角形反转 |
| 扩张三角形空头旗形 | Expanding triangle bear flag | 空头趋势中的扩张三角形延续 |
| 扩张三角形多头旗形 | Expanding triangle bull flag | 多头趋势中的扩张三角形延续 |
| 突破回撤 | Breakout pullback | 突破后的回撤入场 |
| 测量运动 | Measured move | 以形态高度为基准的等距运动 |

### 核心规则
1. 扩张三角形可能是反转形态，也可能是延续形态，至少有五个波段构成（有时是七个波段，极少情况下是九个），每个波段都比前一个大
2. 它的力量部分来自每个新突破处被套的交易者
3. 在多头反转（扩张三角形底）中，市场有足够的力量向上超越最后一个更高高点，把多头套入；然后暴跌至第三个低点
4. 初始目标是突破三角形的另一侧，市场常常在那里再次反转
5. 如果突破成功，那么反转失败，该形态成为原来趋势中的一个延续形态
6. 如果突破成功，下一个目标是一波向上的测量运动，约等于三角形中最后一条腿的高度
7. 如果突破失败，市场向下反转，那么它现在就是一个更大的扩张三角形顶，包含七条腿
8. 术语"三角形"容易引起误导，因为该形态常常看起来不像是三角形

## P127-P129: 最终旗形的交易机制

### 原始章节
第7章 最终旗形（续）

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 买进高潮 | Buying climax | 连续强多头运动 |
| 高点1/高点2买进架构 | High 1 / High 2 buy setup | 回撤高点处的买进 |
| 刮头皮交易 | Scalp trade | 短期快速获利的交易 |
| 波段交易 | Swing trade | 持有较长时间的交易 |
| 双重顶 | Double top | 两次测试同一高点 |
| 买进真空 | Buy vacuum | 缺少卖方导致快速上涨 |
| 磁力效应 | Magnetic effect | 交易区间对价格的吸引力 |
| 突破回撤 | Breakout pullback | 突破后的回撤入场 |

### 核心规则
1. 当突破形成于趋势已经行进了几十棒之后，它常常成为趋势的最终旗形
2. 如果原来的趋势持续了50到100棒，那么反转更有可能演变为一个大旗形，而不是一轮反向趋势
3. 趋势拥有极大的惯性，倾向于拒绝所有反转尝试
4. 一般每次反转都比前一次大，最后，一次反转成功，令趋势反转
5. 延长的高潮常常在短暂的最终旗形突破后结束
6. 如果足够多的交易者把突破看作连续的买进高潮，那么很多人只会在至少包含两条腿和10棒的回撤形成后再次买进
7. 最终多头旗形的突破有三种方式：
   - 突破强劲，向上超越多头趋势原有高点，然后市场在一个更高高点反转中向下反转
   - 突破可能较弱，市场可能在前一高点下方向下反转，形成一个更低高点反转
   - 可能根本没有突破多少，甚至没有向上突破
8. 如果多头旗形向下突破，那么突破通常是一个尖峰，随后是一条空头通道
9. 对于任意多头旗形，回撤型交易者都会买进，并且打算在测试趋势极点时离场

### 重要段落
> 趋势拥有极大的惯性，倾向于拒绝所有反转尝试。然而，一般每次反转都比前一次大，最后，一次反转成功，令趋势反转，进入反向趋势。

> 当突破形成于趋势已经行进了几十棒之后，它常常成为趋势的最终旗形。突破之后，顺势交易者对获利了结更感兴趣，逆势交易者将在趋势尝试恢复时逆势入场。

### 核心规则
1. 有时最终旗形突破在一个更低高点处反转，而不是在一个更高高点处反转
2. 当市场两次试图做某件事情均告失败后，它通常做反向的趋势运动
3. 连续的卖出高潮常常引起延长的调整，有时引起反转
4. 棒1中断了卖出行为，使它成为两波独立的卖出高潮

6. 激进型多头会在棒1收盘价做多，承担风险约等于棒1高度
7. 在连续卖出高潮之后，十字星信号棒是疲弱的做空信号棒，激进型交易者会在它们的低点或其下方买进
8. 多头通道是空头旗形，像所有通道一样，交易者会在前一棒低点或其下方买进

## P144-P145: 最终旗形的空头突破与尖峰高潮

### 原始章节
第7章 最终旗形 — 图7.5-7.6（续）

### 概念定义

| 中文 | 英文 | 说明 |
|------|------|------|
| 多头最终旗形 | Final bull flag | 多头趋势中的最终旗形 |
| 空头突破 | Bear breakout | 向下突破 |
| 抛物线楔形反转 | Parabolic wedge reversal | 抛物线楔形后的反转 |
| 均线缺口棒 | Moving average gap bar | 远离均线的棒线 |
| 低点1/低点2/低点3架构 | Low 1/2/3 setup | 回撤低点处的做空架构 |
| 尖峰和高潮底 | Spike and climax bottom | 尖峰+高潮型底部 |
| 买压 | Buying pressure | 多头买入的力量 |
| 卖压 | Selling pressure | 空头卖出的力量 |

### 核心规则
1. 棒12是一个多头旗形的起点，跟在从棒11低点开始的强上涨运动之后
2. 当空头旗形向上突破时，多头需要一条多头趋势棒，它的收盘至少比旗形顶部高几个跳动
3. 类似地，当多头旗形向下突破时，交易者们希望看到一条强空头趋势棒，它的收盘比旗形底部低几个跳动
4. 从棒14开始的四条连续多头趋势棒显示出买压
5. 机构不会在通道中棒线的低点下方卖出，因为那不是他们的做法
6. 多头认为棒3、9和11正在形成一个楔形多头旗形，当市场跌破棒11时，楔形失败
7. 棒15是一个低点1，聪明的交易者预期那个做空架构失败
8. 不像正在增长的空头旗形中之前的多头突破，棒19的突破拥有坚持到底

### 图表描述

  - 棒1-22标注
  - 价格范围: 1,166-1,188
  - 多头最终旗形的空头突破

### 重要段落
> 当空头旗形向上突破时，比如棒19，多头需要一条多头趋势棒，它的收盘至少比旗形顶部高几个跳动，以便让空头放弃他们之前认为那波反弹只是空头趋势中一波回撤的预期。

> 机构不会在通道中棒线的低点下方卖出，因为那不是他们的做法。如果他们卖空，那么市场会下跌，但是，由于市场正在上涨，所以他们肯定是在买进。
