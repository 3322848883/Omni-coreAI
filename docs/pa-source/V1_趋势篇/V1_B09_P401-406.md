### 章节标题

**Figure 26.1 STAIRS: BROAD CHANNEL TREND**（台阶：宽通道趋势）

**图26.1 空头台阶形态**

### 概念定义

| 中文术语 | 英文术语 | 定义 |
|---------|---------|------|
| 空头台阶形态 | Bear Stairs Pattern | 一条向下倾斜的通道，其中每个形成新低的突破之后都有一个回撤，它将向上超越突破点 |
| 宽通道趋势 | Broad Channel Trend | 价格在两条平行趋势线之间呈台阶式运行的趋势形态 |
| 逆突破交易 | Counter-Breakout Trade | 在突破方向相反的方向上入场，预期出现突破测试（突破回撤） |
| 突破测试 | Breakout Test | 价格突破后回撤测试突破点的行为 |
| 逐步加仓 | Scaling In | 在多个价位分批建立头寸的策略 |
| 趋势通道线 | Trend Channel Line | 与趋势线平行的通道另一侧边界线 |
| 趋势线 | Trend Line | 连接波段高点（空头趋势）或波段低点（多头趋势）的线 |

### 规则条件（编号列表）

1. **突破距离观察规则**: 交易者们要注意突破超越最近波段点的跳动数，然后利用那个数据在随后的突破做逆突破交易，预期出现突破测试。
2. **多头逐步加仓规则**: 如果上个波段低点比它前面的波段低点低14个跳动，那么交易者们就要准备在最近的波段低点下方10个跳动左右开始对多头头寸逐步加仓，通常是在趋势通道线附近。
3. **获利了结规则**: 如果最近的突破回撤幅度约为15个跳动，那么他们将准备在低点上方10到15点处获利了结，通常是在趋势线附近（空头通道顶部）。
4. **空头台阶回撤规则**: 跌破棒6、跌至棒9的突破腿形之后形成一波回撤，返回棒7低点上方。
5. **区间重叠规则**: 跌破棒9、跌至棒13的那条腿后的上涨跟着一个回撤，向上超越棒9突破点，与前一个区间重叠。

## 第402页（物理页码403）— Figure 26.1 空头台阶形态（下）

### 章节标题

**434 COMMON TREND PATTERNS Figure 26.1**（常见趋势形态 图26.1）

### 概念定义

| 中文术语 | 英文术语 | 定义 |
|---------|---------|------|
| 收缩台阶 | Contracting Stair / Shrinking Step | 向前一波段点延伸的幅度小于前一次延伸幅度的台阶 |
| 三次下推 | Three Pushes Down | 三次向下推动的价格运动，可能预示趋势反转 |
| 多头尖峰 | Bull Spike | 一段强势的多头上涨运动 |
| 空头尖峰 | Bear Spike | 一段强势的空头下跌运动 |
| 双棒反转 | Two-Bar Reversal | 由两根K线组成的反转形态 |
| 最终旗形 | Final Flag | 趋势末端出现的旗形整理，预示趋势即将反转 |
| 楔形空头旗形 | Wedge Bear Flag | 呈楔形形态的空头旗形整理 |
| 双重顶 | Double Top | 两个近似等高的顶部形成的看跌形态 |

### 规则条件（编号列表）

1. **经验丰富交易者规则**: 在空头趋势中，空方看到过去的上涨幅度约为4到6点，于是他们在最近的波段低点上方3到5点左右对空头头寸逐步加仓，那是在空头趋势线区域。**注意**: 这种类型的交易只适用于经验丰富的交易者。
2. **初学者约束规则**: 初学者应该约束自己停止入场，让市场继续行进（这将在第二本书中讨论）。
3. **多头限价单调整规则**: 当市场跌至棒7下方时，再次把限价买单下调3到4点。
4. **三次下推不保证反转规则**: 三次下推并不保证趋势肯定反转。需要结合其他信号（如大型多头趋势棒、高潮反转等）判断。
5. **空头趋势恢复条件**: 当多头反转不够强势（没有大型多头趋势棒、没有很强的高潮反转），市场形成楔形空头旗形和更低高点后，空头趋势恢复。

### 概率数据与具体数值

| 数据项 | 数值 | 说明 |
|-------|------|------|
| 过去上涨幅度 | 约4到6点 | 空头加仓的参考距离 |
| 空头加仓位置 | 波段低点上方3到5点 | 在空头趋势线区域 |
| 限价买单下调幅度 | 3到4点 | 跟随市场下跌调整 |
| 先前上涨幅度 | 约4点 | 用于计算获利目标 |
| 获利了结位置 | 入场点上方约3点 | 在趋势线附近 |

### 图表描述（续Figure 26.1）

**同一张图表的更深入分析**:

- 棒7是第三次下推和一个收缩台阶（它向棒5下方延伸的幅度小于棒5向棒3下方延伸的幅度）
- 通道线是最佳拟合线，强调市场正在一条通道内趋势下跌
- 存在明显的双向交易机会，当交易者们看到恰当的架构时，应该在低点买进，在高点卖出

### 案例分析：这张图表的更深入讨论

> 图26.1中，市场在从昨日开始的一条空头通道底部附近开盘，并且向下突破了那条通道。那个突破以一个双棒反转失败，引出一个四棒多头尖峰。在一个测试空头趋势线（利用那条最佳拟合趋势通道线的平行线绘制）的双重顶之后，市场形成一个截止棒13的下跌尖峰。当既有多头尖峰又有空头尖峰时，是多空双方在为了预期通道的方向而战斗。多方发起一条通道，但是它在趋势线处失败，向下反转进入一条空头通道。在测试趋势通道线后，市场向上反转，棒16并未触及趋势通道线。这是一种积极买进的征兆。棒16双棒反转也是从棒15四棒最终旗形开始的一个最终旗形多头架构。

> 三次下推并不保证趋势肯定反转。截止棒7的下跌运动只有非常少的买压。没有大型多头趋势棒，没有很强的高潮反转。从棒7开始的上涨运动也不是特别强。这不是强势反转一般的样子，因此，它并未吸引足够多的强势多头来使市场反转。相反地，市场形成一个楔形空头旗形（三推包括棒6和接下来从棒7开始的两个小型上推）和一个更低高点（虽然反弹超越棒6，所以是某种强势征兆，但它仍低于棒4），空头趋势恢复。

### 重要段落（引用）

> 利了结。在截止棒11和棒16的下跌中，他们采用相同的操作。他们尝试在截止棒13的下跌中入场，但是市场的跌幅不足以让他们的订单执行。空方的做法相反。他们看到过去的上涨幅度约为4到6点，于是他们在最近的波段低点上方3到5点左右对空头头寸逐步加仓，那是在空头趋势线区域。这种类型的交易只适用于经验丰富的交易者。初学者应该约束自己停止入场，让市场继续行进（这将在第二本书中讨论）。

> 棒7是第三次下推和一个收缩台阶（它向棒5下方延伸的幅度小于棒5向棒3下方延伸的幅度）。通道线是最佳拟合线，是为了强调市场正在一条通道内趋势下跌。存在明显的双向交易，当交易者们看到恰当的架构时，应该在低点买进，在高点卖出。

> 三次下推并不保证趋势肯定反转。截止棒7的下跌运动只有非常少的买压。没有大型多头趋势棒，没有很强的高潮反转。从棒7开始的上涨运动也不是特别强。这不是强势反转一般的样子，因此，它并未吸引足够多的强势多头来使市场反转。相反地，市场形成一个楔形空头旗形（三推包括棒6和接下来从棒7开始的两个小型上推）和一个更低高点（虽然反弹超越棒6，所以是某种强势征兆，但它仍低于棒4），空头趋势恢复。

### 概念定义

| 中文术语 | 英文术语 | 定义 |
|---------|---------|------|
| 台阶加速 | Stair Acceleration | 台阶形态突破通道后加速进入更强的趋势 |
| 测量运动 | Measured Move | 价格目标计算方法，幅度约等于通道宽度 |
| 安德鲁音叉线 | Andrew's Pitchfork | 技术分析工具，使用三条平行线（中线+上下通道线）衡量价格运动 |
| 楔形顶部 | Wedge Top | 由三个上推形成的看跌楔形形态 |
| 楔形顶部失败 | Failed Wedge Top | 楔形顶部未能引发下跌，反而向上突破 |

| 空头反转棒 | Bear Reversal Bar | 具有看跌反转信号的K线 |

### 规则条件（编号列表）

1. **台阶加速规则**: 台阶形态可能加速进入更强的趋势。当价格在通道内形成三个或更多更高高点和低点后，可能突破通道进入强趋势。
2. **突破测量运动规则**: 突破应该延伸约一波测量运动，到达上方的平行线处，幅度约等于中间一条线到底部那条线的距离（安德鲁音叉线）。
3. **楔形顶部失败规则**: 当楔形顶部失败后，一般市场会向上加速。
4. **楔形失败后测量运动规则**: 失败的楔形之后大约是近似等于楔形高度的一波测量运动（从楔形顶部高点至楔形底部低点）。
5. **重新计数规则**: 如果使用强多头上涨尖峰重新计数的话，可以把楔形后面的小型波段高点看作第三个上推。

|-------|------|------|
| 通道内更高高点数 | 3个 | 截止棒7形成三个更高高点和低点 |
| 测量运动幅度 | 约等于通道宽度 | 中间线到底部线的距离 |
| 楔形高度测量 | 棒6高点至棒3或棒1低点 | 用于计算突破后的目标 |

## 第404页（物理页码405）— Figure 26.3 收缩台阶形态

### 章节标题

**436 COMMON TREND PATTERNS Figure 26.3**（常见趋势形态 图26.3）

**图26.3 收缩台阶形态**

### 概念定义

| 中文术语 | 英文术语 | 定义 |
|---------|---------|------|
| 收缩台阶形态 | Contracting Staircase Pattern | 每个突破都小于前一个的台阶形态，代表趋势动能衰退 |
| 动能衰退 | Momentum Decline | 趋势中每次推动的幅度逐渐减小 |
| 大型空头旗形 | Large Bear Flag | 通道整体充当一个大规模的空头旗形 |
| 空头突破 | Bear Breakout | 价格向下突破通道底部 |
| 更低高点突破回撤 | Lower High Breakout Pullback | 突破后回撤形成的更低高点 |
| 双重顶空头旗形 | Double Top Bear Flag | 两个近似等高的顶部形成的空头旗形 |
| 逆势刮头皮交易 | Counter-Trend Scalp Trade | 在趋势方向相反的方向上进行的短期交易 |
| 止损单入场 | Stop Order Entry | 使用止损单在市场反转时入场的方式 |

### 规则条件（编号列表）

1. **收缩台阶动能衰退规则**: 当每个突破都小于前一个时，趋势的动能正在衰退，不久将会出现更深的回撤或反转。
2. **收缩台阶预警规则**: 棒4、6和8形成收缩台阶，代表着看涨动能的衰退，预示着反转的到来。
3. **通道=大型空头旗形规则**: 多头趋势台阶形态的通道作用就像一个大型空头旗形，空头突破发生在棒9。
4. **突破回撤规则**: 在棒9突破之后，出现一个更低高点突破回撤，至棒10结束，结果形成一轮台阶形空头趋势。
5. **空头刮头皮交易规则（下降台阶）**: 一旦市场开始形成下降的台阶形态，可以在每条收盘低于前一空头台阶的空头趋势棒收盘后做多，做刮头皮交易。
6. **多头刮头皮交易规则（上升台阶）**: 在多头台阶中，可以在超越前一台阶高点的任意一条趋势棒收盘后做空头刮头皮交易。
7. **安全入场规则**: 但总的来说，在市场反转时使用止损单入场会较为安全（举例说明，如果市场从通道底部向上反转，那么就在前一棒上方使用止损单入场）。
8. **通道刺穿规则**: 棒11向下刺穿空头通道，引起一个小型的两条腿向上反转，预计会刺穿通道顶部。

## 本节核心知识点总结

### 第26章 台阶形态（Stairs）三大变体

| 变体 | 英文 | 图表 | 核心特征 | 交易含义 |
|------|------|------|---------|---------|
| 空头台阶 | Bear Stairs | Figure 26.1 | 向下通道中每次新低后回撤超越突破点 | 在通道线附近双向交易；观察突破距离做逆突破交易 |
| 台阶加速 | Stair Acceleration | Figure 26.2 | 台阶突破通道后加速进入强趋势 | 楔形顶部失败后向上加速；测量运动目标为通道宽度 |
| 收缩台阶 | Contracting Staircase | Figure 26.3 | 每次突破幅度递减，动能衰退 | 预示反转到来；通道充当大型反向旗形 |

### 关键交易规则汇总

1. **逆突破交易**: 观察突破超越波段点的跳动数，在趋势通道线附近逐步加仓
2. **经验分级**: 通道内双向交易仅适用于经验丰富的交易者；初学者应停止入场
3. **三次下推**: 不保证反转，需结合买压力度、高潮反转等信号综合判断
4. **楔形失败**: 楔形顶部失败后市场一般向上加速，目标为楔形高度的测量运动
5. **收缩台阶**: 每个突破小于前一个时动能衰退，可做逆势刮头皮交易
6. **安全入场**: 使用止损单在市场反转时入场比限价单更安全
