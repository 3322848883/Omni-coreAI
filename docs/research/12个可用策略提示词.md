# 12 个优秀交易策略提示词（可直接复制使用）

每条都是完整提示词。使用方法：整段复制进 ChatGPT / 任意 LLM，把 `[方括号]` 里的内容换成你的参数。

---

## 1. 趋势跟随策略

```text
你是一位专业的加密货币永续合约交易策略师。

请为我制定一个趋势跟随策略，参数如下：
- 品种：[如 BTC_USDT]
- 周期：[如 4 小时]
- 资金规模：[如 1000 USDT]
- 单笔风险：权益的 [如 1%]
- 最大杠杆：[如 5 倍]

要求：
1. 用均线判断趋势方向（如 EMA20 与 EMA50）
2. 趋势向上只做多，趋势向下只做空，震荡则观望
3. 进场条件必须可量化（写清具体数值或指标状态）
4. 止损用 ATR 的倍数确定距离，写成具体价格
5. 止盈用盈亏比至少 1.5:1
6. 同时最多持有 1 个仓位
7. 信号在 K 线收盘确认，下一根 K 线开盘进场
8. 不确定就空仓，宁可错过不要做错

请输出：
- 进场规则（逐步说明）
- 离场规则（止损/止盈/移动止损）
- 仓位计算公式
- 一条完整的示例信号（JSON）
```

## 2. 均值回归策略

```text
你是一位量化交易专家，擅长震荡行情的均值回归策略。

制定一个均值回归策略：
- 品种：[如 ETH_USDT]
- 周期：[如 1 小时]
- 适用行情：明确震荡、无单边趋势
- 单笔风险：[如 1%]

要求：
1. 用布林带 + RSI 判断超买超卖
2. 价格触及布林下轨且 RSI < 30 → 做多
3. 价格触及布林上轨且 RSI > 70 → 做空
4. 回到中轨或反向信号出场
5. 严格止损：若价格突破布林带后继续走，立即止损
6. 行情变成单边趋势时停止使用本策略（给出识别趋势的方法）
7. 一次只开一仓，不加仓摊平

请输出完整的交易规则表，以及一条多单和一条空单的示例信号。
```

## 3. 突破追单策略

```text
你是突破交易专家。

制定一个突破进场策略：
- 品种：[如 SOL_USDT]
- 周期：[如 15 分钟]
- 突破定义：[如突破 N 根 K 线最高点/最低点]
- 成交量确认：成交量放大 [如 1.5 倍] 于均量

要求：
1. 价格突破近期高点 + 成交量放大 → 突破做多
2. 价格跌破近期低点 + 成交量放大 → 突破做空
3. 这是追单，用条件单（stop entry），不是市价追
4. 止损放在突破位内侧或 ATR 距离
5. 假突破过滤：突破后收回区间 → 不追或平仓
6. 同方向不追第二刀，除非回踩确认

请输出：
- 突破判定规则（多少根 K 线、点位）
- 条件单触发价与方向
- 止损止盈规则
- 失败模式及处理
```

## 4. 网格交易策略

```text

制定一个网格策略：
- 品种：[如 BTC_USDT]
- 价格区间：[如 60000 ~ 70000 USDT]
- 网格档数：[如 10 档]
- 每档仓位：[如 100 USDT]
- 适用行情：横盘震荡

要求：
1. 区间内均分挂买单和卖单
2. 低吸高抛，每档小止盈
3. 必须有整体止损（跌破区间下沿离场）
4. 区间突破后如何处理（转趋势策略或停网格）要写清
5. 说明资金占用与最大回撤估算

请输出网格档位表（价格、方向、数量）和风控规则。
```

## 5. 剥头皮（短线）策略

```text
你是职业剥头皮交易员。

制定一个短线剥头皮策略：
- 品种：[如 BTC_USDT]
- 周期：[如 5 分钟]
- 每笔目标：[如 0.1%~0.3%]
- 单笔风险：[如 0.5%]
- 交易时段：[如伦敦/纽约盘]

要求：
1. 只在高流动性时段交易
2. 进场：价格回调到 EMA9 或 EMA20 附近 + 微观结构确认
3. 止损非常紧（ATR 的 1~1.5 倍）
4. 盈亏比至少 1:1，到价就走，不贪
5. 连续亏损 3 次停止交易 1 小时
6. 避开重要数据发布时段

请输出完整的进出场清单和一条示例交易日志格式。
```

## 6. 动量策略

```text
你是动量交易专家。

制定一个动量策略：
- 品种：[如 ETH_USDT]
- 周期：[如 4 小时]
- 动量确认指标：MACD、RSI、成交量

要求：
1. MACD 金叉 + RSI 从 50 下方向上突破 + 放量 → 做多
2. MACD 死叉 + RSI 从 50 上方向下突破 + 放量 → 做空
3. 指标共振才进场，单一指标不进场
4. 动量减弱（柱状图缩短）→ 减仓或止盈
5. 反向信号 → 全平

请输出指标参数、共振条件表、以及一条多单示例信号（JSON）。
```

制定一个双均线交叉策略：
- 品种：[如 BTC_USDT]
- 周期：[如 1 小时]

要求：

## 8. 多指标共振策略

```text
你是多指标共振交易策略师。

制定一个多指标确认策略：
- 品种：[如 SOL_USDT]
- 周期：[如 1 小时]
- 指标组合：RSI + MACD + 布林带 + 成交量

要求：
1. 至少 3 个指标同时看多才能开多
2. 至少 3 个指标同时看空才能开空
3. 写出每个指标的看多/看空条件
4. 任何指标冲突 → 不进场
5. 止损必须包含，止盈按盈亏比
6. 仓位：高共振（4/4）可以标准仓，低共振（3/4）减半

请输出指标条件对照表和开仓检查清单。
```

## 9. 资金费率套利策略

```text
你是资金费率套利专家。

制定一个永续合约资金费率策略：
- 品种：[如 BTC_USDT]
- 关注：资金费率高低

要求：
1. 资金费率过高（如 >0.1%）→ 现货买入 + 永续开空对冲，吃费率
2. 资金费率过低或为负 → 反向操作
3. 说明对冲比例如何计算
4. 何时平仓（费率回归正常、价差变化）
5. 说明风险：单腿未成交、费率突然反转、交易所风险

请输出操作步骤与风险清单。
```

## 10. 风控经理提示（交易前审查）

```text
你是一名严格的投资风控经理。在每笔交易执行前，必须完成以下审查。

交易计划如下：
- 方向：[多 / 空]
- 品种：[如 BTC_USDT]
- 入场价：[价格]
- 止损价：[价格]
- 止盈价：[价格]
- 仓位大小：[数量或金额]
- 杠杆：[如 5 倍]
- 我的交易逻辑：[一句话]

请从以下 5 个方面审查，并给出「批准 / 否决 / 修改后执行」：

1. **逻辑风险**：我的交易逻辑有什么漏洞？反面观点是什么？
2. **仓位风险**：仓位相对于账户是否过大？按 ATR 衡量是否合理？
3. **时机风险**：现在进场是否追高杀跌？有没有更好的等回踩点位？
4. **情景推演**：最好 / 一般 / 最差 / 黑天鹅 四种情况结果如何？
5. **风险缓解**：止损是否合理？要不要分批？加仓减仓退出规则是什么？

最后用一句话结论：是否建议执行这笔交易。
```

## 11. 仓位管理与资金管理

```text
你是一位资金管理专家。

请为我的交易设计仓位管理规则，账户情况如下：
- 账户总资金：[如 10000 USDT]
- 风险偏好：[保守 / 平衡 / 激进]
- 主要交易：[合约 / 现货]
- 最大可接受回撤：[如 20%]

要求：
1. 单笔最大风险百分比（按风险偏好给出）
2. 仓位计算公式（不是拍脑袋）
3. 连亏时如何降仓（具体规则）
4. 连赢时如何适度加仓（不要加太猛）
5. 最大同时持仓数量
6. 单品种最大暴露
7. 整体回撤达到多少必须停止交易

请输出一份完整的资金管理规则表。
```

## 12. 交易纪律与复盘助手

```text
你是我的交易教练，负责交易纪律和复盘。

我的交易日志：
[粘贴你的交易记录]

请帮我：
1. 统计胜率、盈亏比、最大连亏、最大回撤
2. 找出我的交易问题（是否扛单、是否频繁交易、是否不带止损等）
3. 对比我的交易计划，哪些交易违反了规则
4. 给出 3 条可执行的改进建议
5. 用表格列出每笔交易的评估

说话直接，不要客套，只要能帮我省钱和提升胜率的话。
```
